# 企画: ロール

**2026-09-04 記録。** **構想の段階。** 実装されているのは**弓 1 本だけ**で、
下の 6 つはまだ 1 つも分かれていない。

> ### **ゲームの中では「エンチャント」と呼ぶ**（2026-09-05）
>
> **仕組みの名前は「モーション強化」のまま。**
> **人に見せる字だけ「エンチャント」**——出す 3 つが、そういうものに見えるため。
> **v1 の「札（エンチャント）」とは別**（あちらは装備に挿す形。やめた）。

## 1. 形

```
武器種（弓・剣・…）
   └─ ロール（その武器種の中での役割）
        └─ モーション強化（左クリックの中身を伸ばす）
```

| | |
| --- | --- |
| **いまある武器種** | **弓だけ** |
| **これから増やす** | **剣**、その他 |
| **弓のロール** | **6 つを構想**（2 章） |

> ### 「ロール」と「武器種」の間には何も無い
>
> **職業のような中間の層は作らない。** 武器種の下がそのままロール。

## 2. 弓のロール（構想 6 つ）

**左クリック（特殊攻撃）が、ロールの正体。**

| # | ロール | 左クリック | 性格 |
| --- | --- | --- | --- |
| 1 | **通常のみ** | **無し** | **通常攻撃の火力が ×2** |
| 2 | **連射・技** | **連射** | **外さないと火力が上がる** |
| 3 | **連射・剛** | **連射** | **外してよい。散りが大きめの連射** |
| 4 | **爆発** | **爆発矢** | 着弾で範囲 |
| 5 | **トラッパー** | **着弾地点に罠を置く** | 置いて誘い込む |
| 6 | **サポート** | **回復** | 味方を支える |

**通常攻撃（右クリック）は 6 つとも同じ弓**——違うのは左クリックと、その伸ばし方。

## 2-1. 選び方（2026-09-05）

**ロビーに立てた村人から選ぶ。**

| | |
| --- | --- |
| **村人** | `pve_v3:vendor`（`sells` ＝ `role`）。**見た目は仮** |
| **呼び方** | **`/pve:jobmaster`**——**いま立っている所に呼ぶ** |
| **盤面** | **チェストの見た目・27 枠（縦 3 × 横 9）**。持ち物欄は出さない |
| **確認** | `/pve:role` |

> ### 呼ぶ場所は決め打ちにしない
>
> **ロビーは手で建てたもの**なので、こちらは中の配置を知らない。
> **立ってほしい所で打つ。**

> ### いま選べるのは 1 つだけ
>
> **左クリック（特殊攻撃）の仕組みがまだ無い。**
> **左クリックを使わない「通常のみ」だけを選べる**——
> 残り 5 つは盤面に並ぶが、押すと「まだ作っていない」と断る。

**「通常のみ」を選ぶと、通常攻撃の威力が ×2 になる**（`services/attack.ts`）。

## 3. モーション強化は、ロールごとに違う

**休憩所の 3 択で拾うもの**（[00-concept.md](00-concept.md) 4 章）。
**左クリックの挙動を変える。**

> ### 中身は、**まだ 1 つも決まっていない**
>
> **ロールごとに別々に決める。** 「トラッパーなら範囲を伸ばす／鈍化を足す」
> といった方向性はあるが、**確定した項目は無い。**
>
> **勝手に決めて実装しない。**
