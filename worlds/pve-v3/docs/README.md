## v2 から持ってきたもの

**5 つだけ。**

| | |
| --- | --- |
| **ダメージ** | 1 本道の `hit()`・手応え・ダメージの数字 |
| **弓** | 右クリック連射・自前の弾 |
| **確認用のモブ** | ゾンビ 1 種・味方の的 |
| **ネザーゲート（飾り）** | 通れないブロックと、通さない係 |
| **HP 表示** | 名札・アクションバー |

**捨てたもの:** エンチャント・属性・状態異常・鈍化・シールド・領域・
地形生成・シート・きらめき。

**仕様を引き継いだもの:** **敵の「呪い」と数・HP・丸め**（[spec/16-enemy.md](spec/16-enemy.md) 1 章）。
**数値は引き継いでいない。**

> ### 何を作るかが決まる前に、仕組みだけ残した
>
> **v2 は「札で組み立てるビルド」を前提に作りすぎた。**
> **どんな遊びになっても要るもの**——**当たる・削る・見える**——だけを残し、
> **その上に何を載せるかは、企画から決め直した。**
