>
> **敵の作り方を決め直した**（[../07-enemy-plan.md](../07-enemy-plan.md)）。
> **ここに書いたものは、いったん全部見送り。**
> **捨てるのではなく、種として残しておく**——**後で引っ張り出すことがある。**

**2026-09-08。** **50 種類ほど作るための、たたき台。**
**ここから採る／捨てるを決めて、採ったものだけ [spec/23-enemy-unit.md](spec/23-enemy-unit.md) の発注票に落とす。**

> ### ここはまだ企画。**決定ではない**
>

> **★は「だいたいこのへん」の目安。** 実際の値は発注のときに決める。

## 守っている前提

| | |
| --- | --- |
| **見た目はバニラから借りる** | **模型・絵は持ち込まない。** 色や大きさで差を付ける |
| **動きはビヘイビアで書く** | **script は「バニラに無いこと」だけ**（[spec/24-mob-howto.md](spec/24-mob-howto.md)） |
| **固有値は 5 つ** | HP ／ 力 ／ 移動速度 ／ 攻撃速度 ／ エメラルド倍率 |
| **浮かせない** | ノックバックは水平だけ（[spec/22-feedback.md](spec/22-feedback.md) 6-2）。**例外を作るなら相談** |

**手間**の読み方:

| | |
| --- | --- |
| **軽** | **ビヘイビアの JSON だけ。** ひな形（`tools/pve3-newmob.mjs`）で起こして値を書けば終わり |
| **中** | **いまある script の組み替え**（弾・呪い・当たり判定の使い回し） |
| **重** | **新しい仕組みが要る。** 作る前にドキュメントを書く |

## 採るときの目安

**50 に絞るときは、この配分を勧める。**

| 区分 | 目安 | なぜ |
| --- | --- | --- |
| **軽（ビヘイビアだけ）** | **25 種ほど** | **数が要る。** 戦場を埋めるのはここ |
| **中（組み替え）** | **20 種ほど** | **味が出る。** 1 つの仕組みで何種類も作れる |
| **重（新しい仕組み）** | **5 種ほど** | **1 つ作るのに時間がかかる。** 目玉になるものだけ |

> ### **同じ仕組みを使い回すほど得**
>
> **「鈍足を付ける」を 1 つ作れば、14・27・53 が同時にできる。**
> **「爆発する」を 1 つ作れば、71〜76 が全部できる。**
> **重いものを選ぶときは、「これで何種類できるか」で選ぶ。**

**先に決めてほしいこと**:

1. **どの区分から手を付けるか**（軽を並べて数を揃えるか、重を 1 つ作って幅を出すか）
2. **入れない方針のもの**——**視界を塞ぐ系**（41・55・62・70）と**行動を奪う系**（54・58・60）は、
   **面白さより先にストレスになりやすい。** 採るなら 1〜2 種に絞りたい
3. **浮かせる例外**（29）と**壁抜け**（78）を認めるかどうか
