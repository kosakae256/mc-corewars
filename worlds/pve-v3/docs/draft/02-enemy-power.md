## 0. 前提

### 0-1. **ほとんどの敵は「近づいてぶん殴る」だけ**

**それでいい。** 違いは、この 4 つのどれかで付く。

| | 例 |
| --- | --- |
| **ステータスの偏り** | 力が強い／足が速い／硬い／手数が多い |
| **攻撃に何か付く** | 毒／鈍足／一瞬のフリーズ |
| **倒したときに何か起きる** | 分裂／爆発／仲間が強くなる／**こちらに恩恵** |
| **殴られたときに何か起きる** | 速くなる／仲間を呼ぶ／**豹変する** |

**ひな形（`tools/pve3-newmob.mjs`）から起こして、値を書けば終わる。**
**新しい仕組みが要るのは全体の 2 割まで。**

### 0-2. **名前を見ただけで分かること**

> ### **説明を読まないと分からない敵は、作らない**
>
> **パワーピグリン**は力が強い。**スピードグモ**は速い。**毒バチ**は毒。
> **名前が仕様書**になっているのがいちばん親切。

### 0-3. **見た目は散らす**

> ### **ゾンビばかりにしない**
>
> **バニラにはモブが大量に居る。** **借りられるものは借りる。**
> **足りなければ、人型の模型に自前の絵を貼って別のモブにする。**

**見た目を増やす手は 4 つ**——**どれも軽い。**

| | |
| --- | --- |
| **別のバニラモブを借りる** | いちばん安い。**模型も絵もアニメもある** |
| **自前の絵を貼る** | **人型の模型はそのまま、絵だけ描く**（絵は自分で作る。**持ち込まない**） |
| **大きさを変える** | `minecraft:scale`。**同じ模型で「大」「小」を作る** |
| **持ち物を変える** | 手に持たせる（[spec/24-mob-howto.md](spec/24-mob-howto.md) 10-3） |

### 0-4. 攻撃手段は、基本この 3 つ

| | |
| --- | --- |
| **殴る** | 近づいて叩く |
| **撃つ** | 弾を飛ばす。**弾速と射程を必ず持つ** |
| **時間差で爆発** | 近づいて溜めて爆発 |

**「切り替える」敵は全体の 1 割強。** あっても「遠ければ撃つ、近ければ殴る」程度。

### 0-5. **★が上がっても、素の性能はあまり上がらない**

**★1 と ★5 の差は、力で 2 倍もない。**
**差を開けすぎると、3 択（[spec/20-portal.md](spec/20-portal.md)）が「選択」でなくなる。**

**★6 だけは、この原則の外**（9 章）。**いまは深く考えなくてよい。**

## 1. 値の読み方

| 固有値 | 単位 |
| --- | --- |
| **HP** | そのままの数値 |
| **力** | 攻撃 1 発の元 |
| **速度** | **1.0 ＝ プレイヤーの歩き。** バニラのゾンビは 0.8 |
| **攻撃速度** | **大きいほど速い。** 1.0 ＝ 1 秒に 1 回 |
| **弾速／射程** | マス／秒 ／ マス |

### 1-1. プレイヤー側の基準（[spec/15-growth.md](spec/15-growth.md)）

| | 初期 | 上限 |
| --- | --- | --- |
| **HP** | **100** | **2,100** |
| **弓 1 発** | **20** | **100**（クリティカルで ×2） |
| **攻撃速度** | ×1.0 | ×3.0 |
| **足の速さ** | ×1.0 | ×2.0 |

| 目安 | |
| --- | --- |
| **力 20 の敵** | 初期のプレイヤーを **5 発**で殺す |
| **HP 40 の敵** | 初期の弓 **2 発**で落ちる |

> ### **速度 1.3 を超えさせない**
>
> **走っても振り切れない敵は、逃げるという選択肢を消す。** 超えるのは ★6 だけ。

### 1-2. ウェーブで伸びるのは HP だけ

```
HP ＝ 固有値 × 1.1^(wave−1) × 呪い × 丸め係数
力 ＝ 固有値 × 人数倍率 × 呪い
```

**wave 30 で HP は ×15.9。** **強さの伸びはここが担う。** **★は同じウェーブでの選択肢。**

**名前の頭に付けて、性質を伝える。** **ステータスの振り方もここで決まる。**

| 接頭辞 | 意味 | HP | 力 | 速 | 攻速 |
| --- | --- | --- | --- | --- | --- |
| **（無し）** | 素直 | ×1 | ×1 | ×1 | ×1 |
| **パワー** | **力が強い** | ×0.7 | **×2** | ×0.85 | ×0.35 |
| **スピード** | **足が速い** | ×0.85 | ×0.8 | **×1.3** | ×1 |
| **タフ** | **硬い** | **×2.2** | ×1.2 | ×0.7 | ×0.7 |
| **ラッシュ** | **手数だけ** | ×0.8 | **×0.2** | ×1.3 | **×2.5** |
| **ガラス** | **柔らかいが痛い** | **×0.45** | ×1.5 | ×1.1 | ×1.1 |
| **毒** | **当たると毒** | ×1 | ×1 | ×1 | ×1 |
| **氷** | **当たると鈍足** | ×1 | ×1 | ×1 | ×1 |
| **帯電** | **当たると 0.3 秒フリーズ** | ×1 | ×1 | ×1 | ×1 |
| **爆** | **突っ込んで爆発** | ×0.6 | ×2 | ×1.05 | — |
| **恵み** | **倒すとこちらに恩恵** | ×1.2 | ×1.1 | ×1 | ×1 |

> ### **パワーは「力 ×2」まで**
>
> **一撃で殺す敵は作らない。** 攻撃速度を落として、**当たらなければ怖くない**形にする。

> ### **ラッシュの「力 4」**
>
> **★1 で 力 4、★5 でも 力 8。** 1 発では何も起きない。
> **止まって殴り合うと削られる。** **無敵時間を潰してある**ので全部当たる。

## 3-1. **押す強さ**（ノックバック）

**これも性能のひとつ。** **全部の敵に入れる**（[spec/22-feedback.md](spec/22-feedback.md) 6-1）。

> ### **殴られて位置が崩れるかどうかは、体格で決まる**
>
> **バニラでラヴェジャーに殴られると大きく飛ぶ。** **虫に噛まれても動かない。**
> **見た目の重さと、押される量を合わせる。**

| 手合い | 押す強さ | 例 |
| --- | --- | --- |
| **虫・小動物** | **0.15〜0.3** | ラッシュ虫 0.15 ／ 蟲の群れ 0.2 ／ 洞窟グモ 0.3 |
| **軽い人型** | **0.7〜0.9** | 狂戦士 0.7 ／ 盗賊 0.8 ／ ゾンビ 0.9 |
| **並の人型** | **1.0** | 黒骨剣士 ／ 斧将 ／ 衛兵 |
| **重装** | **1.1〜1.4** | タフハスク 1.1 ／ タフ石人形 1.2 ／ 鉄面 1.3 ／ 重装ブルート 1.4 |
| **一撃型** | **1.5〜1.6** | パワーピグリン 1.5 ／ パワー斧将 1.6 ／ 処刑ゴーレム 1.6 |
| **巨体** | **1.8〜2.2** | 突進ラヴェジャー 1.8 ／ 城壁ゴーレム 2.0 ／ **ラヴェジャー王 2.2** |
| **突き飛ばし専門** | **2.0** | 突きヤギ（ダメージは低い） |
| **矢** | **0.4** | スケルトン（弾は軽い） |

**基準は 0.9**（書かなければこれ）。**1 体ずつの値は 8 章の表の「押」の列。**
**実装済みのものは `scripts/core/roster.ts` の実値**、**未実装のものは案。**

## 3-2. **エメラルド倍率**

> ### **★は「群れの目安」でしかない**
>
> **★2 の敵をたくさん並べて ★3 の群れにする**こともある。
> **だから倍率は ★ に付けるのではなく、その 1 体に付ける。**
> **「こいつ強いな」と感じる個体は、同じ ★ の中でも高くていい。**

**倒す手間と危険度から出す。**

```
手強さ ＝ 0.50 × (HP ÷ ★基準)
       ＋ 0.22 × (力 × 攻撃速度 ÷ ★基準)      … 削られ続ける怖さ
       ＋ 0.18 × (力 ÷ ★基準)                  … 一発の怖さ
       ＋ 0.10 × (速度 ÷ ★基準)                … 逃げられない怖さ

倍率 ＝ ★の基準 × 手強さ^0.85 × 特例
```

| ★ | 基準の倍率 |
| --- | --- |
| **★1** | **1.0** |
| **★2** | 1.6 |
| **★3** | 2.3 |
| **★4** | 3.1 |
| **★5** | **3.8**（**上限 4.0**） |

**下限 0.6。** **★1 でも硬ければ 1.5、柔らかければ 0.7 になる**——**同じ ★ でも揃わない。**

**特例**:

| | |
| --- | --- |
| **分裂する親** | **×0.45。** **払うのは子を倒したとき**（下） |
| **杭のような的** | ×0.5。**倒す価値が薄い** |
| **支援・一点もの**（治癒師・呼び手・貢ぎ・収穫…） | **×1.25。** **先に潰す価値を作る** |
| **恵み・祝福**（別の恩恵がある） | ×1.1 |

### 3-2-1. **分裂する敵は、子で払う**

> ### **親で払うと、割る前に倒したほうが得になる**
>
> **それでは分裂の意味が無い。**
> **親は薄く（×0.45）、子に本来の分を持たせる。**
> **全部倒せば、普通の敵 1 体ぶんより少し多い。**

**大量に出る敵**（虫の群れなど）は、**HP が低いので式が自然に下げる。**
**数が多いぶん 1 体あたりは安い**——**総量で釣り合う。**

**★6 の倍率は規格外**（10 倍など）**だが、まだ開けないので決めない。**

## 5. **家畜枠**——**殴るまで無害**

> ### **殴らなければ、何もしてこない**
>
> **ブタやウシが最初から襲ってくるのは、雰囲気に合わない。**
> **殴った瞬間に豹変する。** **こちらが選べる爆弾。**

| | |
| --- | --- |
| **普通のとき** | **プレイヤーを狙わない。** うろうろしている |
| **殴られたら** | **殴った相手だけを追う。** **速度と攻撃速度が跳ね上がる**（×1.4） |
| **戻るか** | **戻らない。** 一度怒ったら最後まで |

**実装は軽い**——**`nearest_attackable_target` を外して、`hurt_by_target` だけ残す。**
**豹変は、部品の差し替え（component group）で足す。**

**ウェーブを終えるには全部倒す必要がある**ので、**「いつ起こすか」を選ぶ敵**になる。

## 6. 味付けと、独自の仕組み

### 6-1. 味付け（一覧から選ぶ）

| 味付け | 中身 |
| --- | --- |
| **分裂** | **倒すと、決まった相手が決まった数だけ出る**（6-3。**乱数なし**） |
| **死に際の爆発** | 倒すとその場で爆発（**予告が出せないので威力半分**） |
| **遺す** | 倒すと、近くの仲間 1 体が 1 段強くなる |
| **数で奮う** | 仲間が減るほど速くなる（上限 ×1.3） |
| **手負い** | HP 半分で攻撃速度が上がる（×1.3） |
| **持ち替え** | 近づかれたら、撃つのをやめて殴る |
| **踏ん張り** | 押されない |
| **硬い皮** | 小さいダメージが通りにくい |
| **呼ぶ** | 殴られるたびに雑魚を 1 体 |
| **豹変** | **殴られるまで無害**（5 章） |

### 6-3. **分裂の決まり**（2026-09-08 決定）

> ### **数は固定。乱数を使わない**
>
> **「2〜4 体」のような幅を持たせない。** **振れ幅が大きすぎて、群れの重さが読めなくなる。**
> **1 体倒したら、必ず同じ数だけ出る。**

| | |
| --- | --- |
| **割れる数** | **必ず 2 体** |
| **段数** | **1 段だけ。** **子は割れない** |
| **1 体から出る総数** | **親 1 ＋ 子 2 ＝ 3 体**（それ以上は増えない） |
| **出る場所** | **親が倒れた所。** 左右に少し離して置く |
| **子の中身** | **別の敵として登録してあるもの**（★1 つ下） |

**書き方**——**親に「何が何体出るか」を持たせる。**

```
分裂スライム（★2） → 小スライム ×2
大マグマキューブ（★3） → マグマキューブ ×2
```

**子は必ず「分裂しない敵」にする。** **子がまた割れると、数が読めなくなる。**

#### エメラルドは、**子で払う**

| | 倍率 |
| --- | --- |
| **親**（分裂スライム） | **0.7**（**普通の ★2 は 1.6**——**薄い**） |
| **子**（小スライム ×2） | **0.7 ずつ** |
| **合計** | **2.1**（★2 を 1 体倒すより少し多い。**3 体倒す手間のぶん**） |

**親だけ倒して逃げても、ほとんど貰えない。** **割ったあとを片づけて、はじめて見合う。**

#### ウェーブの数え方

**子も「その戦場の敵」として数える。** **全部倒すまでウェーブは終わらない。**
**湧かせる数の上限**（`min(100, 40 + 10 × wave)`）**は、湧かせる時だけの話**——
**割れて増えるぶんは、そこに含めない。**

> ### **上限ぎりぎりで分裂させない**
>
> **100 体の群れが全部割れると 300 体になる。**
> **分裂する敵は、群れの中では「添え」までにする。**

### 6-2. **マイクラに無い仕組み**（独自枠・全体の 2 割まで）

**「倒す価値がある強敵」を作るための枠。**

| 名前 | 中身 | なぜ面白いか |
| --- | --- | --- |
| **恵み** | **倒すと光を落とす。拾うと 10 秒 攻撃力 ×1.5** | **強いが、倒せば得** |
| **祝福** | **倒すと、その場の全員が 20 秒 攻撃速度 ×1.5** | **みんなで殴る理由** |
| **貢ぎ** | **生きている間、エメラルドが 2 倍。倒すと止まる** | **わざと残す**選択 |
| **収穫** | **落ちたエメラルドを吸う。倒すと全部吐く** | 追う理由 |
| **呼び手** | **殴られるたびに雑魚を 1 体呼ぶ** | 一気に倒す判断 |
| **鎖** | **2 体 1 組。相方が生きている間ダメージ半減** | どちらから倒すか |
| **身代わり** | **倒すと、いちばん近い仲間が全快する** | 倒す順番が全て |
| **時限** | **60 秒で自分から消える。報酬も消える** | 急ぐか、無視するか |

## 7. 決まりごと

### 7-1. 爆発を理不尽にしない 5 条件

| | |
| --- | --- |
| **1. 予告する** | 膨らむ・光る・音。**最低 1.0 秒** |
| **2. 逃げ切れる** | **予告の間に歩いて出られる**（半径 ≦ 4 マス） |
| **3. ブロックを壊さない** | 地形が変わるとマップの読みが崩れる |
| **4. 上に飛ばさない** | 落下と重なると理不尽 |
| **5. 割合で決めない** | **固定値。** 育てた人ほど有利にする |

### 7-2. 撃つ敵の決まり

| | |
| --- | --- |
| **弾速を必ず持つ** | 見てから避けられるのが前提 |
| **射程は 30 マスまで** | |
| **壁越しに撃たない** | 視線が通ったときだけ |
| **弾速の目安** | 大玉 6〜10 ／ 普通の矢 9〜15 ／ 削り 20〜25 |

### 7-3. 数を絞るもの

| | 上限 |
| --- | --- |
| **帯電**（0.3 秒フリーズ） | **3 種**まで |
| **視界を塞ぐ** | **1 種**まで |
| **動きを奪う**（1.5 秒） | **1 種**まで |
| **こちらの強化を下げる** | **1 種**まで。★5 以上 |

## 8. 一覧（★1〜★5）

| 印 | 意味 |
| --- | --- |
