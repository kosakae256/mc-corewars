# スティーブのアニメーションをユーザーが作成する（2026-09-10）

ユーザー依頼: 参考画像の構えを作成後、校正した描画ツールを基に、
ユーザー自身でアニメーションを調整できるツールを作る。
追加依頼: 散弾に限定せず、スティーブのモデルで他の用途のアニメーションも作れること。

## 操作

- `python tools/pve3-rig-editor.py` でローカルのブラウザー画面を開く。
- 起動時に現在のパックの構えを読み込む。頭・胴・左右の腕と脚・持ち物・衣服など、
  スティーブの模型に存在するすべての骨の位置・回転・拡大率を調整できる。肘は追加しない。
- 複数の名前付きアニメーションを作成・複製・削除・切り替えできる。
  時間軸にキーフレームを追加・削除し、長さ・ループを設定する。
  再生・一時停止・スクラブに対応する。補間は linear / step / catmullrom を扱う。
- 銃の表示を切り替えられる。スティーブと銃は別のアニメーションとして同時プレビューできる。
- 画像をドラッグして見る方向を変え、ホイールで拡大縮小する。
  正面・左右・斜め・上からのプリセットも使える。
- 値を変えるたび、Python の `rig_preview` で未保存の定義を描画する。
  ブラウザー側に別の模型・回転・binding の計算を実装しない。
- 戻す・やり直す・保存した状態へ戻す操作を用意する。
- 「散弾に保存」で選択した体と銃のアニメを、散弾用の2ファイルの対象クリップへ書き換える。
  他のクリップ・模型・テクスチャは保存対象外。保存前に元のファイルを
  `out/shotgun-rig/editor-backups/` へ残す。外部で変更されていたら上書きせずエラーにする。
- 「ゲームへ配置」は保存後に `npm.cmd run check` と `npm.cmd run local-deploy` を実行する。
  進捗・失敗を画面に表示する。ゲームの再入場はユーザーが行う。
- Bedrock アニメーション JSON の読み込み・書き出しと、編集用プロジェクトの保存・読み込みに対応する。
  他の敵へ使う場合は書き出した JSON を利用できる。閉じる前に未保存の変更がある場合はブラウザーが確認する。

## 制約

ゲーム全体の Molang・状態機械・被弾処理・照明は再現範囲外。
数値および `数値 - this` のキーフレームを編集し、元の加算／上書きの意味を保つ。
外部 JSON に未対応の式が含まれる場合はエラーを表示し、ゼロなどに置換しない。
プレビュー時はファイルを書き換えない。保存先は固定し、任意パスを受け付けない。
サーバーは 127.0.0.1 に限定し、変更操作は画面に渡すセッショントークンを検証する。
生成スクリプトは、編集済みのアニメを通常の再生成で上書きしない。

## 起動と基本操作

`tools/open-rig-editor.cmd` をダブルクリックするか、リポジトリで次を実行する。

```powershell
python tools/pve3-rig-editor.py
```

画面は `http://127.0.0.1:8766`。すでに起動中なら同じ画面を開く。
起動したターミナルを終了するとサーバーも停止する。

1. 「新規」で `animation.custom.walk` などの名前を付ける。銃のないスティーブから始まる。
2. 左の一覧から骨を選ぶ。17本すべてを編集できる。衣服の骨は対応する腕・脚などに追従する。
3. 0秒の値を設定し、時刻を移動して別の値を入れる。値の変更で自動的にキーができる。
   「この時刻にキーを置く」で同じ値のキーも追加できる。
4. 再生で動きを確認する。Spaceで再生／停止、Ctrl+Zで戻す、Ctrl+Shift+Zでやり直す。
5. 他で使うときは「アニメJSONを書き出す」。編集状態ごと残すときは「プロジェクト保存」。
   「読み込む」からどちらも読み戻せる。

「散弾に保存」は体と銃の選択中の2クリップを、既存の散弾用クリップへ適用する。
任意のアニメ名で作ったものも対象になるので、他の敵用の作業ではJSONを書き出す。
「保存してゲームへ配置」は検査が成功してから配置し、RPの版も通常の配置処理で更新する。
最後にMinecraftのワールドへ入り直して表示を確認する。

`pve3-gunrig.py` は既存のアニメを通常は維持する。初期の構えへ戻す場合だけ
`python tools/pve3-gunrig.py --reset-pose` を使う。

## 検証記録

- Python 10テスト: 階層変換、this、奥行き、透過、時間補間、保存時の他クリップ保持、競合検出。
- JavaScript 3テスト: キー間の配列共有による書き換えの防止、0秒の初期値、stepのpre/post出力。
- 実ブラウザー: 初期描画、新規クリップ、脚の2キー、0.5秒の補間と画像の変化、
  JSON書き出し／読み戻し、パックから読み直しを確認。実パックを変更せず検証した。
- 画面の記録: `out/shotgun-rig/editor-screen.png`。
