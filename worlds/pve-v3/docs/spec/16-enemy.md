**1 体をどう作るかは [23-enemy-unit.md](23-enemy-unit.md)。**

> ### 数値はほぼ**仮**（2026-09-04）
>
> **仕組みは決まった。数字は当てただけ。**
> **仮の数字には「（仮）」を付けてある**——**遊んでから直す。**

## 1. 形

```
出す種類と数 ＝ 敵グループ（★）
1 体の値     ＝ 固有値 × 人数倍率 × ウェーブ倍率 × 呪い倍率 × 丸め係数
```

| 項 | 何で決まるか |
| --- | --- |
| **固有値** | **敵の種類**（ゾンビ・スケルトン…）。ステータスごとに持つ |
| **人数倍率** | **参加人数だけ**で決まる |
| **ウェーブ倍率** | **ウェーブの進み**だけ（**HP だけが持つ**） |
| **呪い倍率** | **ウェーブを越えるたびに積まれるランダム強化**（4 章） |
| **丸め係数** | **HP にだけ掛かる**（3-2。出せなかった数を HP に詰め替える） |

### 1-2. **倍率の重ね方**（2026-09-07 決定）

| ステータス | 重ね方 |
| --- | --- |
| **力・攻撃速度** | **加算。** `1 ＋ Σ(それぞれの倍率 − 1)` |
| **移動速度** | **呪いだけ。** **人数では速くならない** |
| **HP** | **掛け算のまま。** ウェーブ倍率と呪いは**二重に伸びるのが狙い** |

> ### **速さが上がるのが、いちばん脅威**（2026-09-07 決定）
>
> **人数が増えても、逃げ切れなくなってはいけない。**
> **移動速度を上げるのは呪いだけ。**

> ### 掛け算にしない
>
> **人数 ×1.10 と呪い ×1.85 を掛けると ×2.035。足せば ×1.95。**
> **重なるほど跳ね上がるのを避ける。**

**上限は呪いの側で掛かっている**（4 章。速さ系は ×3.0 まで）。
**重ねた後には掛けない**——人数のぶんまで削られてしまうため。

### 1-1. ステータスごとの一覧

| ステータス | 人数倍率 | ウェーブ倍率 | 呪い倍率 | 丸め |
| --- | --- | --- | --- | --- |
| **数** | **1 ＋ 0.5 × (人数 − 1)** | — | — | **上限で切る** |
| **HP** | **無し** | **`1.1^(wave−1)`**（3-3） | **あり** | **掛かる** |
| **攻撃力** | **1 ＋ 0.05 × (人数 − 1)** | 無し | **あり** | 掛からない |
| **移動速度** | **無し**（2026-09-07 変更） | 無し | **あり（上限）** | 掛からない |
| **攻撃速度** | 同上 | 無し | **あり（上限）** | 掛からない |

> ### v2 の**仕様**を引き継いだ（2026-09-04 決定）
>
> **[../../../pve-v2/docs/spec/16-enemy.md](../../../pve-v2/docs/spec/16-enemy.md) の
> 「呪い」「倍率を掛け合わせる」「上限に当たった数を HP へ詰め替える」は、そのまま使う。**
>
> **違うのは「数」だけ**——**v2 は wave で決めていたが、v3 は敵グループごとに基礎値を持つ。**
> **どのグループを選んだかで、出る数が変わる。**

> ### 防御は置かない
>
> **カット率の計算が面倒なわりに、やっていることは「硬くなる」だけ。**
> **硬さは HP に一本化する。**

## 3. 数

### 3-1. 決め方

```
出したい数 ＝ ceil( グループの基礎数 × 人数倍率 )
上限       ＝ min(100, 40 ＋ 10 × wave)          （仮）
実際に出る数 ＝ min(出したい数, 上限)
丸め係数   ＝ 出したい数 ÷ 実際に出る数           （上限に届いていなければ 1.0）
```

**端数は切り上げ。丸め係数は小数のまま。**

| 人数 | 1 | 2 | 4 | 10 |
| --- | --- | --- | --- | --- |
| **数の倍率** | 1.0 | 1.5 | 2.5 | **5.5** |
| **攻撃力・速度の倍率** | 1.00 | 1.05 | 1.15 | **1.45** |

### 3-2. 丸めは「詰め替え」であって、増減ではない

**ゾンビ軍団・10 人・wave 1:**

| | |
| --- | --- |
| 出したい数 | ceil(15 × 5.5) ＝ **83** |
| 実際に出る数 | **50**（上限） |
| 丸め係数 | 83 ÷ 50 ＝ **1.66** |
| 1 体の HP（固有 40） | 40 × **1.66** ＝ **66** |
| 1 体の攻撃力 | 固有 × **1.45**（**丸めは掛からない**） |

**83 体 × 40 と 50 体 × 66 で、総量はほぼ同じ。**

> ### 上限に当たると、**受ける攻撃の総量は頭打ちになる**
>
> **HP は詰め替えられるが、手数は詰め替えられない**——
> **人数が多いほど、1 人あたりが受ける圧は緩む。**（意図どおり）

### 3-3. HP のウェーブ倍率（2026-09-06 に決め直した）

```
HP のウェーブ倍率 ＝ 1.1 ^ (wave − 1)
```

| wave | 1 | 5 | 10 | **15** | 20 | 30 |
| --- | --- | --- | --- | --- | --- | --- |
| **倍率** | 1.00 | 1.46 | 2.36 | **3.80** | 6.12 | 15.86 |

> ### 帯で積む形はやめた（2026-09-06）
>
> **前は「wave 2〜5 は ＋0.4、16 以降は ×1.25」と帯で積んでいた。**
> **wave 30 で ×301 まで伸び、数字が壊れていた。**
> **1 本の式にして、wave 15 で約 4 倍。** ここに呪いが乗る。

**呪いと合わせた実際の硬さ**（呪いの期待値は 4 章）:

| wave | ウェーブ倍率 | 呪い倍率 | **合計** |
| --- | --- | --- | --- |
| 5 | 1.46 | 1.75 | **2.6** |
| 10 | 2.36 | 2.60 | **6.1** |
| **15** | **3.80** | **4.40** | **16.7** |
| 20 | 6.12 | 6.15 | **37.6** |
| 30 | 15.86 | 9.65 | **153** |

## 3-4. 湧かせ方（2026-09-06 に決め直した）

### 3-4-0. **ボスと雑魚は別もの**

| | |
| --- | --- |
| **ボス** | **基本 1 体。** あるいは**ボス ＋ 取り巻き** |
| **どちらになるか** | **敵グループを選んだ時点で決まる**（休憩所の 3 択。`13-flow.md` 3-2） |
| **雑魚** | 下の決まりで湧く |

**ボスの湧かせ方は、まだ書いていない。**

### 3-4-1. 雑魚の湧き方

| | |
| --- | --- |
| **積む** | ウェーブに入った瞬間に、出す中身を全部決めて**待ち行列に積む** |
| **出す速さ** | **2 秒に 10 体**（40 tick ごとに 10 体）。100 体なら **20 秒**かけて全部出る |
| **近すぎる所には湧かない** | **プレイヤーの半径 3 マス以内の点は、その回だけ外す** |
| **値の持たせ方** | HP は `state/hp.ts`、**攻撃力と種類はその個体の動的プロパティ**（`pve3:atk` / `pve3:kind`） |

**種類ごとの間隔・届く距離・動き方も、その個体から読む**——
**表を 1 つ直せば、湧いている敵にも次から効く。**

### 3-4-2. **湧く場所は、マップごとに登録する**（2026-09-06）

> ### 壁や天井に埋まって出てくるのを無くす
>
> **地形から自動で判定しない。** 屋内・張り出し・薄い床——**判定が当たらない形が多すぎる。**
> **出てよい所を、マップごとに人が決めておく。**

| | |
| --- | --- |
| **決め方** | **建築モードで範囲を選ぶ。** 範囲は**いくつでも**足せる |
| **持つデータ** | **「どのブロックの上から出るか」の 1 点ずつ。** 範囲そのものではなく、**点の並び**として持つ |
| **どのマップのものか** | **マップ名で引く。** マップを焼き直しても、点はそのまま使える |
| **変えないもの** | **地形の見た目とブロックそのものは触らない。** 湧く場所を決めるだけ |

> ### **点の並びで持つ理由**
>
> **範囲のままだと、範囲の中の「立てない所」まで含んでしまう。**
> 選んだ時に**その場で「立てる面」だけを拾って点にする**ので、
> **出した敵が埋まらない**ことを、湧かせる側が確かめなくてよくなる。

**登録が無いマップでは、雑魚を出せない。** 運営に**そう伝える**。

## 4. 呪い

> ### 呪い ＝ **ウェーブを越えるたびに、敵へ積み上がる強化**
>
> **n 個引く。同じものが続けて選ばれることもある。**
> **一度付いた呪いは消えない。**

> ### 引くのは「**戦場のゲートをくぐって移動するとき**」（2026-09-07 決定）
>
> **倒し切った瞬間ではない。** **まだ戦場に居るのに強くなるのはおかしい。**
> **次の戦場へ移る、その時に引き、その時に見せる。**
>
> | | |
> | --- | --- |
> | **戦場 → 次へ** | **引く**（休憩所へ向かうときも、次の戦場へ向かうときも） |
> | **休憩所 → 戦場** | **引かない。** 休憩所のゲートは関係ない |
> | **全滅で終わった** | **引かない。** 次が無い |

| | 値（仮） |
| --- | --- |
| **引く数 n** | **wave 1〜5 は 3／6〜10 は 5／11 以降は 7** |
| **HP** | **＋0.2**（上限なし） |
| **攻撃力** | **＋0.2**（上限なし） |
| **移動速度** | **＋0.05。上限 ×3.0** |
| **攻撃速度** | **＋0.05。上限 ×3.0** |

**上限に達したものは、候補から外す**——溢れたぶんは残りへ流れる。
**引いたものは毎ウェーブ見せる**——見せないと理不尽にしか見えない。

### 4-1. 実装（2026-09-06）

| | どこ |
| --- | --- |
| **数え方** | `core/curse.ts`（**純粋**。`tests/curse.test.ts` で固めてある） |
| **積み上がり** | `state/curse.ts`。**ワールドに 1 本の文字列**（`hp,power,speed,haste`） |
| **引く・見せる** | `services/curse.ts`。**戦場を出るときに 1 度だけ**（`services/match.ts` の `exit`） |
| **落とす** | **試合の準備に入るとき**（`services/match.ts`） |
| **効かせ方** | **湧かせるときに、種類ごとの倍率で計算**（`core/enemy.ts` の `statsOf`） |

**見せ方はチャット 2 行**——引いたものと、いまの倍率。

### 4-2. **難易度に左右させない**（2026-09-06）

> ### ピースフルで敵が動かなかった
>
> **`monster` の家族を持つ実体は、ピースフルではプレイヤーを狙わない。**
> **家族から `monster` を外した**——**どの難易度でも同じように動く。**

**新しい敵にも `monster` は持たせない**（`23-enemy-unit.md` 9-1-1）。

### 5-1. 動きは 3 通り（**どれも仮**）

| 動き | 中身 |
| --- | --- |
| **殴る** | 届く距離まで寄って `hit()` |
| **撃つ** | 離れた所から `hit()`。**弾は飛ばさない**（見た目と音だけ） |
| **自爆** | 届く距離で**消えて、周りの人に `hit()`**。**地形は壊さない** |

> ### **取り消した**（2026-09-06）
>
> **「弾は飛ばさない」はやめる。**
> **遠距離は弾を飛ばし、実体に当たったときだけヒット**にする
> （[23-enemy-unit.md](23-enemy-unit.md) 3-1）。

### 5-2. クリーパーは、爆発の**見た目だけ**

| | |
| --- | --- |
| **地形破壊** | **無し**（そもそもバニラの爆発を使わない） |
| **ダメージ** | **`hit()` で自前に出す**。範囲 **3.5 マス**（仮） |
| **見た目・音** | **出す** |

**マップを壊させない**——[14-map-build.md](14-map-build.md) の構造物が崩れると、次の戦場が汚れる。
