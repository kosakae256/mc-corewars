# ポータルの色（★1〜6）

**2026-09-05。** **次に戦う敵グループの★で、戦場のポータルの色を変える。**

## 0. 何をするか

**戦場の奥のゲートを、次に行く先の色に塗る。**
**倒し切った瞬間に色が変わる**ので、**次がどれくらい重いか**が見える。

| 行き先 | 色 |
| --- | --- |
| **★1** の敵群 | 紫 |
| **★2** | 赤紫 |
| **★3** | 紅紫 |
| **★4** | 朱 |
| **★5** | 赤 |
| **★6** | **赤黒**（いちばん重い） |
| **休憩所** | **水色**（3 戦ごと。`13-flow.md` 1 章） |

**★は敵グループが持っている**（`16-enemy.md` 2 章の `star`）。

## 0-1. **ゲートの箱は決まっている**

```
(1, 1, 39) 〜 (-1, 5, 39)
```

**どのマップでも、ここが戦場のゲート。**
**塗り替えるのはこの箱の中だけ**——ロビーや休憩所の飾りには触らない。

**マップを作るときも、ここに立てる**（`14-map-build.md` 0-2）。

## 0-2. **いつ色が変わるか**

| いつ | 何色 |
| --- | --- |
| **マップを置いたとき** | **これから戦う敵群の★**（いま戦っている相手の重さ） |
| **敵を倒し切ったとき** | **次の行き先**（次の敵群の★、または休憩所の水色） |

**「クリアするまで灯らない」はやらない**（一度作って取り消した。`13-flow.md` 2-4）。

## 1. **いまのポータルは触らない**

`pve_v3:portal` は**ロビーの装飾に使っている。残す。**

> ### **色ごとに別のブロックを 7 つ足す**
>
> `pve_v3:portal_1` 〜 `pve_v3:portal_6` と `pve_v3:portal_rest`。
> **中身はいまのポータルと同じ**（模型・当たり・光り方）。**テクスチャだけ違う。**

> ### 状態（`states`）で 1 つにまとめてはいけない
>
> **2026-09-05 に一度やって、失敗している。**
>
> | 起きたこと | なぜ |
> | --- | --- |
> | **クリエイティブに 1 つしか出ない** | 状態を持つカスタムブロックは、**代表 1 つしか並ばない** |
> | **全部のポータルが消えた** | **状態の並びの先頭が既定値。** `off` を先頭に書いていた |
>
> **別ブロックにすれば、どちらも起きない。**

## 2. 見た目

| | |
| --- | --- |
| **模型** | `geometry.pve_v3_portal`（いまのものと同じ） |
| **テクスチャ** | **自前で作る**（`tools/pve3-portal.py`）。**バニラのものは使わない** |
| **登録** | `textures/terrain_texture.json` に 6 つ |
| **動き** | `textures/flipbook_textures.json`。**8 コマ・2 tick ごと** |
| **状態** | `pve_v3:across`（向き）は**いままでどおり持たせる** |

> ### `ambient_occlusion` は**数**
>
> **`false` と書くと `invalid numeric value` で、そのブロックが丸ごと読み込まれない**
> （2026-09-05 の失敗。ロビーの装飾が消えた）。**`0` と書く。**

> ### テクスチャは 16 × 128（8 コマ）
>
> **1 コマ 16 × 16 を縦に 8 枚。** `flipbook_textures.json` が上から順に回す。

## 3. いつ塗り替えるか

> ### **マップを置き終わった直後**
>
> マップは**保存された構造物**なので、中のポータルは `pve_v3:portal` のまま出る。
> **置き終わってから、ゲートの位置だけ塗り替える。**

| | |
| --- | --- |
| **探す範囲** | **(1, 1, 39) 〜 (−1, 5, 39)**（0-1 の箱そのもの） |
| **置き換えるもの** | その中の `pve_v3:portal` **だけ** |
| **向き** | 元の `pve_v3:across` を**そのまま移す** |

**塗り替えるのは戦場のゲートだけ。** ロビーや休憩所には触らない（範囲の外）。

## 4. どの色にするか

| | |
| --- | --- |
| **次が戦場** | **その敵グループの★。** いまは `/pve:legion` で選んでいる 1 つ |
| **次が休憩所** | **水色**（`3n` 戦目を終えたとき。`13-flow.md` 1 章） |
| **最終戦を終えた** | **水色**（行き先はリザルト） |
| **★が分からない** | **1 として塗る**（いちばん軽い色） |
| **試しに見たい** | `/pve:portal <1〜6 か rest>`（運営用） |
