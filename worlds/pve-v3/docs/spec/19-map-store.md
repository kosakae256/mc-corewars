# 仕様: マップ倉庫と建築モード

**2026-09-05 決定。** 戦場を**実際に戦う場所で手直しし、データとして持つ**ための仕組み。

## 0. **マップは並べて常設する**（2026-09-07 決定）

> ### 毎回 0,0,0 へ置き直すのをやめる
>
> **構造物を置くのに時間がかかる。** 幕間が**置き終わるのを待つ形**になっていて、
> **暗転の長さ・締め切り・先行生成**と、仕掛けが積み上がっていた。
>
> **マップを 1000 マスずつ離して常設し、移動は TP だけにする。**

### 0-1. 並べ方

```
x =     0   **作業台**。作る・直す・焼く・戻す。**試合では使わない**
x =  1000   1 枚目
x =  2000   2 枚目
     …      **1000 × 番号**
```

| | |
| --- | --- |
| **間隔** | **1000 マス。** 戦場は ±50 なので、隣とぶつからない |
| **z** | **0 固定。** 休憩所（−2000）・ロビー（1250）ともぶつからない |
| **番号** | **倉庫に入れた順。** 覚え書き（`MapMeta`）に持つ |
| **0,0,0** | **作業台として残す**——**そこで作り、直し、焼き、戻す** |

### 0-2. 何が変わるか

| | 前 | いま |
| --- | --- | --- |
| **幕間** | 暗転 → **構造物を置く** → 置き終わりを待つ → 運ぶ | 暗転 → **運ぶだけ** |
| **休憩所** | **次のマップを裏で組む** | **何もしない**（読み込みだけ先に） |
| **座標** | どのマップも 0,0,0 | **マップごとの原点 ＋ 相対** |

**湧き点は元から相対で持っている**（`21-spawn-mark.md`。1 バイト ＋50）ので、**そのまま使える。**
**マップの手順も元から相対**（`builder.start(ops, origin)`）なので、**渡す原点が変わるだけ。**

### 0-3. **読み込みは先に済ませる**

> ### 1000 マス先は読み込まれていない
>
> **着いた瞬間に地面が無いと、落ちるか埋まる。**

| | |
| --- | --- |
| **やり方** | **次のマップに `tickingarea` を張る。** 休憩所に居る間、または幕間の頭で |
| **数** | **全部には張らない**——**重い。** **いま居る 1 枚と、次の 1 枚だけ** |
| **消す** | **使い終わったら外す。** 張りっぱなしにしない |

### 0-4. 倉庫は残す

**役割が変わる。**

| 前 | いま |
| --- | --- |
| **毎ウェーブ置くためのもの** | **直すためのもの**——傷んだら作業台で組み直し、焼き直して、スロットへ置く |

**常設だと、傷が残り続ける。** **戻せる口は要る。**

### 0-4-1. **マップに紐づくもの、全部**（2026-09-07 に洗い出した）

| 何 | どこに持っているか | 移すのに要るか |
| --- | --- | --- |
| **地形** | **構造物**（世界の中） | **置き直すだけ。** 中身は相対 |
| **湧き点** | **動的プロパティ。原点からの相対** | **要らない。** 読むときに原点を足す |
| **強化の台の印** | **地形の中のブロック** | **要らない**（地形と一緒に動く）。**探す所を原点にずらした** |
| **ゲート** | **地形の中**（x −1〜+1・z 39） | **要らない。** 塗る所を原点にずらした |
| **覚え書き**（表示名・出る／出ない・大ジャンプ・番号） | **動的プロパティ** | **要らない** |
| **バリア**（±60） | **手で張ったもの。地形の外** | **移らない**（0-4-2） |

### 0-4-2. **バリアだけは移らない**

**構造物は ±50 まで。** **±60 のバリアはその外**なので、**構造物には入っていない。**
**スロットごとに、要るなら張り直す。**

### 0-6. **構造物はバックアップ**（2026-09-07 決定）

> ### 世界に構造物を持っているだけで重い
>
> **マップは常設**なので、**普段は構造物が要らない。**
> **取るのも、消すのも、運営メニューから。**

| ボタン | 何が起きるか |
| --- | --- |
| **バックアップを取る** | **そのマップの場所へ飛び、いまの姿を焼き直す。** 直した後はこれ |
| **バックアップを消す** | **構造物だけ消す。** **世界が軽くなるが、直せなくなる** |
| **倉庫から消す** | **構造物と覚え書きを消す。** **置いてある地形は残る**（試合には出なくなる） |

> ### **バックアップが無くても、試合には出る**
>
> **遊べる条件は「出す」＋「場所がある」の 2 つだけ**（2026-09-07 変更）。
> **構造物は要らない**——**置き直したいときに要るだけ。**

**焼くのは「そのマップの場所」**——**作業台ではない。**
**焼き直しても番号は変わらない。**

### 0-7. **敵は、いまの戦場の中だけ数える**（2026-09-07）

> ### 世界中を数えると、ウェーブが終わらない
>
> **マップは 1000 マスずつ離して常設してある。**
> **別のマップに 1 体でも残っていると、「敵 0」にならない。**

| | |
| --- | --- |
| **数える範囲** | **いまの戦場の箱の中だけ**（`services/field.ts` の `enemies`） |
| **箱の外に居たら** | **消す。** 倒すのではない——**報酬は出ない**（`entity.remove()`） |
| **いつ消すか** | **① 倒し切った瞬間 ② マップを切り替えるとき ③ 試合を畳むとき** |

**片付けは世界中を見る**（`clearEnemies`）——**どのマップに残っていても消す。**

### 0-5. 移す手順（**一度だけ**）

> ### **人が動きながら、1 枚ずつ置く**
>
> **構造物は、読み込まれていない所へは置けない。**
> **運営がそのスロットへ飛び、置き、次へ飛ぶ**——これを順に繰り返す。

```
1 枚目のスロットへ飛ぶ → 置き終わるまで待つ → 2 枚目へ飛ぶ → …
```

| | |
| --- | --- |
| **番号** | **倉庫の順に振る**（`MapMeta` に持たせる） |
| **置く** | **1 枚ずつ。** 置き終わってから次へ |
| **湧き点** | **触らない**（相対なので、そのまま効く） |
| **やり直し** | **何度でも。** 置き直すだけ



## 1. 何が問題だったか

> ### 生成器だけでは、手直しが残らない
>
> 地形はコードで組んでいる。**ゲーム内で直しても、次に組み直せば消える。**
> かといって**コードへ写し戻すのは現実的でない。**

> ### 置くものは「保存されたものだけ」にしたい
>
> **生成器が毎回その場で作る**形だと、
> **何が出るのかを人が確かめられない。**
> **保存した地形だけが出る**——それなら、出るものは全部見たものになる。

## 2. 形

```
生成器（下地）  →  建築モードで手直し  →  倉庫へ保存  →  倉庫から置く
  /pve:mapdraft      （ふつうに建てる）      /pve:mapsave    /pve:mapload
```

| | |
| --- | --- |
| **1 マップ** | **16 枚の構造物**（`pve3:<名前>_0`〜`_15`）＋ **1 つの覚え書き**（表示名・出るかどうか・**割り方**・**大ジャンプ**） |
| **保存先** | **ワールドの中**（`StructureSaveMode.World`） |
| **覚え書き** | ワールドの動的プロパティに JSON で 1 本 |

> ### なぜワールドに保存するのか
>
> **スクリプトはパックにファイルを書けない。**
> ワールド保存なら、**追加・削除・書き換えが全部スクリプトからできる**——
> `createFromWorld` / `place` / `delete` / `getWorldStructureIds`。
>
> **パック同梱は「配るとき」の話**（`14-map-build.md` 1 章）。
> **まず倉庫を回せるようにして、配る段になったら道具で移す。**

## 3. 区画の割り方

**構造物 1 枚は 1 辺 64 マスまで。**

| | |
| --- | --- |
| **平面** | **4 × 4。** ±50（101 マス）を 4 等分（26・25・25・25） |
| **高さ** | **−34 〜 +29（64 マス）。** 割らない |
| **枚数** | **16 枚** |

**保存も設置も、xz ＝ 0, 0 を中心とした同じ座標**。

> ### **なぜ 16 枚なのか**（2026-09-05 に 4 枚から変えた）
>
> **1 辺 64 マスの制限だけなら 4 枚で足りる。**
> **置いている間サーバーが止まり、暗転が切れて一瞬明るく見えた**ので割った
> （`14-map-build.md` 2-2）。
>
> **割り方は覚え書きに `grid` として残す**——
> **無ければ 2（＝ 4 枚）**として置くので、**前に焼いたマップもそのまま出る。**
**別の場所で作らない**——置き直したときにずれる。

**±50 の外は保存しない**（`14-map-build.md` 0-1）。

### 3-4. **置く前に、範囲を丸ごと空気にする**（2026-09-06）

> ### 構造物が持っているのは y **−34〜+29** だけ
>
> **その下に前のマップの残りがあると、新しい島の下にぶら下がって見える。**

> ### 水・溶岩は、**半端に消すと湧き直す**
>
> 一部だけ消すと、**残りが流れ込んで無限水源になる。**

だから、**置く前に `-64`〜`+40` を空気で埋める**（`services/mapstore.ts` の `wipeAll`）。

| | |
| --- | --- |
| **上から下へ** | 下から消すと、**上に残した水が落ちてくる** |
| **1 回 32768 まで** | `fillBlocks` の上限。**厚さを割って、`runJob` で少しずつ** |
| **その後に構造物を置く** | 一度空にしてから置くので、**前のマップは残らない** |

## 4. 建築モード（世界の状態 `build`）

**`idle` からだけ入れて、`idle` にだけ戻る**（`17-state.md` 2-9）。

| | |
| --- | --- |
| **最中** | 敵は湧かない。ウェーブは進まない。**参加者は居ない** |
| **入口・出口** | **何もしない。** マップを組み直さない（手直しを消さないため） |

**試合中には入れない。** 入ろうとしたら断る。

## 5. 覚え書き

```jsonc
{
  "basin": { "label": "宙の窪地", "on": true },
  "ruins": { "label": "崩れた回廊", "on": false }
}
```

| | |
| --- | --- |
| **名前** | 英小文字・数字・`_` のみ。**識別子の一部になる**ので、後から変えない |
| **表示名** | 画面に出す名前。**変えてよい** |
| **`on`** | **false なら試合に出ない。** 作りかけを置いておける |

**倉庫に無い名前は出ない。** 覚え書きに有っても**構造物が欠けていれば出さない。**

## 6. 操作

| | |
| --- | --- |
| `/pve:mapdraft <生成器> ok` | **下地を組む**（開発用。`basin` だけ） |
| `/pve:mapsave <名前>` | **いまの ±50 を 16 枚に分けて保存** |
| `/pve:maps` | 一覧（出るかどうかも） |
| `/pve:mapload <名前> ok` | **倉庫から置く** |
| `/pve:mapdel <名前> ok` | **消す**（構造物 16 枚と覚え書き） |
| `/pve:mapon <名前> <on\|off>` | **出るかどうかを切り替える** |
| `/pve:build <on\|off>` | **建築モード**の出入り |

**消す・置くは `ok` が要る。** どちらもそこにあるものを壊す。

### 7-0. 試合の手当て（2026-09-05 追加）

**試している間、進行を手で押したいことがある。**

| ボタン | 何が起きるか | 打つなら |
| --- | --- | --- |
| **敵を全滅させる** | **いま場に居る敵を消す。** 湧き待ちも止める。**あとは普通の流れ**——殲滅の合図が出て、ゲートが灯る | `/pve:kill` |
| **ウェーブを終わらせる** | **敵を消したうえで、ポータルまで歩くのを飛ばす。** そのまま幕間へ | `/pve:skip` |

> ### 2 つに分ける
>
> **「敵だけ消したい」と「先に進めたい」は別。**
> 殲滅の演出やゲートの色を確かめるときは**前者**、
> 何戦も回して次を見たいときは**後者。**

**戦場に居るときだけ効く。** 休憩所や非開始では何もしない。

### 7-0-1. **敵を呼ぶ**（2026-09-06 追加・確認用）

**1 体だけ見て確かめたい**ことがある。**湧き点も待ち行列も通さず、その場に出す。**

| 選ぶもの | |
| --- | --- |
| **種類** | **敵の表**（`core/enemy.ts`）**＋ カカシ**（`23-enemy-unit.md` 1-1） |
| **数** | **1〜20。** 押し間違いで戦場が埋まらないように上限を置く |
| **いまのウェーブと呪いを乗せる** | **既定は乗せる。** 外すと**固有値そのまま**（wave 1・呪い無し・1 人） |

| | |
| --- | --- |
| **出る場所** | **見ている所の 1 つ上。** 何も見ていなければ**足元から 3 マス先** |
| **重なり** | **少しずつずらして出す** |
| **値の付け方** | **湧かせるときと同じ**（`services/spawn.ts` の `summon`）——HP・攻撃力・速さ・攻撃速度・エメラルド倍率 |

> ### **どこでも呼べる**
>
> **湧き点が登録されていないマップでも出せる。**
> ウェーブの敵は湧き点からしか出ないが、**これは確認用なので別扱い。**

**飛竜は `/pve:boss`**——ボスは湧かせ方が別（`16-enemy.md` 3-4-0）。

## 7-1. 試合の中での動き（2026-09-05 実装）

| いつ | 何が起きるか |
| --- | --- |
| **休憩所に入った瞬間** | **ブロック以外を片付け**（敵・落ちている物・矢）、**倉庫から次のマップを置く** |

> ### 黙って何も起きないのが、いちばん困る
>
> **倉庫が空なら「空だ」と言う。** 置けなければ理由を言う。

## 8. 控え（2026-09-06 追加）

> ### **ワールドが壊れたら、手で直したマップは戻らない**
>
> `StructureSaveMode.World` で保存したものは**ワールドの db の中**にあり、
> **`structures` フォルダにファイルは作られない**（2026-09-06 に確かめた）。
> **アドオンを別のワールドへ持って行っても、マップは付いてこない。**

```
node tools/pve3-map-freeze.mjs            全部
node tools/pve3-map-freeze.mjs testmap    1 つだけ
node tools/pve3-map-freeze.mjs --list     何が入っているか見るだけ
```

```
worlds/pve-v3/backup/maps/<マップ>/<マップ>_<区画>.mcstructure.gz
                          └ manifest.json（枚数・割り方・取った日・ワールド名）
```

**ゲームを閉じてから走らせること。** db は写してから読むが、書き込みの途中を写すと欠ける。

### 8-1. **パックには入れない**

| | |
| --- | --- |
| **大きさ** | **1 マップ 5 MB。** 65 万マス × 4 バイト × 2 層、**無圧縮**（`.mcstructure` の仕様） |
| **17 マップ** | **85 MB。** 遊ぶ人のディスクにそのまま残る |
| **gzip すると** | **29 KB。** 中身はほとんど空気と一様な埋め |

**ゲームは gzip した `.mcstructure` を読まない**ので、**縮めるなら「読ませない」＝控えにするしかない。**
**生成器があるマップは、そもそも焼く必要がない**（`/pve:mapdraft` で作れる）。

### 8-2. **戻し方**（まだ道具は無い）

**控えは「いつか使うかもしれない」ためのもの。** 戻す口は書いていない。
戻すとしたら、道は 3 つある。

| | どうやるか | 何が要るか |
| --- | --- | --- |
| **A. db へ書き戻す** | `gunzip` して、ワールドの db に `structuretemplate_pve3:<名前>` というキーで値を入れる | **`leveldb-zlib` は入っている**（`tools/package.json`）。**書き込みは未検証。ゲームを閉じて、db を控えてから** |
| **B. パックに置いて読ませる** | `gunzip` して `behavior_packs/<パック>/structures/pve3/<名前>.mcstructure` に置く | **その場で読める**（識別子は `pve3:<名前>` のまま）。**ただし 5 MB × 枚数を配ることになる** |
| **C. 構造物ブロックで置く** | B のあと、ゲーム内で `/structure load pve3:<名前> <x> <y> <z>` | 手で 16 回。**位置を間違えるとずれる** |

**A が本筋。** 戻せば**倉庫の側は何も変えずに動く**（`complete()` が揃いを見るだけなので）。

> ### 戻すときに要るもの
>
> | | |
> | --- | --- |
> | **構造物 16 枚** | 控えにある |
> | **覚え書き**（表示名・出す/出さない・**割り方**） | **控えていない。** `manifest.json` の `grid` から割り方だけ分かる |
>
> **覚え書きはワールドの動的プロパティ**（`pve_v3:maps`）で、db の別の場所にある。
> **戻したあと `/pve:mapon <名前> on` を打ち直せばよい**ので、控えていない。
>
> **置く座標は控えなくてよい**——**保存も設置も xz ＝ 0, 0 の同じ枠**（`14-map-build.md` 2 章）。
