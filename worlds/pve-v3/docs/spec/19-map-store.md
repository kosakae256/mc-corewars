# 仕様: マップ倉庫と建築モード

**2026-09-05 決定。** 戦場を**実際に戦う場所で手直しし、データとして持つ**ための仕組み。

## 1. 何が問題だったか

> ### 生成器だけでは、手直しが残らない
>
> 地形はコードで組んでいる。**ゲーム内で直しても、次に組み直せば消える。**
> かといって**コードへ写し戻すのは現実的でない。**

> ### 置くものは「保存されたものだけ」にしたい
>
> **生成器が毎回その場で作る**形だと、
> **何が出るのかを人が確かめられない。**
> **保存した地形だけが出る**——それなら、出るものは全部見たものになる。

## 2. 形

```
生成器（下地）  →  建築モードで手直し  →  倉庫へ保存  →  倉庫から置く
  /pve:mapdraft      （ふつうに建てる）      /pve:mapsave    /pve:mapload
```

| | |
| --- | --- |
| **1 マップ** | **16 枚の構造物**（`pve3:<名前>_0`〜`_15`）＋ **1 つの覚え書き**（表示名・出るかどうか・**割り方**） |
| **保存先** | **ワールドの中**（`StructureSaveMode.World`） |
| **覚え書き** | ワールドの動的プロパティに JSON で 1 本 |

> ### なぜワールドに保存するのか
>
> **スクリプトはパックにファイルを書けない。**
> ワールド保存なら、**追加・削除・書き換えが全部スクリプトからできる**——
> `createFromWorld` / `place` / `delete` / `getWorldStructureIds`。
>
> **パック同梱は「配るとき」の話**（`14-map-build.md` 1 章）。
> **まず倉庫を回せるようにして、配る段になったら道具で移す。**

## 3. 区画の割り方

**構造物 1 枚は 1 辺 64 マスまで。**

| | |
| --- | --- |
| **平面** | **4 × 4。** ±50（101 マス）を 4 等分（26・25・25・25） |
| **高さ** | **−34 〜 +29（64 マス）。** 割らない |
| **枚数** | **16 枚** |

**保存も設置も、xz ＝ 0, 0 を中心とした同じ座標**。

> ### **なぜ 16 枚なのか**（2026-09-05 に 4 枚から変えた）
>
> **1 辺 64 マスの制限だけなら 4 枚で足りる。**
> **置いている間サーバーが止まり、暗転が切れて一瞬明るく見えた**ので割った
> （`14-map-build.md` 2-2）。
>
> **割り方は覚え書きに `grid` として残す**——
> **無ければ 2（＝ 4 枚）**として置くので、**前に焼いたマップもそのまま出る。**
**別の場所で作らない**——置き直したときにずれる。

**±50 の外は保存しない**（`14-map-build.md` 0-1）。

## 4. 建築モード（世界の状態 `build`）

**`idle` からだけ入れて、`idle` にだけ戻る**（`17-state.md` 2-9）。

| | |
| --- | --- |
| **最中** | 敵は湧かない。ウェーブは進まない。**参加者は居ない** |
| **入口・出口** | **何もしない。** マップを組み直さない（手直しを消さないため） |

**試合中には入れない。** 入ろうとしたら断る。

## 5. 覚え書き

```jsonc
{
  "basin": { "label": "宙の窪地", "on": true },
  "ruins": { "label": "崩れた回廊", "on": false }
}
```

| | |
| --- | --- |
| **名前** | 英小文字・数字・`_` のみ。**識別子の一部になる**ので、後から変えない |
| **表示名** | 画面に出す名前。**変えてよい** |
| **`on`** | **false なら試合に出ない。** 作りかけを置いておける |

**倉庫に無い名前は出ない。** 覚え書きに有っても**構造物が欠けていれば出さない。**

## 6. 操作

| | |
| --- | --- |
| `/pve:mapdraft <生成器> ok` | **下地を組む**（開発用。`basin` だけ） |
| `/pve:mapsave <名前>` | **いまの ±50 を 16 枚に分けて保存** |
| `/pve:maps` | 一覧（出るかどうかも） |
| `/pve:mapload <名前> ok` | **倉庫から置く** |
| `/pve:mapdel <名前> ok` | **消す**（構造物 16 枚と覚え書き） |
| `/pve:mapon <名前> <on\|off>` | **出るかどうかを切り替える** |
| `/pve:build <on\|off>` | **建築モード**の出入り |

**消す・置くは `ok` が要る。** どちらもそこにあるものを壊す。

## 7. 運営用コンパス

**GUI で触りたい**——名前を打つのは、直すたびには重い。

| | |
| --- | --- |
| **持ち物** | `pve_v3:admin`（コンパス）。**OP だけが出せる** |
| **開き方** | 右クリック |
| **中身** | **建築モードの入切** ／ **マップ一覧**（選ぶと、置く・出るかどうか・消す） ／ **試合の手当て**（下） |

**打つコマンドと、できることを揃える**——GUI でしかできないことを作らない。

### 7-0. 試合の手当て（2026-09-05 追加）

**試している間、進行を手で押したいことがある。**

| ボタン | 何が起きるか | 打つなら |
| --- | --- | --- |
| **敵を全滅させる** | **いま場に居る敵を消す。** 湧き待ちも止める。**あとは普通の流れ**——殲滅の合図が出て、ゲートが灯る | `/pve:kill` |
| **ウェーブを終わらせる** | **敵を消したうえで、ポータルまで歩くのを飛ばす。** そのまま幕間へ | `/pve:skip` |

> ### 2 つに分ける
>
> **「敵だけ消したい」と「先に進めたい」は別。**
> 殲滅の演出やゲートの色を確かめるときは**前者**、
> 何戦も回して次を見たいときは**後者。**

**戦場に居るときだけ効く。** 休憩所や非開始では何もしない。

## 7-1. 試合の中での動き（2026-09-05 実装）

| いつ | 何が起きるか |
| --- | --- |
| **休憩所に入った瞬間** | **ブロック以外を片付け**（敵・落ちている物・矢）、**倉庫から次のマップを置く** |
| **選び方** | **出せるもの − 直前の 1 つ**から一様ランダム（`14-map-build.md` 4 章） |
| **ウェーブに入った瞬間** | 選ばれている敵グループを**待ち行列に積む** |
| **運営への報せ** | **マップを置いた／敵を積んだ／倉庫が空だった**を、OP にだけ出す |

> ### 黙って何も起きないのが、いちばん困る
>
> **倉庫が空なら「空だ」と言う。** 置けなければ理由を言う。
