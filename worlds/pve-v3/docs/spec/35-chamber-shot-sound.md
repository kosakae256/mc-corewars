# チェンバーの発砲音

2026-09-10 の依頼: 仮の爆発音を VALORANT のツール・ド・フォースの発砲音に置き換える。

- 音源: [Chamber Ultimate Sound (Sound Effect) | Valorant](https://www.youtube.com/watch?v=TQqNY3eNlnA)。冒頭の装備後、最初の発砲を映像と波形で特定し、3.219～5.100 秒を使用する。後半のヘッドハンターは使用しない。
- 取得した動画全体は作業用 `.scratch/` に置く。使用する一発だけを `user/chamber-tour-de-force-shot.wav` に保存し、出典・切り出し区間・ハッシュを併記する。
- モノラル 48 kHz、音程・速度は変更しない。終端 40 ms をフェードし、ピークを 0.9 にそろえて OGG Vorbis にする。
- RP の `pve_v3:chamber.shot` / `sounds/pve3/chamber_shot.ogg` として登録する。
- `beam.report` の任意設定で音名・音程を選択できるようにし、チェンバーにのみ指定する。既存の `loud` 判定、発砲時刻、位置、50 マス以内への再生処理は維持する。チェンバーの音程は 1.0。
- ウルトのセリフ `pve_v3:chamber.call` は発砲音と別のまま。
- 音源は Riot Games の VALORANT 由来。フリー素材として扱わない。

音声追加後は Minecraft のアプリ全体を再起動して読み込む（既存の音声導入手順）。

## 確認

公式エージェントページのツール・ド・フォース動画も取得したが、音声が全区間ゼロのため不採用。採用動画は最初の発砲が約 3.22 秒にあり、次の発砲より前で切る。ゲーム内の最終的な音量・距離感は実機で確認する。
