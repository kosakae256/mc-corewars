# 散弾のスキン試作

2026-09-10、ユーザーから散弾の独自スキンの試作依頼。

## 初案

スティーブの標準体型（腕幅4）、64×64 PNG の標準スキンUVで作る。
現在の `geometry.pve3.humanoid` は texture_width / texture_height が64。
Bedrockのスキン取り込みは64×64と128×128の両方に対応する。
根拠は同梱公式サンプルの `bedrock-samples/resource_pack/texts/en_US.lang` にある
`dr.classic_skins.custom_skin_description` と `dr.classic_skins.invalidCustomSkin`。
今回は現在のUVと同じ64×64を選ぶ。
既存の銃の構えに合わせ、近距離射撃兵を想定した防具と弾薬の意匠にする。
ユーザーの追加指定は「散弾銃を扱う、軍の兵士のような外見」。
初案はオリーブ色の軍服、暗い防弾ベスト、軍用ヘルメット、散弾の薬莢ポーチ、
ゴーグル、手袋とブーツ。実在の軍の徽章や国旗は使わない。
既存キャラクターや第三者配布スキンを転用せず、内蔵画像生成で新規作成する。

## 保存と確認

- 生成した原稿と生成プロンプトを `user/shotgun-skin-v1/` に残す。
- 完成PNGは `user/shotgun-skin-v1/shotgun-skin-64.png`。
- 画像生成だけでは厳密なUV位置が得られなかったため、生成原稿の各面を
  `uv-map.json` の矩形で切り出し、`build-atlas.ps1` で標準UVに配置する。
  最近傍縮小で64×64に合わせ、ベース面を不透明・それ以外を透明にする。
  左腕は原稿右腕の意匠を利用し、手底・足底・頭底は対応部位の生成色から取る。
- 散弾だけが参照する専用テクスチャとしてRPに追加する。元のスティーブ画像は保持する。
- 標準UV、ベース面の不透明度、64×64寸法を確認する。
- 既存プレビューツールで正面・背面・斜めと銃を持った姿を確認する。
- `npm run check` 後、RPの版を上げて配置する。実機での最終見た目は別途確認。
