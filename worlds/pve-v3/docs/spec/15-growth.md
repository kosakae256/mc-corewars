企画は [../00-concept.md](../00-concept.md) 4 章。

## 1. 伸ばせるもの（4 本）

**休憩所のショップで、エメラルドを払って買う。**

| ステータス | 初期 | 1 回で | 上限 | 上限まで伸ばすと |
| --- | --- | --- | --- | --- |
| **HP** | **100** | **＋50** | **40 回** | **2,100**（×21） |
| **足の速さ** | **1.0** | **＋0.025** | **40 回** | **2.0** |
| **攻撃速度** | **1.0** | **＋0.05** | **40 回** | **3.0** |
| **攻撃力** | **1.0** | **＋0.1** | **40 回** | **5.0** |

**火力は 攻撃力 × 攻撃速度 ＝ ×15。**

## 2. 値段

```
n 回目の強化 ＝ 50 × n エメラルド        （n はそのステータスの強化回数）
```

| n | 1 | 10 | 20 | 30 | 40 |
| --- | --- | --- | --- | --- | --- |
| **その 1 回** | 50 | 500 | 1,000 | 1,500 | **2,000** |

| | |
| --- | --- |
| **1 本を上限まで** | **41,000** |
| **4 本とも上限まで** | **164,000** |

> ### `n` は「そのステータスを買った回数」（2026-09-04 の読み）
>
> **通算にすると 4 本で 644,000 になり、桁が変わる。**
> **上限が 1 本ごとに 40 回なので、数え方も 1 本ごとに揃える。**

**エメラルドの入りとの釣り合いは、まだ合わせていない**（5 章）。

## 3. 攻撃速度は「溜め」で作る

> ### tick は整数なので、**素直に割ると刻みが潰れる**
>
> 弓の間隔は **10 tick**。**10 ÷ 1.05 ＝ 9.52 → 丸めると 10 のまま。**
> **1 回目の強化で、何も起きない。**
> **10→3 tick の間には整数が 8 段しか無いのに、強化は 40 段ある。**

**間隔を割るのではなく、溜めを足す。**

```
毎 tick   溜め ＝ min(溜め ＋ 攻撃速度, 10)
撃てる    溜め ≧ 10
撃ったら  溜め ← 溜め − 10
```

| 攻撃速度 | 撃つ間隔（平均） |
| --- | --- |
| 1.00 | 10.00 tick |
| **1.05** | **9.52 tick**（9 と 10 が交互） |
| 1.50 | 6.67 tick |
| 2.00 | 5.00 tick |
| **3.00** | **3.33 tick** |
| 5.00 | 2.00 tick |

| | |
| --- | --- |
| **40 段が全部効く** | **平均で正しく縮む。1 回目から変わる** |
| **溜めは 10 で頭打ち** | **撃たずに待って連射を貯める、ができない** |
| **見え方** | **数が大きいほど速い**（ユーザー指定） |

**いまの実装**（`features/bow/index.ts` の `cooldownOf()`）は**割り算なので、この形に置き換える。**

## 4. 足の速さは、実体イベントで変える

**プレイヤーの `minecraft:movement` を、`entities/player.json` のイベントで切り替える。**

| | |
| --- | --- |
| **刻み** | **0.025** |
| **範囲** | **1.000 〜 5.000**（＝**161 個**のイベント） |
| **名前** | **`pve_v3:spd_<倍率×1000>`**（`spd_1000` ＝ 1.000、`spd_5000` ＝ 5.000） |
| **値** | **`minecraft:movement.value` ＝ 0.1 × 倍率** |

> ### 上限を 5.0 にしておく理由（2026-09-04 決定）
>
> **買える範囲は 2.0 まで**（1 章）。
> **それでもイベントは 5.0 まで用意する**——**買う以外の何かで、そこまで伸びうる。**

> ### v2 の遺産は作り直す
>
> `entities/player.json` には **`pve_v3:spd_100`〜`spd_300`（0.05 刻み・41 個）**が
> 残っているが、**v3 のコードからは 1 度も呼ばれていない。**
> **0.025 刻みで作り直して、古いほうは消す。**

**イベントは道具で生成する**（手で 161 個書かない）。

## 5. エメラルド

| | |
| --- | --- |
| **持ち方** | **個人持ち** |
| **入る条件** | **キル／アシスト／ウェーブクリア** |
| **★との関係** | **★が高いほど多い**（倍率は未定） |

> ### アイテムではなく、**数値で持つ**（2026-09-04 決定）
>
> **本物のエメラルドにすると、死んだときに落ちる・人に渡せる・持ち物を圧迫する。**
> **動的プロパティで数を持ち、画面に出す。**

### 5-1. 配分（**仮**・2026-09-04）

| いつ | 誰に | いくら |
| --- | --- | --- |
| **倒した** | とどめを刺した人 | **12** |
| **アシスト** | その敵を削った人（とどめの人を除く） | **6** |
| **ウェーブ突破** | **立っている人全員** | **40 ＋ 8 × wave** |

**アシストに時間制限は無い**——その敵に 1 発でも入れていれば入る。
**★ごとの倍率はまだ無い**（敵グループができてから）。

`services/reward.ts`。**誰が削ったかは、その敵が消えるまでだけ覚える。**

## 5-2. ショップ

| | |
| --- | --- |
| **売り子** | **5 人**。真ん中が「ショップ」（4 本まとめて）、左右が 1 本売り |
| **場所** | 休憩所の中心から `core/shop.ts` の `VENDOR_SPOTS`（z ＝ +31） |
| **見た目** | **仮**。人の形を借りているだけ（`pve_v3:vendor`） |
| **開き方** | **右クリック。** 休憩所に居るときだけ |
| **買い方** | **1 回 / 5 回 / 40 回**。**買えるところまで買う**（足りなければ足りるぶんだけ） |

> ### 居ない売り子は、周期ごとに立て直す
>
> **消しても `/reload` しても戻る**（`docs/imp.md` 10-7）。
> **素性の分からない売り子は片付ける**——二重に立てない。
