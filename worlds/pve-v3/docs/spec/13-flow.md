# 仕様: 進行

企画は [../00-concept.md](../00-concept.md)。**ここは「どう動くか」。**

## 1. 全体

```
ロビー(1255,15,701)
   │ 始める
   ▼
休憩所(-1000,0,-1000) ──30秒 or 全員ポータル──▶ 戦場(0,0,0)
   ▲                                              │ 敵が 0
   └──────────────────────────────────────────────┘
                                                   │ 全員死亡
                                                   ▼
                                                  終了
```

**30 戦を終えるか、全滅するまで回る。**

## 2. 休憩所（30 秒）

| | |
| --- | --- |
| **持ち時間** | **移動してから 30 秒** |
| **早く出る** | **奥のポータルに全員が入ったら、待たずに出発** |
| **時間切れ** | **自動的に次の戦場へ** |
| **死んでいた人** | **ここで復活する** |

## 3. 戦場

| | |
| --- | --- |
| **作る時機** | **休憩所にいる 30 秒のあいだ**（[14-map-build.md](14-map-build.md)） |
| **勝ち** | **敵が 0 になったら、そのウェーブは終わり**→休憩所へ |
| **負け** | **全員が死んだら終了** |
| **ticking area** | **手動で張る。**スクリプトからは張らない |

## 4. 死亡

```
死ぬ → スペクテイター → （誰か生きている限り待つ） → 休憩所で復活
                      └ 全員死んだ → 終了
```

| | |
| --- | --- |
| **死んだ直後** | **スペクテイターになる** |
| **戻るのは** | **次の休憩所** |
| **全滅の判定** | **生きている人が 0 になった時点** |

> ### 復活は「休憩所に着いたとき」であって、時間ではない
>
> **戦闘中に戻ってくることはない。** 死んだらそのウェーブは終わり。
