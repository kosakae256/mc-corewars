# 汚染・帯電の通常攻撃

ユーザー指定: 汚染と帯電が近づいて殴るようにし、基本ダメージは両方1発4。
攻撃間隔は既存の汚染に合わせて20tick（1秒）とし、呪いの攻撃速度を適用する。
移動速度2.0、間合い2.5、押す力0、死に際の毒円・落雷は維持する。
汚染はattackを4へ変更。帯電は死に際の基本威力50を残すためmeleeAttack:4を設け、
通常攻撃のときだけ個体の攻撃力×4/50へ換算する。人数・呪い倍率は通常攻撃にも反映する。
BPの追跡用melee_box_attackを攻撃可能に戻し、全呪い段の間隔も更新する。
既存個体はAI移行版2で汚染の攻撃値を4へ、帯電の攻撃間隔を旧値×20/72000へ一度だけ移行する。
