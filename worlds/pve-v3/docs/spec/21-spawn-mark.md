# 仕様: 湧く場所を決める道具（2026-09-06）

**何を作るかは [16-enemy.md](16-enemy.md) 3-4-2。ここは道具と持ち方。**

## 0. なぜ要るのか

> ### 地形から自動で判定しない
>
> **屋内・張り出し・薄い床・柱の上**——**当たらない形が多すぎる。**
> **壁や天井に埋まって出てくる**のを、判定の工夫で無くすのは無理がある。

> ### **人が見て選ぶ**
>
> **その場に立って、出てよい所を選ぶ。** そのための道具を持たせる。

## 1. 杖（`pve_v3:spawnwand`）

**運営だけが持てる。** 建築モードで使う。

| 操作 | 何が起きるか |
| --- | --- |
| **ブロックを殴る** | **範囲の 1 点目**（壊さない） |
| **ブロックに使う**（右クリック） | **範囲の 2 点目 → その範囲を足す** |
| **しゃがんで使う** | **その 1 マスだけを足す／外す**（単体指定）。**足せるのは 1-1 と同じ「立てる面」だけ** |
| **何も無い所で使う** | **メニューを開く**（下） |

### 1-1. 範囲を足すとき、何が点になるか

> ### **範囲の中の「立てる面」だけを拾う**
>
> 範囲そのものは持たない。**選んだ瞬間に点へ畳む。**

| 条件 | |
| --- | --- |
| **足元** | **実体のあるブロック。** 空・液体・**半ブロック・階段・柵・板ガラス・草・松明・絨毯**などは駄目 |
| **頭上** | **その上 2 マスが空**（敵が埋まらない） |
| **範囲の外** | **±50 の外は拾わない**（`14-map-build.md` 0-1） |

**同じ点は 2 度入らない。**

> ### **実体のあるブロックからしか湧かせない**（2026-09-06）
>
> `Block.isSolid` は**この版の API に無い**（`isAir` / `isLiquid` だけ）ので、
> **名前で見分ける**（`core/spawnmark.ts` の `isFullBlock`）。
> **半ブロックや草の上から湧く**のを止めるため。**取りこぼしがあれば表に足す。**

> ### **空気は指定できない**（2026-09-06）
>
> **単体指定でも同じ物差しを使う。** 空・頭上が塞がっている所・±50 の外は**足さない。**
> **外すのはいつでもできる**——地形を直したあとの掃除に要るため。

### 1-2. メニュー

| | |
| --- | --- |
| **どのマップのものか** | **いま編集しているマップ名**を選ぶ／変える |
| **数** | いま何点あるか |
| **見る** | **点の上に粒を出す**（10 秒。近くの 200 点まで） |
| **全部消す** | そのマップの点を捨てる |

## 1-3. **消し杖**（`pve_v3:erasewand`・2026-09-07 追加）

> ### 範囲で消す口が無かった
>
> **範囲でできるのは「足す」だけ**だった。**消すのは 1 マスずつか、全消しか。**
> **地形を直したときに、その一帯だけ落としたい**ことがある。

**杖と同じ持ち方。違うのは向きだけ。**

| 操作 | 杖（`spawnwand`） | **消し杖（`erasewand`）** |
| --- | --- | --- |
| **ブロックを殴る** | 1 点目 | **1 点目**（同じ） |
| **ブロックを右クリック** | **範囲を足す** | **範囲の中の点を、全部外す** |
| **しゃがんで右クリック** | 1 マス足す／外す | **1 マス外す**（無ければ何もしない） |
| **何も見ずに右クリック** | メニュー | **同じメニュー** |

> ### **見るのは、覚えている点だけ**
>
> 足すときは**ブロックを 1 マスずつ見る**（重い）。
> **消すときは地形を見ない**——**覚えている点のうち、箱に入るものを落とすだけ。**
> **一瞬で終わる。**

| | |
| --- | --- |
| **使えるのは** | **運営だけ**（杖と同じ） |
| **どのマップか** | **杖と同じ選び方**（`/pve:marks <名前>`。**そのマップの上に立っていること**） |

## 2. 持ち方

```
ワールドの動的プロパティ  pve_v3:spawn:<マップ名>
```

| | |
| --- | --- |
| **1 点** | **3 バイト**（x＋50, z＋50, y＋50。どれも 0〜255 に収まる） |
| **並べ方** | 3 バイト × 点数を **base64** にした文字列 |
| **目安** | **1000 点で約 4 KB** |

> ### **上限に当たったら分ける**
>
> 動的プロパティ 1 本には上限がある。**溢れたら `…:2` `…:3` と続ける。**
> **読む側は、無くなるまで順に読む。**

> ### マップを焼き直しても、点は残る
>
> **点はマップ名で引く**ので、`/pve:mapsave` をやり直しても消えない。
> **地形を大きく変えたら、点も選び直すこと。**

## 3. 使う側（湧かせるとき）

| | |
| --- | --- |
| **選ぶ** | 登録された点から選ぶ。**プレイヤーの半径 3 マス以内は避ける**（`16-enemy.md` 3-4-1） |
| **点が無い** | **雑魚を出せない。** 運営に「このマップに湧き点が無い」と伝える |
| **点が足りない** | **同じ点を何度使ってもよい**（2026-09-06 決定）。100 体に点 20 でも回す |
