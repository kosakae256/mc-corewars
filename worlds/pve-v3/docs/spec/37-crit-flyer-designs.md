# 痛恨の一撃と飛行の専用外観

対象は実装済みの `crit` / `flyer`。既存の攻撃力・確率・移動・当たり判定は維持し、
仮スティーブを専用のテクスチャ・ジオメトリ・アニメーションへ置き換える。

## 飛行

羽のある女の子。既存ワールドに合わせたRPG風で、細い3px幅の腕、空色と白の衣装、
淡い青紫の髪、金の小さな飾り。背中から左右一対の白い羽が生える。
羽は根元と先端を持つ立体の羽毛形状で、左右対称に羽ばたく。
飛行姿勢は腕を少し開き、脚を揃え気味に後ろへ流す。髪と衣装にも控えめな揺れ。
近接時は既存の同期済み攻撃時計に専用の腕の振りを合わせる。

## 作成と確認

imagegenでモデルへ貼るテクスチャのタイルシートを作成し、原画とプロンプトをuser配下に保存。
専用UVの128x128アトラスへ最近傍縮小し、低解像度のドット感を保つ。
画像をコードで描き直さず、骨・キューブ・UVとアニメーションを生成する。
既存のhumanoid互換ボーンを維持し、頭の追尾・ダメージ色・鼓舞の演出も引き継ぐ。
実アセットの正面・側面・背面と時系列画像を確認し、npm run check後に開発パックへ配置。

再生成は `tools/pve3-crit-flyer-texture.ps1` → `tools/pve3-crit-flyer.py`。
原画と生成プロンプトは `user/crit-flyer-designs/`、実使用画像は
`textures/entity/pve3/{crit,flyer}_rpg_v1.png`。旧画像は保持する。
`tools/pve3-crit-flyer-preview.py` は配置対象の参照をたどり、
`out/crit-flyer/index.html` に待機・羽ばたき・攻撃の再生画面と6方向の画像を作る。
上体の傾きは腰の骨を使い、首付近を中心に傾けて腰と脚が離れることを避ける。
攻撃は既存の `pve_v3:swing`（10→0）を0〜0.5秒へ変換して同期。
汎用の腕振りは専用動作へ置換する。部位名・頭の追尾・共有エフェクト参照は維持。

## 痛恨の一撃

ユーザー選択で棍棒を持つ鬼・魔物。くすんだ緑の肌、太い眉、牙、短い角。
暗い鉄と赤茶の布、金の留め具でRPG風にまとめる。
肩当て・手甲・ブーツ・腰布と太い棍棒を立体化し、普通のスティーブと輪郭で区別する。
腕は通常幅を基にがっしりした外装。棍棒を構え、既存の攻撃時計で勢いのある振り下ろしと戻しを再生。
通常攻撃と痛恨の確率・ダメージは変更しない。今回は共通の攻撃モーションを使用する。

## 今回の検証・配置

飛行は26ボーン・60キューブ、痛恨の一撃は30ボーン・37キューブ。
各128x128テクスチャ、全キューブのUV境界・親子関係・名前の重複を確認。
正面・左右・背面、羽ばたきの上下、棍棒の振り下ろし途中を実アセットで描画して確認。
`npm run check` は108テスト成功、BP62件・RP61件・アニメーション61件・姿勢37件すべて成功。
RP 1.0.208を開発パックへ配置。プレビューで読んだ全アセットのハッシュが配置済みファイルと一致。
実機の見た目・動作は確認待ち。ワールド再入場でリソースパックを読み直す。

## 羽が動かない問題の修正

飛行の羽ばたき定義に`.25`・`.6`など先頭ゼロのない時刻があるため、`0.25`・`0.6`へ正規化する。
生成器と出力JSONをともに直す。骨・振幅・周期は維持し、姿勢検査にも時刻文字列の形式検査を加える。
実機ContentLogの19:29:02に、両翼の`.25`・`.6`について`child not valid here`を確認。
修正後は実アセットの0秒/0.25秒をプレビューで描画し、両翼が上下することを確認した。実クライアントでの再生は再読み込み後に確認する。
