# 溜め始めた射撃を撃ち切る

ユーザー指定: ブレイズは溜め始めたら、標的が射程外へ出ても3連射を撃ち切る。
2026-09-11: 撃ち始める機会が少ないため、開始射程を15から30マスへ拡大する。
弾の最大飛距離は共通の射程2倍に従い60マス。溜め4秒・3発・発射間隔0.3秒・弾速0.75マス/tickは維持。
接近中は経路探索が体の向きを決める。Scriptの照準による向きの上書きは実際の発射時だけ行い、
移動しながら溜める際に壁を回る向きと競合させない。照準位置は溜め中も更新する。
呪いは個体の攻撃間隔/基本間隔の比で溜め・連射間隔を短縮する。

2026-09-11追加: 発射前の溜め中、胴体の周囲に橙色の炎をまとわせる。
`charge.particle`で指定する短命の粒をScriptから4tickに1度生成し、初弾から後は新しく生成しない。
粒はバニラの炎テクスチャを使い、1回8粒・寿命0.35～0.55秒。胴体を囲む範囲から上昇する。
既存のcharged発光は維持する。呪いで溜めが短縮されれば演出も同時に終わる。
パーティクル生成の失敗で攻撃の時計を止めず、死亡・消滅時は追加生成を止める。

`charge.commit`を持つ射撃だけScriptで時計と標的を保持する。
開始時のみ射程・射線を検査。距離が変わっても同じ標的の位置へ向く。
追加指定によりブレイズは溜め中も10マスまで接近し、3連射中だけ接近を止める。
`charge.approach: 10`で、攻撃開始射程30と位置取りの距離10を分ける。
射程外・遮蔽時も同じ接近AIを継続する。10マス以内で射線があれば停止し、離れられたら追う。
`charge.approach`のない敵は従来どおり溜め中も停止する。
壁の後ろへ移動した相手へも発射動作は完了するが、弾は従来どおり壁で止まる。
標的が死亡・退出・別次元・クリエイティブ/観戦になったら最後の照準へ撃ち切る。
撃った本人の死亡・消滅・アンロード時は中断し、時計を掃除する。
3発目の後で停止を解除し、次の溜め開始時に射程と射線を検査し直す。接近の再開で射撃の時計は初期化しない。

BPのブレイズから通常/呪い各段のnative ranged_attackを外して重複射撃を防ぐ。
代わりに`minecraft:is_charged`の部品群を溜め開始で追加、連射終了で解除し、既存の発光と炎を維持する。
弾は既存mobshotの発射部分を共用し、同じ粒・当たり・ノックバック・ばらつきを使う。発射音も維持する。

検証: 射程外への退避、連射中の退避、壁、標的無効化、呪い、死亡と再読み込み、native重複射撃の防止を確認する。
