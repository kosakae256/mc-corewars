# カウボーイの拳銃

2026-09-10、ユーザーが指定スキン `user/cowboy.png` に合わせた拳銃の生成と装備を依頼。
構えのアニメーションは散弾と同じものを使う。

追加指定: リボルバーは片手で構える。カウボーイ専用`animation.pve3.pistol.hold`へ分け、
右腕・銃の位置は維持し、左腕の回転は[0,0,0]へ上書きして下ろす。散弾の両手構えは維持。

## 外見と配線

- 西部劇風のリボルバー。銀灰色の銃身、木製グリップ、控えめな真鍮色。64×64のアイコン。
- 内蔵画像生成で新規作成。原稿・指示を `user/cowboy-pistol/` に保存。
- `pve_v3:pistol` を別アイテムとして作成し、カウボーイの右手装備に指定する。
- アイコンの不透明画素を押し出した専用geometryを作る。厚み0.9モデル単位を基準とし、散弾銃より短くする。
- 腕は既存の `animation.pve3.gun.hold` を参照する。持ち物も `animation.pve3.gun_item.shotgun` を再利用。
- 拳銃専用attachableと装備条件のcontrollerを作る。画像のグリップを手の基準点へ合わせる。
- 既存の射撃処理・発射間隔・弾の威力と速さはそのまま使用する。
- 指定スキンの弾幕・カウボーイとまとめて検査・配置する。銃の構えを複数方向のプレビューで確認する。

## 配置結果

RP1.0.189へ配置済み。全パック検査合格。原稿は内蔵画像生成、64角への変換は最近傍。
生成器 `tools/pve3-pistol.py` は46cube、グリップ座標(53,38)、1px=0.14、厚み0.9。
`tools/pve3-gunrig.py` の既定引数で散弾模型が変化しないことも確認した。
実データの構えは `out/user-skins/gunner-views.png`。ゲーム内の最終確認は未実施。
既存カウボーイは出し直して装備を更新する。
