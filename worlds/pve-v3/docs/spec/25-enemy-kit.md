# 仕様: 敵の共通部品

現在の遠距離AI・追尾弾の頻度・遮蔽判定は [38-ranged-ai-and-cover.md](38-ranged-ai-and-cover.md) を優先する。
本文の固定砲台・距離維持・追尾弾2秒周期は旧仕様。射程外または射線なしでは接近し、射程内かつ射線ありで停止する。

**2026-09-08 に作った。** **残り 37 体を作る前の土台。**

---

## 0. なぜ先に作るのか

> ### **同じ仕組みを、敵ごとに書かせない**
>
> **爆発を使う敵は 5 体いる**（クリーパー・帯電クリーパー・爆弾・ボマー・ガスト）。
> **別々に書けば、5 種類の爆発ができる。**
> **見た目も、押す強さも、当たる範囲も、微妙に違うものが 5 つ。**
>
> **仕組みは 1 つ、値は敵ごと。**

```
roster.ts の EnemyDef ── 旗を書くだけ（fall / lob / beam / sweep / aura / blink）
       ↓ services/traits.ts が読む
services/ の共通部品（boom / zone / sweep / beam / lob / aura / ailment / onfall）
       ↓
core/tuning.ts の既定値（**調整はここ 1 箇所**）
```

**敵を 1 体足すのは「`roster.ts` に 1 行」だけ。** **コードは書かない。**

### 調整のしかた

| 変えたいもの | どこ |
| --- | --- |
| **全部の敵に効く既定値**（爆発の半径、毒の刻みなど） | **[`core/tuning.ts`](../../packs/pve_v3/scripts/core/tuning.ts)** |
| **その敵だけの値** | **`roster.ts` の `EnemyDef`** |
| **仕組みそのもの** | `services/<部品>.ts` |

## 2. 爆発（`services/boom.ts`）

```
中心 ── 力そのまま・押す強さも最大
  │      外へ行くほど、まっすぐ減る
  └── 半径で 0
```

| 決まっていること | |
| --- | --- |
| **巻き込む相手** | **プレイヤーだけ。** **仲間の敵には当たらない** |
| **押す強さ** | **必ず弾く**（[07-enemy-plan.md](../07-enemy-plan.md) 6 章）。**中心ほど強い** |
| **浮かせる** | **爆発だけの例外**（[22-feedback.md](22-feedback.md) 6-2） |
| **地形** | **壊さない** |

**既定値は `BOOM`**（半径 4／押す 3.0／浮き 0.55）。

---

### 2-0. **爆発は必ず浮かせる（浮）**

| | |
| --- | --- |
| **上へ飛ばす強さ** | `BOOM.up`（既定 **0.55**）。**敵ごとに変えるなら `EnemyDef.boom.up`** |
| **効き方** | **中心ほど高く、縁で 0**（押す強さと同じ減り方） |
| **書き忘れない** | **`services/boom.ts` が必ず渡す**ので、**爆発する敵は全部浮く** |

**性能表の「押」に `（浮）` と書いてある**（[07-enemy-plan.md](../07-enemy-plan.md) 6 章）。
**浮かせるのは爆発だけ**——**ほかの攻撃では浮かせない**（[22-feedback.md](22-feedback.md) 6-2）。

### 2-2. **見た目は半径で変える**（2026-09-09）

| 半径 | 真ん中 | 輪の粒 |
| --- | --- | --- |
| **3.5 以上** | `minecraft:huge_explosion_emitter`（**50 粒を広く撒く**） | **半径 × 1.5 と × 2.5** |
| **3.5 未満** | `minecraft:large_explosion`（**粒 1 つ**） | 同上 |

> ### **小さい爆発が広く見えていた**（ボマー・2026-09-09）
>
> **`huge_explosion_emitter` は大きさを持たない**——**半径 2 でも 4 でも同じ広さに撒く。**
> **輪の粒も 16 個で固定だった**ので、**小さい円では重なって塊に見えた。**

### 2-1. **爆ぜた後は、円を出さない**（2026-09-09 決定）

**一度は「届いた範囲」を爆発の瞬間に敷いてみたが、要らないと言われた。**
**もう終わったことを見せても遅い。**

**円を敷くのは、爆ぜる前だけ**——**爆弾の予告**（[24-mob-howto.md](24-mob-howto.md) 16-8）。
**爆発そのものの見え方は、中心の大きい粒 ＋ 輪の粒 2 重**（`services/boom.ts` の `draw`）。

## 3. 山なりに投げる（`services/lob.ts`）

| 敵 | 飛距離 | 着弾まで | 見て避けられるか |
| --- | --- | --- | --- |
| **投石ハスク**（★2） | **7 マス** | **0.5 秒**（10 tick） | **無理** |
| **ボマー**（★3） | **10 マス** | **1.5 秒**（30 tick） | **避けられる** |

> ### **「何マス先へ、何 tick で」から逆算する**
>
> **水平の速さ** ＝ 距離 ÷ tick 数。
> **上向きの速さ** ＝ 落ちる速さ × tick 数 ÷ 2（**投げた高さに戻ってくる**）。
>
> **速さを指定させると、狙った所に落ちない。** **落とす所を指定させる。**

**`boomRadius` を書けば、着弾で爆ぜる**（ボマー）。**書かなければ当たった点で小さく効く。**

**飛ぶものは `body` で実体にできる**——**ボマーは `pve_v3:minibomb`**（爆弾の小さい版）、
**劇薬は `pve_v3:flask`。** **そのときは `noTrail` で跡を消す。**

### 3-3. **落ちてから爆ぜる**（`lob.fuse`・ボマー・2026-09-09）

**着弾した所に爆弾を置く**（`services/onfall.ts` の `putBomb`）。
**死に際に落とす爆弾と、まったく同じ仕組みを通る。**

| | |
| --- | --- |
| **待つ長さ** | **30 tick（1.5 秒）** |
| **半径** | **2 マス**（爆弾の 4 より小さい） |
| **見た目** | **膨らんで赤く点滅 ＋ 範囲の円が地面に出る**（16-8） |
| **散らばり** | **`lob.scatter`**（ボマーは 3 マス）——**必ず当たると、避ける遊びが無い** |

> ### **投げる前に、相手のほうを向く**（2026-09-09）
>
> **経路探索は「歩く先」を向くだけ。** **投げる敵は、横を向いたまま投げていた。**
> **`faceAt`**（`services/traits.ts`）**で、投げる瞬間に体を向ける。**

### 3-0. **毒の瓶**（劇薬・2026-09-09）

| | |
| --- | --- |
| **溜め** | **20 tick**（1 秒）。**腕を振り上げてから離す**（`lob.windup`） |
| **投げ方** | **山なり。** **着弾まで 14 tick**——**長いと山が高すぎて、頭の上から湧いて落ちるように見える** |
| **出どころ** | **胸**（`at.y + 1.1`） |
| **飛ぶもの** | **瓶の実体**（`pve_v3:flask`）。**跡は出さない** |
| **落ちた所** | **半径 2.5 の毒だまりが一瞬**（`pve_v3:venom_circle`・**中まで塗りつぶした緑**）＋ **緑の飛沫**（`pve_v3:venom_splash`） |
| **効き目** | **その円の中に居た人に毒**——**1 秒に最大 HP の 4 % を 5 回**（合計 20 %・5 秒） |
| **音** | **`random.glass`**（バニラのガラスが割れる音） |
| **間合い** | **3 マス。** **`behavior.avoid_mob_type` で下がる**（14-2） |
| **爆発** | **しない** |

> ### **山なりは「高さ」ではなく「時間」で決まる**（2026-09-09）
>
> **上向きの初速 ＝ 落ちる速さ × tick 数 ÷ 2。**
> **`flight` を伸ばすほど高く上がる**——**30 tick だと 3 マス以上真上へ飛ぶ。**
> **「投げつける」に見せたいなら、`flight` を短くする。**

> ### **力 0 のつもりでも爆発していた**（**踏んだ**・2026-09-09）
>
> **`attackOf` は必ず 1 以上を返す**（`core/enemy.ts`）。
> **`power <= 0` で止める書き方では止まらなかった。**
> **毒で削る敵は、毒だけ**——**`poison` を書いたら、そこで終わり。**

### 3-1. **投げる敵は腕を振る**（2026-09-09）

**`lob.arc` を書いた敵は、投げた瞬間に `services/swing.ts` を回す。**
**弓を引く敵**（`bow_and_arrow`）**と違い、投げる動きはバニラの部品に無い**——
**`pve_v3:swing` から `variable.attack_animation_tick` を作って、殴りの腕振りを流用する。**

### 3-2. **投げた物の見た目**（`body` / `noTrail`・2026-09-09）

| | |
| --- | --- |
| **軌跡**（`trail`） | **通った跡に粒を置き続ける。** **速い弾を「線」で見せるためのもの** |
| **物**（`body`） | **弾に連れて飛ぶ実体。** **模型があるので、粒と違って「物」に見える** |
| **`noTrail`** | **跡を出さない。** **`body` と組で使う** |

> ### **粒では「物」に見えない**（2026-09-09）
>
> **一度は「1 tick に 1 粒だけ置く」で済ませようとしたが、
> 遅い弾では点が並んで、やはり跡に見えた。**
> **遅く飛ぶ物は実体を連れる。**

| 敵 | 物 | |
| --- | --- | --- |
| **投石ハスク**（★2） | `pve_v3:rock` | **灰色の石。** **跡は出さない** |

> ### **連れる実体は、まず出せるようにする**（**踏んだ**・2026-09-09）
>
> **`pve_v3:fireball` は実体そのものが無かった**ので、**「出せなかった」と言われ続けた。**
> **`pve_v3:arrow` は実体があったのに描かれなかった**——
> **`pre_animation` に、その実体が持っていない property を読む式が入っていた。**
>
> | 作るもの | |
> | --- | --- |
> | **ビヘイビア** | `behavior_packs/pve_v3/entities/<名>.json`（**重力なし・当たりなし・押されない・時間で消える**） |
> | **見た目** | `resource_packs/pve_v3/entity/<名>.entity.json`（**`scripts` は書かない**） |
> | **模型** | `resource_packs/pve_v3/models/entity/<名>.geo.json` |
> | **絵** | `resource_packs/pve_v3/textures/entity/<名>.png` |

## 4. 地面に残る円（`services/zone.ts`）

```
敵が倒れる
  └ その場に円ができる（半径 3・5 秒）
       └ 2 tick ごと、中の人へ 最大 HP の 1 %
```

> ### **実体を置かない**
>
> **実体を置くと、当たり判定も AI も付いてくる。**
> **円は「場所と時間」だけ**なので、表に持てば足りる。

## 5. 状態異常（`services/ailment.ts`）

| | 誰が使うか | 中身 |
| --- | --- | --- |
| **鈍足** | 冷気（★2） | **バニラの効果**（`slowness`）をそのまま |
| **毒** | 劇薬（★3） | **最大 HP の割合**を、時間をかけて削る |

> ### **毒にバニラを使わない**
>
> **こちらの HP はバニラの体力ではない**（[24-mob-howto.md](24-mob-howto.md) 4 章）。
> **バニラの毒はバニラの体力を削る**ので、こちらの HP には効かない。

**重ねずに、時間を戻す**——**もう一度受けると残り時間が最初に戻る。削る量は積み上がらない。**

## 6. 弾の向き（`services/steer.ts` ＋ `services/bullet.ts`）

**弾エンジンに 3 つ足した**（2026-09-08）。

| | |
| --- | --- |
| **`gravity`** | **毎 tick、下向きの速さが増える**（山なり） |
| **`homing`** | **毎 tick、いちばん近い人へ向きを寄せる**（0〜1） |
| **`onEnd`** | **誰にも当たらずに終わった**（壁・射程の端）。**爆発する弾はここで爆ぜる** |

> ### **一気に向けない**
>
> **`homing` が 1 なら即座に向く**——**避けられない弾になる。**
> **0.1 ならゆるく曲がる**——**回り込めば振り切れる。**
>
> **追尾弾は 0.15**（2026-09-10 に 0.1 から 1.5 倍にした）。

### 6-1. **壁を無視する弾**（`throughWall`・追尾弾だけ・2026-09-10）

> ### **遠距離の共通判断の、唯一の例外**（`38-ranged-ai-and-cover.md`）
>
> **ほかの遠距離の敵は「射線が無ければ近づく」。**
> **追尾弾は動けない**（`still`）**ので、それだと壁の裏に入られた瞬間に無力になる。**
> **こいつだけ、壁越しに撃つ。**

| | |
| --- | --- |
| **撃つとき** | **射線を見ない**——**壁の裏に居ても撃ってくる** |
| **弾と壁** | **当たっても消えない。** **壁の手前で向きを変えて、迂回する** |
| **迂回の仕方** | **進む先が塞がっていたら、上・左右へ順に振って、通る向きを探す**（`services/bullet.ts`） |
| **完全に囲まれていたら** | **そのまま進む**——**消えるよりは通り抜ける。** **避け続けるしかない敵、という性能** |

### 6-1-1. **消えるのは時間だけ**（`shotLife`・2026-09-10）

| 消える理由 | |
| --- | --- |
| **当たった** | 消える |
| **時間切れ** | **20 秒**（400 tick）で消える |
| **距離** | **見ない**——**`shotLife` を書いた弾は、射程で消えない** |
| **壁** | **消えない**（6-1） |

### 6-1-2. **狙う相手は、撃った瞬間に 1 人決める**（`lockOn`・2026-09-10）

> ### **いちばん近い人へ寄せると、集団の真ん中へ吸い込まれる**
>
> **`steer` は毎 tick「いちばん近い人」へ向きを寄せる。**
> **人が動くと狙う相手も入れ替わるので、弾は誰にも当たらず群れの中心をうろつく。**

| | |
| --- | --- |
| **選び方** | **撃った瞬間、100 マス以内の人から**——**ランダムに 1 人** |
| **その後** | **その人だけを追い続ける**（近い人が居ても乗り換えない） |
| **その人が居なくなったら** | **いちばん近い人へ戻る**（消えはしない） |

**「自分が狙われている」が分かる**——**避ける相手が決まっているほうが、逃げ方を考えられる。**

**逃げ切るのではなく、当てさせないように動き続ける**——それがこの敵の要求。

### 6-1. **弾幕の玉**（`orbit`・2026-09-10 に作り直した）

**追加変更（同日・[spec/36](36-barrage-bullet-look.md)）:** 下記の実体方式は負荷が大きいため退役。
現在の弾幕は `orbit.sprite: pve_v3:barrage_bullet` を使う。丸い白芯・青緑の32×32画像を
4tickの短寿命パーティクルで直進表示する。弾エンティティを生成せず、固定した軌跡も出さない。
当たり・速度・射程・発射方向は以下の数値を維持する。下表の実体名は旧方式の記録。

> ### **粒の跡ではなく、物を飛ばす**
>
> **軌跡の粒は「線」に見える。** **弾幕は「玉が飛んでくる」のが見えないと避けられない。**
> **実体を飛ばして、跡は出さない**（投石ハスクの石と同じ考え・3-2）。

| | |
| --- | --- |
| **玉** | `pve_v3:orb`——**東方の弾幕をイメージした玉**（**白い芯 ＋ 青緑の身 ＋ 濃い縁**） |
| **跡** | **出さない**（`trail` を書かない） |
| **速さ** | **0.225 マス／tick**（1 秒に 4.5 マス）。**0.1 → 0.15 → 0.225 と、2 回 1.5 倍にした**（2026-09-10） |
| **届く距離** | **30 マス**（2026-09-10 に 12 から伸ばした）。**飛びきるのに 134 tick かかる**——**玉の実体の `minecraft:timer` は、それより長くしておく**（12 秒） |
| **当たりの太さ** | **0.9**（2026-09-10 に 0.45 から 2 倍にした） |

**`orbit.body` / `orbit.fat` で、玉と当たりの太さを敵ごとに書ける。**

### 6-2. **弾幕は飛んで、20 マスまで寄る**（2026-09-10）

> ### **うろつくだけでは、弾が当たらない**
>
> **人を追わない敵は、射程 30 の外に居ることのほうが多かった。**
> **「飛行」と同じ作りにして、20 マスまでは寄る**——**そこから先は寄らない。**

| | |
| --- | --- |
| **飛び方** | **`fly`（ミツバチの形）**——`movement.hover` ＋ `navigation.hover` ＋ `can_fly`（11 章） |
| **寄る距離** | **`behavior.move_towards_target` の `within_radius: 20`**——**公式に「相手から居たい距離」とある** |
| **移動速度** | **0.5**（飛ぶ敵の物差し。`baseSpeed` 0.15） |
| **殴らない** | **`noMelee`**——**20 マスで止まるので、そもそも殴る間合いに入らない** |
| **止まらない** | **`random_stroll` の `interval: 1`**（14-2）——**寄り終えた後も、その場でうろつき続ける** |

**当たり判定は 1 マスに切る**（`navigation.hover` は小さい体を想定している・11 章）。

## 7. 薙ぎ払い（`services/sweep.ts`）

| 使う敵 | 形 |
| --- | --- |
| **回転**（★2） | **全周**（`angle: 360`・半径 4） |
| **妖狐**（★5） | **前方の扇** |
| **散弾**（★4） | **前方の狭い扇 ＋ `hits: 50`** |

> ### **50 発飛ばすと重い**
>
> **弾は 1 発ずつ毎 tick 進める。** **50 発 × 敵の数だけ増える。**
> **当たりはその場で決めて、見た目だけ出す**（[07-enemy-plan.md](../07-enemy-plan.md) 散弾）。

**`hits` は「同じ人に何回当たるか」。** **2 回目からは押さない**（吹き飛びが重ならないように）。

### 7-2. **散弾は実体のある弾を飛ばす**（`buck`・2026-09-09 に作り直した）

> ### **その場で当たりを決めると、避ける手が無い**
>

```
味方が居る ── 味方に寄る（follow_mob・優先度 1）

   └ 居ない ── 人から逃げる（avoid_mob_type・優先度 2）
                  └ それも無い ── うろつく（random_stroll・優先度 7）
```

**味方が居る限り、逃げるより寄るほうが勝つ**（`07-enemy-plan.md` 恵み）。

| 部品 | 値 | |
| --- | --- | --- |
| **`follow_mob`** | `search_range: 24` / `stop_distance: 3` | **公式**: *Allows the mob to follow other mobs.* **3 マスで止まる**ので、**効き目の半径 5 の中に必ず入る** |
| **`avoid_mob_type`** | `max_dist: 10` / `max_flee: 12` | **10 マス以内に人が居たら下がる。** **12 マスで止まる** |

> ### **踏んだもの**（2026-09-09）
>
> | | |
> | --- | --- |
> | **`aura.keepAway` は旗だけ** | **動かしている所が無かった** |
> | **`move_around_target` は「寄る」足でもある** | **帯より遠いと近づく**——**「寄りながらうろつく」動きの正体。外した** |
> | **`ignore_visibility` の既定は `false`** | **見えていないと逃げない。** こちらは `must_see: false` で狙うので、**必ず `true` にする** |

### 10-1. **帯電の落雷**（2026-09-10）

> ### **どこまで巻き込んだのかが、見えていなかった**
>

## 11. 飛ぶ（`fly`）——**ミツバチの形**

**2026-09-08 に 4 回作り直した。** **最後に行き着いたのがこれ。**

### 11-1. **バニラの飛ぶモブを全部読み比べた**

| バニラ | 構成 | 人を追うか |
| --- | --- | --- |
| **コウモリ・ガスト** | `navigation.float` ＋ `float_wander` | **追わない**（狙う部品を持たない） |
| **ファントム** | `movement.glide` ＋ **経路探索なし** ＋ `swoop_attack` | 急降下だけ |
| **ヴェックス** | `navigation.walk` ＋ `physics.has_gravity: false` | 追うが、**地面の経路を空で辿る**ので不安定 |
| **ミツバチ** | **`navigation.hover` ＋ `movement.hover` ＋ `flying_speed`** | **追う。空中で経路を引く** |

> ### **`navigation.hover` の公式の説明**
>
> *Allows this entity to generate paths **in the air** like the vanilla Bees do.
> **Keeps them from falling out of the skies** and doing predictive movement.*

### 11-2. **こうする**

```json
"minecraft:movement.hover": {},
"minecraft:navigation.hover": {
  "can_path_over_water": true, "can_sink": false,
  "can_pass_doors": true, "can_path_from_air": true,
  "avoid_water": true, "avoid_damage_blocks": true
},
"minecraft:can_fly": {},
"minecraft:flying_speed": { "value": 0.15 },
"minecraft:physics": {}
```

| | |
| --- | --- |
| **重力は切らない** | **`navigation.hover` が浮かせる。** **切ると摩擦も消えて、止まれなくなる** |
| **速さは `flying_speed`** | **`minecraft:movement` とは別**（公式: *Speed in Blocks that this entity flies at*・既定 0.02） |
| **攻撃はそのまま** | **`melee_box_attack` も `ranged_attack` も、空中の経路の上で噛み合う** |

> ### **踏んだ間違い**（全部やった）
>
> | やったこと | どうなったか |
> | --- | --- |
> | `movement.fly` ＋ `navigation.fly` | **人を襲わない。** 飛び方も不自然 |
> | `navigation.float` ＋ `float_wander` | **飛び回るだけで追ってこない**（コウモリの部品） |
> | 経路探索を外して script で動かす | **経路探索と綱引き。** 上へ上がり続けた |
> | `navigation.walk` ＋ 重力オフ | **追うが、地面の経路を空で辿る。** 摩擦が無く速すぎる |
> | `float_wander` を `has_move_control: false` で併用 | **公式**: *false なら他の移動ゴールと同時に動ける*——**追いながら勝手な方へも動いた** |

### 11-3. **飛ぶ速さは部品群で差し替える**（実測・2026-09-08）

> ### **`minecraft:flying_speed` は、効果でも属性でも伸びない**
>
> **移動速度のポーションを掛けても、飛ぶ速さは変わらない**——**バニラのミツバチで確かめた。**
> **`minecraft:movement` を上げても変わらない。**

**だが JSON に書いた値は効く**——**2.0 にしたら、はっきり速くなった。**

**攻撃速度と同じ手を使う**（[24-mob-howto.md](24-mob-howto.md) 3 章）:

```
pve_v3:fly_100 → flying_speed 0.50   （素）
pve_v3:fly_293 → flying_speed 1.46   （呪い ×2.93）
… 41 段
```

**湧いた瞬間に段の部品を足す**（`services/flyspeed.ts`）。**`value` の書き換えには頼らない。**

| 値 | 見え方 |
| --- | --- |
| **0.15**（ミツバチ） | **遅い** |
| **0.5** | **これを既定にした** |
| **2.0** | **めちゃくちゃ速い** |

> ### **呪いの移動速度は 1 個で ×1.05**
>
> **`core/curse.ts` の `STEP.speed = 0.05`**（上限 ×3）。
> **数個では目で見て分からない。** **「乗っていない」ように見えるのはこれ。**

### 11-4. **script が足すもの**（`services/hover.ts`）

**経路探索は横の道は作るが、「相手の頭上にいたい」までは面倒を見ない。**

| | |
| --- | --- |
| **高さの帯** | **`EnemyDef.hover`**（狙う人から見て `min`〜`max` マス上） |
| **やり方** | **帯から出たときだけ、上下に弱く押す。** **横には触らない** |

**壁を抜ける**（ファントム）**は `ghost`**——`physics.has_collision: false` を足す。

### 11-5. **当たり判定**（`minecraft:collision_box`）

**飛ぶ敵は 1 マス角までにする**（`pve3-newmob.mjs` の `FLY_BOX`）。

> **`navigation.hover` を使うバニラは全部小さい**——
> **ミツバチ 0.55 × 0.5 ／ アレイ 0.35 × 0.6 ／ オウム 0.5 × 1.0。**
> **背の高い体だと、1 マスの段差に引っかかって進めなくなる。**

**`tallFly` を書いた敵だけ、この上限を外す。**

| | |
| --- | --- |
| **見た目とは別** | **公式**: *collision_box — Sets the width and height of the Entity's collision box*。**`minecraft:scale` は見た目だけを変える。片方だけ変えられる** |
| **ひな形は触らない** | **`pve3-mobjson.mjs` は当たり判定を書き換えない**（`24-mob-howto.md` 5 章）。**手で書いた値はそのまま残る** |

**上限より大きくしている敵**:

| 敵 | 当たり判定 | なぜ |
| --- | --- | --- |
| **ガスト** | **1.5 × 1.5** | **当てにくいので広げた**（2026-09-09）。**見た目は 0.25 倍のまま変えない**——**当たり判定だけ 1.5 倍** |

## 14. **殴らない敵**（`noMelee` / `roam`）

> ### **「寄る」と「削る」は別物**（2026-09-08 に 2 度直した）
>
> **`minecraft:behavior.melee_box_attack` は「殴る」部品に見えるが、
> ひな形の中で**目標へ寄る唯一の部品**でもある。**
>
> **一度これを丸ごと外した。** **すると:**
>
> | 敵 | 何が起きたか |
> | --- | --- |
> | **クリーパー** | **近づけない** → **導火線に火が付かない** → **一生爆発しない** |
> | **ボマー** | **投げる間合いに入れない** |
> | **爆弾** | **寄ってくるだけ、が成立しない** |

**正しい形**:

| | やること |
| --- | --- |
| **ビヘイビア** | **`melee_box_attack` は残す**（寄るため）。**`minecraft:attack` の力を 0** |
| **script** | **`services/enemydef.ts` の `hitsInMelee()` が `false` を返す** → 当たっても削らない |

### 14-1. **殴りで削らない敵**（`hitsInMelee`）

| 条件 | なぜ |
| --- | --- |
| **`noMelee: true`** | 表に「近接は無い」「攻撃しない」と書いてある（爆弾・ボマー・劇薬・帯電） |
| **`kind: "boom"`** | **クリーパーの攻撃は爆発だけ** |
| **`sweep` を持つ** | **回転・妖狐・散弾。** **当たりは薙ぎ払いが決める** |

> ### **薙ぎ払う敵が二重に当てていた**（実測・2026-09-08）
>
> **回転は近接と薙ぎ払いが同じ間隔で回っていた。** **半径 4 の中に居ると 10 ＋ 10。**
> **表の備考は範囲攻撃しか書いていない。**

### 14-2. **寄りもしない敵**

| 条件 | なぜ |
| --- | --- |
| **`aura` を持つ** | **恵み・鼓舞は「プレイヤーから 10 マス以上離れていたい」。** 寄る動きと綱引きになる |
| **`roam: true`** | **弾幕は「プレイヤーを追わず、ずっとランダムウォーク」。** 狙う部品も、殴られて狙う部品も外す |

> ### **うろつく敵は、止まらないようにする**（2026-09-10）
>
> **`behavior.random_stroll` の `interval` は「1/interval の確率でこの目標を選ぶ」**（既定 120）。
> **そのままだと、歩いては立ち止まる。** **`interval: 1` にすると、着いた次の拍でまた歩き出す**——
> **止まることがない。**

> ### **速さ 0 だけでは止まらない**（**踏んだ**・2026-09-09）
>
> **カウボーイを移動速度 0 にしたのに、普通に歩いて寄ってきた。**
> **実体に「寄る足」が残っていた**——
> `melee_box_attack`（`noMelee` のはずなのに付いていた）と `move_around_target`。
>
> **止まって撃つ敵から外すもの**:
>
> | | |
> | --- | --- |
> | `behavior.random_stroll` | **じりじり歩き回る** |
> | `behavior.melee_box_attack` | **「殴る」だけでなく「寄る」役でもある**（11 章） |
> | `behavior.move_around_target` | **相手の周りを回る** |
> | `pushable_by_entity` / `pushable_by_block` | **押されると、表示だけが取り残される** |
>
> **`movement` と `navigation` は残す**——**外すと弾を撃たなくなる**（`ranged_attack` が動く部品を前提にしている）。

> ### **動かない敵は、向きも自分で作る**（**踏んだ**・2026-09-09）
>
> **歩く敵は経路探索が向き直してくれるが、動かない敵はそれが無い。**
> **カウボーイは相手を見ずに撃っていた。**
>
> | | |
> | --- | --- |
> | **普段** | **`behavior.look_at_target`**（公式: *Allows the mob to look at the entity they are targeting.*）。**既定は 8 マス・確率 0.02** なので、**`look_distance` と `probability` を書き直す** |
> | **撃つ瞬間** | **script で向ける**（`faceAt`）——**「たまに見る」では、撃つ瞬間に向いている保証が無い** |

### 14-3. **撃つ敵に `lob` を書くとき**

**ガストは `kind: "shoot"` と `lob` を両方持つ。**

| | |
| --- | --- |
| **弾を出すのは `mobshot.ts`** | バニラの `ranged_attack` が種を出し、それを自前の弾に差し替える |
| **`services/throw.ts` の `doLob` は走らせない** | **両方走ると 1 周期に 2 発撃つ**（実測） |
| **重力は掛けない** | **`mobshot` は相手へまっすぐ狙う。** **そこから落ちると狙いが外れる**（15 マス先を 30 tick で狙うと 13 マス沈んだ） |

**`lob` のうち使うのは `boomRadius` だけ**——**当たった所・届いた所で爆ぜる。**
