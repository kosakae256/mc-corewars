## 1. パック

| | |
| --- | --- |
| 場所 | [packs/pve_v3/](../../packs/pve_v3/) |
| BP | `pve_v3` … `blocks` / `entities` / `items` / `scripts` |

| 名前空間 | **実体・道具・粒は `pve_v3:`**／**動的プロパティは `pve3:`**／**コマンドは `pve:`** |

```bash
cd worlds/pve-v3/packs/pve_v3
npm run local-deploy      # ビルドしてゲームへ
```

## 2. 機能（6 つ）

**`scripts/features.ts` の並びが、そのまま tick の順番**（[imp.md](../../../../docs/imp.md) 10-1）。

```
damage → growth → bow → mob → portal → hud
```

| 機能 | 場所 | 何をするか |
| --- | --- | --- |
| **damage** | `features/damage/` | **手応えと数字の配線**（削る仕事そのものは `services/combat.ts`） |
| **growth** | `features/growth/` | **ステータス強化を買う・足の速さを効かせ直す** |
| **bow** | `features/bow/` | 右クリックで撃つ・弾を進める・当てる |
| **mob** | `features/mob/` | モブを湧かせる・殴らせる・HP を持たせる |
| **portal** | `features/portal/` | ゲートを通さない・飾りを敷く |
| **hud** | `features/hud/` | 名札・アクションバー・ハートを消す |

## 3. ダメージ

**`hit()` が唯一の通り道**（`services/combat.ts`）。**層は [12-architecture.md](12-architecture.md)。**

```
最終攻撃力 → 防御率で削る → HP を引く → 0 なら倒れる
                                  ↓
                          当たった後のフック（基礎だけ）
```

| | |
| --- | --- |
| **防御率** | **いまは誰も持たない**（`defenseOf()` が 0 を返す）。硬さは HP だけ |
| **基礎 / 追加** | `kind: "base" | "extra"`。**追加からはフックを呼ばない**（追加が追加を呼ぶのを止める） |
| **HP** | **バニラの体力は使わない。** 動的プロパティで持つ（`state/hp.ts`） |
| バニラのダメージ | **打ち消す**（`events/hurt.ts`）。**通すのは `/kill` と `override` だけ** |

### 3-1. 手応え（`features/damage/feedback.ts`）

| | |
| --- | --- |
| 赤く光る | 実体の属性 `pve_v3:hurt` を **10 tick** の間 true |
| 音 | **殴った本人にだけ**鳴らす（`game.player.hurt`）。**場所からは鳴らさない**——弓は 48 マス届く |
| ノックバック | **プレイヤーが受けたときだけ**（水平 0.9 / 垂直 0.35） |
| 数字 | **敵にだけ**出す。`pve_v3:dmg` を **24 tick** 浮かべる |

## 4. 弓

| | 値 | 場所 |
| --- | --- | --- |
| 撃ち方 | **右クリック。ためは無い。押しっぱなしで連射** | `features/bow/index.ts` |
| 間隔 | **10 tick ÷ 攻撃速度。溜め方式**（[15-growth.md](15-growth.md) 3 章） | 同上 |
| 弾速 | **4 マス/tick**（80 マス/秒） | `features/bow/shoot.ts` |
| 当たりの算数 | **`core/geometry.ts`**（純粋。テストがある） | `tests/core.test.ts` |
| 射程 | **48 マス** | 同上 |

| 当て方 | **点ではなく区間**——1 tick に 4 マス進むので、点で見ると隙間を抜ける | 同上 |
| 壁 | `getBlockFromRay` で探し、**外したら 0.25 マス刻みで触って確かめる** | 同上 |
| 軌跡 | `pve_v3:arrow_trail` を **0.7 マスおき** | 同上 |
| 味方 | **素通りする**（プレイヤーと `pve_v3:ally`） | 同上 |

### 4-1. 当たったときの見え方（2026-09-02 決定）

> ### 弓の通常ヒットは、**クリティカルの粒**を使う
>
> **v2 の「通常ヒット」の粒（`hit_burst` 1 枚）は、弓には弱すぎた。**
> **刺さった手応えは、光の筋があって初めて出る。**

**クリティカルが出たときだけ、音が足される**（`random.anvil_land`）。

## 5. 攻撃力（`services/attack.ts`）

**v2 の式から、札の項を全部外した。** いまは**素の値とクリティカルだけ。**

| | 値 |
| --- | --- |
| **通常攻撃力** | **20** |
| **特殊攻撃力** | **20**（**使う所はまだ無い**） |
| **クリティカル威力** | **2.0 倍** |
| **クリティカル率** | **0％**——**伸ばす手段がまだ無いので、1 度も出ない** |
| **攻撃力**（買う） | **1.0〜5.0。** 通常攻撃力に掛かる |

```
1 発 ＝ 通常攻撃力(20) × 攻撃力 × クリティカル威力
```

## 5-1. ステータス強化（`features/growth/` ・ `services/growth.ts` ・ `core/growth.ts`）

**仕様は [15-growth.md](15-growth.md)。数値は仕様どおり入っている。**

| | 初期 | 1 回 | 上限 | 効いている所 |
| --- | --- | --- | --- | --- |
| **HP** | 100 | ＋50 | 40 回 | `features/mob/` の `baseHp()` |
| **足の速さ** | 1.0 | ＋0.025 | 40 回 | **実体イベント** `pve_v3:spd_1000`〜`spd_5000`（**161 段**） |
| **攻撃速度** | 1.0 | ＋0.05 | 40 回 | **弓の溜め**（`features/bow/`） |
| **攻撃力** | 1.0 | ＋0.1 | 40 回 | `services/attack.ts` の `buildShot()` |

| | |
| --- | --- |
| **値段** | **50 × n**（n はそのステータスの n 回目） |
| **エメラルド** | **数で持つ。**アイテムにしない |
| **足の速さの段** | **`tools/pve3-player-move.py` が `player.json` に書く**（0.025 刻み・1.000〜5.000） |
| **効かせ直し** | **5 tick ごとに、いまの値と違えばイベントを投げる**（`/reload` でも戻る） |

**ショップはまだ無い**——**買うのはコマンド**（9 章）。
**エメラルドの入手条件（キル／アシスト／クリア）も、まだ無い。**

## 6. モブ（`features/mob/index.ts`）

| | 値 |
| --- | --- |
| `pve_v3:grunt` の HP | **500** |
| 攻撃力 | **20** |
| 殴る間隔 | **20 tick（1 秒）** |
| 届く距離 | **2.5 マス** |
| 湧かせる上限 | **20 体** |
| プレイヤーの HP | **100**（`/pve:hp` で 1〜1000） |

**モブの殴りも `hit()` を通る**——通り道は 1 本。

**HP を持っていない実体には、毎周期で持たせる**（[imp.md](../../../../docs/imp.md) 10-7
「覚えるより、あるべき姿へ寄せる」）——`/reload` で記録が消えても戻る。

## 7. ネザーゲート（`features/portal/`）

**二段構え。**

```
毎 tick   足元か頭が minecraft:portal → 直前の安全な場所へ戻す
次元変化  オーバーワールド以外        → 元の場所へ引き戻す（保険）
```

> ### 「行く前に止める」だけでは足りない
>
> **次元移動を打ち消せる before イベントが無い**（`playerDimensionChange` は after だけ）。

**飾りのブロック `pve_v3:portal`** は、**バニラのアトラス名 `portal` をそのまま参照**する——
**アニメーションもバニラのまま動く。** 当たり判定は無く、光る（`light_emission: 11`）。

**カスタムブロックはワールド読み込み時にしか登録されない**——
**`/reload` では出てこない。入り直す。**

## 8. HP 表示（`features/hud/`）

| 何 | どこ | 中身 |
| --- | --- | --- |
| **名札** | 全員に見える | 名前／帯（20 目盛り・25％ ごとに色が変わる）／`HP 320/500` |
| **アクションバー** | 本人だけ | 自分の HP ＋ **狙っている敵**の HP（10 目盛り） |
| **ハート** | — | **消す**（5 秒ごとに消し直す。再入場や `/reload` で戻るため） |

**書き直すのは 2 tick に 1 回**——毎 tick 書くと文字が点滅する。
**中身が変わったときだけ `nameTag` を書く**（控えと比べる。読み返さない）。

## 9-1. 開発用の道具

**遊ぶ人には配らない。** `features/devtools/`。

| 道具 | 出し方 | 何をするか |
| --- | --- | --- |
| **境界の棒** | `/give @s pve_v3:border_wand` | **右クリックした場所の真下（y ＝ −64）に `border_block` を置く** |

> ### なぜ y ＝ −64 なのか
>
> **`border_block` は、置いた所から上下いっぱいに壁を張る。**
> **世界の底に 1 つ置けば、その柱が上まで通れなくなる**——
> **平面図を描く感覚で、地面を叩いて回れる。**

**状態は見ない**（[17-state.md](17-state.md) 4 章の例外）。**棒を持っている人にだけ効く。**

**弓は `/give @s pve_v3:bow`。**

## 9-2. チェストの盤面

**`worlds/core-wars` から持ってきた道具**（`scripts/vendor/chest-ui/`）。

| | |
| --- | --- |
| **RP 側** | `resource_packs/pve_v3/ui/`（`_global_variables.json` ほか 4 枚）と `textures/ui/` |
| **大きさ** | **27（縦 3 × 横 9）だけ**を有効にしてある |
| **持ち物欄** | **出さない**（`$show_inventory: false`） |

> ### 2 か所を必ず揃える
>
> **`ui/_global_variables.json` の `$show_inventory`** と
> **`scripts/vendor/chest-ui/constants.js` の `inventory_enabled`**。
> **ずれると、押した場所と押された物がずれる。**
