# 仕様: 手応え（当たった・受けた）

**2026-09-06 に書いた。** 実装は `packs/pve_v3/scripts/services/feedback.ts`。
**削る流れそのものは [11-damage.md] ではなく `services/combat.ts`**（通り道は 1 本）。

> ### 手応えは「見える・聞こえる・動く」の 3 つ
>
> **数字だけでは、当たったことが分からない。**

| | 誰に | いつ |
| --- | --- | --- |
| **赤くする** | 受けた実体 | **毎回。** モブは**バニラの被弾演出**（7 章）、プレイヤーは揺れ |
| **当てた音** | **殴った本人だけ** | 通常攻撃のときだけ。**`random.anvil_land`／音量 0.35／高さ 1.9** |
| **受けた音** | **受けた本人だけ** | **毎回。必ず** |
| **ノックバック** | **プレイヤーだけ**（既定） | 殴った相手が居るとき |
| **画面の揺れ（小）** | 受けたプレイヤー | **毎回**（2026-09-06 追加。0.12 秒・強さ 0.06） |
| **大ダメージの揺れ** | 受けたプレイヤー | **最大 HP の 24% 以上を持って行かれたとき** |

## 1. 受けた音は、**必ず鳴る**（2026-09-06 決定）

> ### 「何で削られたか」より、「削られた」が先
>
> **奈落に落ちたときも、毒でも、爆風でも鳴らす。**
> **鳴らない削られ方があると、HP が減った理由が分からない。**

**当てた音**（殴った側）は今までどおり**通常攻撃のときだけ**——
毎秒刻むものでも鳴らすと、鳴りっぱなしになる。

## 2. 大ダメージの演出（2026-09-06 追加）

| | |
| --- | --- |
| **出す条件** | **削られた量が、最大 HP の 24% 以上** |
| **やること** | **体から赤い粒が噴き出す**（2026-09-07 に、音と揺れはやめた） |
| **粒** | `pve_v3:hurt_burst`。**小さい赤い点が 22 粒、胸のあたりから散って、地面に落ちる** |
| **誰に** | **受けた本人だけ** |

**受けるたびの揺れ**（0.12 秒・強さ 0.06）も別に出している。**大きいほうはそれより強い。**

> ### なぜ「最大 HP の割合」なのか
>
> **固定値だと、HP の大きい人には何も起きない。**
> **いまの HP で見るのも駄目**——**瀕死のときは擦り傷でも「大ダメージ」**になる。

### 2-2. **揺らしているのは `camerashake` ではない**（2026-09-06 に突き止めた）

> ### **`camerashake` は処理から外した**（2026-09-08）
>
> **「成功」を返すのに何も起きない**ので、**流すだけ無駄だった。**
> **揺れは `damage` コマンドが出している**——**バニラの被弾の揺れ 1 本。**


> ### そもそも、何を受けても揺れなかった
>
> **このゲームはバニラのダメージを全部打ち消している**（`events/hurt.ts`）。
> **だから被弾の揺れも音も起きない。** HP はこちらが別に持っている。

**`camerashake` は「成功」を返すのに、何も起きなかった。**
**バニラの被弾の揺れを借りることにした。**

| | |
| --- | --- |
| **やり方** | **1 だけ本物のダメージを入れて、同じ tick で体力を戻す** |
| **原因** | **`override`**——`events/hurt.ts` が打ち消さない唯一の原因 |
| **安全** | **バニラの体力は 1000**（`entities/player.json`）。**1 tick に何発入っても、戻す処理が間に合う** |
| **強さ** | **選べない。** バニラの揺れは 1 種類だけ |
| **`camerashake`** | **一応流す。** 効く端末なら、そのぶん強く揺れる |

> ### 短い間に何度も揺れない
>
> **バニラの無敵時間（10 tick）に飲まれる。**
> **0.5 秒に 1 回まで**——連打されても、そのぶんは揺れない。

### 2-1. **画面を赤くするのは諦めた**（2026-09-06）

**4 通り試して、全部駄目だった。**

| 試したもの | 駄目だった理由 |
| --- | --- |
| **自前の霧**（`fog push`） | **コマンドは通るのに、何も見えない**（`0〜10` まで詰めても） |
| **`camera.fade`** | **一度必ず塗り潰す。** 濃さを選べず、**合計 0.5 秒より短くできない**（下回ると既定の 3 秒に落ちる） |
| **バニラの被弾表示** | **Bedrock にそんな表示は無かった。** Java の話だった |
| **自前の板を HUD に重ねる** | **HUD が壊れた。** 赤い枠が出っぱなしになり、他の表示も消えた |

> ### 学んだこと
>
> **`ui/hud_screen.json` に手を入れるときは、書いた要素しか変わらない。**
> **書いていない要素はバニラのまま**——**消せば、勝手に元へ戻る。**
> **タイトルの枠を差し替えてはいけない**（2026-09-06 の失敗）。

**いまは揺れだけ。** 赤くするなら、**HUD を壊さない別の描き方**を見つけてから。

## 3. 出ているか確かめる

```
/pve:hurttest      揺れと赤みを 1 回出す
```

**揺れを出して、ok か理由を出す。**

> ### `camerashake` はチート扱い
>
> **`Player.runCommand` はその人の権限で走る。**
> 権限が無いと弾かれるので、**弾かれたら次元から名前を指して流し直す。**
> **`ok` なのに揺れないのは、端末側の設定**（映像の「カメラの揺れ」）。
> **2026-09-06 に、実際にこれだった。こちらから直せるものではない。**

## 4. 1 tick に何発も入る（確かめた・2026-09-06）

**このゲームは 1 tick に 2 発・3 発と入る**（`11-damage.md` 1-1）。**そこは通っている。**

| 見たもの | どうなっているか |
| --- | --- |
| **削り** | `state/hp.ts` の `damage()` は**読んで引いて書く**だけ。**動的プロパティは書いた値がすぐ読める**ので、2 発目は 1 発目の後の値から引く |
| **無敵時間** | **こちらの HP には無い。** バニラの体力を使っていないので、飲まれない |
| **音・揺れ** | **発ごとに鳴り、発ごとに揺れる** |
| **赤いふち** | **バニラの無敵時間（10 tick）に飲まれる。** 同じ 0.5 秒の中の 2 発目は出ない |
| **体力を戻す処理** | **バニラの体力は 1000。** 1 tick に何発入っても、**戻す前に落ちることはない** |

> ### バニラのハートは隠した
>
> **上限 1000 だと、ハートが 500 個並ぶ。**
> `ui/hud_screen.json` で `heart_renderer` を消した——
> **HP はアクションバーに出している。**

## 5. 当てた音は、**pve-v2 のクリティカル音**（2026-09-06 決定）

| | |
| --- | --- |
| **音** | `random.anvil_land`（金床） |
| **音量／高さ** | **0.35 ／ 1.9**（`pve-v2` の `features/bow/shoot.ts` と同じ値） |
| **散らし** | 高さを ±5% だけ揺らす。**同じ音が続くと機械的に聞こえる** |

> ### 通常ヒットとクリティカルで、音は変えない
>
> **前は `game.player.hurt`（通常）と金床（クリ）で分けていた。**
> **通常のほうに刺さった手応えが無かった。**
> **両方を金床に揃え、クリは光の筋で見分ける**（`features/bow/shoot.ts` の `critFx`）。
>
> **鳴らすのは `services/feedback.ts` 1 か所だけ**——
> 弓の側でも鳴らしていたので、**クリだけ 2 重に鳴っていた。**

## 6. ノックバック

> ### **押すのは、一箇所だけ**（2026-09-08 決定）
>
> **押す処理は `services/knockback.ts` にしか置かない。**
> **飛竜の攻撃も、弾も、範囲も、雑魚の殴りも、全部ここを通る。**
> **`applyKnockback` を直接呼ばない。**

```
攻撃 → services/combat.ts の hit()      ┐
飛竜 → features/boss/util.ts の knockFrom() ├→ services/knockback.ts → applyKnockback
範囲 → features/boss/util.ts の splash()  ┘
```

### 6-1. 押す強さ

**押す強さ ＝ その攻撃の強さ × (1 − 受け手の軽減)**

| | どこで決まる | 既定 |
| --- | --- | --- |
| **その攻撃の強さ** | **攻撃する側が決める。** 敵なら `EnemyDef.knockback` | **0.9**（`core/knockback.ts` の `KNOCK_H`） |
| **受け手の軽減** | **受ける側が持つ割合**（0〜1）。モーション強化で増やす | **0**（軽減なし） |
| **軽減の上限** | **0.9。** **完全には消せない** | — |

> ### **重い敵は強く、素早い敵は弱く**
>
> **敵ごとに `knockback` を書く。書かなければ既定。** **0 と書けば押さない。**
> 湧かせるときに個体へ持たせ（`services/spawn.ts`）、殴るときに読む（`services/melee.ts`）。

> ### **軽減はモーション強化で伸ばす**
>
> **受け手の値は `state/knockback.ts` の `setResist()` で入れる。**
> **プレイヤーにもモブにも同じように効く。**
> **中身（何 % 減らすか）はまだ決めていない**——決まってから書く。

### 6-2. 上へは飛ばさない（2026-09-08 決定）

**浮くと、着地するまで動けない。** **殴られるたびに宙に浮くのは、このゲームに合わない。**
**水平に押すだけ**にして、足は地面に残す。**飛竜の攻撃・弾・範囲も同じ。**

**例外は 2 つだけ。**

| | 上へ飛ばす強さ | どこで書くか |
| --- | --- | --- |
| **爆発** | `BOOM.up`（0.55）／敵ごとに `boom.up` | `services/boom.ts` |
| **ゴーレム**（★5） | **`EnemyDef.knockUp`（0.35）** | `services/melee.ts` の `swingOf` |
| **チェンバー**（★5） | **`EnemyDef.knockUp`（0.35）** | `services/beam.ts`（**一撃が重いので浮かせる**・2026-09-10） |

> ### **ゴーレムだけは殴りでも浮かせる**（`07-enemy-plan.md` 6-5・2026-09-10 に実装）
>
> **「攻撃が全部、少し浮かせるノックバックを持つ」と表に書いてあったのに、
> 殴りの側が上向きの値を持っていなかった**——**書いてあるのに浮かなかった。**
> **`knockUp` を持つ敵は、その一発ごとに上へも飛ばす**（**痛恨の一撃の `crit.up` と同じ通り道**）。

### 6-3. 誰が押されるか

> ### **敵は押されないのが普通**（2026-09-07 決定）
>
> **押すと、多段ヒットの武器が当てるたびに遠ざける。**
> **押したい攻撃だけが、そう言う。**

| | |
| --- | --- |
| **既定** | **プレイヤーが受けたときだけ押す。** モブは押さない |
| **押したい攻撃** | **`hit()` に `knock: true` を渡す**（`services/combat.ts`） |
| **向き** | **殴ってきたものから、受けたものへ**の水平の向き |
| **モブが殴ったとき** | **`hit()` に `source`（そのモブ）を渡す**——`by` はプレイヤーしか入らないため |
| **弾** | **弾の位置から押す**（撃った本人からではない） |

> ### 2026-09-06 に一度「全部押す」にして、戻した
>
> **バニラと同じ手触りに、と考えて全部押すようにしたが、
> 敵が殴るたびに吹き飛ぶのは普通ではなかった。**

## 7. モブの被弾演出（2026-09-07 追加）

**敵に当たったとき、バニラと同じ「赤く光る」を出す。**

```
/damage @s 0 self_destruct
```

| | |
| --- | --- |
| **量** | **0。** **光るだけで、体力は動かない** |
| **原因** | **`self_destruct`**——`events/hurt.ts` が打ち消さない原因なので、演出だけが通る |
| **誰に** | **モブだけ。** プレイヤーは揺れ（2-2） |
| **誰に** | **相手が誰でも。** **プレイヤーもモブも同じ 1 本**（2026-09-08 に統一） |

> ### **プレイヤーだけ別扱いにしない**（2026-09-08 決定）
>
> **前はプレイヤーだけ `applyDamage`（`override`）で揺らしていた。**
> **同じ「削られた」なのに出方が二通りある**のは、追いにくいだけだった。
> **赤く光るのも、画面が揺れるのも、`damage` コマンド 1 本から出る。**
> **`camerashake` はその上乗せ。**

> ### `applyDamage` では代わりにならない
>
> **0 を渡しても何も起きない。** **コマンドでないと演出が出ない。**
> `avoid-unnecessary-command`（この道具の既定の決まり）は、**ここだけ切っている。**

## 8. 音は、**バニラのまま**（2026-09-07 に戻した）

**自前の音を一通り作ったが、雰囲気に合わなかった。**
**大ダメージの音・自前の被弾音・自前のヒット音は、すべて取り消した。**

| 場面 | 音 |
| --- | --- |
| **当てた**（殴った本人） | `random.anvil_land`（金床・高さ 1.9） |
| **受けた**（受けた本人） | `game.player.hurt` |
| **大ダメージ** | **無し。** **赤い粒だけ** |

> ### 残したのは「向きを消す」ことだけ
>
> **`is3D: false`**（`sound_definitions.json`）。**音そのものはバニラのまま。**
> **後ろから鳴ると、ほとんど聞こえない**——それだけを止めている。

**作った道具は残してある**（`tools/pve3-sound.py` ／ `pve3-soundlab.py` ／ `pve3-bighit.py`）。
**また使うときのために。**

## 9. **どこまで聞こえるか**（2026-09-08 決定）

> ### **全部の音が、全員に、同じ音量で届いていた**
>
> **向きを消すために `is3D: false` にした**（1-1）。
> **そのぶん距離も効かなくなり、`max_distance` は 128。**
> **`damage` コマンドは当たるたびに鳴る**ので、
> **敵が 100 体いる戦場では、被弾音が壁になっていた。**

| 音 | 誰に届くか | 音量 |
| --- | --- | --- |
| **自分が受けた** | **本人だけ** | **0.3**（**下げた。前は 0.7**） |
| **他の人が受けた** | **その人から 5 マス以内** | **0.18 から、距離で絞る** |
| **敵が受けた** | **その敵から 5 マス以内** | **0.18 から、距離で絞る** |
| **当てた本人** | **鳴らさない**（2026-09-08 追加） | — |

> ### **当てた人に「相手の被弾音」を鳴らさない**
>
> **当てた合図（金床の音）が別に鳴っている。**
> **殴っている相手は必ず 5 マス以内**なので、**そのままだと毎回 2 つ重なり、
> 「2 発当たった」ように聞こえる。**
| **当てた音**（ヒット音） | **当てた本人だけ** | 0.35（**変えない**） |
| **弓を撃った音** | **撃った本人だけ** | 0.5（**変えない**） |

**距離での絞り方**——**5 マスで 0、近いほど大きい。**

```
音量 ＝ 0.18 × (1 − 距離 ÷ 5)
```

### 9-1. **`damage` の音は殺す。鳴らすのは script**

> ### **`damage` コマンドは消さない**（`24-mob-howto.md` 7 章）
>
> **赤く光らせるのに要る。** **消していいのは音だけ。**

| | |
| --- | --- |
| **`game.player.hurt`** | **音量 0 にする**（リソースパックで上書き）。**`damage` では何も鳴らない** |
| **`pve_v3:damaged`** | **中身は同じバニラの音。** **script が、聞かせたい人にだけ鳴らす** |

**同じイベントで音だけ止めることはできない。** **名前を分けて、片方を黙らせる。**
**音の素材はバニラのまま**（`sounds/damage/hit1..3` を指すだけ。持ち込まない）。

**鳴らすときは必ず `location` に聞き手の頭を渡す**（1-1）——
**渡さないと、後ろから鳴ったときにほとんど聞こえない。**
