# 丸ノコ・爆弾・ボマーの専用模型

2026-09-10 のユーザー依頼。既存の一括生成保留とは別に、この3体の制作を再開する。
低解像度（32×32）のRPG風テクスチャを使用し、リアルな質感は求めない。

## 外見

- 丸ノコ `sawman`: スティーブ相当の骨格を残した、革の作業着と手袋の戦士。
  前方に持つ丸ノコを立体で作り、歯のある円盤だけを軸の周りに常時回転させる。
  胴体に埋めず、右手のグリップと左手の補助持ち手を独立して設ける。
  追加のユーザー希望「回転してるように見える」に合わせ、刃の偏った位置に真鍮色の目印を置く。
  刃の両面から目印が見え、回転対称な歯だけより動きを判別しやすくする。回転周期は0.5秒。
- 爆弾 `bomblet`: 骨の細い腕・脚、空洞のある肋骨、大きめの頭を持つ骸骨。
  腹の前で黒い丸いボムを両手で抱える。布の襟と導火線でRPGらしさを出す。
- ボマー `bomber`: 頭巾とゴーグル、革の爆弾袋を身につけた小柄な投擲兵。
  右手に小さなボム、腰と背中に予備のボム。投擲時に腕を振る。

## 実装

3体に専用のBedrockジオメトリを用意する。32×32の共通アトラスは8×8の区画に分け、
顔と素材を面ごとのUVで参照する。画像生成の原稿とプロンプトを `user/saw-bomb-designs/` に保存。
最終画像は最近傍で32×32へ縮小し、`textures/entity/pve3/saw_bomb_rpg_v1.png` とする。
標準スキンの展開図ではなく、この3体の専用模型用のテクスチャである。

既存の頭・胴・脚の骨名、被弾表示、鼓舞の表示を維持する。
武器や抱えたボムの姿勢は専用アニメーションで制御し、移動中も保持する。
丸ノコの刃は独立した子ボーンで回転し、本体や握りは回さない。
ボマーは既存の攻撃状態に連動して投げる。攻撃力・周期・弾道・爆発範囲・当たり判定は変更しない。
落下／投擲後の爆弾エンティティは既存の実装を使う。

ボマーの現在の `throwOne` は溜め無しの投擲で腕振り時計を開始しないため、
ボマーに限って投擲時に既存の `startSwing` を呼ぶ。
投擲クリップの時刻は `(10 - q.property('pve_v3:swing')) * 0.05` で既存の時計へ合わせる。
時計が正の間はループ可能なクリップを有効にし、再投擲による時計のリセットにも追従させる。
手のボムは発射直後に隠して0.32秒で補充し、待機へ戻ると通常表示する。
保持アニメーションは腕の位置と角度を既定位置へ上書きし、通常の殴りで持ち手がずれないようにする。
`anim_time_update` で外部の進行値へ追従する形式は公式同梱の `axolotl.animation.json` 等を参照。

## 検証と配置

実際のentity・geometry・animation・PNGを読む既存プレビューで、前・斜め・横・後ろを確認する。
回転の異なる時刻、保持姿勢、ボマーの投擲姿勢も確認する。
UVの範囲、骨参照、パック全体を検査後、RP版を上げて開発パックへ配置する。
プレビューとゲームの描画が完全一致したという保証はせず、ゲームでの外見確認の有無を記録する。

## 制作結果（2026-09-10）

- 模型: `models/entity/pve3_{sawman,bomblet,bomber}_rpg_v1.geo.json`。
  丸ノコ19ボーン・69立方体、爆弾18ボーン・37立方体、ボマー21ボーン・70立方体。
- 画像: 内蔵画像生成を使用。原稿 `user/saw-bomb-designs/atlas-source.png`、
  プロンプト `user/saw-bomb-designs/atlas-prompt.txt`。
  `tools/pve3-saw-bomb-texture.ps1` で最近傍の32×32へ変換。
- 再生成: `tools/pve3-saw-bomb.py`。実データのプレビュー: `tools/pve3-saw-bomb-preview.py`。
- 表示画像: `out/saw-bomb-rpg/overview.png`、各敵の `*-views.png`。
  動作: `sawman-motion.gif`／`bomber-motion.gif`、静止コマ比較 `*-motion.png`。
- 検証: `npm run check` 全項目合格。最後の刃の目印追加後もRP・アニメ参照・骨検査合格。
  全UVが32×32内、先行する腕振りでも保持位置不変、左右のグリップ中心が手袋内、
  刃の軸固定とループ接続、投擲時のボム非表示と補充を確認。
  入力ハッシュと追加検査結果は `out/saw-bomb-rpg/{inputs,validation}.json`。
- RP **1.0.196** へ配置。関連RP10ファイルとコンパイル済みスクリプトは配置先と一致。
  プレビューに対してユーザーから「いい感じ」との反応あり。今回のゲーム内表示は確認待ち。
