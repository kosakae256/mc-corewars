# 仕様: 敵個体のひな形

**2026-09-06 に決めた。** 敵グループ（★・数・呪い）は [16-enemy.md](16-enemy.md)。
**ここは「1 体の敵をどう作るか」。**

> ### 敵は 2 段で決まる
>
> ```
> 敵グループ（★）  …… どの種類が、何体出るか      → 16-enemy.md
> 敵個体            …… その 1 体が何をするか        → この文書
> ```

## 0. 決まりごと

> ### **挙動もステータスも、まずビヘイビア側で書く**（2026-09-06 決定）
>
> **`entities/*.json` に書けるものは、そちらに書く。**
> **エンジンが動かすほうが軽い**——100 体を script で毎 tick 動かすのは重い。
>
> **script に持ってくるのは、ビヘイビアで書けないものだけ。**
> **HP・呪い・ウェーブ倍率のような「こちらの数字」**と、
> **「行動をどう選ぶか」**は script。**歩く・登る・押し合う**はビヘイビア。

## 0-1. ひな形が要る理由

**敵は種類ごとに違うが、決まりは全部同じ。**
**固有値の持ち方・強さの計算・索敵・報酬・湧き方**は、1 か所に置く。
**種類ごとに書くのは「固有値」と「行動」だけ**にする。

## 1. 土台

| | |
| --- | --- |
| **実体** | **カスタム実体**（`pve_v3:<id>`）。1 種類 1 ファイル |
| **バニラの体力** | **飾り。** 削るのはこちらの HP（`state/hp.ts`）。バニラのダメージは `events/hurt.ts` が全部打ち消す |
| **経路探索** | **バニラのゾンビと同じ**（`is_amphibious` ／ `can_pass_doors` ／ `can_walk`）。**扉は壊さない**——マップを傷めないため |
| **当たり判定** | **敵ごとに変える**（`minecraft:collision_box`） |
| **押し合い** | **する。** 重ならせない。**`minecraft:pushable_by_entity` を全部の敵に**（無いと**同じ所に重なる**） |
| **タグ** | **ボスかどうかを持たせる**（4 章） |

> ### **重なりは「押し合う部品」で防ぐ**（2026-09-07）
>
> **付けていなかったので、ゾンビ同士が同じ所に重なっていた。**
> **バニラのゾンビと同じ 2 つ**を、**`pve_mob` を持つ実体すべて**に入れた。
>
> | | |
> | --- | --- |
> | `minecraft:pushable_by_entity` | **実体どうしで押し合う** |
> | `minecraft:pushable_by_block` | ピストンなどで押される（バニラに合わせて） |
>
> **カカシには入れない**——**動かない的**なので、押されては困る。

### 1-1. **訓練用のカカシ**（`pve_v3:dummy`）

> ### 動かないテスト用の的が要る
>
> **強さの計算・当たり判定・数字の出方**を確かめるのに、
> **殴り返してこない、死なない的**がいちばん早い。

| | |
| --- | --- |
| **HP** | **無限。** 100 万を持たせ、**毎 tick 満タンに戻す**——**数字は出るが、倒れない** |
| **動き** | **無し。** AI の部品を 1 つも入れない。**押されない**（ノックバック耐性 1） |
| **バニラのダメージ** | **通さない**（`damage_sensor`）。倒れるのはこちらの HP だけ |
| **見た目** | **自作のカカシ**（`models/entity/pve3_dummy.geo.json`）。杭・十字の腕・麻袋の頭・麦わら帽子 |
| **大きさ** | 当たり判定 **0.7 × 1.9**。**見た目は帽子のぶん少し高い** |
| **家族** | **`pve_dummy`。** **`pve_mob` を持たせない**——持たせると**ウェーブが終わらなくなる**（`services/field.ts`） |
| **報酬** | **無し**（エメラルド倍率 0） |
| **出し方** | `/pve:dummy`（足元に 1 体）／ `/pve:dummy true`（**全部消す**）。**ウェーブの敵としては湧かない** |

## 2. 固有値（種類ごとに持つ 5 つ）

| 固有値 | 単位・意味 |
| --- | --- |
| **HP** | そのままの数値 |
| **力** | **攻撃 1 発の元になる値。** 実際のダメージは**行動ごとの倍率**を掛ける（3 章） |
| **移動速度** | **1 ＝ プレイヤーの歩く速度**（4.317 マス／秒）。**2 なら倍の速さ** |
| **攻撃速度** | **大きいほど速い。** **1 ＝ 基準**。間隔は **基準の間隔 ÷ 攻撃速度** |
| **エメラルド倍率** | **基本 1。** 強い個体ほど大きい（5 章） |

> ### 移動速度の 1 は「プレイヤーの歩き」
>
> **バニラの `minecraft:movement` の値とは別物。**
> **1 がプレイヤーの歩きになるよう、換算の定数を 1 か所に置く**——
> **実際の値はゲーム内で測って合わせる。**

> ### 攻撃速度は「大きいほど速い」（2026-09-06 決定）
>
> **呪いは ＋0.05 ずつ積む。** 間隔で持つと**割り算になって分かりにくい。**
> **持つのは速さ。間隔に直すのは使う側。**

## 3. 行動（攻撃）

**1 体は「行動」を n 個持つ。** 基本は 1 個。**複数持つものは、それぞれ中身が違う。**
**組み立て方は飛竜（[18-boss-wyvern.md](18-boss-wyvern.md)・`core/boss.ts`）に倣う。**

| 項目 | 中身 |
| --- | --- |
| **id ／ 名前** | |
| **ダメージ倍率** | **力に掛ける。** 絶対値では持たない |
| **間合い** | 届く距離（マス）。**最短も持てる**（近すぎると使わない） |
| **角度** | 前方何度まで当たるか |
| **溜め** | **始めてから何 tick 後に当たるか。** 複数回当たるものもある |
| **硬直** | 行動の長さ（tick） |
| **クールタイム** | **その行動を次に使えるまで。** **攻撃速度で縮む** |
| **形** | **単体 ／ 範囲（半径）／ 弾** |
| **狙い** | **その行動ごとに決める**（4 章） |
| **音・粒** | **無いものもある** |

### 3-1. 遠距離は**弾を飛ばす**（2026-09-06 決定）

> ### 距離だけ見て当てるのはやめる
>
> **[16-enemy.md](16-enemy.md) 5-1 の「弾は飛ばさない」を取り消す。**
> **実体に当たったときだけヒット**にする。**避けられる。遮蔽物で止まる。**

### 3-3. **振る動きと当たる瞬間を、必ず一致させる**（2026-09-07 決定）

> ### 自前のタイマーで殴らせない
>
> **前は script が「間合いに入って n tick 経ったら当てる」としていた。**
> **振る動きはバニラ、当たるのは script**——**両者がずれて、腕と攻撃が合わなかった。**

| | |
| --- | --- |
| **振る・間合い・向き** | **バニラ**（`melee_box_attack`） |
| **当たった瞬間** | **バニラのダメージを打ち消す、その場でこちらの HP を削る**（`events/hurt.ts` → `services/melee.ts`） |

> ### **バニラのダメージそのものに乗る**（2026-09-07）
>
> **`entityHitEntity`（当たった）ではなく、`entityHurt`（傷ついた）に乗せる。**
> **そこまで来ているということは、バニラが「本当に当たった」と認めている。**
>
> | 勝手に付いてくるもの | |
> | --- | --- |
> | **クリエイティブ** | **殴られない**（バニラが弾く） |
> | **スペクテイター** | 同上 |
> | **無敵時間** | 同上 |

> ### 狙う相手からも外す
>
> **クリエイティブの人は狙わない**——`nearest_attackable_target` の filter に
> **`has_ability: instabuild` を `none_of` で足した**（バニラの shulker と同じ書き方）。

> ### **攻撃速度は、部品の差し替えで効かせる**
>
> **`cooldown_time` は実行中に書き換えられない。**
> **段ごとの部品**（`pve_v3:haste_100` … `haste_300`）**を実体に持たせ、
> 湧いた瞬間に切り替える。**
>
> **段は ×1.0 ／ 1.25 ／ 1.5 ／ 2.0 ／ 2.5 ／ 3.0 の 6 つ。**
> **一番近い段に丸める**（`core/enemy.ts` の `hasteTier`）。
>
> **script 側で間隔を測って当てると、また動きとずれる。**

**移動の動きは、バニラが速さを見て合わせる**（`query.modified_move_speed`）——
**速くすれば足も速く動く。**

### 3-2. どれを出すかは、**行動が決める**

**間合い・クールタイム・ランダム・HP の残り**——**種類ごとに違う。**
**ひな形は「選ぶ仕組み」だけ持ち、選び方は種類ごとに書く**（飛竜の `pickAct` と同じ形）。

## 4. 索敵と狙い

| | |
| --- | --- |
| **範囲** | **100 マス。壁越しでも見つける** |
| **既定の狙い** | **いちばん近い人**（ゾンビのような近接はこれ） |
| **狙いを変える** | **行動ごとに差し替えられる。** ランダムな人を狙う、遠い人を狙う、など |
| **狙い続けるか** | **基本はずっと同じ相手。** ただし**行動が切り替えることがある** |
| **誰も居ないとき** | **バニラのランダムウォーク** |

**AI は固定しない。** **使い回せる部品**として置き、**種類ごとに組み合わせる。**

> ### **狙い方はバニラのまま**（2026-09-07 決定）
>
> **細かく足すと、かえっておかしくなる。**
> `scan_interval` ／ `track_target` ／ `speed_multiplier` ／ `melee_fov` を足したら、
> **数秒おきに立ち止まって狙い直す**ようになった。**全部外した。**
>
> **バニラのゾンビの形をそのまま使い、変えるのは 3 つだけ。**
>
> | 変えるもの | |
> | --- | --- |
> | **距離** | `within_radius` ／ `max_dist` を **100** に |
> | **壁越し** | `must_see` を **false** に |
> | **狙う相手** | **クリエイティブを外す**（`has_ability: instabuild` を `none_of`） |

## 5. 報酬（エメラルド）

**ウェーブごとに、1 体倒したときの取り分が決まる。**

| いつ | いくら |
| --- | --- |
| **とどめ** | **20 × wave × エメラルド倍率 × 丸め係数** |
| **アシスト** | **4 × wave × エメラルド倍率 × 丸め係数** |

> ### **丸め係数はエメラルドにも掛ける**（2026-09-07 決定）
>
> **上限で数を削ったら、1 体あたりの取り分をそのぶん増やす。**
> **135 体ぶんを 50 体に詰めたなら、1 体が 2.7 体ぶんを落とす。**
>
> **もらえる総量を、出た数で変えない**——HP の詰め替えと同じ考え方
> （[16-enemy.md](16-enemy.md) 3-2）。**削らなければ 1.0。**

**運営メニューから呼んだ 1 体は 1.0**（詰め替えが無いので）。

> ### **★ごとの倍率は置かない**（2026-09-06 決定）
>
> **強い個体はエメラルド倍率が高い。**
> **強い個体が多い群れは★が高い。**
> **だから★が高いほど、自然に多く入る。** 別の倍率は要らない。

**[15-growth.md](15-growth.md) 5-1 の「12 ／ 6」は、これに置き換える。**

## 6. 強さの計算（[16-enemy.md](16-enemy.md) 1 章の実体）

```
HP       ＝ 固有値 × 1.1^(wave−1) × 呪い × 丸め係数
力       ＝ 固有値 × 人数倍率 × 呪い
移動速度 ＝ 固有値 × 人数倍率 × 呪い（上限 ×3.0）
攻撃速度 ＝ 固有値 × 人数倍率 × 呪い（上限 ×3.0）
```

| | |
| --- | --- |
| **wave 倍率** | **HP だけ。** `1.1^(wave−1)`。**wave 15 で約 3.8 倍** |
| **人数倍率** | **力と攻撃速度だけ**に `1 ＋ 0.05 ×(人数−1)`。**HP と移動速度には掛からない** |
| **呪い倍率** | **湧いた瞬間に固定。** 途中で強くならない |
| **丸め係数** | **HP だけ。** 数の上限で出せなかったぶんを詰め替える（[16-enemy.md](16-enemy.md) 3-2） |

## 7. ボス

**ボスも同じひな形で作る。** **違うのは印だけ。**

| | |
| --- | --- |
| **印** | **「ボスである」というタグを持たせる** |
| **数** | **必ず 1 体**（取り巻きが付くことはある） |
| **湧く場所** | **雑魚と別にすることがある** |
| **計算** | **同じ。** ただし**人数倍率だけ別の値になるかもしれない**（例: 人数 1 人ごとに HP ＋1.0） |

**いまは印を持たせるだけ。** 中身の違いは、必要になったときに足す。

## 9-1. **グラント**（`grunt`・2026-09-06 に作った）

**ひな形で作った 1 種類目。** 発注は「ゾンビの見た目で、近づいて殴る雑魚。★1 くらい」。

| | |
| --- | --- |
| **id ／ 名前** | `grunt` ／ **ゾンビ**（2026-09-06 に改名） |
| **見た目** | **バニラのゾンビ。** **描画の定義を丸ごと写した**（模型・材質・38 個のアニメ・`pre_animation`） |
| **役割** | **いちばん近い人へ寄って殴る** |
| **固有値** | **HP 40 ／ 力 20 ／ 速度 0.8 ／ 攻撃速度 1.0 ／ エメラルド倍率 1.0** |
| **当たり判定** | 0.6 × 1.9 |
| **行動** | **殴る**（倍率 1.0 ／ 間合い 2.5 ／ 20 tick ごと ／ いちばん近い人） |

### 9-1-1. **追ってこなかった理由**（2026-09-06・**分かった**）

> ### ワールドの難易度が**ピースフル**だった
>
> **ピースフルでは、`monster` の家族を持つ実体はプレイヤーを狙わない。**
> **バニラの AI（`nearest_attackable_target`）を使っている以上、そこに縛られる。**
>
> **飛竜は動いていた**——**あちらは script が動かしている**ので、難易度に関係ない。

**難易度に左右されないよう、`monster` の家族を全部外した**（2026-09-06）。

| | |
| --- | --- |
| **外したもの** | `monster`。**7 体すべて**（雑魚 6 種＋飛竜） |
| **残したもの** | **`pve_mob`**（敵を数えるのに使う・`services/field.ts`）と `mob` |
| **効き目** | **どの難易度でも狙う。** ピースフルでも動く |

> ### **`monster` は持たせない**（これからも）
>
> **難易度でゲームの中身が変わってはいけない。**
> **バニラの敵対判定に乗らない**——狙う相手はこちらで決める。

**前に「`follow_range` が原因」と書いたのは誤り。** それも 16 のままだったので直したが、
**追わなかった理由はピースフル。**

### 9-1-2. **速さと攻撃速度は、湧いた瞬間に入れる**

**ビヘイビアに書いた値は「呪いも人数も無いときの値」。**
**湧かせるときに、その個体へ入れ直す**（`services/spawn.ts`）。

| | どこへ |
| --- | --- |
| **移動速度** | `minecraft:movement` の**現在値を書き換える** |
| **殴る間隔** | **動的プロパティ**（`pve3:swing`）。**攻撃速度で割った後の値** |

**上限は ×3.0**（呪いと同じ・`16-enemy.md` 4 章）。

## 11. モブを作るときに渡すもの（**発注の型**）

> ### 埋める枠は [../templates/enemy-order.md](../templates/enemy-order.md)
>
> **毎回それをコピーして埋める。** ここは中身の説明。

**毎回同じ順で書く。** 抜けがあれば**こちらが仮値を置いて、そう言う。**

### 11-1. **必ず要るもの**

| | 何を書くか |
| --- | --- |
| **① id ／ 名前** | `grunt` のような英小文字の id と、画面に出す名前 |
| **② 見た目** | **バニラの誰を借りるか**、または**自作**（自作なら形を一言） |
| **③ 役割** | **一言で。**「近づいて殴る」「遠くから撃つ」「自爆」「取り巻きを呼ぶ」 |
| **④ 固有値 5 つ** | **HP ／ 力 ／ 移動速度 ／ 攻撃速度 ／ エメラルド倍率**（2 章の単位で） |
| **⑤ 当たり判定** | 幅 × 高さ（マス） |
| **⑥ 行動** | **1 つにつき下の 9 項目**（11-2）。基本は 1 つ |

### 11-2. 行動 1 つぶん

| | 何を書くか | 書かなければ |
| --- | --- | --- |
| **名前** | `殴る` `火を吐く` | — |
| **ダメージ倍率** | **力に掛ける値。** 1.0 が基準 | **1.0** |
| **間合い** | 最短〜最長（マス） | **0〜2.5** |
| **角度** | 前方何度まで当たるか | **90°** |
| **形** | **単体 ／ 範囲（半径）／ 弾（速さ・大きさ）** | **単体** |
| **溜め** | 始めてから何 tick 後に当たるか。複数可 | **6 tick** |
| **硬直** | 行動の長さ（tick） | **溜め ＋ 6** |
| **クール** | 次に使えるまで（tick）。**攻撃速度で縮む** | **20 tick** |
| **狙い** | **いちばん近い ／ ランダム ／ 遠い ／ 指定** | **いちばん近い** |
| **いつ使うか** | 間合いに入ったら／確率／HP が減ったら | **間合いに入ったら** |

### 11-3. **言わなければ、こう作る**（既定）

| | 既定 |
| --- | --- |
| **ボスか** | **雑魚** |
| **索敵** | **100 マス・壁越し** |
| **誰も居ないとき** | **ランダムウォーク** |
| **経路探索** | **バニラの歩行。1 マスの段差は登る** |
| **押し合い** | **する**（ノックバック耐性 0） |
| **火・窒息** | **効かない**（戦場が燃えても死なない） |
| **名前の色** | **赤**（`§c`） |
| **倒したときの粒・音** | **共通のもの** |

### 11-4. **こちらが勝手に決めるもの**（指示は要らない）

## 12. 弾が通るブロック（2026-09-07）

> ### 空気でないだけでは、壁ではない
>
> **はしご・松明・草・カーペットで弾が消えていた。**
> **その中に立っている敵を撃てない。**

| 直したもの | |
| --- | --- |
| **レイ** | `getBlockFromRay` に **`includePassableBlocks: false`**（通り抜けられるものは見ない） |
| **触って確かめる方** | **「水で流されるブロックは、弾も通る」**（`canBeDestroyedByLiquidSpread`） |

**`Block.isSolid` は 2.9.0 に無い**ので、**水で流されるかどうか**で代えている。
