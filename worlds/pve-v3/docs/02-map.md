# 企画: 戦場のマップ

**2026-09-04 決定（仮案）。** **組み立て方は [spec/14-map-build.md](spec/14-map-build.md)。**
ここは**何を作るか**だけ。

## 1. 毎ウェーブ、別のマップになる

| | |
| --- | --- |
| **枚数** | **20 通り**を用意する |
| **選び方** | **完全にランダム。ただし直前 1 回に出たものは選ばない** |
| **いつ変わるか** | **ウェーブごと**（＝1 戦ごと） |
| **隠すか** | **隠さない。最初から 20 通りとも出る** |

> ### 除外するのは「直前の 1 つ」だけ
>
> **同じマップが 2 連続で来ると、変わった感じがしない。**
> **それだけを避ける。** 使い切るまで出さない、といった管理はしない。

## 2. 大きさと位置

```
        z = −50
          ┌──────────┐
x = −50   │          │   x = +50
          │  0, 0, 0 │
          └──────────┘
        z = +50
```

| | |
| --- | --- |
| **広さ** | **100 × 100**（x・z ともに **−50 〜 +50**） |
| **中心** | **0, 0, 0** |
| **実際に使う所** | **中央の 60 × 60 ほど**。外側は壁・景色・落ちる所 |

> ### 位置は動かさない
>
> **どのマップも同じ座標に置く。**
> **ずらすと「マップがずれる」類の分かりにくい事故が起きる。**

## 3. 高さ（**暫定。要確認**）

**ユーザーの指定は縦横だけ。高さは決まっていない。**

| | 暫定値 | なぜ |
| --- | --- | --- |
| **範囲** | **y = 0 〜 63**（64 マス） | **構造物 1 枚の上限が 64**。段を増やすと枚数が倍々になる |

**空中戦のマップも、この 64 マスの中で床を高い位置に置いて作る**——
**下を空にすれば「雲の上」に見える。**

> ### ここは変えられる
>
> **高さを 128 にすると、1 マップの構造物が 2 倍になる**（[spec/14-map-build.md](spec/14-map-build.md) 2 章）。
> **足りなければ増やす。** まず 64 で作ってみる。

## 4. 向きと、置くもの

**どのマップも、この決まりだけは共通にする。**

```
          奥（z ＝ +50）
        ┌──────[ ポータル ]──────┐
        │                        │
        │      中央 60 × 60      │   ← ここで戦う
   x=−50│         (0,0,0)        │x=+50
        │                        │
        └────[ 湧く場所 ]────────┘
          手前（z ＝ −50）
```

| | 場所 | 何のため |
| --- | --- | --- |
| **プレイヤーの湧く場所** | **手前（0, 地面, −40）** | **どのマップでも同じ所に立つ**——迷わせない |
| **ポータル** | **奥の端（0, **0**, ＋40）** | **必ず置く。** 遠くから見えて、向かう先になる。**裏は塞ぐ**（`spec/14-map-build.md` 0-3） |
| **敵の湧く場所** | **奥寄り**（z ＝ ＋10 〜 ＋40 のうち、立てる所） | 手前から押し寄せる形 |

> ### ポータルは「奥に必ずある」ことが大事（2026-09-04 決定）
>
> **どのマップでも、奥を向けばポータルが見える。**
> **地形がどう変わっても、向かう方向は変わらない。**
>
> **役割はまだ決めていない**——休憩所へ戻る出口になる想定だが、
> **いまは「置く」ことだけを決める。**

**地形の都合で真ん中に置けないときは、奥の端でいちばん平らな所へずらす。**

### 5-0. `stronghold` は「ポータル部屋だけ」にしない

> **ポータル部屋 1 つでは狭すぎる**（2026-09-05）。
> **石レンガの迷宮ぜんぶ**を戦場にする——**部屋・通路・図書室・牢**。
> **ポータル部屋は奥の見どころ**として置く（枠だけ。**ゲートの箱には触らない**）。

### 5-0-1. `sanctum` は休憩所と同じ意匠

> **ダンジョンらしいものが少ない**ので足した（2026-09-05）。
>
> **休憩所の神殿**（[spec/14-map-build.md](spec/14-map-build.md) 6 章、`core/rest-temple.ts`）
> **と同じ材料・同じ空気**——**クォーツ、市松の床、列柱、ステンドグラス、シーランタン。**
> **休憩所が「安全な神殿」なら、こちらは「戦う神殿」。**
>
> **同じ見た目の場所が 2 つある**ことで、**世界に筋が通る。**

### 5-1. ばらけ方

**同じ形が続かないように、骨で分けてある。**

| 骨 | どれ |
| --- | --- |
| **平ら**（撃ち合い） | 4・8・14・17 |
| **高低差**（登る・見下ろす） | 1・5・8・12・14・16 |
| **足場が切れる**（落ちる） | 2・3・6・7・12・13 |
| **屋根がある**（屋内） | 7・10・11・15・16・17 |
| **建物が遮る**（迷路） | 4・5・10・11・16 |

> ### 落ちたら死ぬのは 4 つ（2・3・6・9）
>
> **緊張の質が変わる**ので、絞ってある。

> ### 屋内が 6 つある
>
> **天井の高さを間違えると、弓が当たらない。**
> **最初の 1 つ**（`crypt` あたり）**で高さを確かめてから**、残りを作る。
