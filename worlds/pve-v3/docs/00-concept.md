# 企画: PVE v3

**2026-09-04 決定（仮案）。** ここから細かい仕様が枝分かれする。

> ### v2 の企画は引き継いでいない
>
> **札（エンチャント）で組み立てる形はやめた。**
> **伸びるものは、買うステータス 4 本と、拾うモーション強化だけ。**

## 1. 何を遊ぶのか

**ロールを 1 つ選び、30 戦を戦い抜く。**
**戦場は毎回変わる。** 休憩所で強くなり、**次の相手を自分たちで選ぶ。**

```
ロビー ──→ 休憩所 ⇄ 戦場 ── ×30
             ↑        │
             │        └─ 全員死んだ → 終了
             └─ 死んだ人はここで復活
```

| | |
| --- | --- |
| **終わり方** | **30 戦を終える**か、**全滅する**か。その 2 つだけ |
| **1 戦** | 戦場に湧いた敵を**全部倒す** |
| **人数** | 複数人での協力。**人数で敵が変わる**（[spec/16-enemy.md](spec/16-enemy.md)） |

**1 戦 ＝ 1 ウェーブ。** **ウェーブごとにマップが変わる。**

## 2. 3 つの場所

| 場所 | 中心 | 何をする所か |
| --- | --- | --- |
| **ロビー** | **1255, 15, 701** | 試合前に集まる所。**すでに建ててある** |
| **休憩所** | **−2000, 0, −2000** | 買う・選ぶ・復活する。**30 秒** |
| **戦場** | **0, 0, 0** | 戦う。**毎戦つくり直す**（[02-map.md](02-map.md)） |

**ticking area は手動で張る**（自動では張らない）。

## 3. 休憩所で決めること

**30 秒のあいだに、4 つ選ぶ。**

| 選ぶもの | 誰が決めるか |
| --- | --- |
| **次の相手**（3 択・★つき） | **全員で選び、多数決** |
| **モーション強化**（3 択） | **各自。中身も人ごとに違う。取らない自由がある** |
| **ステータス強化**（4 種） | 各自。エメラルドで買う |
| **消費アイテム** | 各自。**次のウェーブへ持ち越せる** |

**奥のポータルに全員入れば、30 秒を待たずに出発する。**

詳しくは [spec/13-flow.md](spec/13-flow.md)。

### 3-1. ★は、リスクとリターン

**★1〜6。高いほど難しい敵の集団が出て、その分エメラルドが多い。**

> ### ブレーキは「死ぬこと」だけ
>
> **★を選んだから後が辛くなる、といった仕掛けは置かない。**
> **その場で勝てるかどうか**だけを見て選ぶ。

## 4. 強くなる道は 2 本

| | 何で伸びるか | どこ |
| --- | --- | --- |
| **ステータス** 4 本<br>（HP・足の速さ・攻撃速度・攻撃力） | **エメラルドで買う** | [spec/15-growth.md](spec/15-growth.md) |
| **モーション強化** | **休憩所の 3 択で拾う** | **ロールごとに違う。中身は未定** |

> ### モーション強化 ＝ **左クリック（特殊攻撃）の中身を変える枠**
>
> **序盤は攻撃力を伸ばすほうが強い。**
> **終盤の敵の伸びには、ここを伸ばさないと追いつかない**——という配分にする。

ロールの構想は [01-roles.md](01-roles.md)。

## 5. 敵も、戦うたびに強くなる

**ウェーブが終わるたび、敵に「呪い」が積まれる**（v2 の仕組みを引き継ぐ）。
**★が「その戦いの難しさ」を、呪いが「進んだぶんの重さ」を担う。**

[spec/16-enemy.md](spec/16-enemy.md)。
