# 企画: 敵をどう揃えるか

2026-09-10 調整: 遠距離16種の位置取りを統一。妖狐は遮蔽物の奥へダメージを与えない。追加調整として命中後の5秒炎上を撤廃し、直接ダメージと炎の演出は維持する。
全rosterの索敵は100マス、名前には `[★N]` を明記する。詳細は [spec/38-ranged-ai-and-cover.md](spec/38-ranged-ai-and-cover.md)。

**2026-09-08 に決め直した。** **前のアイデアは [draft/](draft/) に置いてある**（使わない）。

## 1. 目標

| | |
| --- | --- |
| **合計** | **50 体ほど** |
| **内訳** | **★1 〜 ★5 を、だいたい 10 体ずつ**（**きっちりでなくてよい**） |

**★6 は数に入れない。** **理不尽枠なので、50 体が揃ってから考える。**

## 2. 中核の 10 体

**まず「ものさし」を作る。** **他の敵は、これと比べて語る。**

| | |
| --- | --- |
| **ゾンビ系** | **★1〜★5 に 1 体ずつ。合計 5 体** |
| **スケルトン系** | **★1〜★5 に 1 体ずつ。合計 5 体** |

> ### **中核は、素直に強くなるだけ**
>
> **トリッキーなことをしない。** **上に行くほど、ただ強い。**
> **「★3 のゾンビより硬い」「★4 のスケルトンより痛い」**——
> **他の 40 体を測る物差しになる。**

**★1 の 2 体だけ実装してある。** **★2〜★5 の値も見た目も、まだ決まっていない。**

| ★ | id | 名前 | 実装 | 確認 |
| --- | --- | --- | --- | --- |
| ★1 | `grunt` | **ゾンビ** | **済** | **確** |
| ★1 | `archer` | **スケルトン** | **済** | **確** |
| ★2〜★5 | — | ゾンビ系 4 体 | — | — |
| ★2〜★5 | — | スケルトン系 4 体 | — | — |

> ### **値も見た目も、こちらでは決めない**（2026-09-08）
>
> **性能（HP・力・速度・攻撃速度・押す強さ・エメラルド倍率）も、
> 見た目（大きさ・色・模型）も、本人が決める。**
> **渡されてから作る。**

## 3. 残りの 40 体

**トリッキーなもの・極端な性能のものを混ぜる。**

| | |
| --- | --- |
| **強さの並び** | **★1 が弱く、★5 が強い。** ここは崩さない |
| **アイデアの出どころ** | **こちらで決める**（40〜45 個ほど固める） |

> ### **アイデアはこちらで出す**（2026-09-08 決定）
>
> **Claude に案を出させると、当たりが悪い。**
> **「こういう敵」を渡すので、それを形にする。**

## 3-1. 進め方（2026-09-08 決定）

**1 体ずつ「作って完成」を繰り返さない。** **順番を決めて、まとめて進める。**

| 段 | やること | 誰が |
| --- | --- | --- |
| **1** | **ゾンビとスケルトンを ★1〜★5 まで仕上げる。** **同時に、ひな形と道具を整える** | Claude |
| **2** | **残り 40 体を、アイデアをもらって一気に作る** | Claude（**1 体につき 1 つの下請けに任せる**） |
| **3** | **動かして確認 → おかしいものを直す → OK を付ける**、を繰り返す | 本人 ＋ Claude |

> ### **段 1 が土台になる**
>
> **40 体を一気に作るとき、ひな形が固まっていないと 40 個の穴が空く。**
> **中核 10 体で、作り方・見た目・照合の手順を完成させてから広げる。**

## 3-2. 見た目の方針（2026-09-08 決定）

| | |
| --- | --- |
| **ゾンビ・スケルトン** | **バニラの絵をそのまま使う**（中核なので、見て分かるのがよい） |
| **それ以外** | **バニラの絵をそのままは使わない。** 少し変えるか、自前にする |
| **例外** | **クリーパーのような「その形しかない」モブ**は、そのまま使うこともある |
| **自前の絵** | **カカシのように、模型ごと自前で作る**か、**絵を持ってきて貼る** |

> ### **スキンの出どころ**
>
> **自作するか、どこかから持ってくる**（2026-09-08）。
> **持ってくる場合、配布物に入れるので、使ってよい絵かどうかだけは確かめる。**

## 6. 性能表

**ここが決定表。** **決めたらここに書き、書いてあるものだけ作る。**

| 列 | 意味 |
| --- | --- |
| **見た目** | 借りるバニラのモブ名、または「自前」。**被り物・持ち物もここ** |
| **HP ／ 力** | そのままの数値（ウェーブ倍率・人数倍率・呪いが掛かる前） |
| **速** | **1.0 ＝ 基準**（ゾンビ ★1）。大きいほど速い |
| **攻速** | **大きいほど速い。** 1.0 ＝ 1 秒に 1 回 |
| **押** | 押す強さ（ノックバック）。**0.9 が基準・0 で押さない** |
| **エメ** | エメラルド倍率。**空欄は未決定** |
| **備考** | **その敵の肝。** 特別な動き・見分け方・注意 |
| **採用** | **○** ＝ 作ると決めた ／ **✕** ＝ 見送り。**既定は ✕**——**○ を付けたものだけ作る** |
| **実装** | **済** ＝ 作った ／ **空欄** ＝ まだ |
| **確認** | **確** ＝ 動かして OK を出した ／ **空欄** ＝ まだ |

**各 ★ だいたい 10 体**（**多少前後してよい**）。**採用が ○ になったものだけ、まとめて実装する。**

### 共通の決まり

> ### **爆発する攻撃は、必ず弾く**
>
> **爆発を使う敵は、押す強さを 0 にしない。** **当たったら必ず飛ぶ。**
> **中心ほど強く押し、外へ行くほど弱くなる**（ダメージの減り方と同じ）。
> **爆発だけは上へも飛ばしてよい**——**ほかの攻撃では浮かせない**（[spec/22-feedback.md](spec/22-feedback.md) 6-2）。
> **例外はゴーレム（★5）だけ**——**殴りでも少し浮かせる。**

**いま爆発を持っているもの**: クリーパー（★4）／**帯電クリーパー**（★5）／爆弾（★2）／ボマー（★3）／ガスト（★2）。


> ### **「押」の欄の `（浮）`**（2026-09-09）
>
> **押すときに、上へも飛ばす。** **爆発だけの決まり**（[spec/22-feedback.md](spec/22-feedback.md) 6-2）。
> **爆発する敵は全部そうなる**——**1 本の仕組みを通っている**ので、書き忘れは起きない
> （[spec/25-enemy-kit.md](spec/25-enemy-kit.md) 2 章）。
