## 1. 弓に絞ると、職業は 4 つ

| 職業 | スキル（左クリック） | 何のビルドか |
| --- | --- | --- |
| **弓／通常攻撃のみ** | **無し** | 素の弓。**初見はここから** |
| **弓／爆発矢** | 爆発矢を撃つ | **範囲攻撃** |
| **弓／連射** | 連射する | **手数** |
| **弓／盾** | 盾を召喚する | **耐久・守り** |

**左クリックでスキルを撃つ**（[docs/research/14-left-click.md](../../../../docs/research/14-left-click.md) で拾えることを確認済み）。

## 2. 職業固有のエンチャントがある

**その職業を選んだときだけ出る札。** **スキルの挙動が変わる。**

**「通常攻撃のみ」には固有の札が無い**——素の弓のまま、汎用の札だけで戦う。

### 2-1. ［挙動変化］は**どちらか片方しか取れない**

**取ると、そのスキルが別のものになる札。** 排他。
**どちらを選ぶかが、そのビルドの分かれ道になる。**

> ### Wynncraft の考え方を持ってくる
>
> **ロールを選ぶ → その中で札を選ぶ**の二段。
> 職業が「何をするか」を決め、**札が「どうやるか」を決める。**

### 2-2. **弱い札があってよい**（2026-09-02 決定）

> ### 全部の札に存在意義を持たせなくてよい
>
> **どんなゲームにも、明らかに弱いスキルはある。**
> **それがある分には問題ない。**

**釣り合いを取るときの前提にする:**

| | |
| --- | --- |
| **狙わない** | 全札が同じ強さ。**どれを取っても同じ**になり、選ぶ意味が消える |
| **狙う** | **強い札・普通の札・弱い札が混ざっている。** 見抜くことが上達になる |
| **やめること** | **弱い札を消して回る**こと。数が減り、提示が痩せる |

**ただし「何も起きない札」は別**——**効果が発動しない**（条件が満たせない）のと、
**効果が弱い**のは違う。前者は直す。**後者は放っておく。**

### 2-3. **説明は簡潔に。隠し仕様があってよい**（2026-09-02 決定）

**札に書くのは、何が起きるかだけ。** 数値・条件・例外まで書き切らない。

| | |
| --- | --- |
| **書く** | **何が起きるか**（「盾が壊れたとき、速くなる」） |
| **書かない** | 何％か・何秒か・誰に起きるか・他の札との噛み合い |
| **理由** | **途中参加がある**（[00-concept.md](../00-concept.md) 2 章）。読ませる時間が無い |

**気付いた人が得をする**形にする——**噛み合わせを見つけることが、遊びの中身になる。**

### 2-4. 札には**前提**がある（2026-09-02）

> ### **持っていないと、提示に出ない札がある**
>
> **元からあった考え方をここに書き直す。**
> 札は横並びではなく、**引いた札が、次に出る札を開く。**

| | |
| --- | --- |
| **前提** | その札を持っていないと**提示に出ない** |
| **派生** | 前提を引いた瞬間、**その枝がまるごと提示に入る** |
| **代償** | **提示は 3 枚。** 枝を開くほど、**その枝が提示を埋める** |

**弓の札の前提関係は [../spec/21-cards.md](../spec/21-cards.md) 6 章。**

> ### **強い枝を開くことと、他を諦めることが同じ操作**
>
> **枠を奪い合っているのは「持てる数」ではなく「提示される機会」。**
> **禁止していない。** ただ**出なくなる。**

#### 例: 爆発矢

```
火薬矢（前提）
 ├─［挙動変化］設置 → 地雷になる
 │    └ ワイヤー／設置数／トラップの挙動
 │      ※ ここへ進むと、爆発を強くする札はもう出ない
 └─［挙動変化］単体化 → 1 体を吹き飛ばす一撃
      └ 爆風／巻き込み／爆発の威力
```

**地雷を取った人に「爆風」は出ない。** 爆発しなくなっているので、**意味が無い。**
**強い札を諦めたのではなく、別の強い札のほうへ行った**という形にする。

## 4. 爆発矢の札（書き出し・仮決め）

**既定は「着弾時に爆発する」＝範囲攻撃。**

| 札 | 何が起きるか |
| --- | --- |
| 爆発の威力が上がる | |
| 爆発の範囲が上がる | |
| 爆発時に周囲へバフを撒く | 味方支援へ寄る |
| **［挙動変化］単体化** | **範囲攻撃ではなくなる代わりに、威力が大幅に上がる** |
| **［挙動変化］設置** | **着弾地点にトラップを設置する**（爆発しなくなる） |
| トラップの挙動が変わる | **トラップ間にワイヤーが張られ、継続ダメージ** |
| トラップの設置数が上がる | |
| 爆発の威力に応じて〜 | **（書きかけ。何が起きるか未定）** |
| 爆発に小ノックバックが付く | |
| **爆発が自分にヒットする** | 自爆する代わりに、何かを得る？ |

**まだ足すかもしれない。**

### 4-1. ［挙動変化］が作る分岐

```
爆発矢（既定：範囲）
 ├─［挙動変化］単体化 → 1 体を吹き飛ばす一撃
 └─［挙動変化］設置   → 爆発を捨ててトラップ屋になる
                        └ ワイヤー（継続ダメージ）／設置数
```

**片方を取ると、もう片方は取れない。** 同じ「爆発矢」でも、**別の遊びになる。**

## 5. 連射（仮決め）

**1 秒かけて一直線に連続で撃つ。10 発（1 tick に 1 発）。**
**ほんの少しだけ分散する。反動がある。**

| 札 | 何が起きるか |
| --- | --- |
| **［挙動変化］散弾** | **大きくばらける代わりに、数が大幅に増える** |
| **［挙動変化］多段** | **矢が多段ヒットし、分散が消える。有効射程が短くなる** |
| 弾の数が増える | |
| 弾の威力が上がる | |
| 着弾点に床を置く | **少しだけ移動速度が落ちる、範囲ダメージの床** |
| 反動が消える | |
| 分散が収まる | |
| 味方モブ（コウモリ）を召喚 | **スキルで倒したとき** |
| 攻撃が少し追尾する | |

### 5-1. 追加の案（未採用）

**「回数が多い」を活かす向き**——連射は**固定値**が乗るほど強くなる
（[2026-09-01-build-axes.md](2026-09-01-build-axes.md) 2-1 の算数）。

| 案 | 何が起きるか | なぜ連射向きか |
| --- | --- | --- |
| **集中射撃** | **同じ敵に当てるほど、1 発ごとに固定値が乗る**（10 発目が最も重い） | 回数がそのまま火力になる。**散弾とは噛み合わない**——選択になる |
| **締めの一撃** | **10 発目だけ大きい**（貫通する／爆ぜる） | 撃ち切る動機。多段と相性がよい |
| **貫通** | 弾が敵を抜けて、後ろにも当たる | 散弾と組むと殲滅、単体だと無駄——**分岐が生きる** |
| **反動跳び** | **反動が消えるのではなく、逆に強くなって後ろへ跳ぶ** | 「反動が消える」と正反対の札。**逃げ・位置取りに化ける** |
| **撃ち続けると硬い** | 連射中だけ被ダメージが減る | 立ち止まる代償への見返り |
| **当てると伸びる** | **命中するたびに 1 発追加**（最大 ＋5） | 当て続ける腕前が伸びに変わる |
| **撃ち切ると速い** | 終了後の数秒だけ、通常攻撃の間隔が縮む | スキルと通常攻撃を繋ぐ |
| **落ちた矢** | 撃った矢が地面に残り、拾うとエメラルド | **金**へ寄る枝 |

## 6. 盾（仮決め）

**いかなる攻撃も 1 発だけ無効化する盾を召喚する。**

| | |
| --- | --- |
| **既定の数** | **2**（2026-09-02 決定。札を取る前の数） |
| 付く先 | **自分** |
| 最大数 | **無し** |
| 重ね方 | **スキルを使うと張り直し**（2026-09-02 決定） |

> ### 「更新」＝**張り直し**であって、足し算ではない
>
> スキルを使うと、**いま付いている盾は捨てて、規定の数を付け直す。**
> **積み上がらない**——待つほど固くなる遊びにはしない。
> 「最大数は無し」は**上限の判定を持たない**という意味で、
> **無限に溜められる**という意味ではない。

### 6-1. ［挙動変化］の二択（2026-09-02 決定）

| 札 | 何が起きるか |
| --- | --- |
| **［挙動変化］ガーディアン** | **盾がガーディアンに変わり、自動で攻撃する**（**外さない**）。**20 回攻撃すると消える** |
| **［挙動変化］配る** | **スキルで撃った味方に付く。** 上限 **8**（**複数人が同じ人に付けても 8 まで。古いものが優先**）。**代わりに自分には付かない** |

> ### 上限 8 に達したら、**新しい盾が付かない**（2026-09-02 決定）
>
> **古いものを押し出さない。** 満杯の味方に撃っても、**何も起きない。**
> **配る相手を選ぶこと**が、この枝の腕前になる。

> ### ガーディアンは「盾の読み替え」
>
> **別枠ではない。** **盾が増えるときはガーディアンも増える。**
> 盾の数を増やす札は、そのままガーディアンの数を増やす。

> ### 消えるのは **20 回攻撃したときだけ**（2026-09-02 決定）
>
> **時間切れは無い。** 撃たなければ、いつまでも残る。
> **スキルを使えば張り直される**（6 章）ので、溜め込むことにはならない。

> ### 「配る」が対になる理由
>
> **ガーディアン＝自分の火力**、**配る＝味方の生存**。
> **パーティ前提のゲーム**（1 人でも遊べるが、途中参加もある）で、
> **一人だけ役割が違う職業**があると卓が締まる。

### 6-2. 盾固有の札（仮決め）

| 札 | 何が起きるか |
| --- | --- |
| 盾の数 ＋1 | **スキル発動時に、付与する／される盾の数が増える** |
| **破裂** | **盾が壊れたとき、攻撃してきた相手にノックバックとダメージ** |
| **駆け出し** | **盾が壊れたとき、0.5 秒だけ移動速度 ＋300％** |
| **肩代わり** | **盾に付与者の最大 HP の x％ が乗る。** 壊れたとき**他に盾が無ければ**、**ノックバック無しの貫通ダメージ**を受ける |
| ガーディアンの攻撃速度が上がる | |
| ガーディアンの攻撃力が上がる | |
| **重ね着** | **付いている盾の数に応じて、攻撃力が上がる**（2026-09-02 決定） |
| **取り立て** | **ガーディアンが倒した敵は、エメラルドを多く落とす**（2026-09-02 採用） |

> ### 破裂・駆け出しが起きるのは **盾を付けられている人**（2026-09-02 決定）
>
> **撃った人ではない。** **配る**を取ると、
> **味方の盾が割れたときに、その味方が速くなる／その味方の周りが弾ける。**
>
> **札の効果ごと味方に配ることになる**——
> 盾の数だけでなく、**盾に乗せた仕掛けも渡す。**
> 自分は何も受け取らない代わりに、**盾 1 枚の値打ちが上がる。**

> ### 肩代わりは **最大 HP** を見る（2026-09-02 決定）
>
> **付与時の HP でも、現在の HP でもない。**
> 減っているほど弱くなる作りにすると、**追い込まれてから配れなくなる。**
>
> **x％ の値は未定。**

> ### 「重ね着」は**自分の盾だけ**を数える
>
> **味方の火力を上げる札は入れない**（2026-09-02 決定）。
> 支援は**生存だけ**を担当する——火力まで配れると、支援が万能になる。
>
> **［挙動変化］配る**を取ると自分に盾が付かないので、**この札は死ぬ。**
> **出し分けはしない**——**弱い札があってよい**（2-2）。

> ### ガーディアンの攻撃力は**低く**する
>
> **ガーディアンの取り柄は「外さない」こと。**
> だから**当てるたびに効く札**（状態異常・固定値・回収）と噛み合う——
> **火力そのものではない。**
>
> **その代わり「取り立て」は弱い札になる**——
> 攻撃力が低ければ、ガーディアンが**とどめを刺す機会が少ない。**
> **それでよい**（2-2）。**ガーディアンの攻撃力を上げる札と重ねて初めて活きる**、
> という位置づけにする。

### 6-3. 追加の案（未採用）

**「配る」を取ると支援職になるので、味方を保たせ続けることが得になる札**を厚くしたい。

> **「取り立て」は 6-2 へ移した**（採用）。
> **「手厚い」（味方の盾の数で自分の攻撃力が上がる）は不採用**——
> **味方の火力は上げない**と決めたため。

| 案 | 何が起きるか | 狙い |
| --- | --- | --- |
| **移り気** | **壊れた盾が、近くの盾を持たない味方へ 1 回だけ飛び移る** | 配ると噛み合う。**撒き直しの手間が減る** |
| **返礼** | **盾を付けた味方が敵を倒すと、盾が 1 つ戻る** | **維持のループ。** 前に出る味方を選ぶ動機になる |
| **割って進む** | **全部の盾を消費して、その数だけ範囲攻撃／範囲回復** | 溜めた盾を**使い切る**選択。ガーディアン側とも噛み合う |
| **見張り** | **ガーディアンが、自分の通常攻撃に合わせて撃つ** | ガーディアンを「置物」から「連動」へ |
| **自動配布** | **盾を持たない味方が近くに来たら、自動で 1 つ付く**（間隔あり） | 撃つ手間を減らす代わりに、狙って配れなくなる |
