まず**軸が何本あるか**と、**どう組み合わさるか**を決める。札の中身はそのあと。

## なぜ変えるか

> ### 「見えない数字を買う」がローグライトに合っていない
>
> 炎上・凍結・感電といった**属性そのもの**は、Dead Cells・Hades・Risk of Rain 2 に普通にある。
> 珍しいのは**「属性値に点を振る」形**——それは ARPG / MMO の作り。
> それらの作品では**属性は拾ったモノに付いてくる。**

さらに **ウェーブの途中から参加できる**（[00-concept.md](../00-concept.md) 2 章）。
**説明する機会が無い前提**で組む——**札を数枚配れば成立する形**なら、教えなくてよい。

**作ったものは捨てない。** 炎・氷・雷のエフェクト、状態異常、ダメージ計算は**そのまま使う。**
変えるのは**「数字がどこから来るか」**だけ。

## 1. 軸は 3 段に分ける

> ### 11 本を横並びにすると、全部が薄まる
>
> 1 ゲームで取れる札は **20 枚前後**。11 本なら**1 軸あたり 2 枚**——どれも育たない。
>
> **役割で段を分ける。** 同じ段どうしは**競合**し、違う段は**乗る**。

| 段 | 何を決めるか | 何本 | いくつ選ぶか |
| --- | --- | --- | --- |
| **主軸**（火力の出し方） | **どうやってダメージを出すか** | 5 | **1 本**（2 本目は重い） |
| **副軸**（乗せるもの） | 主軸に何を乗せるか | 4 | **1〜2 本** |
| **汎用** | どのビルドでも入る | — | 余り |

### 1-1. 主軸（5 本）——**ここが競合する**

| 主軸 | 出し方 | 伸びるもの |
| --- | --- | --- |
| **単体火力** | 1 発を重くする | **倍率**（×） |
| **範囲攻撃** | 巻き込む | **巻き込む数・半径** |
| **手数** | 回数を増やす | **発射数・間隔・移動** |
| **延焼（毒）** | 時間で削る | **秒あたりの固定値** |
| **トラップ** | 置いて当てる | **設置数・持続・再設置** |

### 1-2. 副軸（4 本）——**主軸に乗る**

| 副軸 | 何をするか |
| --- | --- |
| **会心** | 会心率・会心倍率 |
| **鈍化** | 止める・遅くする（凍結の蓄積） |
| **耐久** | 被ダメ減・回復 |
| **サポート** | 味方を強くする・蘇生・供給 |

### 1-3. 金——**副軸だが、性質が違う**

**持っているエメラルドが多いほど強い。**
**使うと弱くなる**ので、**買い物と正面から衝突する**——そこが選択になる。

| | |
| --- | --- |
| 効き方 | 所持エメラルドに比例して**最終ダメージに加算** |
| 衝突 | **HP もアイテムも買えなくなる**（守りが薄いまま強い） |
| 相性 | **耐久**と組むと成立しやすい／**サポート**とは噛み合わない |

## 2. 中途半端を弱くする仕掛け

**「盛り方を間違えると微妙になる」を、禁止ではなく算数で作る。**

### 2-1. 効き方の種類を、主軸ごとに変える（疎結合）

> ### 手数が増えても、単体火力がただ上がるわけではない
>
> **単体火力は倍率（×）、延焼は秒あたりの固定値、手数は回数。**
> **種類が違うものは、掛け合わせても伸びない。**

**例**——「攻撃の最終値に ＋10」の札があるとき:

| ビルド | 1 秒あたり |
| --- | --- |
| 単体火力（1 発 100・毎秒 1 発・倍率 ×2） | (100 ＋ 10) × 2 ＝ **220** |
| 手数（1 発 40・毎秒 4 発・倍率 ×1.2） | (40 ＋ 10) × 1.2 × 4 ＝ **240** |

**固定値は「回数が多いほど得」。** だから**手数ビルドは固定値の札を集める**。
逆に**倍率の札は 1 発が重いほど得**——**単体火力が集める。**

**同じ札でも、ビルドによって価値が変わる。** これが疎結合の正体。

### 2-2. しきい値（掛け切ると極致に至る）

**タグ 4 / 8 / 12 で段が上がる。**

| 段 | 何が起きるか |
| --- | --- |
| **4** | その軸が「使える」水準になる |
| **8** | **軸の看板になる効果**が開く |
| **12** | **極致。** その軸だけの、明らかに強い効果 |

**20 枚では、12 に届くのは 1 本だけ。** 2 本に割ると **8 と 8**、
3 本なら **8・4・4**——**極致には届かない。**
**届かないだけで、成立はする**（尖らせない遊び方も選べる）。

### 2-3. 主軸どうしは、譲り合わない

**主軸の札は「その出し方」にしか効かない。**
単体火力の倍率は、延焼にも設置にも乗らない。
**2 本取ると、どちらの札も半分ずつしか活きない**——
**禁止ではなく、単に効率が落ちる。**

> ### 攻撃系を 2 本は「難しいが、できる」
>
> **範囲 ＋ 手数**のように**相性のいい組**はある（弾数が増えれば巻き込みも増える）。
> **単体 ＋ 範囲**は正面からぶつかる（1 発を重くする札と、広げる札が同じ枠を取り合う）。

## 3. 通常攻撃だけでは足りない

> ### トラップとサポートは、弓を撃つだけでは出せない

**札が「新しい行動」を配る**必要がある。

### 3-1. スキルを持つ（2026-09-01 決定）

| | |
| --- | --- |
| 撃ち方 | **左クリック**（`world.afterEvents.playerSwingStart`。`swingSource` で理由が分かる） |
| 選び方 | **ゲーム開始前に 1 つ選ぶ。** 途中で変えない |
| **スキル無しでも始められる** | **通常攻撃 ＋50％。** 初見はこちらで始める |
| ビルドとの関係 | **選んだスキルで、ビルドの軸が決まる。** |
| 札との関係 | **選んだスキルによって、出てくる札が変わる** |

> ### 初見はスキル無しで始める
>
> **途中参加もある**（[00-concept.md](../00-concept.md) 2 章）。
> **何も選ばなくても戦える**状態を先に用意し、
> **分かってきた人だけがスキルを選ぶ。**

**スキルが軸を決めるので、「主軸を 1 本選ぶ」は実質「スキルを選ぶ」**になる。
札の提示も、そのスキルの軸に寄る。

> ### 拾えることは確認した（2026-09-01 実機）
>
> **空振りでも `Attack` が飛ぶ。** 採掘（`Mine`）・設置（`Build`）とも区別できる。
> 詳細は [docs/research/14-left-click.md](../../../../docs/research/14-left-click.md)。
>
> **after イベントなので振り自体は止められない。** 再使用時間はこちらで持つ。

## 3-2. 周回で解放するもの（**再検討中**）

> ### 2026-09-02: **考え直している**
>
> **何も解放しない案もある。** 下は 2026-09-02 に一度決めた内容。

**解放するのは「エンチャント」と「ロール」。** **強さは周回を跨がない。**

| | |
| --- | --- |
| **エンチャントの解放** | そのゲームで使った札が、次の周回からプールに入る |
| **ロールの解放** | 周回で新しいロールが選べるようになる |
| **恒久的な数値強化** | **入れない**（途中参加があるので、数値差は片方を空気にする） |

**解放型**（選択肢が増える）であって、**恒久強化型**（数値が積み上がる）ではない。

## 4. 何が変わるか

| | |
| --- | --- |
| ショップ | **属性を売らない。** 最大 HP・アイテム・引き直しだけ |
| 強くなる道 | **札に一本化**（[00-concept.md](../00-concept.md) 3-1 の「2 本」を書き換える） |
| 属性値 | **買う数値 → 札で溜まるタグ数**。**保存の形はそのまま使える**（`scripts/state/element.ts`） |
| 属性札 26 種 | **タグを付け替える。** エフェクトと状態異常はそのまま |
| 「属性」という語 | **表に出さない。** 札には「延焼」「会心」と、伸びるものを直接書く |
| 途中参加 | **札を数枚配れば成立** |

## 5. まだ決めていないこと

- **スキルは解放の対象か**（ロールに紐づくのか、独立して増えるのか）
- **スキルの数と中身**（軸ごとに 1 つずつか、軸をまたぐか）
- **スキルの再使用時間**（何秒か、敵を倒すと縮むか）
- **しきい値の具体値**（4 / 8 / 12 でよいか）
- **金の係数**（所持エメラルド何個で ＋1 か）
- **提示の寄せ方**（寄せすぎるとビルドが 1 本道になる）
- **1 枚が持つタグ数**（2 個の札をどれくらい混ぜるか）
