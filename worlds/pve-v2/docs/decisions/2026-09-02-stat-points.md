# エンチャントをやめて、ステータスポイントにする（2026-09-02 決定）

> ### これが今のビルドの根元
>
> **[2026-09-02-roles-and-skills.md](2026-09-02-roles-and-skills.md) の「職業固有の札」も、
> [../spec/21-cards.md](../spec/21-cards.md) の 200 枚も、いったん止める。**
> **記録として残すが、実装の拠り所にしない。**

## 1. なぜやめるか

> ### **エンチャントという要素が、だいぶノイズ**
>
> **マイクラをやっている人に、この「エンチャント」は理解されない。**
> バニラのエンチャントとは別物なのに名前が同じで、
> **札の効果・前提・レア度・Focus といった概念を、遊びながら読ませることになる。**

**途中参加がある**（[../00-concept.md](../00-concept.md) 2 章）以上、**説明する機会が無い。**
**読ませないと成立しない仕組みは、この遊びに合わない。**

## 2. 代わりにやること

**ウェーブごとに「何のステータスを伸ばすか」を決める。それだけ。**

| | |
| --- | --- |
| **配り方** | **ウェーブを越えるたび、全員に固定のポイント** |
| **なぜ固定か** | **1 人だけ強くなることを防ぐ**——倒した数で配らない |
| **何をするか** | **どのステータスに振るかを選ぶ** |
| **札** | **無し** |

> ### 稼ぎとビルドを切り離した
>
> **エメラルド（買い物）は今までどおり働きに応じて増える**
>（[../spec/17-level-and-emerald.md](../spec/17-level-and-emerald.md)）。
> **ステータスポイントだけは、全員同じ。**
>
> **上手い人は速く倒せる。でも数値で置いていかれることはない。**

## 3. 特殊能力は、**最初に全部渡す**

> ### 途中から新しい概念が出てこないようにする
>
> **Focus のような仕掛けが、ウェーブ 7 で急に札として出てきても、誰も分からない。**
> **その職業が持つ仕掛けは、始まった時点で全部揃っている**——
> **あとは数字が伸びるだけ。**

| | |
| --- | --- |
| **最初に選ぶ** | **ロール**（弓／爆発矢／トラップ…）。ここは今までどおり |
| **そのとき決まるもの** | **通常攻撃の形・特殊攻撃の中身・固有の仕掛け** |
| **後から増えるもの** | **数値だけ** |

**ビルドの軸は、こちらが固めて渡す。** プレイヤーが軸を組み立てるのではなく、
**選んだロールが軸そのもの**になる。

## 4. 「不自由に選択させる」

**全部のステータスに自由に振れると、正解が 1 つに決まる。**
**選ばせるが、自由にはさせない。**

### 4-1. 案（どれにするかは未定）

| 案 | 中身 | 効き方 |
| --- | --- | --- |
| **提示型** | 毎ウェーブ、**伸ばせる項目が 2〜3 個だけ提示される**。その中から振る | **引きで揺れる。** 札に近いが、**中身は数値だけ**なので読まなくて済む |
| **コスト逓増型** | 同じ項目を伸ばすほど、次が高くなる | **尖らせにくい。** 器用貧乏になりやすい |
| **枠型** | **攻め・守り・機動**のように枠があり、**枠ごとに上限**がある | **配分を考えさせる。** 分かりやすい |
| **ロール制限型** | **ロールごとに伸ばせる項目が違う**（弓は攻撃速度が伸びる、盾は HP が伸びる） | **軸がさらに固まる。** 選択肢は減る |

**提示型 ＋ ロール制限型**の組み合わせが素直だと思う——
**「この職業で伸ばせるものの中から、今回出た 3 つのどれかを選ぶ」。**

### 4-2. 伸ばせるもの（案）

| | |
| --- | --- |
| **通常攻撃力** | 右クリック |
| **特殊攻撃力** | 左クリック |
| **攻撃速度** | |
| **クリティカル率** | 初期 0％ |
| **最大 HP** | ショップでも買える |
| **移動速度** | |
| **回復** | |

**計算の形は変えない**（[2026-09-02-damage-formula.md](2026-09-02-damage-formula.md)）——
**通常攻撃力と特殊攻撃力は別**、**加算が先・乗算が後**。

| | |

## 6. 後半（extra）をどうするか——**これが最大の問題**

> ### 数値が線形なら、指数の敵には追いつけない
>
> **ステータスポイントは足し算。** 敵の HP は extra で **1 ウェーブ 1.25 倍**。
> **個人の数値では、絶対に追いつかない。**

**追いつけないままでよい**（[../spec/16-enemy.md](../spec/16-enemy.md) 5-0）が、
**「どこで力尽きるか」が全員同じになると、遊びが薄くなる。**

### 6-1. 差をどこで作るか

**数値ではなく、この 3 つで差が出るようにする。**

| | 何で伸びるか |
| --- | --- |
| **腕前** | **当てる・避ける・囲まれない。** 実際に出る火力は、当たった数で決まる |
| **編成** | **盾・トラップ・範囲・単体が噛み合うと、掛け算で効く** |
| **ルート** | **どこで戦うか。** 隘路・高台・戻り道——**敵の到達を遅らせれば、削る時間が増える** |

> ### **乗算はプレイヤーの数値に持たせない**
>
> **数値は足し算だけ。乗算は「立ち回り」と「編成」が持つ。**
> こうすると、**上手い卓と下手な卓で、到達ウェーブがはっきり分かれる**——
> **「うまければやれる／組めばやれる／ルートが良ければやれる」**が成立する。

### 6-2. まだ決めていない

- **ルートで差が出る形にするには、マップに何が要るか**（隘路・高台・封鎖できる道）
- **編成の掛け算を、どの仕組みで作るか**（盾の配り・トラップ・範囲の重なり）
- **extra の報酬をどうするか**（ポイントを増やすのか、据え置きか）
