# 攻撃力の計算（2026-09-02 決定）

> ### これが汎用エンチャントの土台
>
> **[../spec/11-damage.md](../spec/11-damage.md)（v1 系の「袋に足す」式）とは別物。**
> 汎用の札を書く前に、**どの数字を動かす札なのか**が言えるようにする。

## 1. 攻撃力は **2 本だけ**

| | 撃ち方 | 式 |
| --- | --- | --- |
| **通常攻撃** | **右クリック** | `通常攻撃力 × クリティカル威力` |
| **特殊攻撃** | **左クリック**（スキル） | `特殊攻撃力 × クリティカル威力 × 特殊攻撃の固有値` |

| 数字 | 初期値 |
| --- | --- |
| **通常攻撃力** | **20** |
| **特殊攻撃力** | **20** |
| **クリティカル威力** | **2 倍**（出たときだけ） |
| **特殊攻撃の固有値** | スキルごと（未定） |

> ### 「基礎攻撃力」は置かない（2026-09-02 決定）
>
> **共通の土台をもう 1 本置くと、割り算が合わなくなる。**
> `基礎 10 ＋ 通常 10` の形だと、**基礎を 2 倍にしても攻撃は 1.5 倍**——
> **札に書いた数字と、実際に起きることがズレる。**
>
> **両方を上げたいときは、2 本ともに効く札を書けばよい。**
> 分母が 1 本なので、**書いた数字がそのまま出る。**

## 2. **「攻撃力」と書いたら、2 本ともに効く**

| 札の言い方 | 効く先 |
| --- | --- |
| **攻撃力** | **通常攻撃力・特殊攻撃力の両方** |
| **通常攻撃力** | 通常攻撃だけ |
| **特殊攻撃力** | 特殊攻撃だけ |

> ### **特殊攻撃力を上げても、通常攻撃は 1 も上がらない。**
>
> ここが**この計算の要**。
> **片側を伸ばす札**と、**両方を伸ばす札**が、はっきり別のものになる。

### 2-1. 両方に効く札は、**数字を小さくする**

**同じ数字なら、両方に効く札が常に上位互換になる。** 値で差を付ける。

| 引いた札 | 通常攻撃 | 特殊攻撃（固有値 1.0 として） |
| --- | --- | --- |
| **攻撃力 1.2 倍**（両方） | **24** | **24** |
| **特殊攻撃力 1.5 倍**（片側） | 20 | **30** |

**スキル主体なら片側、両方使うなら両側。**
**足し算の中に隠れない**ので、**プレイヤーが暗算で比べられる。**

## 3. 1 本の中では、**足し算が先・掛け算が後**

```
その攻撃力 ＝ (初期値 20 ＋ Σ加算) × Π乗算
```

**例——通常攻撃力に「＋10」と「1.5 倍」が付いた場合:**

```
通常攻撃力 ＝ (20 ＋ 10) × 1.5 ＝ 45
```

> ### 掛け算は、**掛かった攻撃力の中だけで閉じる。**
>
> 通常攻撃力の 1.5 倍は、**特殊攻撃力には乗らない。**
>
> **札には「どの攻撃力に、加算か乗算か」を必ず書く**
>（[../spec/11-damage.md](../spec/11-damage.md) 4 章の規則をここでも使う）。

### 3-1. スキル無しは **通常攻撃力 1.5 倍**

[2026-09-01-build-axes.md](2026-09-01-build-axes.md) 3-1 の
「スキル無しで始めると通常攻撃 ＋50％」は、**通常攻撃力 1.5 倍**。

```
通常攻撃力 ＝ 20 × 1.5 ＝ 30
```

**書いたとおりに 1.5 倍になる**（旧案では 1.25 倍にしかならなかった）。

## 4. 札の書き方（2026-09-02 決定）

**言い方を 2 つに絞る。** 混ぜない。

| 種類 | 書き方 | 例 |
| --- | --- | --- |
| **加算** | **「＋◯」**（数で書く） | 「攻撃力 ＋10」「特殊攻撃力 ＋30」 |
| **乗算** | **「◯倍」**（倍で書く） | 「威力が 1.2 倍」「通常攻撃力が 1.5 倍」 |

> ### **「◯％ 上がる」は使わない**
>
> **％ は、足し算にも掛け算にも読める。**
> 「攻撃力が 50％ 上がる」を見て、**袋に ＋0.5 を入れる**と思う人と、
> **1.5 倍**だと思う人に割れる——**v1 の袋式を知っていると特にそう読む。**
>
> **加算は数、乗算は倍。** これなら読み違えようがない。

**「威力」は、その一撃の結果を指す言葉として使う**——
**攻撃力とは別の数字ではない。** 「威力が 1.2 倍」は
**その攻撃に使う攻撃力が 1.2 倍**という意味で書く（新しい枠を増やさない）。

## 5. クリティカル

**確率で出て、出たら乗算**（2026-09-02 決定）。

| | |
| --- | --- |
| **初期の率** | **0％**。**エンチャントでしか上がらない** |
| **威力** | **2 倍**が基準。**札で上がることもある** |
| 掛かり方 | **出たときだけ乗算。** 通常攻撃・特殊攻撃の両方 |

> ### 初期 0％ にした意味
>
> **何も取らなければ、クリティカルは一度も出ない。**
> **率を上げる札を取って初めて、会心という軸が始まる**——
> **中途半端に振ると、威力の札だけ持っていても出ない。**

## 6. 追加攻撃は、**通常攻撃では起きない**（2026-09-02 決定）

> ### 通常攻撃に追加攻撃が乗ると、計算がごちゃごちゃになる
>
> **右クリック 1 回＝ 1 つの数字**に保つ。

**特殊攻撃からは普通に起きる。**

> 例: **トラップが爆発したとき、追加で雷が降る。**

**追加攻撃を書くときは、[../spec/11-damage.md](../spec/11-damage.md) 3 章のとおり
「何を見た％か」を必ず書く**（特殊攻撃の値の何倍／固定値、など）。

## 7. 属性は**完全に撤廃**（2026-09-02 決定）

> ### 複雑すぎる
>
> 火・雷・風・水・氷の**属性値と、それを参照する計算は全部やめる。**
> 式に属性の項は**無い。**

| | どうするか |
| --- | --- |
| **属性値**（0〜20 の点） | **廃止。** ショップでも売らない |
| **属性エンチャント 26 種** | **この計算に載せ替えるか、捨てる**（[../spec/20-enchant.md](../spec/20-enchant.md)） |
| **エフェクト・状態異常** | **残す。** 炎上・凍結などは**札の効果**として使う |
| **足元のきらめき**（`features/glow`） | **属性値を見ている。** 何を見て出すか**要り直し** |
| [../spec/12-element.md](../spec/12-element.md) | **廃止。** 差し替えの見出しを付けた |

## 8. 伸びの目標（2026-09-02 決定）

**倍率を直接決めず、「1 体倒すのに何発か」を固定する。**

> ### 敵 HP と攻撃力を、**同じ倍率で伸ばす**
>
> ウェーブ 1 の雑魚が **2 発**なら、**ウェーブ 20 でも 2 発。**
> **難易度は、数と敵の攻撃力で作る。**
>
> 強くなった実感は「同じ敵を早く倒せる」ではなく、
> **「増えた敵をさばける」**に寄る——**ウェーブ制と噛み合う。**

### 8-1. ウェーブ 1〜15（本編）

> ### 下の「×20」は**仮に置いた目標**（2026-09-02 追記）
>
> **根拠のある数字ではない。** 敵側は [../spec/16-enemy.md](../spec/16-enemy.md) で決まったので、
> **必要な伸びはそちらから逆算する**（3 章）——
> **wave 15 の敵 HP は ×46.6。** ただし **wave 1 を緩く作る**ので、
> **TTK が 4 倍になるのを許せば、必要な伸びは ×11.7**（[../spec/16-enemy.md](../spec/16-enemy.md) 5 章）。

| | |
| --- | --- |
| 札の枚数 | **ウェーブ報酬 15 枚 ＋ チケット** |
| **最終倍率** | **×20 前後**（通常攻撃力 **20 → 420**） |
| 1 枚あたり | 平均 **1.22 倍**ぶん |
| ウェーブ 15 | **ボス。** ここまでが「1 周」（[../00-concept.md](../00-concept.md) 2 章） |

### 8-2. 札の値は**固定**（2026-09-02 訂正）

> ### 帯でうんぬんは間違い
>
> **エンチャントはランダムに出る。** ウェーブによって**同じ札の値が変わることはない。**
> **「序盤は ＋10、終盤は ＋80」という作りにはしない。**

**枚数も決まっていない**——**ショップのガチャで引く**ので、
**どれだけ稼いだかで変わる**（[../00-concept.md](../00-concept.md) 3 章）。

| | |
| --- | --- |
| **加算札** | **「＋◯」。** 早く引くほど効く（初期 20 に対しての比が大きい） |
| **乗算札** | **「◯倍」。** 後で引くほど効く。**1.5 倍が 2 枚なら 2.25 倍**（掛ける） |

**値は未定。** **敵から逆算する**（[../spec/16-enemy.md](../spec/16-enemy.md) 5 章）。

### 8-3. ウェーブ 16〜30（extra）——**敵が先に行く**

| | |
| --- | --- |
| **敵の伸び** | **1 ウェーブごとに 1.15 倍**（**一定**） |
| **こちらの伸び** | **加算札は固定値**なので、**倍率は落ちていく一方**（枚数が増えるほど 1 枚の重みが減る） |
| **差** | **序盤の extra は付いていける。終盤で急に置いていかれる** |

**敵は指数（一定の倍率）、こちらは固定値の足し算。**
**必ずどこかで追い抜かれる。**

> ### extra は「勝てなくなる」ように作る
>
> **全滅で終了**（[../00-concept.md](../00-concept.md) 2 章）なので、
> **終われる形**が要る。**30 で必ず終わる**のではなく、
> **たいてい 25〜28 で力尽きる**くらいを狙う。
>
> **加算札が固定値である以上、この失速は自動で起きる。**
> 敵だけを指数で伸ばせばよく、**別に難易度を足す必要がない。**

## 9. まだ決めていないこと

| ~~防御・耐性~~ | **敵は基本持たない**（[../00-concept.md](../00-concept.md) 8-2）。こちらは**札で割合カットを持つ可能性がある** |
