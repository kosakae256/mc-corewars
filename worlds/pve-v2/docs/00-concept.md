# 企画: PVE v2

**[worlds/pve](../../pve/) の作り直し。** 2026-08-30 に決めた。

> ### 何の遊びか
>
> **パーティで挑む、30 分のローグライト。**
> ウェーブを凌ぎ、**倒してポイントを稼ぎ、その場で強くなる。**
> **全滅で終わり。** 次の周回は、**前に触ったエンチャントから始められる。**

## 1. なぜ作り直すのか

**v1 は広げすぎた。**

| v1 で作ったもの | 何が起きたか |
| --- | --- |
| **武器 48 本** | **1 本ずつ絵と音と能力**が要る。作り切る前に手が止まった |
| 武器が落ちる（未鑑定・レア度・属性抽選） | **拾って初めて何か分かる**——遊ぶ側も、作る側も、覚えることが多い |
| 属性が**武器に付く** | 「この弓は火」「あの弓は氷」で、**同じロールでも別のゲーム**になった |
| 蓄積・属性耐性 | **見えない数字**が増えた。効いているのか分からない |

> ### 減らす。**選ぶ余地は、別のところで作る。**
>
> **武器は 1 本に固定して、強くなる道をスキルポイント 1 本に絞る。**

## 2. 基本仕様

| | |
| --- | --- |
| 遊び方 | **ローグライト**（周回して、少しずつ解放していく） |
| 人数 | **パーティ**。1 人でも遊べる |
| 1 回の長さ | **30 分**想定 |
| 難易度 | **easy / normal / hard / insane**。insane は**初見では無理**なくらい。難しくしすぎない |
| 進み方 | **ウェーブ制。** 突破すると **10〜30 秒**の休憩を挟んで次へ |
| **ウェーブ数** | **上限 30**（2026-09-02 決定） |
| **15 がひと区切り** | **ウェーブ 15 にボスを置く。** ここまでを「1 周」と考える |
| **16 以降は extra** | **敵の強さが段違いになる。** どこまで行けたかを競う延長戦 |
| 終わり | **全滅で終了** |
| 敵の量 | **ウェーブごとに増える。** 人数でも増える（**1 次関数ではない**） |
| 中ボス | 置く（詳細は後） |
| 死亡 | **ウェーブが終われば復活**（ペナルティは未定） |
| 途中参加 | **多少は追いつける**ようにする |

> **ウェーブを越えるたび、全員に固定のステータスポイント。**
> **ガチャも札も無い**——**エメラルドは買い物だけに使う。**
>

## 3. 遊びの輪（v1 からいちばん変わった所）

```
敵を倒す / アシスト
   ↓
└ エメラルドが落ちる
        ↓
     休憩のショップ
        ├ ガチャを引く → エンチャントが 3 つ提示 → 1 つ選ぶ
        └ 最大 HP・アイテム
   ↓
強くなって次のウェーブへ
   ↓（全滅）
使ったエンチャントが「解放」される
   ↓
次の周回では、解放済みのものを最初から付けられる
```

**これがローグライトである理由**——
**負けても、次に持ち越せるものが増える。**

### 3-1. 強くなる道は 2 本（2026-08-31 決定）

| | どこで | 何が増えるか |
| --- | --- | --- |
| **エンチャント** | **ショップのガチャ**（2026-09-02 変更） | **引くと 3 つ提示され、1 つ選ぶ** |
| **買い物** | **休憩のショップ** | **最大 HP・アイテム**（**属性値は廃止**） |

> ### **ウェーブを越えたことは、札とは関係ない**（2026-09-02 決定）
>
> **「ウェーブ突破で 1 枚」ではない。** **ショップでガチャを引いたときだけ**札が出る。
> **エメラルドで引く。値段は「引いた回数 × 50」**（7 章）。

### 3-2. 札にはレベルがある（2026-09-02 決定）

| | |
| --- | --- |
| **上限レベル** | **札ごとに違う。1〜3 / 5 / 10 くらい** |
| **同じ札を引いたら** | **レベルが上がる** |
| **提示の重み** | **一度取った札は、出やすくなる** |

> ### 引くほど「広がる」のではなく「深くなる」
>
> **取った札が出やすいので、引き続けると同じ札が育つ。**
> **40 回引いても、8 種類が平均レベル 5**——**全部を取り揃える形にはならない。**
>
> **上限レベルが、枚数を吸う仕掛けになる。**
> **強い札ほど上限を高くしておけば、収入が増えても選択が薄まらない。**

**未定:** **重みをどれだけ付けるか**（付けすぎると 1 本道になる）。
**上限に達した札を提示から外すか。**

> ### 引かせるのではなく、選ばせる（2026-08-31 決定）。
>
> **初見でも比べられる**——引くと「何が出たのか」が分からない。

> **レベルでステータスは伸びない**（2026-08-30 決定）。
> **伸ばす先を選ぶことが、そのまま戦い方の選択**になる。

### 3-2. 解放（ゲームを跨ぐもの・2026-09-02 決定）

**周回を跨いで残るのは「選べるものが増える」ことだけ。** 強さは残さない。

| 残るもの | どう増えるか |
| --- | --- |
| **エンチャントの解放** | **そのゲームで使った札**が解放され、次の周回から**プールに入る** |
| **ロールの解放** | 周回で新しいロールが選べるようになる |
| **別枠の通貨** | ゲームを跨いで貯まる。**見た目・ロールの解放に使う** |

> ### 恒久的な数値強化は入れない
>
> 「周回するほど HP ＋5％」の類は、**このゲームでは特に危ない。**
>
> | | |
> | --- | --- |
> | **途中参加がある**（2 章） | 古参と初参加が同じ卓に座る。**数値差があると片方が空気になる** |
> | **難易度を誰に合わせるか決まらない** | 強化の量だけ敵を強くする、を繰り返すことになる |
> | **1 周目がいちばん弱くなる** | **初見の体験が最悪になる。** 逆をやるべき |
>
> **解放型**（選択肢が増える）にする。**恒久強化型**は採らない。

**これがローグライトである理由**——**負けても、次に選べるものが増える。**

## 4. 職業（武器 × スキル・2026-09-02 決定）

**武器は 1 本だけ。** **落ちない・拾わない・持ち替えない。**
**その武器に、左クリックのスキルが 1 つ付く**——**この組が「職業」。**

詳細は [decisions/2026-09-02-roles-and-skills.md](decisions/2026-09-02-roles-and-skills.md)。

| 武器 | 職業 | スキル（左クリック） | 何のビルドか |
| --- | --- | --- | --- |
| **弓** | 通常攻撃のみ | **無し** | 素の弓。**初見はここ** |
| 弓 | **爆発矢** | 爆発矢を撃つ | 範囲攻撃 |
| 弓 | **連射** | 連射する | 手数 |
| 弓 | **盾** | 盾を召喚する | 耐久・守り |
| **剣** | （未定） | | 後で同じ形で足す |

**職業ごとに固有のエンチャントがある**——**スキルの挙動が変わる。**
**［挙動変化］の札は排他**（どちらか片方しか取れない）。

**サイコロ・カードのような変わり種**は、**別の武器**として後で足す。

### 4-1. Archer

| | |
| --- | --- |
| 操作 | **長押しで連射。** CT **0.5 秒** |
| ため | **無し**（2026-08-30 決定。溜めるのが面倒だった） |
| 性格 | **1 発が重い。** 手数は少ない |

> v1 は「ため 1 秒で 2.5 倍」だった。**やめた。**
> **基礎攻撃力の物差しも「1 秒ためた 1 発」から「1 発」に変わる**——
> 数値は全部引き直す。

### 4-2. Blade（仮）

| | |
| --- | --- |
| 通常 | **3 振りでループ。** 火力は **1 段目 ×1 / 2 段目 ×0.75 / 3 段目 ×2** |
| 右クリック | **0.5 秒ためて前進し、横なぎ。** **前進中は無敵** |

**まだ作っていないので仮。** Archer と違って**ためが残る**——
**ロールごとに手触りが違うのは、個性として扱う。**

## 5. 属性

**属性はプレイヤーに付く**（武器ではない）。**全ロール共通。**

| 属性 | 何が起きるか | 20 点で |
| --- | --- | --- |
| **火** | **通常攻撃の威力** | ＋50％ |
| **雷** | **クリティカル率**（**倍率は上がらない**） | ＋50％ |
| **風** | **足の速さ**＋**撃つ間隔** | 速さ ＋100％・間隔 −10％ |
| **水** | **防御**（ダメージカット） | 50％ カット |
| **氷** | **鈍化**（**氷だけ蓄積が残る**） | 蓄積率 100％ |

**属性値は 0〜20。** **エメラルドで買う**（休憩のショップ）。
**終盤で合計 50 点前後**——**上限まで振れるのは 2 属性ちょっと。**

| | |
| --- | --- |
| 伸ばし方 | **スキルポイント**（3-1） |
| 蓄積 | **原則やめる**（v1 の「溜まるまで効かない」は廃止）。**氷だけ残す**（[spec/12-element.md](spec/12-element.md) 2-5） |
| 属性耐性 | **やめる**（v1 の「満ちるまでの量」も廃止） |

> **どの属性を伸ばすかで戦い方が変わる**——それが選択の中心。
> **数値は [spec/12-element.md](spec/12-element.md) に決めた**（0〜80 点・1 点あたりの効き）。

## 6. エンチャント

| | |
| --- | --- |
| 付き方 | **ゲーム中に、ガチャとして引く**（スキルポイントを払う） |
| 数 | **ロールごとに 20 種**を目標 ＋ **共通** |
| グレード | **mythic / fable / legendary / rare / uncommon** の 5 段（**common は無い**） |
| 形式 | **独自のもの。** バニラのエンチャントは使わない |

### 6-1. 3 種類ある（2026-08-30 決定）

**2 つの軸で分かれる**（2026-08-31 に整理）。

| | **汎用**（属性を見ない） | **属性**（振った属性で性能が変わる） |
| --- | --- | --- |
| **全ロール共通** | 強撃・クリティカル・吸収・採掘者… | **属性ごとに 2 枚だけ**（延焼・焼灼／雷速・放電／疾走射・追い風／**自然回復**・深水／霜纏い・砕氷） |
| **ロール固有** | マルチショット・貫通・反射・追尾… | **それ以外の属性札すべて**（火薬矢・落雷・軌跡…） |

> ### 全ロール共通の属性札は「前提」か「パッシブ」だけ
>
> **延焼のように、他の札が乗る土台になるもの。**
> **属性を盛るほど効くが、武器の振る舞いは変えないもの。**
> **派手なもの・弾や軌跡に乗るものは、全部ロール固有。**

**全ロール共通**——どのロールで引いても同じように効く:

- **特定の属性を強くする**（火だけ、氷だけ…）
- **全属性を強くする**
- **強撃**（威力）／**クリティカル**／**吸収**
- **採掘者**（エメラルドが増える）／**本の虫**（経験が増える）

**ロール固有・汎用**——**そのロールの武器の振る舞いを変える。**
Archer なら **マルチショット／反射／追尾／速射** など。
**v1 にもあった形**——ここは持ってこられる。

**ロール固有・属性**——**属性スキルポイントの割り振りで性能が変わる。**
「火に振っているほど効く」「風と氷の両方に振っていないと出ない」といった形。

> ### 3 つ目は、これから考える（2026-08-30）
>
> **v1 に無かった種類。**
> **属性の振り方が、武器の振る舞いそのものを変える**ようにしたい——
> 振り分けを「数字が伸びる」だけで終わらせないため。
> **中身はまだ 1 つも決めていない。**

### 6-2. v1 から持ってくるもの

**ロールごとの中身は考え直す。**
v1 の弓 20 種は**一部だけ持ってくる**（そのまま全部は使わない）。

**そのままでは使えないもの**——**前提が消えたから**:

| | なぜ |
| --- | --- |
| **ため**に関わるもの（速射・集中・矢継ぎ早） | **ためが無くなった**（[spec/10-bow.md](spec/10-bow.md) 1 章） |
| **蓄積**に関わるもの（貫魔・浸食） | **蓄積を原則やめた**（5 章） |

### 6-3. テスト解放に入れないもの（2026-08-31 決定）

**実装は済んでいるが、テスト解放では配らない。**

| | なぜ |
| --- | --- |
| **軌跡**（5 枚） | **飛んでいる線が働く**——効いているのが分かりにくい |
| **2 属性・3 属性・5 平均**（12 枚） | **両方に振らないと出ない**——**初見で条件を読み解けない** |

> ### 難しいものより、先に回る仕組み
>
> **弓の札は 40 枚以上ある。** テストで見たいのは
> **「ウェーブが回るか」「強くなる実感があるか」**であって、
> **札の種類の多さではない。**
>
> **消しはしない**（`docs/spec/20-enchant.md` には残す）——**出す札の一覧から外すだけ。**

## 7. エメラルドとショップ

| | |
| --- | --- |
| 落ち方 | 敵から。**キルとアシストで入る**（[spec/17-level-and-emerald.md](spec/17-level-and-emerald.md)） |
| 使い道 | **休憩のショップ**（ウェーブとウェーブの間） |
| 何が買えるか | **最大 HP の強化**（8 章）／**ガチャ**（3 章）／**アイテム** |
| **HP 強化の値段** | **強化レベル × 25**（n 回目が 25n） |
| **ガチャの値段** | **レベル × 50**（n 回目が 50n） |

**どちらも「買うほど高くなる」形。** **同じ財布を取り合う。**

| 引いた回数 | その回の値段 | そこまでの合計 |
| --- | --- | --- |
| 1 | 50 | 50 |
| 10 | 500 | **2,750** |
| 20 | 1,000 | **10,500** |
| 30 | 1,500 | **23,250** |

**アイテムの中身は未定。**

> **属性は廃止**（[decisions/2026-09-02-damage-formula.md](decisions/2026-09-02-damage-formula.md) 7 章）。
> **エンチャントはガチャで引く**——**ウェーブを越えた報酬ではない**（2026-09-02 変更）。

## 8. こちらの HP と守り（2026-09-02 決定）

| | |
| --- | --- |
| HP | **バニラの体力は使わない**（削られない。`/kill` は効く） |
| **初期 HP** | **100** |
| **上限** | **1000** |
| **伸ばし方** | **ショップで買う。1 回 ＋20**（45 回で上限） |
| **値段** | **強化レベル × 25**（**買うほど高くなる**） |
| 多段ヒット | **無敵時間を作らない** |

> ### 「レベル」は **HP 強化そのものの回数**
>
> **[spec/17-level-and-emerald.md](spec/17-level-and-emerald.md) の LV（場のレベル）とは別物。**
> **n 回目の強化が 25n エメラルド。**

| 回 | 値段 | そこまでの合計 | HP |
| --- | --- | --- | --- |
| 1 | 25 | 25 | 120 |
| 10 | 250 | **1,375** | 300 |
| 25 | 625 | **8,125** | 600 |
| **45**（上限） | 1,125 | **25,875** | **1000** |

### 8-1. 生き残り方は**ビルドで変わる**

| やり方 | 何で作るか |
| --- | --- |
| **やられる前にやる** | 火力。**弓しか無いいまは、これが基本** |
| **逃げる** | 速さの札 |
| **遅くする** | 鈍化の札 |
| **耐える** | HP・盾 |

### 8-2. 防御（割合カット）

| | |
| --- | --- |
| **敵** | **基本は持たない。** 今後、**固定で 90％ カット**のような敵を作るかもしれない |
| **こちら** | **エンチャントで持つ可能性がある**（割合カット） |

**敵が基本カットを持たないので、固定値の札が無力化される事故は起きない。**
