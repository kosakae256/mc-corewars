## 1. 言葉の決まり

### 1-1. **Focus ＝ 連続で当てた回数**

**当てるたびに 1 増え、外すと 0 に戻る。** 「段」と呼んでいたものはすべてこれ。

| | |
| --- | --- |
| **増える** | 通常攻撃が敵に当たったとき |
| **0 に戻る** | 外したとき（**暴射**を持っていれば減らない） |
| **参照する札** | フォーカス・ヒートアップ・ラッシュ・照準・常在戦場・研ぎ澄まし・覚醒・習熟・アクセル |
| **未定** | 上限・時間で落ちるか（**余熱**が猶予を伸ばす前提） |

### 1-2. **攻撃力**と**威力**を混ぜない

| | |
| --- | --- |
| **攻撃力** | **ステータス**（通常攻撃力・特殊攻撃力）。「＋◯」で足す |
| **威力** | **その一撃の結果**。「◯倍」で掛ける |

### 1-3. **乗る攻撃**を必ず書く

| | |
| --- | --- |
| **通常** | 右クリックだけ |
| **特殊** | 左クリック（スキル）だけ |
| **両方** | どちらにも乗る |
| **—** | 攻撃に乗らない（移動・経済・場に置くもの） |

> ### **命中ごとに発動するものは、原則「通常」だけ**
>
> **連射は 1 回で 10 発当たる。** 火矢・毒牙・放電・炸裂のような
> **当てるたびに発動する札**を特殊に乗せると、**連射だけが 10 倍**になる。
>
> **特殊に乗せたいものは「スキル 1 回につき 1 度」**に制限する。
> **倍率で効くもの**（延焼・火種・砕氷）は**両方**でよい——**回数に比例しない**ため。

## 5. レア度

> ### **強さ順ではない**
>
> **ビルドの核は、低いレア度に置く。** 引けないと軸が立たない札が
> **legendary だと、ビルドが運だけで決まる。**
>
> **legendary は「引けたら組み替える」札**——**挙動が劇的に変わるもの。**

| | 何を入れるか | 数 |
| --- | --- | --- |
| **uncommon** | **ビルドの核。** 攻撃力・状態を付ける札・貫通・炸裂・Focus の土台 | **59** |
| **rare** | 条件つきの倍率・状態を参照する札・構造の変更 | **106** |
| **legendary** | **挙動が劇的に変わる**もの。確定クリティカル・即死・排他の解除 | **35** |

**レア度が高いほど出にくい**（重みは未定）。

> ### 例: **火矢は uncommon、劫火は legendary**
>
> **燃やすビルドは「火矢」から始まる**ので、引けないと軸が立たない。
> **重ねがけができる「劫火」は、燃やすビルドが化ける札**——**引けたら別物になる。**
>
> 同じ考えで、**貫通は uncommon・貫徹（減衰なし）は legendary**、
> **フォーカスは uncommon・暴射（外しても減らない）は legendary**。

## 8. 対になっている枠

| **精密射撃**（拡散を減らす） | ↔ | **スプレッド・乱れ撃ち**（拡散を増やす） |

| **マルチショット**（本数） | ↔ | **精密射撃・引き絞り**（1 本を重く） |
