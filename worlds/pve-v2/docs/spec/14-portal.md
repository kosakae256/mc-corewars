# ネザーゲートを通さない

**ゲートは飾りとして残す。** ただし**ネザーへは行かせない。**

> ### なぜ要るか
>
> 要塞にネザーゲートがある。**触らないようにはするが、万一触れたときに
> くぐってしまうのを防ぎたい**（2026-09-01）。
>
> ゲートを壊す・囲うという手もあるが、**見た目を残したい**ので、
> **移動そのものを止める。**

## 一番いいのは、飾りに差し替えること

**見た目だけのブロック `pve_v2:portal` を用意した。**

```
/pve:map portal     まわり 64 x 56 x 64 の本物のゲートを、飾りに差し替える
```

| | |
| --- | --- |
| 見た目 | **バニラのアトラス名 `portal` をそのまま指す**——渦の動きも同じ |
| 形 | 厚さ 2 ピクセルの板（`geometry.pve_v2_portal`）。**向きは本物から受け継ぐ**（`portal_axis` が `z` なら 90 度回す） |
| 当たり判定 | **無し**（すり抜けられる。ただし移動は起きない） |
| 光 | 11 |
| 壊す | 掘れば壊せる（0.4 秒）。**爆発では壊れない** |

> ### なぜテクスチャを自前で持たないか
>
> `material_instances` の `texture` は**アトラスの名前**を指す。
> **バニラの `portal` を指せば、テクスチャも flipbook（渦の動き）もそのまま使える。**
> 画像を複製すると、バージョンが上がったときにズレる。

**置くこともできる**（建築タブに「ネザーゲート（飾り）」として出る）。

## 二段構え（本物が残っている場合の保険）

> ### 「行く前に止める」だけでは足りない
>
> Script API v2 に**次元移動を打ち消せる before イベントは無い**
> （`playerDimensionChange` は **after** しかない）。
> だから**踏んだ時点で押し戻し、それでも飛んだら引き戻す。**

| | いつ | 何をするか |
| --- | --- | --- |
| **1. 押し戻す** | 毎 tick | 足元か頭が `minecraft:portal` なら、**直前の安全な場所へ戻す** |
| **2. 引き戻す** | 次元が変わった後 | オーバーワールド以外へ出たら、**元の場所へ戻す** |

**1 で止まるのが普通**（ネザーゲートは踏んでから数秒かかる）。
**2 は保険**——読み込みの都合などで 1 をすり抜けたときのため。

## 安全な場所

**「直前の安全な場所」は、毎 tick 記録する。**

| 条件 | なぜ |
| --- | --- |
| ゲートの中にいない | 戻した先がゲートだと、また吸い込まれる |
| **地に足が着いている** | 空中を記録すると、戻した瞬間に落ちる |

記録が無いときは**その場で 1 マス外へ押し出す**（初回にいきなりゲートの中にいた場合）。

## 知らせ方

**戻したときだけ、短く伝える。**

```
§7ネザーゲートは飾り。§f通れない
```

**2 秒に 1 回まで**——連打すると画面が埋まる。

## 触らないもの

- **ゲートのブロックそのもの**——`/pve:map portal` を打つまでは消さない・置き換えない
- **他の次元への移動全般**——止めるのは**オーバーワールドから出る**ことだけ。
  戻す先は必ずオーバーワールド。
