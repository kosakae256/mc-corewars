# 足元のきらめき（属性の見せ方）

**振った属性が、足元に散る粒の色と量になる。**

> ### 何のためか
>
> 属性は**プレイヤーに付く**（[12-element.md](12-element.md)）。
> だが数字でしか分からない——**自分の育ち方も、味方の育ち方も見えない。**

## 1. 決めたこと

> ### 回さない。**多いか少ないか、それだけ。**
>
> 最初は玉を輪にして回した。**機械的でダサかった**（2026-09-01 実機）。
> **見せたいのは「どの属性を、どれだけ振ったか」**——
> **色**と**量**で足りる。

| | |
| --- | --- |
| 色 | **属性の色**（火 橙／雷 黄／風 緑／水 青／氷 淡い水色） |
| 量 | **1 点につき 1 tick あたり 0.0125 個。** 20 点なら 4 tick に 1 個（毎秒 5） |
| 1 個未満 | **確率で出す**（ほぼ全部これ）——1 点なら 80 tick に 1 個。切り捨てると何も出ない |
| 0 点の属性 | 出さない |

**5 属性を満額まで振っても 1 tick に 1.25 個。** 振り方がそのまま光り方になる。

> ### 毎秒 20 個は多すぎた（2026-09-01 実機）
>
> バニラの粒は **0.4〜2 秒残る**ので、出した数の何倍も同時に見える。
> **1/4 に落とした**——20 点で常時 3 個前後。

## 2. 粒

> ### バニラの「レッドストーン通電中の粒」をそのまま写す
>
> 自分で粉の絵を描いたら**全然違う**と言われた（2026-09-01 実機）。
> `minecraft:redstone_wire_dust_particle` の定義を**丸ごと写し、色だけ変える。**

| | |
| --- | --- |
| 絵 | **バニラの粒地図**（`textures/particle/particles` の uv[56,0] から 8 コマ） |
| 材質 | `particles_alpha`（バニラと同じ） |
| 大きさ | `random_3 * 0.075 + 0.075`（バニラと同じ） |
| 寿命 | `2 / random(1.0, 5.0)` ＝ **0.4〜2 秒**（バニラと同じ） |
| 動き | 初速 ±0.4（左右）・±0.1（上下）、**ブロックに当たる**（バニラと同じ） |
| ちらつき | `(r1 * 0.2 + 0.8) * (r2 * 0.4 + 0.6)` を**色に掛ける**——これがレッドストーンの粒の揺らぎ |
| 色 | 火 (1.0, 0.42, 0.1) / 雷 (1.0, 0.92, 0.3) / 風 (0.45, 1.0, 0.45) / 水 (0.25, 0.65, 1.0) / 氷 (0.7, 0.95, 1.0) |
| 出す場所 | 足元から**半径 0.42**、高さ 0.05〜0.22 |

**円の中に均等に散らす**（`sqrt(random)` を掛ける。掛けないと中心へ寄る）。
**粒自身も飛ぶ**ので、置く場所は狭くてよい。

## 3. 追従のさせ方

> ### 粒は世界に置かれる。**貼り付けることはできない。**

**毎 tick、いまの足元から出す。** 走れば粒は後ろに残る——
**軌跡になって、かえって速さが見える。**

## 4. 誰に見えるか

**全員に見える**（`dimension.spawnParticle`）。
味方がどう育っているか分かるほうがよい。
**足元なので、一人称でも視界を塞がない。**
