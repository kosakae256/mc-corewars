## 名前の付け方（2026-08-30 決定）

| 何 | 接頭辞 | なぜ |
| --- | --- | --- |
| アイテム・実体・粒 | **`pve_v2:`** | パック名。**v1 と同じワールドに入れても衝突しない** |
| 動的プロパティ | **`pve2:`** | 短く。`state/keys.ts` だけで決める |
| **コマンド** | **`pve:`** | **打つのが面倒**（`/pve:spawn` で済ませたい） |

> ### コマンドだけ短いのは意図的
>
> **アイテムや実体の名前は、ゲームが衝突を検出する。**
> **コマンドは毎回手で打つ**——短さのほうが効く。
>
> **v1 のパックと同時に有効化すると、コマンド名がぶつかる**（v1 も `pve:` を使う）。
> **両方入れない。**
