# 仕様: 手応え

計算は [11-damage.md](11-damage.md)、札は [20-enchant.md](20-enchant.md)。

> ### 当たったことが分からないと、数字を調整できない。
>
> v1 でも同じ所で詰まった（`worlds/pve/docs/spec/16-feedback.md`）。

## 1. 当たったとき

| | 何 |
| --- | --- |
| 敵 | **赤く光る**（バニラと同じ長さ）＋ **音** |
| 自分 | **ノックバック**（無敵時間は作らない） |
| 倒した | **破裂の粒**（`pve_v2:kill_burst`）＋ 音 |
| **数字** | **敵から飛び出して落ちる**（下） |

## 2. ダメージの数字（2026-08-31 決定）

**敵に当てるたび、その場から数字が飛び出す。**

```
当たる → 敵の少し上に出る → 上へ跳ねて、そのまま落ちて消える（1.2 秒）
```

| | |
| --- | --- |
| 出す先 | **敵だけ**。**自分が受けたぶんは出さない**（v1 で邪魔だった） |
| 何で出すか | **見えない実体**（`pve_v2:dmg`）の名札 |
| 消え方 | **1.2 秒で自然に消える**（取りこぼしても残らない） |
| 出しすぎ防止 | **1 tick に 6 個まで**——範囲攻撃で画面が埋まらないように |

### 2-1. 色で区別する

| 何 | 色 | 例 |
| --- | --- | --- |
| 通常攻撃 | **白** | `120` |
| **クリティカル** | **黄 ＋ `!`** | `360!` |
| **特殊攻撃**（爆発・燃焼・落雷…） | **水色** | `48` |

**クリと特殊攻撃が見分けられれば、札が効いているかが数字だけで分かる。**

## 3. 音（2026-08-31 決定）

> ### 音は**その人にだけ**鳴らす。
>
> 場所から鳴らす（`dimension.playSound`）と、**遠くの敵に当てても聞こえない**
>（弓は 48 マス先まで届く）。**他人のヒット音も要らない**——人が増えると音が埋まる。

| 何 | 誰に | 大きさ |
| --- | --- | --- |
| **当てた**（通常ヒット） | **殴った本人だけ** | **0.2** |
| **クリティカル** | 殴った本人だけ | 0.35 |
| **倒した** | 倒した本人だけ | 0.22 |
| **自分が受けた** | **受けた本人だけ** | **0.3** |
| **札のエフェクト** | **5 マス以内の人だけ**（その位置から） | 0.5 |
| **弓を射った** | 射った本人だけ | **0.5**（`features/bow/shoot.ts`） |

**当てた音は毎発鳴る**ので小さく、**クリはそれより大きく**して立たせる。
**受けた音も控えめ**——手元で鳴るので、大きいと張り付いて聞こえる。

> ### 受けた音は、受けた側で鳴らす（2026-08-31 に直した）
>
> **殴ってきたのがモブだと、「殴った本人」がプレイヤーではない。**
> 当てた側の音だけにしていたら、**プレイヤーが受けたときに誰にも鳴らなかった。**

### 3-1. 鳴らさないもの

> ### 音の枠は限られている（BE の性質・2026-08-31）
>
> **同時に鳴らせる音の数に上限があり、溢れると別の音が消える。**
> **毎秒鳴るもの**（延焼）に枠を使うと、**弓の発射音やヒット音が落ちる**——
> そちらのほうが手応えとして重い。
>
> **繰り返し鳴るものには音を付けない。**

**延焼のような毎秒刻むものでは、当てた音を鳴らさない**——鳴りっぱなしになる。
`feedback()` の音は**通常攻撃（`kind === "base"`）のときだけ。**

> ### 音量では距離を切れない
>
> `WorldSoundOptions.volume` は「相対的な音量と広がり」で、
> **バニラの音自体が持つ到達距離**（`sound_definitions.json`）には勝てない。
> 遠くまで届く音（延焼の `random.fizz`）は、
> **`dimension.getPlayers({ maxDistance })` で人を絞ってから鳴らす。**

## 4. エフェクト

**絵も粒も `tools/pve2-fx.py` が書き出す**（手で JSON を書かない）。
どの札がどれを出すかは `scripts/lib/fx.ts` の表 1 か所で決める。

### 4-1. 通常ヒット（2026-08-31）

**当たった点で火花が弾ける**——`pve_v2:hit_burst`。

| | |
| --- | --- |
| 作り | **1 枚の絵をコマ送り**（`flipbook`・8 コマ・64×64） |
| 長さ | **0.3 秒**（寿命いっぱいで 1 周する） |
| 大きさ | 0.8 ×（1.0〜1.4 のランダム） |
| 向き | **1 発ごとに回る**（`particle_initial_spin`） |
| 形 | **片側へ寄せた扇**。短い棘の間から長い棘が数本 |

> ### 点を撒くのはやめた
>
> はじめは細い粒を 10 個ほど散らしていたが、**火花に見えなかった。**
> **形のある絵が動くほうが、一瞬でも「弾けた」と分かる。**

> ### 参考にした GIF はそのまま使えない
>
> `user/b24e83d00d5d67160594d93464529bad.gif`（Jason Keyser 氏の作例）は
> **全コマに透かしが焼き込まれていて、背景も不透明**。
> **形式（コマ送り）だけ真似て、絵は自分で描いた。**

### 4-2. 属性値で量が変わる（2026-08-31 決定）

**属性を盛るほど、その属性の技のエフェクトが増える。**

| 属性値 | 出る量 |
| --- | --- |
| **0〜4** | **出ない** |
| 5〜9 | **25％** |
| 10〜14 | **50％** |
| 15〜19 | **75％** |
| **20** | **100％**（作り込んだ姿） |

> ### 作り方は「1/4 を何回出すか」
>
> **粒の数は JSON に固定で書く**ので、後から割合で変えられない。
> **1 回ぶんを 25％の量で作っておき、script が 1〜4 回出す。**
> 数で決まらないもの（閃光・輪・線の間隔）は**そのまま**——増やしても意味が薄い。

**効くのは #25 火薬矢・#26 業火の一矢（火）と #27 放電（雷）。**
性能は今までどおり属性値で連続に変わる（`docs/spec/20-enchant.md`）——**見た目だけ 5 刻み。**

### 4-3. 燃えている間（延焼・2026-08-31）

**燃えている敵は、燃えている間ずっと炎を上げる。**

> ### ダメージの瞬間に出すのではない
>
> はじめは**削られた瞬間（毎秒）だけ**出していたが、**燃えているように見えなかった。**
> **状態がある間ずっと**——`features/status/` が回るたび（**0.5 秒おき**）に足す。

| | |
| --- | --- |
| 粒 | **バニラの炎**（`pve_v2:burn_flame` ＝ バニラの粒地図 uv[0,24]） |
| 数 | **3 本**を体の周りに散らす（横 ±0.45・高さ 0.15〜1.35） |
| 間隔 | **0.5 秒おき**（`features/status/` が回るたび） |
| 音 | **鳴らさない**（下） |

> ### 炎だけはバニラの粒を借りる（v1 から持ってきた）
>
> **自分で描いた炎より、バニラのほうが炎に見えた**——v1 でも同じ結論に達していた
>（`worlds/pve/packs/pve/scripts/features/element/effects.ts`）。
>
> 自作の「炎の舌」は**真上から見ると板が寝てしまい**、向きも安定しなかった。
> **バニラの粒は 1 本が小さい**ので、**数と置き場所で炎の塊を作る。**

**煙も、落ちる火の粉も出さない。**
**同じ敵に何人ぶん燃焼が付いていても、炎は 1 体につき 1 回。**

### 4-4. 風の 3 枚（2026-08-31）

| 札 | 何が出るか |
| --- | --- |
| **疾走射** | **当たった敵に葉が散る**（走りながら当てたときだけ） |
| **貫き風** | **貫いた矢の軌跡が緑になる**——**貫通した矢だけ**見た目が変わる |
| **烈風** | **自分の周りに羽が舞う ＋ 音**。**効果が続いている間の再発動では出さない** |

> ### 続けて出すと邪魔になる
>
> 烈風は**倒すたびに発動する**ので、続けて倒すと**羽と音が鳴り続ける。**
> **効果が切れているときだけ**出す——**掛け直しは静かに。**
