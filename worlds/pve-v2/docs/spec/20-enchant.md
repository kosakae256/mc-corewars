| | **汎用** | **属性** |

| **全武器** | 強撃・クリティカル・会心強化・吸収・採掘者・本の虫・火事場 | **属性ごとに 2 枚だけ** |
| **弓のみ** | マルチショット・反射・追尾・連鎖・狙撃… | 火薬矢・落雷・帯電・業火の一矢・吹雪・氷片・絶対零度・恵みの雨・軌跡… |

> ### 弓は単体火力と手数、そのぶん打たれ弱い
>
> **派手な範囲の主砲と、守りの札は Mage / 前衛に回す**（2026-08-31 決定）。
> **実装は済ませてある**ので、そのロールを作るときにそのまま渡せる。
> **範囲攻撃を全部取り上げるわけではない**——火薬矢・落雷のような
> **控えめなもの**は弓に残す。

**全武器で使える属性の札**（各属性 2 枚）:

| 属性 | 2 枚 | どういう役 |
| --- | --- | --- |
| **火** | 延焼／焼灼 | **燃やす前提**と、その上に乗るパッシブ |
| **雷** | 雷速／放電 | クリまわりのパッシブと、倒したときの伝播 |
| **風** | 疾走射／追い風 | 移動中の威力と、手数 |
| **水** | 自然回復／深水 | **じわじわ戻る**／器が大きくなる |
| **氷** | 霜纏い／砕氷 | **鈍らせる土台**と、その上に乗るパッシブ |

> ### 全武器の枠は「前提」と「パッシブ」だけ
>
> **属性を盛るほど効くが、武器の振る舞いは変えない。**
> **派手なもの・弾や軌跡に乗るものは、全部ロール固有。**

**表の「適用」列**がそれ。**Blade / Mage を作るときは、この 10 枚 ＋ 共通・汎用 7 枚がそのまま使える。**

## 3. 範囲攻撃の決まり（2026-08-31 決定）

> ### 範囲で馬鹿げた火力を出さない。
> **主対象に全部、周りは減衰。**

| 形 | 係数の上限 |
| --- | --- |
| 単体・毎ヒット | **R × 1.5 × 段 × x** |
| 単体・間隔つき（5 秒以上） | **R × 5.0 × 段 × x** |
| **範囲・毎ヒット** | **主対象の 25％ まで**（半径 2〜3）。**単体特化の属性（火）は 10％**（火薬矢） |
| 範囲・間隔つき | **R × 1.0 × 段 × x**（半径 5） |
| **奥義**（溜めが要るもの） | **減衰なしで配ってよい**（帯電。半径 6・6 体まで） |
| 持続範囲（毎秒） | **R × 0.3 × 段 × x** |
| 線状（軌跡） | **R × 0.3 × 段 × x**、**1 体につき 1 回** |

**当たる数の上限は 6 体。** 超えた分は **1/2**。

## 3-1. 重なり方（2026-08-31 決定）

**複数人で同じ敵を殴ったとき、どうなるか。**

| 何 | 持ち主 | 重なると |
| --- | --- | --- |
| **燃焼**（延焼） | **敵 × 付けた人** | **人ごとに別々**（3 人なら 3 本）。**同じ人の攻撃は 3 秒ぶん重なる** |
| **被ダメージ増**（焼灼・熔解） | 敵に 1 つ | **強いほうだけ残る**（同じ枠を二重取りしない） |
| **鈍化**（氷） | 敵に 1 つ | **誰が当てても同じゲージに溜まる**（共有） |
| **凍結**（絶対零度） | 敵に 1 つ | 掛かっている間は上書きしない |

> ### 燃焼だけ人ごとに持つ理由
>
> **弱い人の火が、強い人の火を上書きしてしまう**のを避けるため。
> **手柄も分かれる**——燃焼で倒したときの札（烈風）や吸収は、**付けた人**に返る。

## 4. DPS の読み方

**この表の DPS は、下の基準ビルドで計算した値。**

| | 値 |
| --- | --- |
| 基本火力 | 20／発（[10-bow.md](10-bow.md) 4 章） |
| 火 20 点 | **×1.50**（乗算の別枠） |
| 強撃 段 5 | ＋50％ |
| **加算の袋** | **×1.50**（1 ＋ 0.5） |
| **R（通常攻撃の最終火力・クリ前）** | **45** |
| クリ率 | **100％**（雷 20 の ＋50％ ＋ クリティカル 段 5 の ＋50％） |
| クリ倍率 | **3.0**（基礎 2.0 ＋ 会心強化 段 5） |
| **通常攻撃** | **135／発 ＝ 270 DPS** |

**％の上昇は加算の袋に入る**（[11-damage.md](11-damage.md) 1 章）——
**袋が ＋1.0 増えるごとに 180 DPS** 増える、と読める。

**100 発 ＝ 50 秒**として、**発動率を掛けた期待値**で出している
（5 発に 1 回のものは 1/5 に、クリ限定のものはクリ率を掛ける）。
**範囲は 6 体に囲まれたときの合計。**

**`x ＝ その属性の値 ／ 20`**（[12-element.md](12-element.md) 1 章）。
**段は最大・x ＝ 1** で計算している（5 属性平均だけ x ＝ 0.5）。
