# 仕様: 弓（Archer）

企画は [00-concept.md](../00-concept.md) 4-1。**このワールドで最初に作るもの。**

> ### 武器は 1 本しかない。
>
> v1 は 48 本あって、**1 本ずつは雑にしか作れなかった。**
> **1 本だけなら、隅まで作り込める。**

## 1. 操作

| | |
| --- | --- |
| 撃ち方 | **右クリック長押しで連射** |
| 間隔 | **0.5 秒に 1 発**（10 tick） |
| ため | **無し。** 押した瞬間に 1 発目が出る |
| 移動 | **遅くならない** |
| 矢 | **持たない・減らない** |

**押しっぱなしで撃ち続けられる。** 離せば止まる。

> ### なぜ「ため」をやめたのか
>
> v1 は **1 秒ためて 2.5 倍**だった。**溜める時間が退屈だった。**
> **押した瞬間に出て、押している間は出続ける**ほうが、手が止まらない。

### 1-1. 火力の物差しが変わる

**基礎攻撃力＝1 発の火力。**（v1 は「1 秒ためた 1 発」だった）

```
毎秒火力 ＝ 基礎攻撃力 × 2   （0.5 秒に 1 発なので）
```

**弓は 1 発 20、毎秒 40**（[4 章](#4-火力の土台2026-08-30-決定)）。

**v1 の数字はそのまま使えない。** 属性やエンチャントの数値も、ここを基準に引き直す。

## 2. 当て方

**当てるのは script。飛ばすのも script。実体は出さない。**
**見せるのは粒だけ**（[3-3](#3-3-軌跡の粒最初のものに戻した2026-08-30)）。

```
script が「弾」を持つ ──▶ 毎 tick 進める ──▶ 当たりを見る
                              └ 通った跡に粒を置く
```

> ### バニラの矢は使わない（2026-08-30 決定）
>
> **拡散・貫通・追尾を script で決める**（[00-concept.md](../00-concept.md) 6 章）。
> **バニラの発射に乗せると、放った後を触れなくなる。**
> **マルチショットが作れない。**

| バニラの矢に任せると | |
| --- | --- |
| 当たり判定 | **速い弾は 1 tick で通り抜ける** |
| 本数 | **1 発ずつしか触れない**（多重発射が組めない） |
| 挙動 | **重力・跳ね返り・刺さりが勝手に付く** |

### 2-1. 弾速がある（2026-08-30 決定）

> ### 撃った瞬間に当たらない。**飛んでいく時間がある。**
>
> v1 は**線を引いて即当て**だった（当たるのが速すぎて、避ける余地が無い）。

| | 仮の値 |
| --- | --- |
| 速さ | **80 マス/秒**（4 マス/tick） |
| 届く距離 | **48 マス**（12 tick で端まで） |
| 進め方 | **毎 tick 4 マスぶん進め、その区間で当たりを見る** |

**区間で見る**のが大事——**点で見ると、1 tick 4 マスの隙間を抜けてしまう。**

### 2-2. 当たり

| | |
| --- | --- |
| 当たりの太さ | 半径 **0.9 マス**（胴と頭の 2 点で見る） |
| 壁 | **抜けない**（当たった所で消える） |
| 人 | **素通りする**（PvE。味方が壁にならない） |
| 1 発が当たる数 | **1 体**（貫通はエンチャントで） |

## 3. 見せ方

### 3-1. 絵は 64x64

**v1 の描き方をそのまま引き継ぐ**（`worlds/pve/docs/spec/13-bow-view.md`）。

| | |
| --- | --- |
| 大きさ | **64x64**（バニラの 4 倍） |
| 形 | **バニラと同じ並び**（左下から右上へ弧・弦） |
| 描き方 | **1 画素ずつ置く。** ぼかさない |
| 影 | **3 色**（縁・地・光）。**縁を必ず入れる** |
| 角度と大きさ | **変えない**（持ち姿がぶれる） |

**書き出しで作る**——手で描き直さない（`tools/pve2-bow-art.py`）。

### 3-2. 絵は 1 枚。**矢はつがえない**（2026-08-30 決定）

| | |
| --- | --- |
| 枚数 | **1 枚だけ** |
| 姿 | **持っている限り、弦を引いたまま** |
| **つがえた矢** | **描かない**——**撃っていなくても矢が刺さって見える** |
| 撃った合図 | **小さく蹴り返す**（0.15 秒） |

**引く動きは見せない**——**銃のように撃つ**ので、見せる間が無い。
**撃つたびに弓が蹴り返る。** 動かないと、**連射しているのに手元が止まって見える。**

**他人から見た姿も、持っている間ずっと構えたまま**（`tools/pve2-player-bow.py`）。

**姿は「濃い木の弓に白い布、節から色羽根」**（2026-08-30 決定）。

| | |
| --- | --- |
| 弓身 | **濃い木**（縁・地・光の 3 色） |
| 巻き | **白い布**を 3 か所（握りと、その上下） |
| 先端 | **黒い口金** |
| 弦 | **細い銀** |
| 羽根 | **7 色**を、両端と巻きの所から扇状に |

**参考にした画像は `worlds/pve-v2/user/` に置いてある**（よそのゲームの弓）。
**色づかいと「羽根が生えている」という方向だけを取り、絵はこちらで描き起こす。**
**立体の模型は作らない**——絵 1 枚から起こす（`tools/pve2-bow-rig.py`）。

### 3-3. 軌跡の粒（**最初のものに戻した**・2026-08-30）

**琥珀色の粒を、弾の通った跡へ置く。** これだけで見せる（実体は出さない）。

| | |
| --- | --- |
| 何 | **`pve_v2:arrow_trail`**（最初に置いていたもの） |
| 間隔 | **0.7 マスごと**（空けすぎると点線に見える） |
| 消え方 | **0.22 秒で細って消える** |

> **作り直したものより、最初のものが一番良かった。**
> **属性やエンチャントの見せ方は、この上に足す。**

### 3-4. 手元の動き（2026-08-30 決定）

**弓は常に少し動いている。** 止まっていると、**持ち物ではなく貼り紙に見える。**

| いつ | どう動く | どうやって |
| --- | --- | --- |
| **撃った瞬間** | **後ろへ蹴り、先が跳ね上がる**（3 tick で戻る） | 押している長さを 10 tick で折り返し、**発射と位相を合わせる** |
| **持っている間** | **息づかいの揺れ**（わずかな上下と傾き） | `query.life_time` の正弦 2 本 |
| **走っている間** | **下げて傾ける** | `query.is_sprinting` |

**重ねがけで足す**——構え（`wield`）の上に、揺れ・反動・走りが加算される。
**反動は一人称だけに絞らない**（他人からも蹴り返って見える）。

> **書き出しは `tools/pve2-bow-rig.py`。** 手で JSON を書き換えない。

### 3-5. 音

| いつ | 何 |
| --- | --- |
| 放つ | **バニラの弦の音**（`random.bow`） |
| 飛ぶ | **自分たちで合成した軌跡の音**（小さく） |
| 当たる | **手応えの音**（別途） |

**放つ音は変えない**——v1 で作り替えたら、**弓を撃った感じそのものが薄くなった。**

## 4. 火力の土台（2026-08-30 決定）

**v1 の設定を引き継ぐ。** 数値だけ、連射に合わせて置き直した。

| | 値 |
| --- | --- |
| **弓の 1 発** | **20** |
| 間隔 | **10 tick**（0.5 秒） |
| **毎秒火力** | **40** |
| 弾速 | **80 マス/秒**（仮） |
| 届く距離 | **48 マス** |

### 4-1. HP

| | 値 |
| --- | --- |
| **敵** | **200**（10 発で倒れる） |
| **味方** | **10000**——**確かめている間だけ。** 本番は決め直す |

**計算も v1 から引き継ぐ**（[00-concept.md](../00-concept.md) 8 章）:

```
削る HP ＝ 最終攻撃力 × (1 − 防御率)
```

| | |
| --- | --- |
| バニラの体力 | **使わない**（削られない。`/kill` は効く） |
| 無敵時間 | **無い**（多段ヒットがそのまま入る） |
