## 1-1. ダメージの式

```
最終火力 ＝ 基本火力 × (1 ＋ Σ加算％) × 火属性 × 火事場 × クリティカル倍率
削る HP ＝ 最終火力 × (1 − 防御率) × 敵の被ダメージ増
特殊攻撃 ＝ 通常攻撃の最終火力（クリ前）× 係数     ← クリは乗らない
```

**積み上げてみる**（`/pve:ench` と `/pve:el` で 1 つずつ足すと、この順で確かめられる）:

| 積んだもの | 1 発 |
| --- | --- |
| 素 | **20** |
| ＋強撃 段 5（袋 ＋0.50） | **30** |
| ＋火 20（別枠 ×1.50） | **45** ← これが **R** |
| ＋クリティカル（倍率 2.0） | **90** |
| ＋会心強化 段 5（倍率 3.0） | **135** |
| ＋火事場（HP 0％・段 3 で ×2.5） | **337** |

| どこに入るか | もの |
| --- | --- |
| **加算の袋**（足してから 1 回掛ける） | 強撃・狙撃・接射・死神・初撃・疾走射・熱暴走・五行・**砕氷**・焼灼 |
| **乗算の別枠** | **火属性**・**火事場**・クリティカル倍率・撃つ間隔・防御カット・敵の被ダメージ増・**特殊攻撃の係数** |

**数字が合わないときは [spec/11-damage.md](spec/11-damage.md) 1 章を見る。**

### 式に出てくる記号

| 記号 | 意味 |
| --- | --- |
| **R** | **通常攻撃の最終火力（クリ前）**。特殊攻撃はこれを参照する |
| **段** | その札の段（1〜5） |
| **x** | **その属性の値 ÷ 20**（0.00〜1.00） |
| **min()** | 2 つの属性の**低いほう**の x（両方振らないと効かない） |
| **min3** | 3 つの属性の低いものの x |
| **x平均** | 5 属性の平均 ÷ 20（実際は 0.5 前後） |
| **D** | **鈍化度**（0〜1。満タンで敵の移動が半分） |

**特殊攻撃（爆発・燃焼・落雷など）にクリ判定は無く、参照する R もクリ前。**
**クリで増えるのは通常攻撃の一撃だけ。**
