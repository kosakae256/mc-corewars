# 仕様: マップ（城門と戦場）

企画は [00-concept.md](00-concept.md)。**戦うのは城門の外。**

> ### 街には入れない。
>
> **門は閉じている。** 街は**門の向こうに見えるだけ**——
> だから**作り込む所と、見えるだけの所を分ける。**

## 1. 何を作るか

```
            ┌──────────────────────────┐
            │   街（見えるだけ）        │  屋根とシルエット
            │  ┌────┐  ┌────┐         │
   北       │  └────┘  └────┘         │
   ↑        ╞══════[ 門 ]══════════════╡  城壁 ＋ 塔 2 本
   │        │                          │
   │        │        戦  場            │  ここで遊ぶ
   │        │                          │
            │   街道 ──→ 林            │  敵が来る方向
            └──────────────────────────┘
```

| 帯 | 奥行き | 密度 |
| --- | --- | --- |
| **街**（壁の内側） | **80** | **外形だけ。** 中は空。**通りの網・広場・市場・城**（2026-08-31 に広げた） |
| **城壁と門** | 6 | **いちばん作り込む** |
| **戦場** | 56 | **作り込む。** 起伏・遮蔽・街道 |
| 林（奥） | — | 敵の湧き元を隠す |

**総幅 120 × 総奥行き 140**（戦場 56 ＋ 城壁 4 ＋ 街 80）。

## 2. 座標

**原点は門の真ん中・地面の高さ。** ここを `(0, 0, 0)` として、すべて相対で書く。

| 軸 | 向き | 範囲 |
| --- | --- | --- |
| **X** | 左右（城壁に沿う） | **−60 〜 +60** |
| **Y** | 高さ | **−12 〜 +30**（**土台は −12 まで**——元の地形が下がっていても抜けない） |
| **Z** | **＋が街、−が戦場** | **−56 〜 +80** |

**地面は Y ＝ 0。** 敵は **Z ＝ −50 あたり**から来る。

## 4. 戦場

| | |
| --- | --- |
| 地面 | **波を 2 つ重ねた起伏**（±2）。表面は草・粗い土・ポドゾル・砂利を混ぜ、2％ で石が顔を出す |
| 道 | **けもの道**（幅 1〜3・左右に揺れる）。**まっすぐな街道にしない**——人工物に見える |
| 草木 | 短い草と花をまばらに。**林を 36 本**（奥と両端。湧き元を隠す） |
| 起伏 | **±2 まで。** 弓の射線が通らなくなるので、大きな丘は作らない。**城壁ぎわは平ら** |
| 遮蔽 | **岩を 8 個ほど**（半径 2〜4）。**背を高くしない**（1〜3） |
| 堀 | 城壁の前に**幅 6・深さ 3**。**橋は街道の 1 本だけ**——敵の流れを作る |
| かがり火 | 街道沿いに 6 基。**夜でも戦える明るさ** |

> ### 弓が主役の地形
>
> **見通しを塞がない。** 遮蔽は**低く、まばらに。**
> **敵が集まる所**（橋・門の前）を作って、範囲攻撃が活きるようにする。

## 7. 作り方

**プログラムで置く**（`packs/pve_v2/scripts/features/map/`）。

| | |
| --- | --- |
| コマンド | `/pve:map build` で建てる。`/pve:map clear` で消す |
| 置き方 | **1 tick に数千マスずつ**。全体で 10 秒ほど |
| 起点 | **コマンドを撃った人の足元**が `(0,0,0)` |
| やり直し | **数値を変えて建て直す**。手で直さない |

> ### 手で建てない
>
> **数値を変えて出し直す**ほうが速い——「塔をあと 5 段高く」が一発で入る。
> **手で直すと、次に建て直したときに消える。**

## 8. 岩山（`/pve:map rock`）

**立った所に、自然な石の柱・岩山を作る。** 毎回ちがう形・ちがう石。

| | |
| --- | --- |
| 形 | **塊を 2〜5 個重ねる**（metaball）＋ 段差と庇。**毎回ちがう** |
| 高さ | 16〜46 |
| 石 | **要塞（`.schem`）で使われている石 ＋ 丸石**から、**毎回 3〜5 種を引く** |
| 明るさ | **明るい石ほど選ばれやすい**（黒曜石やコールブロックは出にくい） |
| 積み方 | **層で色を変える**——一様に混ぜると砂嵐になる |

### 8-1. 守る範囲（**ここに掛かったら作らない**）

```
(1201, 13, 643) 〜 (1308, 132, 757)
```

> ### 1 ブロックでも掛かったら、**何も置かずに中止**
>
> **途中まで置いて止める**と、壊すのが手作業になる。
> **置く前に全部の座標を調べて、掛かるなら 1 つも置かない。**

## 9. 周りの地形（`/pve:map land`）

**戦場の周り 500 × 500 を、細い岩尾根と歩ける谷で埋める。** 一度のコマンドで全部作る。
**押すたびに違う地形**（種を毎回変える）。

> ### 目指す絵
>
> 見本は Wynncraft の "Canyon of the Lost"（`user/スクリーンショット 2026-09-01 104839.png`）。
>
> **細い山が連なり、その間に歩ける谷がある。**
> 谷を**土の道（けものみち）**が通り、深い谷は**暗い木の橋**で渡る。
> **要塞は岩の輪に囲まれ、入れるのは道の切り通しと、正門前の広場からだけ。**
>
> RPG の地形を想定している。**現実に即している必要はない。**

| | |
| --- | --- |
| 範囲 | 戦場の箱を **±200 マス**広げた所（X 1001〜1508・Z 443〜957） |
| 谷底 | **18〜28。** ここが歩く高さ |
| 尾根 | **5〜7 本の族。** 幅 30〜54 マス、高さ 40〜120。頂は最大 200 |
| 戦場の中 | **1 マスも触らない**（`1201,13,643`〜`1308,132,757`） |
| 囲い | 戦場から **42 マス**を頂点とする岩の輪（高さ ＋58）。**正門前だけ開ける** |
| 正門前 | **`(1255, 792)` を中心に 104 × 80 の舗装広場。** 平ら |
| 道 | `z = 758` の `x = 1246` / `1264` が入口。**勾配は 0.22 まで**（横 4.5 で縦 1） |
| 石 | **戦場に近いほど黒く、遠いほど明るい。** 5 段 × 16 種 |

### 9-1. チャンクが読み込まれていないと置けない

**500 マス先のブロックは、そのままでは置けない**（読み込まれていない）。

> ### `tickingarea` だけでは足りなかった
>
> 実機で **15 万ブロックが置けなかった**（2026-09-01）。
> **帯の真ん中へプレイヤーを飛ばし（観戦にして y = 235）、2 秒待ってから置く。**
> 終わったら元の位置と遊び方に戻す。

```
帯（144 × 144）ごとに
  tickingarea を張る → プレイヤーを飛ばす → 40 tick 待つ → 置く → 外す
```

**16 帯に分けて順に作る。** 全体で数分かかる。

### 9-2. 「細い山が連なる」の作り方

**波の零線を山にする。**

```
|波(x, z)| < 太さ  →  その帯を持ち上げる
```

零線は**長くうねる線**なので、帯はそのまま**細長い山の筋**になる。
族を 5〜7 本、**波長 80〜170 マス**で重ねると、筋が交わって連なる。

| 直したこと | なぜ |
| --- | --- |
| 波長を 300 マス超 → **80〜170** | 尾根が 3 本しか出ず、ただの平原になった |
| 幅を `f × 9` → **`f × 15〜27`** | **ナイフの刃**になり、登ることも歩くこともできなかった |
| 稜線を `^1.3` → **`^0.8`** | 尖りすぎ。上が丸く、裾が締まった山にする |
| 刻みを 6 → **2.5** | **櫛の歯**になった |

高さは**筋に沿って変える**（同じ高さの壁にしない）。**頂**を 3〜5 個、尾根の上に乗せる。

### 9-3. 道は歩けなければ意味が無い

> ### けものみちが急すぎて移動できなかった（2026-09-01 実機）

**点を谷底に置き**（周り 8 か所を見ていちばん低い所を選ぶ）、**近い 2 つずつ結ぶ**。
そのあと**傾きを緩める**——辺ごとに「縦の差 ≦ 長さ × 0.22」へ寄せるのを 60 回繰り返す。
**入口（`z = 758`）は動かさない。**

**1/5 の点は高い所に置く**——尾根へ登る道も要る。**外へ出る道は 1 本だけ**
（四辺すべてに作ったら、外から入り放題になった）。

| 道と地面 | どうするか |
| --- | --- |
| 地面が高い | **削る**（切り通し） |
| 少し低い（9 マス以内） | **盛る**（土手） |
| 大きく低い | **橋を架ける**——暗い木（ダークオーク）の桁・欄干・橋脚 |

**舗装は戦場から 22 マス以内と正門前の広場だけ。** 外は**土の道**
（`grass_path`・粗い土・土・砂利・ポドゾル・泥）。

### 9-4. 崖には地層が出る

> ### 表面 1 マスだけ気を配っても、切り立った面は下の石がそのまま見える
>
> ここが 1 種類だと「岩肌に土が貼ってあるだけ」に見えた（2026-09-01 実機）。

**6 マスごとに層を替える**（`strataAt`）。層の境目は 16 マスの升ごとに上下するので、
**地層が波打って見える**——定規で引いた縞にはならない。
石は表面と同じ**5 段の表**から選ぶので、**戦場に近いほど黒い崖**になる。

### 9-5. 石の表（5 段 × 16 種）

```
明るさの段 = 戦場からの距離（0.6）＋ 高さ（0.25）＋ まだら（±0.25）
```

| 段 | 中身 |
| --- | --- |
| 0（戦場のすぐ外） | 黒石・磨かれた黒石・深層岩・深層岩タイル・玄武岩・黒いテラコッタ |
| 1 | 深層岩・玄武岩・凝灰岩・灰色コンクリート・泥 |
| 2 | 凝灰岩・安山岩・丸石・苔むした丸石・石・砂利・粗い土 |
| 3 | 石・安山岩・花崗岩・石レンガ・苔むした石レンガ・鍾乳石 |
| 4（外周） | 石・滑らかな石・花崗岩・閃緑岩・方解石・鍾乳石 |

**白いブロックは入れない**（明るすぎた）。**要塞で使われている石をそのまま使う**——
地形と建物が地続きに見える。

**選び方**は「まだら（滑らかな波）で選び、粒は表 2〜3 個ぶんだけ揺らす」。
1 マスごとの乱数を強く効かせると**砂嵐**になる。

### 9-6. 見た目は写真で確かめる（`tools/mc-render.py`）

> ### 平面図では、色合いと起伏の違和感が分からない

**地形と要塞を 1 つの場面に起こし、任意の位置・任意の向きから撮る。**
道具の詳細は [docs/spec/07-land-shot.md](../../../docs/spec/07-land-shot.md)。

## 10. 戦場の床を散らす（`/pve:map floor`）

**戦場の床（y = 13）が一色で単調。** 歩いた周りを、**暗い石でまばらに敷き替える。**

```
/pve:map floor      入／切（もう一度で止まる）
```

**入れている間、自分のまわり 14 マスの y = 13 が塗り替わる。** 歩けば塗る範囲が広がる。

| 使うブロック | |
| --- | --- |
| `cobbled_deepslate` | 深層岩の丸石 |
| `deepslate_bricks` | 深層岩レンガ |
| `cracked_deepslate_bricks` | ひび割れた深層岩レンガ |
| `cracked_polished_blackstone_bricks` | ひび割れた磨かれたブラックストーンレンガ |
| `smooth_basalt` | 滑らかな玄武岩 |
| `mud` | 泥 |
| `deepslate_coal_ore` | 深層石炭鉱石（**少なめ**） |
| `bedrock` | 岩盤（**いちばん少なめ**） |

### 10-1. 行き来してもチラつかせない

> ### 毎回引き直すと、通るたびに床が変わる
>
> **同じ場所は必ず同じ石**にする——座標から作ったハッシュで引く（乱数を使わない）。
> **入れ直すと種が変わる**ので、別の散り方をやり直せる。

**4 × 4 の升のハッシュを 6 割、1 マスごとのハッシュを 4 割**混ぜて引く。
こうすると**小さな塊で散る**——1 マスごとに完全に独立させると砂嵐になる。

### 10-2. 触らないもの

| | なぜ |
| --- | --- |
| **空気** | 床がない所は塗らない |
| **上（y = 14）が空気でない所** | **壁や柱の下**。見えないうえに、構造物を壊す |
| **すでにその石だった所** | 置き直さない（無駄） |

**1 tick に 200 マスまで**。一度塗った柱は覚えていて、二度は塗らない
（切ると忘れる）。
