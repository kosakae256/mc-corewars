# 企画: PVE（仮）

## 1. 一言でいうと

**押し寄せるモブを、仲間と捌き続けるローグライク PvE。**

倒すたびに**武器が落ち、レベルが上がり、強くなっていく。**
**全滅したら終わり。** どこまで行けたかを競う。

| | |
| --- | --- |
| 相手 | **モブ**（プレイヤー同士は戦わない） |
| 形式 | **ウェーブ制**。1 波ごとに敵が増える |
| 終わり方 | **全滅** |
| 空気 | **パーティゲームっぽく。** 重い攻略ではなく、わいわい遊べるもの |

## 2. 1 試合の長さ

**始める前に選ぶ。**

| | |
| --- | --- |
| 想定 | **15 分 〜 1 時間** |
| 選び方 | ゲーム時間を選択する |

**15 分想定のウェーブおきにボスが出る**（3 章）。

## 3. 難易度

**4 段階。** 始める前に選ぶ。

| | |
| --- | --- |
| `easy` | |
| `normal` | |
| `hard` | |
| **`insane`** | **初見では無理**なくらい。ただし**難しくしすぎない** |

> **insane は「初見無理」であって「理不尽」ではない。**
> 何度か遊べば形が見える、という所に置く。

## 4. ウェーブ

| | |
| --- | --- |
| 進み方 | **1 波を突破すると休憩 → 次の波** |
| 休憩 | **最低 10 秒・最大 30 秒** |
| 敵の数 | **波が進むほど増える** |
| **ボス** | **15 分想定のウェーブおき**に召喚 |
| 終わり | **全滅した時点** |

### 死んでも戻れる

**倒れても、そのウェーブが終われば復活する。**

**何らかのペナルティを付けるかもしれない**（未定 / 8 章）。

### 途中参加

**後から入っても、スケールに多少は追いつけるようにする。**

具体的な追いつかせ方は未定（8 章）。

### 人数で敵の数を変える

**参加人数に応じて増やす。**

> **1 次関数にはしない。**
> 人数ぶんそのまま増やすと、**多いほど楽になるか、多いほど地獄になるか**の
> どちらかに振り切れる。**別の式で調整する**（式は未定 / 8 章）。

## 5. 職業（ロール）

詳細は [04-roles.md](04-roles.md)。

## 6. 武器とエンチャント

**大量の武器と、大量のエンチャント。**

| | |
| --- | --- |
| 目安 | **武器 10 種 × エンチャント 5 種**（職業ごと） |
| エンチャント | **独自のもの。** バニラのエンチャントは使わない |
| 手に入り方 | **敵を倒したときにランダムで、未鑑定の状態で落ちる** |
| レア度 | **mythic / legendary / rare / uncommon / common** |

詳細は [03-content.md](03-content.md)。

## 7. 数字の作りはバニラと切り離す

| --- | --- |
