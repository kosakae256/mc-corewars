# 中身: 武器・エンチャント・属性

企画は [00-concept.md](00-concept.md)、職業ごとの一覧は [04-roles.md](04-roles.md)。

## 1. レア度

| レア度 | 位置づけ |
| --- | --- |
| **common** | **初期武器だけ。** ここに該当するのは支給品のみ |
| **uncommon** | |
| **rare** | |
| **legendary** | **普通に遊んでいる分には最強** |
| **mythic** | **一人で全ウェーブを壊せる、馬鹿な性能** |

### 1-1. 基礎攻撃力とは（2026-08-28 決定）

**1 秒ためて撃ったときの火力。**

| | |
| --- | --- |
| **1 秒ため** | **基礎攻撃力そのもの**（ため時間が長い武器以外は、これが最大ため） |
| **ためなし** | **1/10** |
| ため時間が長い武器 | **1 秒の時点が基礎。** そこから先は武器ごとの倍率で伸びる |

> **「最大ためで n 倍」ではなく、「基礎＝最大ため」にする。**
> どの武器も**溜めて撃つ**のが基本なので、
> **普段出す数字を基礎に置いたほうが、比べられる。**

### 1-2. 目指す毎秒火力（2026-08-28 決定）

**「だいたいこれくらい出ればいい」という目安。**

| レア度 | 毎秒 | 内訳 |
| --- | --- | --- |
| **common** | **30** | 効果なし |
| **uncommon** | **50** | **特殊能力を含めて 50** |
| **rare** | **60** | **60 ＋ 特殊能力**（火力の上乗せ・足止めなど） |
| **legendary** | **60** | **60 ＋ より強い特殊能力** |
| mythic | — | **気にしない**（まだ作らない） |

**撃った後の 0.05 秒は誤差**として扱う——
**基礎攻撃力の数字を、そのまま毎秒とみなしてよい**（実際は約 5% 低い）。

| | |
| --- | --- |
| **火力を増やす特殊能力を持つ武器** | **基礎を下げて、合わせて目安に収める** |
| **足止め・回復・稼ぎの武器** | **基礎はそのまま。** 目安は火力だけを見る |

> **rare と legendary の毎秒は同じ 60。**
> **差は特殊能力の強さ**であって、**素の火力ではない**
>（[1 章](#1-レア度)の「威力は横並び」と同じ考え）。

**ためなしが 1/10** なのは、**溜めずに連打する遊びを潰すため。**
ため時間が無い武器（速射弓）は、**その 1/10 を高速で撒く**という別の形になる。

| | |
| --- | --- |
| 落ち方 | **敵を倒したときにランダム。未鑑定の状態で手に入る** |
| 後半ほど | **レア度の高いものが落ちやすい** |
| **基本威力** | **どのレア度もほぼ同じ**にする |
| **差が出るところ** | **エンチャントの付きやすさ** |

> **威力で殴り合わない。**
> レア度が上がると**エンチャントが付きやすくなる**——そこが強さの差になる。
>
> **mythic だけは別枠。** エンチャントが恐ろしく付きやすく、威力も高い。

## 2. エンチャント

| | |
| --- | --- |
| 形式 | **独自のもの。** バニラのエンチャントは使わない |
| 数の目安 | **職業ごとに 5 種**（武器は 10 種） |
| 付き方 | **ランダム。** レア度が高いほど付きやすい |

### 2-1. 共通エンチャント

**どの職業にも付く。**

| | |
| --- | --- |
| **強撃** | 基本威力が **1%〜100%** 上昇する |
| **クリティカルヒット** | クリティカル時の威力が上がる（**50%〜200%**） |
| **吸収** | （効果の詳細は未定） |
| **採掘者** | **エメラルドのドロップ率が上がる**（[01-rules.md](01-rules.md) 4 章） |
| **本の虫** | **経験値の取得量が上がる**（同 3 章） |
| **背水の陣** | **HP が低いほど火力が上がる** |

職業ごとのエンチャントは [04-roles.md](04-roles.md)。

> **背水の陣は共通のもの**（HP 依存）。
> Archer 側の**「近いほど火力が上がる」は接射**に改名した（2026-08-28）。
> **同じ名前で別の効果**があると、どちらの話をしているのか分からなくなる。

### 2-2. 戦うためだけのものではない

| 種類 | 例 |
| --- | --- |
| 火力を上げる | 強撃・クリティカルヒット・背水の陣 |
| **稼ぎを増やす** | **採掘者**（エメラルド）・**本の虫**（経験値） |

> **強さ以外に振れる枠を作る。**
> 「火力は落ちるが、次の武器が早く来る」——**選ぶ余地**になる。

## 3. 属性

### 3-1. 種類

**水・雷・火・風・氷** の 5 つ。

### 3-2. 付き方

| レア度 | 付く確率 |
| --- | --- |
| uncommon | **20%** |
| rare | **50%** |
| legendary | **100%** |
| **mythic** | **別枠で付く** |

**2 属性目が付くこともある。** 確率は**元の確率 × 20%**。

| 元の確率 | 2 つ目 |
| --- | --- |
| 20% | 4% |
| 50% | 10% |
| 100% | 20% |

### 3-3. 弱点も耐性も作らない（2026-08-29 に言い直した）

**属性による有利不利は無い。** **ダメージが増えも減りもしない。**

> **「属性耐性」という数値はある**が、**軽減率ではない**——
> **効果が満ちるまでの量**（[spec/17-element.md](spec/17-element.md) 2 章）。
> 耐性 50 なら**蓄積 50 で最大の効果**になる。**削られる HP は 1 も変わらない。**

あるのは**「その挙動が効くか、効かないか」と「満ちるのが速いか遅いか」だけ。**

> 例: **氷が炸裂しないモブ**が居る。
>
> ダメージ量で有利不利を作ると、**その場に合う武器を持っているかどうか**で
> 勝負が決まってしまう。**挙動のほうを効かなくする。**

**耐性値が無いので、「耐性を無視する」効果も作らない。**

### 3-4. 効き方は武器ごとに違う

**属性の付いた武器は、攻撃時・ヒット時に特殊な挙動をする。**

**効果もパーティクルも、武器によって異なる。**
職業ごとの一覧は [04-roles.md](04-roles.md)。

### 3-5. 蓄積は「与えたダメージ」で溜まる

**ヒット数では溜まらない。**

> **数を刻めば早い、にしない。**
> そうすると**弱い多段武器がいちばん属性を回せる**ことになる。

**耐性はモブごとに決める**（3-3、[spec/17-element.md](spec/17-element.md) 2-1）。

## 4. 決まっていないこと

- **吸収**の効果
- 未鑑定の**鑑定のしかた**（どこで・どう開けるか）
- 武器の名前（`○○` になっているもの）
- レア度ごとの落ちやすさの数値
- mythic の枠（別枠とは具体的にどう付くか）
- 属性ごとの蓄積量の式
