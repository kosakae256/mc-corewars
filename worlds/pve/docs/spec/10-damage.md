# 仕様: HP とダメージ

企画は [00-concept.md](../00-concept.md)、ルールは [01-rules.md](../01-rules.md)。

## 1. バニラの体力は「残すが、削られない」（2026-08-29 に言い直した）

**プレイヤーもモブも、戦いの HP はこちらが持つ。**

| バニラに任せると | |
| --- | --- |
| 無敵時間 | **多段ヒットが刻めない** |
| 防具・軽減 | **武器の数字が相手によって変わる** |
| 上限 20 前後 | **桁が足りない**（3 桁を扱う） |

**攻撃・落下・炎——ダメージの原因は全部打ち消し、体力は満タンに戻す。**

> ### ただし、体力そのものは残っている
>
> **`/kill` は効かなければならない。**
> 「体力が無い」のではなく、**「削られない」だけ。**
>
> | | |
> | --- | --- |
> | 敵の攻撃・落下・炎 | **打ち消す**（こちらの HP で処理する） |
> | **`/kill`（`self_destruct`）** | **通す。** 運営が消せなくなると詰む |

**見た目のハートは消す**（[15-hud.md](15-hud.md) 2-1）。中身が飾りなので、
残っていると嘘をつく。

### 1-2. 人同士は当たらない（2026-08-29 決定）

> ### PvE なので、**プレイヤー同士のダメージは無い。**

| | |
| --- | --- |
| 矢 | **人を素通りする。** 味方が前に立っても**矢が止まらない** |
| 範囲・爆発・属性 | **モブだけを拾う**（`abilities/util.ts` の `mobsAround`） |
| 例外 | **癒しの弓・光の射手だけ**、人を的にする——**削らずに回復させる** |

**「当たらない」だけでなく「止まらない」ことが大事。**
止まると、**味方が壁になって撃てない。**

### 1-1. 無敵時間は無い

**こちらの HP は動的プロパティなので、無敵時間という考えが最初から無い。**

| | |
| --- | --- |
| 1 tick に 3 人から殴られた | **3 回ぜんぶ入る** |
| 星が 5 発同時に落ちた | **5 回ぜんぶ入る** |

**手応えの出し方も、これに合わせる**（[16-feedback.md](16-feedback.md)）——
バニラの赤い点滅を借りると**無敵時間に飲まれて出なくなる。**

## 2. 初期値（2026-08-28 決定）

| | HP | 攻撃力 |
| --- | --- | --- |
| **プレイヤー** | **200**（いまは **10000**。下） | 武器による（[03-content.md](../03-content.md) 1-1） |
| **モブ（ゾンビ）** | **200** | **20** |

> ### プレイヤーの HP は、いま 10000（2026-08-29）
>
> **確かめている間だけの値。** 48 本の弓と 26 種のエンチャントを試すのに、
> **200 ではすぐ倒れて確認にならない。**
> **ウェーブの仕組みを作るときに 200 へ戻す。**

## 3. 計算

```
削る HP ＝ 最終攻撃力 × (1 − 防御率)
```

| | |
| --- | --- |
| **最終攻撃力** | **バフを全部乗せ終えた値。** ここへ来る前に確定している |
| **防御率** | **−100〜100 の %。** 0 で素通り、100 で完全カット、**負で増える** |

> **負の防御率は「水」が作る**（[17-element.md](17-element.md) 3 章）。
> **−20% なら 1.2 倍**入る。**攻撃側を強くするのではなく、受け側を弱くする。**

**軽減はこの 1 段だけ。** 防具も耐性も無い（[01-rules.md](../01-rules.md) 3-5）。

### 3-1. 最終攻撃力の組み立て

**掛ける順番を決めておく。** 足し算と掛け算が混ざると、後から追えなくなる。

```
基礎攻撃力（武器）
  × ため具合           1 秒ためで 1.0 / ためなしで 0.1
  × 職業の倍率         Blade の 3 段目 ×2 など
  × ステータス（力）
  × エンチャント       強撃 +1〜100% など
  × バフ・デバフ
  ＝ 最終攻撃力
```

**組み立てる場所は 1 か所**（`lib/attack.ts`）。
**呼ぶ側は「最終攻撃力」だけを渡す。**

### 3-2. 防御率の集め方

**0 から始めて、持っているものを足す。**

| 何が動かすか | 例 |
| --- | --- |
| バフ | 「防御 +20%」 |
| デバフ | **属性の水**（防御率を削る。[03-content.md](../03-content.md) 3-4） |
| ステータス（防） | [01-rules.md](../01-rules.md) 3-2 |

**足し終えたら −100〜100 に収める**（**負なら受けるダメージが増える**）。

> **水の蓄積は武器ごとに分かれている**（[17-element.md](17-element.md) 2-2）ので、
> **その武器で濡らした分だけ、その武器の攻撃が重くなる。**

## 4. 通り道は 1 本

**武器も、モブの殴りも、属性も、最後はここを通る。**

```
最終攻撃力 ─→ 防御率で削る ─→ HP を引く ─→ 0 なら倒れる
                                     ↓
                              当たった後の処理（フック）
```

**通り道が 1 本なら、数字が合わないときに見る場所も 1 つ。**

### 4-1. 当たった後のフック

**属性・エンチャント・武器の追加効果は、ここに挿す。**

| いつ | 何が要るか |
| --- | --- |
| **当たった** | 誰が・誰に・いくら削ったか |
| **倒した** | 誰が・どこで |

**属性の蓄積は「与えたダメージ」で動く**（[03-content.md](../03-content.md) 3-5）ので、
**削った値がフックに渡る**必要がある。

> **ヒット数で動かさない。**
> 速射の武器が、そのまま属性を回す装置になってしまう。

## 5. 基礎ダメージと追加ダメージ（2026-08-29 決定）

**派手な武器は、2 つの数字でできている。**

| | 何か | 誰が出すか |
| --- | --- | --- |
| **基礎ダメージ** | **当てた 1 発**。矢が刺さった分 | `lib/attack.ts` → `hit()` |
| **追加ダメージ** | **その後に起きること**。星が降る・爆ぜる・連鎖する | フックから `hit()`（`kind: "extra"`） |
| **属性ダメージ** | **属性が削る分**。雷・火・風・氷 | 属性から `hit()`（`kind: "element"`） |

**分けて数える。** 混ぜると、**武器が強いのか効果が強いのかが分からなくなる。**

> 性能表は [14-effect.md](14-effect.md)。**追加ダメージを持つ武器は、必ずそこに表を書く。**

### 5-1. 追加ダメージは、ために従う

> ### ためきっていない攻撃で、演出だけ満額出てはいけない。

**ため具合（0.1〜1.0）は、追加ダメージにも掛かる。**
掛け方は**武器ごとにどちらか**を選ぶ。

| 掛け方 | どう見えるか | 例 |
| --- | --- | --- |
| **数を減らす** | **降ってくる星が 5 発 → 1 発** | 星屑・流星・散華 |
| **威力を減らす** | 爆風の大きさと削りが小さくなる | 爆裂・大砲弓 |

**数で表すほうを優先する。** **画面を見ただけで、ためが足りなかったと分かる。**

```
発数 ＝ clamp(round(最大発数 × ため具合), 1, 最大発数)
```

**1 発は必ず出す。** ゼロにすると「効果が壊れている」ように見える。

| ため | 星屑の星 |
| --- | --- |
| なし（0.1） | **1 発** |
| 半分（0.55） | **3 発** |
| ためきり（1.0） | **5 発** |

### 5-2. ためを持たない武器

**ため具合が常に 1.0 の武器も出る**（速射・自動）。
そのときは**発数も威力もそのまま。** 代わりに**基礎攻撃力で釣り合いを取る**
（[archer-weapons.md](../drafts/archer-weapons.md) 7 章）。

### 5-3. 何がまた何かを呼ぶか（2026-08-29 に整理した）

| 何の攻撃か | 効果フック | 属性 |
| --- | --- | --- |
| **基礎** | ○ | ○ |
| **追加** | **×** | **○** |
| **属性** | × | **×** |

| なぜ | |
| --- | --- |
| 追加 → 効果 を切る | 星が当たって**また星が降ると、無限に増える** |
| 追加 → 属性 は通す | **星の 1 つ 1 つが、火なら燃やす**（2026-08-29 決定） |
| 属性 → 属性 を切る | **火が火を呼んで止まらなくなる** |

> **表示用のフックは無い**（2026-08-29 に消した）。
> **ダメージの数字を出すのをやめた**ため（[15-hud.md](15-hud.md) 4 章）。

## 6. 倒れたとき

| | |
| --- | --- |
| モブ | **消す**（爆ぜる演出） |
| プレイヤー | **いまは満タンに戻す**（下）。倒れ方は[ウェーブの仕組み](../01-rules.md)と一緒に決める |

> ### 0 のまま置かない
>
> **HP 0 のまま放っておくと、殴られるたびに「倒れた」が鳴り続ける**
> （2026-08-29 の直し）。**倒れたらその場で満タンに戻す**——
> **本当の倒れ方（観戦・ウェーブ終わりに復活）ができるまでの仮。**

## 7. まだ無いもの

- ステータス（力・防）の効き方
- バフ・デバフの持ち方
- クリティカル（運）
- プレイヤーの倒れ方と復活
