# 仕様: 属性

企画は [03-content.md](../03-content.md) 3 章、職業ごとの効果は
[04-roles.md](../04-roles.md) 2-4。ダメージの通り道は [10-damage.md](10-damage.md)。

## 1. 何が決まっているか

| | |
| --- | --- |
| 種類 | **水・雷・火・風・氷** の 5 つ |
| 付く先 | **武器 1 本ずつ**（同じ種類の武器でも、付いているものと付いていないものがある） |
| いくつ付くか | **1〜5**。ふつうは 1、まれに 2（[03-content.md](../03-content.md) 3-2） |
| 何で動くか | **与えたダメージ**（ヒット数ではない。[03-content.md](../03-content.md) 3-5） |
| 追加ダメージ | **属性は乗る**（[10-damage.md](10-damage.md) 5 章の「追加」にも） |

## 2. 蓄積と属性耐性（2026-08-29 決定）

```
蓄積  ＝ その属性で与えたダメージの合計
効き具合 ＝ clamp(蓄積 ÷ 属性耐性, 0, 1)
```

> ### 属性耐性は「効きにくさ」ではなく、**「満ちるまでの量」**。
>
> **耐性 50 なら、蓄積 50 で最大の効果になる。**
> 耐性が高いほど**満ちるのが遅い**——**ダメージは 1 も減らない。**

**[03-content.md](../03-content.md) 3-3 の「耐性値は無い」は、
「ダメージ量の有利不利を作らない」という意味に読み替える**（2026-08-29 に言い直した）。

### 2-1. モブごとの耐性

| モブ | 水 | 雷 | 火 | 風 | 氷 |
| --- | --- | --- | --- | --- | --- |
| **グラント** | 50 | 50 | 50 | 50 | 50 |

**既定は 50。** 表に無いモブはこれを使う。

> 弓の 1 発が 45〜65 なので、**ほぼ 1 発で満ちる。**
> **「当てれば効く」**が既定で、**効きにくいモブは耐性を上げて作る。**

### 2-2. 蓄積は武器ごとに分かれる

> ### 弓の雷と、他の武器の雷は**別物。**

**入れ物は「武器の種類 × 属性」ごと**（`pve:g_bow_fire` のように持つ）。

| | |
| --- | --- |
| 分け方 | **武器の種類**（弓／剣／杖…）。**弓 A と弓 B は同じ入れ物** |
| 水の効き先 | **その武器の攻撃だけ**が重くなる（濡らした武器で殴る） |
| 名札に出す分 | **いちばん進んでいる武器の分**（[15-hud.md](15-hud.md) 3-2） |

**持ち替えたら溜め直し。** ひとつの武器で押し切るほうが強い、という形にする。

### 2-3. 溜まらない属性がある

| 武器 | 溜まる | 溜まらない |
| --- | --- | --- |
| **弓** | **水・火・氷** | **雷・風** |

**雷と風には「溜まる」という考えが無い**——**当たれば、その場で満の効果。**

> **溜まらない属性の蓄積率は名札にも出ない**（入れ物を持たないので）。

### 2-4. 時間で落ちる

**1 秒に、耐性の 5%。**

| 耐性 | 毎秒 | 満タンから空まで |
| --- | --- | --- |
| 50 | **2.5** | **20 秒** |

> **前は 3 秒で空になっていた。** 速すぎて、**溜める意味がほとんど無かった。**
> **そう簡単には冷めない**ようにした（2026-08-29）。

## 3. 属性ごとの効き方（2026-08-29 に直した）

**最大の効果**（効き具合 1.0）を書く。**途中は掛け算で薄くなる。**

| 属性 | 効果（最大） | 効き具合をどこに掛けるか |
| --- | --- | --- |
| **水** | **受けるダメージが 1.25 倍** | **倍率**（1.0 → 1.25） |
| **雷** | 与ダメの **50%** ＋ **一瞬止める** | **止める長さ**（[3-1](#3-1-雷は溜まるほど止まらない)） |
| **火** | 与ダメの **75%** を **1 秒おきに 5 回** | **かからない**（[3-3](#3-3-火は積み上げ式)） |
| — | **雷・風は溜まらない**ので、**いつも満**（[2-3](#2-3-溜まらない属性がある)） | — |
| **風** | **後ろへ弾き飛ばす** ＋ 与ダメの **20%** | **弾く強さと量** |
| **氷** | **満ちたら炸裂。** 相手の**現在 HP の 5%** | **炸裂するかどうか** |

**属性が与えるダメージは「属性ダメージ」**として通す（[4 章](#4-通り道)）。

### 3-1. 雷の「減衰」は宙に浮いている

[04-roles.md](../04-roles.md) 2-4 には「**受けるほど減衰し、最終的に効果なし**」とある。
**これは蓄積があって初めて書ける。**

**弓の雷は溜まらない**と決めた（[2-3](#2-3-溜まらない属性がある)）ので、
**いまは減衰しない**——**止める長さは毎回同じ**（6 tick ×(1 − 効き具合) ＝ 0 …ではなく、
溜まらない属性は効き具合 1 として扱うため **止めない**）。

> **止め続けられると、相手が何もできない**——という心配は、
> **止めていないので今は起きていない。**
> **雷の止めをどう表すかは決め直す**（[7 章](#7-まだ無いもの)）。

### 3-2. 氷だけ「満ちて起きる」

**他は当てるたびに効く。**
**氷は満ちるまで何も起きず、満ちた瞬間に炸裂して、蓄積が 0 に戻る。**

**溜める楽しさを 1 つは置く。** 全部が「薄く常に」だと、**手応えが平らになる。**

### 3-3. 火は積み上げ式

> ### 当て続けないと、火力が続かない。

**1 発当てるたびに「燃えの蓄積」が 1 つ増える。**

```
当てた 1 発（与ダメ D）→ 蓄積 1 つ
  1 秒後  D × 15%
  2 秒後  D × 15%
  3 秒後  D × 15%
  4 秒後  D × 15%
  5 秒後  D × 15%   ← ここでこの蓄積は消える（合計 75%）
```

| | |
| --- | --- |
| **蓄積の数** | **上限なし。** 当て続ければ何本でも並ぶ |
| **1 本の寿命** | **5 秒（5 回）。** それより前に受けた分は**もう効いていない** |
| **効き具合** | **量には掛けない**（当たれば必ず 75%） |
| 見た目 | **赤く染めない。** 音は**小さく「シュー」** |

#### 時計は相手ごとに 1 つ（2026-08-29 追加）

**蓄積ごとに時計を持たせない。**

| | |
| --- | --- |
| **初めて燃えた時** | そこから **20 tick おき**の時計が回り始める |
| 途中で足された蓄積 | **同じ時計に乗る**（次の鐘が 1 回目） |
| 鐘が鳴ったら | **燃えている蓄積を全部足して、1 回だけ削る** |
| 全部燃え尽きたら | **時計も止まる**（次に燃えたとき、また 20 tick 後から） |

> **蓄積ごとに削ると、数字が散らばって読めない。**
> **1 秒に 1 つだけ**出す（[15-hud.md](15-hud.md) 4-1）。

> **前の作りは残量を割合で削っていた。**
> **0 ダメージのまま永久に燃え続けた**（2026-08-29 に作り直した）。
> **回数で数える。** 5 回焼いたら消す。

### 3-4. 水は「受けるダメージが増える」

**防御率を下げる ＝ 受けるダメージが増える**、という意味
（2026-08-29 に確認した）。

```
受けるダメージ ＝ ふつうの値 × (1.0 〜 1.25)
```

**満ちて 1.25 倍。** 水そのものはダメージを与えない——
**他の攻撃が重くなる。**

### 3-5. 風は後ろへ飛ばす

**撃った相手から見て、まっすぐ後ろへ。** ＋ 少し浮かせる。

**強さは効き具合で変わる**（溜まるほど遠くへ）。

> **一度は 4 倍の強さで作って、吹き飛びすぎた**（追えなくなった）。
> **2026-08-29 に 1/4 にした。**

> はじめは**上へ浮かせるだけ**だった。**その場で跳ねるだけ**で、
> 「風で吹き飛ばされた」ように見えなかった（2026-08-29 の直し）。

## 4. 通り道

**属性のダメージも `hit()` を通る**（[10-damage.md](10-damage.md) 4 章）。
ただし**属性から属性は起きない。**

| 何の攻撃か | 効果フック | **属性** | 表示 |
| --- | --- | --- | --- |
| **基礎**（当てた 1 発） | ○ | ○ | ○ |
| **追加**（星が降る・爆ぜる） | × | **○** | ○ |
| **属性**（雷・火・風・氷が削る） | × | **×** | ○ |

> **追加ダメージにも属性は乗る**（2026-08-29 決定）。
> 星屑の星 1 つ 1 つが、**火なら燃やし、氷なら凍らせる。**
>
> **属性ダメージからは何も起きない。** でないと**火が火を呼んで止まらない。**

## 5. 見た目

### 5-1. アイテムに属性の印を出す

**説明欄に、属性のアイコンと名前を並べる**（[18-item-view.md](18-item-view.md) 2 章）。

```
§b🜄 水  §c🜂 火        ← 説明欄の 1 行
```

> **名前には出さない**（2026-08-29 変更）。
> **名前はレア度の色**を出す場所——**同じことを 2 回言わない。**

| | |
| --- | --- |
| 出し方 | **専用の字**（`font/glyph_E2.png`。`U+E200`〜`U+E204`） |
| 並び | **水・雷・火・風・氷の順**。付いているものだけ |
| いくつまで | **5 つ**（全部付くこともある） |
| 色 | **絵に焼き込む**（2026-08-29 変更）。出すときは **`§f` を前に置く** |
| 大きさ | **枡 32x32 の中に、高さ 0.20 で置く**（塗りは重いので、**小さくても読める**） |
| 縦の位置 | **枡の中心 0.525。** 0.50 では浮き、0.55 では沈んだ |

```bash
python tools/pve-element-glyphs.py worlds/pve/packs/pve
```

> ### 白い記号を並べるのはやめた（2026-08-29）
>
> **「アイコンが浮いている」だけに見えた。**
>
> | 直したこと | なぜ |
> | --- | --- |
> | **色を焼き込む** | 属性は**色で覚える。** 字の色に頼ると周りに引きずられる |
> | **濃い縁を付ける** | 明るい背景でも沈まない。**形が締まる** |
> | **芯に明るい色** | 平らな塗りは**印刷物**に見える |
> | **文字より小さく** | **塗りつぶした絵は、線でできた文字より重く見える。** 同じ高さだと大きすぎた |
>
> **枡は丸ごと 1 文字ぶん**として描かれるので、**枡の中で下に置けば下にずれる。**
> バニラの字は枡の **0.12〜0.80** に収まっている——**その真ん中に重ねる。**
>
> **色を焼いたので、色記号を掛けてはいけない**——濁る。`elementIcon()` を使う。

> **絵は自分たちで描く**（[11-structure.md](11-structure.md) 3-A）。
> バニラの字を使うと**アイコンに見えない。**

**説明欄は script が組み立て直す。** 属性が変われば説明欄も変わる
（[18-item-view.md](18-item-view.md) 4 章）。

### 5-2. 効いているかは、粒と音で分かる

**数字は出さない**（[15-hud.md](15-hud.md) 4 章）。**名札にも蓄積率は出さない**（同 3 章）。

| 何で分かるか | |
| --- | --- |
| **溜まっている間の粒** | 水は滴り、氷は冷気をまとう（[5-5](#5-5-溜まっている間も見える2026-08-29-追加)） |
| **炸裂の音** | 雷は**ビリッ**、氷は**パリン**（[16-feedback.md](16-feedback.md) 3-1） |
| HP の減り | バーが速く減れば効いている |

> **数字で見せない代わりに、目と耳で分かるようにする。**

### 5-3. 手応えも属性で変える

| 属性 | 音 | 赤く染めるか |
| --- | --- | --- |
| **火** | **小さく「シュー」** | **染めない**（燃えている間ずっと赤くなるため） |
| ほか | 殴られた音 | 染める |

**属性ダメージでは押さない**（風だけが自分で押す）。

### 5-4. 当たったときの粒（2026-08-29 実装）

**属性ごとに 1 つずつ作った**（[04-roles.md](../04-roles.md) 2-4 の「見せ方」に沿う）。

| 属性 | 粒 | 見え方 |
| --- | --- | --- |
| 水 | `pve:el_water` | **滴が弾けて落ちる**（光ではないので加算にしない。**体の外側から**） |
| 雷 | （3 つ組み合わせ） | **上から落ちる 1 本の雷**（[5-7](#5-7-雷は折れ線を引く)） |
| 火 | **バニラの炎** | `minecraft:basic_flame_particle` を**体の周りに 3 つずつ**（[5-6](#5-6-炎は絵を続ける)） |
| 風 | `pve:el_wind` | **緑の筋が横へ抜ける**（白いと**何の属性か分からなかった**） |
| 氷 | `pve:el_ice` | **細かい粉が漂う**（落ちも昇りもしない） |
| 氷（満ちた） | `pve:el_ice_burst` ＋ `_flash` ＋ `_ring` | **粉・閃光・輪を重ねる。** ここだけは派手に |

> ### 記号を描かない。**光の形を描く**（2026-08-29 に作り直した）
>
> はじめは「しずく・稲妻・炎・斬撃・結晶」を**くっきり**描いた——
> **アイコンが飛び出しているようにしか見えなかった。**
>
> | やめたこと | 代わりに |
> | --- | --- |
> | 輪郭のはっきりした記号 | **中心が明るく、外へ溶ける** |
> | 大きい粒を数個 | **小さい粒をたくさん**（細かいほど霧・粉に見える） |
> | 形で見せる | **動きと色で見せる**（落ちる・昇る・抜ける） |

### 5-7. 雷は「1 枚の絵 ＋ パラパラ漫画」（2026-08-29 に作り直した）

**節を縦に繋いで折れ線を作っていた。** 雷に見えなかった——
**粒を並べても点の列**にしかならず、**枝も細かい折れも描けない。**

> ### 雷 1 本を、縦長の絵に丸ごと描く。
> **`flipbook`（コマ送り）で明滅させる。**

| | |
| --- | --- |
| 絵 | **64x256 が 4 コマ横並び**（`pve_bolt_0`〜`_4`） |
| 形 | **5 通り。** 当たるたびに引く（同じ形が続くと「絵」に見える） |
| 寿命 | **0.16 秒。** **細くギザギザなのが出て、すぐ消える** |
| 大きさ | **2.0 × 8.0 マス**。板の中心で位置が決まるので、**半分持ち上げて**足元に着地させる |
| 着弾 | 別の粒で**閃光と火花** |

#### 絵は映像から切り出している

**手で描いた雷は「うねった線」にしかならなかった。**
**実際の落雷の映像**から、**1 本ずつ切り出して**使う。

```bash
python tools/pve-bolt-from-gif.py <映像.gif> worlds/pve/packs/pve
```

| やっていること | なぜ |
| --- | --- |
| **暗いコマで区切る** | **落雷 1 本＝1 種類**に分かれる |
| **下まで届いたコマだけ使う** | 伸びている途中は**途切れた線**に見える |
| **暗い所を完全に切る**（48 未満） | **透かしと背景を落とす。** 残すと**うっすら光る板**が見える |
| **明るさを不透明度にする** | 黒が透ける。**加算合成と相性がよい** |
| **雷の周りだけ縦長に切る** | 余白は**光の板**に見える |

> **他所の素材を持ち込むときは、使ってよいものかを先に確かめること。**
> 見本映像には**作者の透かし**が入っていることがある——
> **暗い所を切れば消えるが、消えたことを目で確かめる。**

**手描きの道具も残してある**（`tools/pve-bolt-flipbook.py`）——
**映像が使えないときのため。**

### 5-6. 炎は絵を続ける

**削るのは 1 秒おき**（[3-3](#3-3-火は積み上げ式)）だが、
**そのたびに 1 回出すだけでは「燃えている」に見えない**——**謎の粒**になった。

| | |
| --- | --- |
| 絵 | **2 tick（0.1 秒）おき。** 少しずつ、続けて出す |
| 何を | **バニラの `minecraft:basic_flame_particle`**（2026-08-29 決定） |
| どこに | **体の周り**（横 ±0.45・高さ 0.15〜1.35）に **3 つずつ** |

**削る間隔と絵の間隔は別のもの。** 揃えると、どちらかが不自然になる。

> ### 炎だけはバニラを借りる
>
> 自分で炎の形を描いて立ててみたが、**バニラのほうが炎に見えた。**
> **揺らぎ・明滅・上昇がすでに作り込まれている。**
>
> **借りるのは絵だけ。** **数と置き場所はこちらが決める**——
> そこを任せると「バニラの燃えているモブ」と同じ見た目になる。

### 5-5. 溜まっている間も見える（2026-08-29 追加）

**当たった時だけでは、効いているのか分からない。**
**水は自分ではダメージを出さない**ので、**何も起きていないように見えていた。**

| 属性 | 粒 | 見え方 |
| --- | --- | --- |
| 水 | `pve:el_water_wet` | **足元へ滴が落ち続ける**（濡れている） |
| 氷 | `pve:el_ice_chill` | **冷気が体をまとう**（半径 0.85・7 つ・1.3 秒） |

| | |
| --- | --- |
| 間隔 | **8 tick（0.4 秒）ごと。** 毎回出すと**粒が濃すぎて相手が見えない** |
| 条件 | **蓄積が 1 以上ある間** |
| 位置 | **体の外側**（半径 0.7〜0.85）。**内側に出すとモブに埋まって見えない** |

**雷・風は出さない**（**一瞬のもの**なので、状態として残らない）。
**火は焼けるたびに出る**ので、これとは別（[3-3](#3-3-火は積み上げ式)）。

**絵も定義も自分たちのもの**（[11-structure.md](11-structure.md) 3-A）。
**書き出しで作る**——手で JSON を書くと、6 つの間で書式がばらつく:

```bash
python tools/pve-element-particles.py worlds/pve/packs/pve
```

## 6. 付け方（いまは試験用）

**拾ったときに付く仕組みはまだ無い**（[03-content.md](../03-content.md) 3-2）。
**手で付けるコマンドだけ**を先に作る。

```
/pve:element water     手に持っているものに水を付ける
/pve:element all       5 つ全部
/pve:element clear     全部外す
```

**属性は「そのアイテム 1 本」に付く**（動的プロパティ）。
同じ種類の弓でも、**別の 1 本には付かない。**

## 7. まだ無いもの

- **拾ったときに付く**（レア度ごとの確率）
- 属性ごとの**専用の粒と音**
- **属性攻撃強化**（属性のダメージだけを増やす効果。**蓄積とは別計算**）
- Blade / Mage の効き方（[04-roles.md](../04-roles.md) 3-5）
