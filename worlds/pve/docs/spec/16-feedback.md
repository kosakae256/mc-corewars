# 仕様: 手応え

数字の出し方は [15-hud.md](15-hud.md)、計算は [10-damage.md](10-damage.md)。

> ### 当たったのか分からない戦いは、遊べない。
>
> バニラのダメージを打ち消した（[10-damage.md](10-damage.md) 1 章）ので、
> **赤い点滅も、音も、ノックバックも、こちらで出す。**

## 1. 出すもの（2026-08-29 決定）

| | 何 | 誰に |
| --- | --- | --- |
| **赤く光る** | モブが **0.5 秒**赤く染まる（**バニラと同じ**） | 全員に見える |
| **音** | 殴られた音が、当たった場所から鳴る | 近くの全員 |
| **ノックバック** | **プレイヤーが受けたときだけ**押される | 本人 |
| 数字 | [15-hud.md](15-hud.md) 4 章 | 全員 |

## 2. 赤く光るのは、バニラの点滅を借りない

**`applyDamage` でバニラに赤くさせる手は使わない。**

| なぜ | |
| --- | --- |
| **無敵時間に飲まれる** | 10 tick 以内の 2 発目は**何も起きない。** [10-damage.md](10-damage.md) 1-1 と噛み合わない |
| 体力が動く | 打ち消しと戻しが増える。**通り道が 2 本になる** |
| 死ぬ | 数字によっては**バニラ側で死ぬ** |

> 前のワールドで同じ穴に落ちた——
> **「+50% が乗らない」の原因が、無敵時間に飲まれた `applyDamage` だった。**

**実体の property で染める。**

| どこ | 何を書くか |
| --- | --- |
| `entities/grunt.json` | `properties` に **`pve:hurt`（bool・`client_sync`）** |
| `render_controllers/` | `overlay_color` を **`q.property('pve:hurt')` で切り替える** |
| script | 当たったら **true**。**3 tick 後に false** |

**script が始めて、script が終わらせる。** 無敵時間は関係ない。

### 2-1. 長さは 10 tick（バニラと同じ）

**0.5 秒。** はじめ 3 tick にしていたが、**一瞬すぎて見えなかった**
（2026-08-29 に直した）。

**多段ヒットの間は赤いままになる**——星屑は 5 tick ごとに落ちるので、
降っている間はずっと赤い。**それでよい。**
バニラも、連続で殴られれば赤いままになる。

### 2-2. 属性ダメージは手応えを変える（2026-08-29 追加）

| 属性 | 音 | 赤く染めるか |
| --- | --- | --- |
| **火** | **小さく「シュー」**（`random.fizz`・音量 0.25） | **染めない** |
| ほか | 殴られた音 | 染める |

**火は 1 秒おきに 5 回焼ける**（[17-element.md](17-element.md) 3-3）。
**そのたびに赤く染めると、燃えている間ずっと赤い。**
**殴られたのか焼かれたのかが分からなくなる。**

**属性ダメージでは押さない**（風だけが自分で押す。[4 章](#4-ノックバック)）。

## 3. 音

**当たった場所から鳴らす**（`dimension.playSound`）。

| | |
| --- | --- |
| 殴られた音 | **バニラの音**（`game.player.hurt`）を借りている |
| **炸裂・弓** | **自分たちで合成した音**（3-1） |

**倒したときの音は別**（`random.explode`。[10-damage.md](10-damage.md) 6 章）。

### 3-1. 音は合成して作る（2026-08-29）

**借りると、他の場面と同じ音になって聞き分けられない。**
**波形を組み立てて `.ogg` で書き出す**（Bedrock が読むのはこれ）。

```bash
python -m pip install soundfile numpy
python tools/pve-sounds.py worlds/pve/packs/pve
```

| 音 | 何 | 作り |
| --- | --- | --- |
| `pve.element.thunder` | 雷の炸裂（**ビリッ**） | 高い側へ寄せた雑音＋弾ける粒。**0.3 秒** |
| `pve.element.ice` | 氷の炸裂（**パリン**） | 高い倍音を数本＋**遅れて落ちる破片**。**0.55 秒** |
| `pve.bow.common` | 支給された弓 | **低く鈍い弦** |
| `pve.bow.charged` | **ためきった合図** | 2 音の澄んだ「キン」。**全部の弓に付く** |
| `pve.trail.steel` | 無銘弓の**軌跡** | 鋭い風切り ＋ 金属の余韻 |
| `pve.trail.star` | 星屑の**軌跡** | 柔らかい風切り ＋ **後から散るきらめき** |
| `pve.weapon.stardust_land` | **星が落ちた** | 短く高い鈴。**0.26 秒・音量 0.35** |

> ### 武器の固有効果には、固有の音を付ける
>
> **何が起きたかは、音のほうが早く分かる。**
> 星屑は**星が落ちるたびに鳴る**——**5 つ続くので、短く・小さく・高さを散らす**
> （同じ高さで続けて鳴らすと濁る）。

| | |
| --- | --- |
| 長さ | **どれも 0.6 秒以内。** 戦闘中に何度も鳴る |
| 大きさ | 炸裂 **0.45** / 星の着地 **0.35** / 軌跡 **0.9** |
| **放つ音** | **バニラで揃える**（`random.bow`）。作り替えると**弓を撃った感じが薄くなる** |

> ### 軌跡の音を「音階」で作らない
>
> 星屑の軌跡に**昇っていく音**を大きく入れたら、**発射音そのものに聞こえた。**
> **頭は風切り**にして、**きらめきは遅らせて小さく散らす**——
> **放った瞬間に鳴るのはバニラの弦の音だけ**にする。
| 置き場所 | `sounds/pve/*.ogg` ＋ `sounds/sound_definitions.json` |

**低い音・長い音は作らない**——**重なると何が起きたか分からなくなる。**

## 4. ノックバック

**プレイヤーが受けたときだけ押す。**

| | |
| --- | --- |
| 向き | **殴った相手から自分へ**。殴った相手が居なければ**押さない** |
| 強さ | 横 **0.9** / 縦 **0.35** |
| モブ | **押さない**（4-1） |

`applyKnockback` で出す。**バニラのダメージを通さないので、押すのもこちらの仕事。**

### 4-1. モブを押さない理由

**多段ヒットの武器が、モブを飛ばしてしまう。**
星屑は 1 発で 6 回当たる——**押すと、当てるたびに遠ざかる。**

> 押したい武器が出てきたら、**その武器の効果として押す**
>（[14-effect.md](14-effect.md)）。**既定では押さない。**

## 4-2. 当たったときの粒は出さない（2026-08-29 決定）

**すべての攻撃で `pve:hit_spark` を出していた。**
**何の粒か分からないものが毎回出て、邪魔だった。**

**当たったことは「赤く光る・音」で分かる。**
**粒は、属性のように「何が起きたか」を伝えるものだけにする。**
