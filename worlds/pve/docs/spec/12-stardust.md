# 仕様: 星屑（演出の見本）

武器そのものは [drafts/archer-weapons.md](../drafts/archer-weapons.md) 33。
**ここは「派手さをどこまでやるか」の見本**として書く。

## 1. 何が起きるか

```
0.00s  閃光（膨らんで消える） ＋ 地を這う輪（広がる）
0.10s〜 星が順に降ってくる（**2 tick おき**）
        各 0.15 秒：芯（大きな星）＋ 筋（縦に細い破片）
        └ 落ちた所で 14 粒が弾ける
0.60s  舞い残る粉が 10 粒、ゆっくり昇って消える
```

**降る高さ 7 マス、速さ 2.8 マス/tick、散らばり ±1.6 マス。**

> **速さと間隔は 2026-08-29 に倍にした。** 前は**間延びしていた。**

> ### ★の形には**しない**（2026-08-29 に試して戻した）
>
> 「光の柱に見える」と言われ、**ポップな★が降る**形に作り替えた——
> **思っていたものと違うと言われ、元に戻した。**
>
> **この武器の見た目は「光る芯＋縦の筋」。**
> 作り替えるときは、**まず 1 本だけ試して見せる。**

## 2. 6 つの粒でできている

| 粒 | 役 | 絵 |
| --- | --- | --- |
| `pve:star_flash` | 着弾の閃光 | `pve_glow`（中心が白く飛ぶ） |
| `pve:star_ring` | 地を這う輪 | `pve_ring`（**寝かせる**） |
| `pve:star_core` | 落ちる星の芯 | `pve_star_big`（四条） |
| `pve:star_streak` | 芯が引く筋 | `pve_shard`（縦に細い） |
| `pve:star_land` | 着地の弾け | `pve_star` ＋ **音**（`pve.weapon.stardust_land`） |
| `pve:star_dust` | 舞い残る粉 | `pve_star` |

**絵は全部こちらで描いた**（[11-structure.md](11-structure.md) 3-A）。

## 3. 作り方の考え方

| | |
| --- | --- |
| **1 つの粒に詰め込まない** | 役ごとに分ける。**混ぜると調整できなくなる** |
| **落ちる動きは script が置く** | 粒に任せると、高さも間隔も決められない |
| **大きさと色は式で動かす** | 膨らむ・細る・褪せる。**時間の割合**で書く |
| **加算合成**（`particles_add`） | 光ものは重なるほど明るくなる |

## 4. どこから呼ばれるか

**ダメージの通り道には触らない**（[10-damage.md](10-damage.md) 4-1）。

```
当たった → フック → 「何で当てたか」が星屑なら → 演出
```

**武器を増やすとき、ダメージ側を触らない**ための形
（[11-structure.md](11-structure.md) 2-2）。

### 4-1. 星は削る（2026-08-29 追加）

**絵だけだった。** 星が降っても**何も起きていなかった。**

**落ちた星は、そこに居るモブを削る。**
何発・いくら・誰に・どこまでは **[14-effect.md](14-effect.md) 2 章の表**。

| | |
| --- | --- |
| 星の数 | **ため具合で減る**（[10-damage.md](10-damage.md) 5-1） |
| 粒と削り | **同じ数。** 片方だけ出さない |
| 追加ダメージからフック | **呼ばない**（星が星を呼ぶと無限に増える） |

## 5. まだ確かめていないこと

- **実機での明るさ**（加算合成は画面で印象が変わる）
- **数の上限**（5 つ × 6 段 ＋ 弾け 14 粒 × 5）。**同時に何発も撃つと重い**
- 落ちる星が**壁を貫く**（見た目も削りも。壁で止めるかは未定）
- **1 つの星＝1 つの粒にできないか。**
  いまは**毎 tick 置き直している**（1 つの星に 6 回）。
  粒自身に**下向きの初速**を持たせれば、**1 回置くだけで滑らかに落ちる**——
  20 分の 1 秒刻みのかくつきも消える。**削る時刻は script が別に持つ**
  （[14-effect.md](14-effect.md) 3-2）
