# 仕様: 武器の追加ダメージ（性能表）

考え方は [10-damage.md](10-damage.md) 5 章、武器の候補は
[drafts/archer-weapons.md](../drafts/archer-weapons.md)。

> ### 追加ダメージを持つ武器は、必ずここに表を書く。
>
> **「星が降る」だけでは実装できない。**
> **何発・いくら・誰に・どこまで・いつ**が要る。

## 1. 表の書き方

| 欄 | 何を書くか |
| --- | --- |
| **基礎** | 当てた 1 発。**1 秒ためたときの値** |
| **発数** | ためきりで何発か。**ためで減る**（[10-damage.md](10-damage.md) 5-1） |
| **1 発** | 追加 1 発の威力。**最終攻撃力に対する %** |
| **対象** | **誰に入るか。** プレイヤーに入るのか、当てた相手だけか |
| **範囲** | 何マスまで |
| **間隔** | 何 tick ごとに落ちるか。**全部終わるまでの時間** |
| **合計** | 基礎＋追加。**毎秒火力の目安と突き合わせる**（archer-weapons.md 7 章） |

**% は最終攻撃力に対して**（基礎攻撃力ではない）。
ため・ステータス・エンチャントを乗せ終えた値に掛かるので、
**強化がそのまま追加ダメージにも乗る。**

## 2. 星屑（legendary 33）

見せ方は [12-stardust.md](12-stardust.md)。

| | |
| --- | --- |
| **基礎** | **45**（1 秒ため・1 発） |
| **発数** | **5**（ためきり） |
| **1 発** | **最終攻撃力の 9%**（ためきりで 4.05） |
| **対象** | **モブだけ。** プレイヤーには入らない（撃った本人にも） |
| **範囲** | 落ちた地点から **半径 2.0 マス**。**居る全員に入る** |
| **間隔** | **2 tick ごと**に 1 発。全部落ちきるまで **約 0.6 秒** |
| **合計（単体）** | **45 ＋ 20.25 ＝ 65.25**（実質 ×1.45） |
| **音** | **落ちるたびに鳴る**（`pve.weapon.stardust_land`。[16-feedback.md](16-feedback.md) 3-1） |

**毎秒 60 の目安に対して 65。** 範囲に複数居ればさらに伸びる——
**それが legendary の取り分**（archer-weapons.md 7-1 の「×1.3〜1.5」の通り）。

### 2-1. ためで何が変わるか

| ため | 基礎 | 星 | 星の合計 | 合計 | 見た目 |
| --- | --- | --- | --- | --- | --- |
| なし（0.1） | 4.5 | **1 発** | 0.4 | **4.9** | 星が 1 つだけ落ちる |
| 1/3（0.4） | 18.0 | **2 発** | 3.2 | **21.2** | ぱらぱら |
| 半分（0.55） | 24.8 | **3 発** | 6.7 | **31.5** | それらしくなる |
| ためきり（1.0） | 45.0 | **5 発** | 20.3 | **65.3** | **空が光で埋まる** |

**粒も同じ数だけ減る。** 星が降らないのに削れる、削れないのに星が降る——
**どちらも起こしてはいけない**（[12-stardust.md](12-stardust.md) 4 章）。

### 2-2. 落ちる前に相手が消えたら

**星は落ち切る。** 削る相手が居なければ**何も起きない**（空振り）。

| | |
| --- | --- |
| 当てた相手が倒れた | **星は降り続ける。** 範囲に他が居れば入る |
| 星が誰にも当たらない | **絵だけ出る** |

**追い掛けない。** 星は**当たった地点**に降る（相手にではない）。
逃げれば避けられる——**それでよい。**

### 2-3. 上限

| | |
| --- | --- |
| 同時に降っている星 | **60 発まで**（同時に撃つ人数を考えて） |
| 1 発が削る相手 | **上限なし**（範囲に居る全部） |

**溢れたら新しい星を出さない。** 古いものを消すと、**降りかけの星が消える。**

## 3. 実体にするか、粒で済ませるか（2026-08-29 決定）

**降る星・爆風・地雷。** これらを**実体（エンティティ）として湧かせる**手もある。
**星屑は粒のままにする。** 判断はこの表でする。

| **実体にする** | **粒＋script で済ませる** |
| --- | --- |
| **地形に当たって止まる**必要がある（矢が壁に刺さる） | **決まった時刻に、決まった場所で起きる** |
| **その場に残って干渉する**（地雷・結界・設置物） | **出したら終わり**（1〜2 秒で消える） |
| **相手を追いかける**（追尾・跳弾） | まっすぐ・落ちるだけ |
| **押される・当たり判定を持つ**必要がある | 当たり判定は script が半径で見る |

### 3-1. なぜ星屑は粒のままか

| | |
| --- | --- |
| **削りは結局 script が出す** | HP は独自（[10-damage.md](10-damage.md) 1 章）。**実体にしても計算は変わらない** |
| **取り残しが出ない** | 実体は `/reload` や落下で**世界に残る。** 前のワールドで何度も掃除を書いた |
| **時刻をこちらが決められる** | 「2 tick ごとに 1 発」がそのまま書ける |
| **数の上限が効く** | 湧かせる前に止められる（2-3） |

**実体にして得られるのは「地形に当たって止まる」だけ。**
それは**script の視線判定でも書ける**——**実体を持ち込む理由にはならない。**

### 3-2. 粒の弱いところ（承知の上）

| | |
| --- | --- |
| **動きが 20 分の 1 秒刻み** | 速いものはかくつく。**粒自身に速度を持たせれば滑らかになる**（[12-stardust.md](12-stardust.md) 5 章） |
| **壁を貫く** | いまは貫く。止めるなら**script で高さを見る** |

### 3-3. 実体にするのはこれ

| 武器 | なぜ |
| --- | --- |
| 地雷矢（23） | **置いたものが残る。** 踏むまで待つ |
| 結界弓（37） | **その場に居続ける** |
| 追尾・跳弾（12・26 ほか） | **相手を追う。** 軌道が script では書ききれない |

**その武器を作るときに、`entities/` を 1 つ足す。**
**そのときも削るのは `hit()` を通す**（[10-damage.md](10-damage.md) 4 章）。

## 4. これから足すもの

追加ダメージを持つ武器は、**実装するときにこの章へ表を足す。**

| 武器 | 何が要るか |
| --- | --- |
| 流星（40） | 星屑と同じ形。**数と範囲を変える** |
| 散華（5）・ハープーン（30） | **1 発ずつが基礎ダメージ**。追加ではない（分けて書く） |
| 爆裂系 | **威力を減らす**ほうのため対応（[10-damage.md](10-damage.md) 5-1） |
