# 仕様: 武器の見せ方（名前と説明欄）

属性は [17-element.md](17-element.md)、武器そのものは
[drafts/archer-weapons.md](../drafts/archer-weapons.md)、
エンチャントは [drafts/archer-enchants.md](../drafts/archer-enchants.md)。

> ### 拾った 1 本が、どれだけのものか——**持ち物の中で分かること。**
>
> レア度・属性・効果を**名前と説明欄だけ**で伝える。
> ゲーム内に別の画面を作らない。

## 1. 名前

```
§b星屑          ← レア度の色だけ
```

**名前は武器の名前だけ。色でレア度を出す**（2026-08-29 変更）。

> **属性の印を名前にも並べていた。**
> **説明欄に同じものが出る**ので、**同じことを 2 回**言っていた。

## 2. 説明欄

```
§b【Legendary】
§8§m                    §r
§7攻撃力   §f45
§7ため     §f1.0 秒
§b🜄 水   §c🜂 火
§8§m                    §r
§d星が降る
§7着弾地点に星が 5 つ落ち、周りのモブも削る
```

| 行 | 中身 | 出ない条件 |
| --- | --- | --- |
| ① | **レア度**（[3 章](#3-レア度の色)） | — |
| ② | **区切り線** | — |
| ③ | 攻撃力（**1 秒ためた 1 発**） | — |
| ④ | ため時間 | — |
| ⑤ | **付いている属性** | 属性が無いとき |
| ⑥ | 区切り線 | 効果もエンチャントも無いとき |
| ⑦ | **効果の名前**（レア度の色） | 効果が無いとき |
| ⑧ | 効果の説明 | 〃 |
| ⑨ | **エンチャント**（1 行 1 つ） | 付いていないとき |

**区切り線は取り消し線の空白**（`§8§m` ＋ 空白）。
**枠線の字を作らなくても、横線が引ける。**

## 3. レア度の色

| レア度 | 色 | 記号 |
| --- | --- | --- |
| common | **濃い灰** | `§8` |
| uncommon | **茶**（銅） | `§n` |
| rare | **ピンク** | `§d` |
| **legendary** | **水色** | `§b` |
| mythic | **紫**（アメジスト） | `§u` |

> `§n` `§u` は**素材の色**（1.19.80 以降）。**16 色に茶が無い**ので借りている。

**名前と説明欄の見出しは、同じ色を使う。**

**【】で囲む。** 英語のまま出す——**日本語に訳すと段の差が伝わりにくい。**

## 4. いつ書き直すか

**属性が変わったとき**（[17-element.md](17-element.md) 6 章のコマンド）と、
**配ったとき**（`/pve:bow`）。

> **説明欄は「その 1 本」に焼き付く**（`ItemStack` に持たせる）。
> **持ち替えても、落としても、チェストに入れても残る。**

**組み立ては 1 か所**（`features/item/view.ts`）。
**名前も説明欄も、同じ関数が作り直す**——片方だけ古い、が起きない。

## 5. 一覧はどこにあるか

**武器の中身は職業ごとの一覧**（`features/<職業>/weapons.ts`。
[11-structure.md](11-structure.md) 2-1）。

**説明欄を作る側は、識別子から一覧を引くだけ。**
職業が増えたら、**引ける一覧を増やす**（`features/item/view.ts` の 1 行）。

## 6. まだ無いもの

- **エンチャント**（[drafts/archer-enchants.md](../drafts/archer-enchants.md)）。
  **説明欄の場所だけ用意してある**——付けば、そのまま並ぶ
- **未鑑定**の見た目（[03-content.md](../03-content.md)）
- 攻撃速度・射程などの細かい数字（**出しすぎると読まれない**）
