# 仕様: 画面に出すもの

HP そのものは [10-damage.md](10-damage.md)、属性は [17-element.md](17-element.md)、
手応えは [16-feedback.md](16-feedback.md)。

> ### HP が見えないゲームは遊べない。
>
> バニラの体力を捨てた（[10-damage.md](10-damage.md) 1 章）以上、
> **自分の残り・相手の残り・いま入った数字**を、**こちらで出す。**

## 1. 出す場所は 2 つだけ（2026-08-29 全面改訂）

| どこ | 何を | 誰に見えるか |
| --- | --- | --- |
| **モブの名札** | 名前・HP バー（＋デバッグの HP 数値） | **全員**（1 つの文字列） |
| **アクションバー** | **自分の HP** ＋ **狙っている敵** | **本人だけ** |

**入ったダメージの数字は出さない**（[4 章](#4-ダメージの数字は出さない)）。
**ハートは消す**（[2-1](#2-1-ハートを消す)）。

### 1-1. 「どのモブのものか」問題

> **モブが重なると、誰の HP で、誰が受けたダメージか分からない。**

**3 つで解く。**

| 手 | どう効くか |
| --- | --- |
| **1 体ぶんを 1 つの塊にする** | 名前とバーを**同じ名札に**積む。**離れて浮かばない** |
| **狙っている敵を、自分の画面に出す** | アクションバーは**本人だけに見える。** 狙った 1 体は必ず分かる |
| **要らない行を出さない** | **名前と残りだけ。** 塊を小さく保つ |
| **数字を出さない** | **いちばん散らかるものを、そもそも出さない**（[4 章](#4-ダメージの数字は出さない)） |

**名札は全員に同じものが見える**（`nameTag` は 1 つの文字列）。
**だから「見ている人ごとに変える」ことは名札ではできない。**
**その役はアクションバーが持つ。**

## 2. 自分の HP（アクションバー）

```
§a||||||||||||||||§0||||  §f142§7/200        ← 自分
グラント §e|||||||||§0||||||  §f96§7/200      ← 狙っている敵（居るときだけ）
```

**アクションバーは 1 行。** 敵を狙っているときは、**同じ行に続けて**出す。

| | |
| --- | --- |
| 更新 | **2 tick ごと**（毎 tick 書くと文字が点滅する） |
| 狙っている敵 | **視線の先 24 マス**。外れたら**1 秒だけ残して**消える |

**ほかの知らせをここに書かない**——上書きし合って、どちらも読めなくなる。

### 2-1. ハートを消す

`setHudVisibility(Hide, [Health])`。**入ったときと、5 秒ごとに掛け直す。**

## 3. モブの名札

**行を分ける。** 1 行に混ぜると読めない。

```
グラント                    ← ① 名前
§a|||||||||||||§0|||||||    ← ② HP バー
§7HP §f120§7/200            ← ③ HP の数値（デバッグ。既定オン）
```

| 行 | いつ出るか |
| --- | --- |
| ① 名前 | 常に |
| ② バー | 常に |
| ③ HP 数値 | **デバッグモードが入のとき**（[6 章](#6-デバッグ)） |

> ### 属性の蓄積率は出さない（2026-08-29 決定）
>
> 一度は名札に並べた。**名前と残りだけで足りる。**
> **行が増えるほど塊が縦に伸び、隣のモブと混ざる**（[1-1](#1-1-どのモブのものか問題)）。

**空の行は出さない。** 出すと**塊が縦に伸びて、隣のモブと混ざる。**

### 3-1. HP バー

| | |
| --- | --- |
| 目盛り | **20 本＝5% きざみ**（色は 16 色しか無く、**なめらかにはできない**） |
| 減った所 | **黒**（`§0`）。**背景を暗くして、残りだけが目に入る** |
| 残りの色 | **25% ごとに変える。** 下の表 |
| 間隔 | **バーと数字の間は空ける**（詰めると 1 つの塊に見える） |

| 残り | 色 |
| --- | --- |
| 75〜100% | **緑**（`§a`） |
| 50〜75% | **黄**（`§e`） |
| 25〜50% | **橙**（`§6`） |
| 0〜25% | **赤**（`§c`） |

**色が変わるのは残っている所だけ。** 減った所はいつでも黒。

## 4. ダメージの数字は出さない（2026-08-29 決定）

> ### 何ダメージ入ったかは、**出さない。**

**2 度作って、2 度とも要らなかった。**

| 作ったもの | どうだったか |
| --- | --- |
| **浮かぶ数字**（実体を飛ばす） | **3 か所にばらけて、誰のものか分からない** |
| **名札にまとめる**（1 tick 合算） | **炎で数字が流れ続け、画面がうるさい** |

**代わりに、これで分かる。**

| 知りたいこと | どこで分かるか |
| --- | --- |
| どれだけ削れたか | **HP バーの減り**（3-1）と、デバッグの HP 数値（6 章） |
| 効いているか | **粒と音**（[17-element.md](17-element.md) 5-2）。濡れている・凍っている・燃えている |
| 当たったか | **赤く光る・音**（[16-feedback.md](16-feedback.md)） |

**数字を出さないぶん、バーを読みやすくする。**

> **戻すときは、まず「何のために出すのか」を決めてから。**
> 「入った数字が見えると気持ちいい」だけでは、**すぐ画面が埋まる。**
> 前回は**クリティカルを大きく出す字**（`U+E210`〜）まで描いたが、
> **数字ごと消したので、その字も消した。**

## 5. 更新の頻度

| 何 | どれくらい |
| --- | --- |
| 名札・アクションバー | **2 tick ごと** |
| ハート消し | 5 秒ごと |

**同じ中身なら書き直さない**（下）。

### 5-1. ちらつかせない

**控えと比べる。** `entity.nameTag` を**読み返して比べない**——
読み返した値が書いた値と同じ保証が無く、**毎回書き直しになる。**

> 前のワールドと、このワールドで**2 回**同じ失敗をした。

## 6. デバッグ

**遊ぶ人には要らないが、作る間は要る**ものを、まとめてここに置く。

```
/pve:debug            いまの状態を出す
/pve:debug plate      名札の HP 数値（ワールド全体・既定オン）
/pve:debug hp         体力の実態を自分の画面に出す（既定オフ）
```

| モード | 何が出るか | どこまで効くか |
| --- | --- | --- |
| **plate** | 名札に **HP の数値**（③ の下） | **ワールド全体。** 名札は全員に同じものが見える |
| **hp** | **独自 HP とバニラ体力の両方**（自分と、狙っている敵） | **その人だけ** |

**`plate` が既定オンなのは、いま作っている最中だから。**
将来は**「ネームプレート表示」のエンチャント**として遊びの側に置く
（[drafts/archer-enchants.md](../drafts/archer-enchants.md)）。

### 6-1. 体力の実態

```
§8自分 独自142/200 バニラ20/20  敵 独自96/200 バニラ1000/1000
```

**バニラの体力が減っていないこと**（[10-damage.md](10-damage.md) 1 章）を、
**目で確かめるためのもの。**
