# 仕様: 弓の見せ方

武器そのものは [drafts/archer-weapons.md](../drafts/archer-weapons.md)。

## 1. バニラの弓の作りを踏襲する（2026-08-28 決定 / 08-29 追記）

**引く動きは、バニラの弓と同じ仕組みで出す。**

| 仕組み | どこ |
| --- | --- |
| **4 段の絵と模型**（構え・引き 0/1/2） | `attachables/pve_bow_*.json` |
| **段の選び方** | `render_controllers`：**`variable.pve_frame`**（1-1） |
| **引く手つき** | `animations`：`variable.charge_amount` |
| **立体の起こし方** | **`texture_meshes`**——**絵からそのまま立体にする** |

置き方（`local_pivot` / `position` / `rotation`）と手つきの値は、
**バニラの `models/entity/bow.geo.json` と `animations/bow.animation.json` と同じ。**

> `texture_meshes` は**絵の不透明な所がそのまま立体になる。**
> だから**絵を描けば模型ができる**——立方体を並べる必要が無い。

**一式は書き出しで作る**（手で JSON を書かない）:

```bash
python tools/pve-bow-rig.py worlds/pve/packs/pve
```

### 1-1. 段だけはバニラと違う

バニラは `query.get_animation_frame` で 4 段を選ぶ。
**これはバニラの弓のために用意された数え方で、独自アイテムで進む保証が無い。**

**引いた長さから、段を出す。**

```
段 = 引いていない ? 0 : clamp(floor(1 + 2 × ため具合), 1, 3)
```

| 段 | いつ |
| --- | --- |
| 0 構え | 引いていない |
| 1 / 2 / 3 | ため 1/2 ごと（ためきりで 3） |

> ### 添字は変数を通さない（2026-08-29 の直し）
>
> はじめは `pre_animation` で `variable.pve_frame` を作り、
> render controller からそれを読んでいた。**引くと弓が丸ごと消えた。**
> **変数が読めない・壊れると、添字が外れてモデルが選ばれない。**
>
> **query から直接組み立て、`math.clamp` で 0〜3 に閉じ込める。**
> こうすれば、**どう転んでも「どれかの弓」は出る。**

### 1-2. ためは自分で切る

アイテムの `use_duration` は **3600 秒**——**勝手に終わらせない。**
1 秒にしておくと、**ためきった瞬間にゲームが使用を完了させてしまい、
離す前に手を離れる。**

離し忘れに備えて、script は `itemCompleteUse` でも撃つ。

## 2. 絵は 64x64 で描き起こす（2026-08-29 に変更）

**はじめはバニラの 16x16 を塗り替えていた。**
**色を替えるくらいしかできず、弓ごとの作りを描き分けられなかった。**

```bash
python tools/pve-bow-art.py worlds/pve/packs/pve
```

| | |
| --- | --- |
| 大きさ | **64x64（バニラの 4 倍）** |
| 形 | **バニラと同じ並び**（左下から右上へ弧・弦・引くと矢が出る） |
| 描き方 | **1 画素ずつ置く。** ぼかさない——にじむと弓に見えない |
| 影 | **3 色**（縁・地・光）。**縁を必ず入れる**——輪郭が無いと沈む |
| 段 | **4 枚。** 引くほど**弦が寄り、矢が下がり、弓が伸びる** |
| 矢 | **引き始めて初めて出る**（[2-4](#2-4-矢は引いてから出す)） |
| 弦と木の間 | **バニラと同じ**（[2-2](#2-2-弦と木の間はバニラに合わせる)） |
| 動き | **星屑だけ、星がゆっくり瞬く**（[2-3](#2-3-うるさくない範囲で動かす)） |

| 弓 | 素材 | 飾り |
| --- | --- | --- |
| 支給された弓 | **木**（革の握り） | 無し |
| 無銘弓 | **鋼**（青みの弦） | 継ぎ目の鋲 |
| 星屑 | **紫の木に金の飾り** | 先端の金具・小さな星 |

### 2-2. 弦と木の間はバニラに合わせる

**測って合わせる。** バニラは **弦から木のいちばん外まで、一辺の 0.35**
（16 画素中 5.7）。

> はじめは 0.08 しか離れていなかった。**弓に見えない**と言われた（2026-08-29）。

**二次ベジェの実際のふくらみは制御点の半分**なので、
`BEND` には **0.7 前後**を置く（`tools/pve-bow-art.py`）。

**矢は弦の軸に沿って右上へ**——これもバニラと同じ向き。

### 2-3. うるさくない範囲で動かす（2026-08-29 決定）

**構えている間だけ、絵をゆっくり入れ替える。**

| | |
| --- | --- |
| いつ | **引いていないとき**（引いている間は段の絵が優先） |
| 速さ | **1.5 回/秒で 3 枚**（0 → きらめき 0 → きらめき 1） |
| 何が変わるか | **星の明るさだけ。** 形は変えない |
| どこに置くか | **星は弓の弧の外側に沿わせる**（浮かせない） |

> ### 絵だけ差し替えても、見た目は変わらない
>
> `texture_meshes` は**絵から立体を起こす**（1 章）。
> **描き分けた絵ごとに立体も要る**——
> render controller で**立体と絵を同じ番で選ぶ**（2026-08-29 に気付いた）。
>
> **形は変えない。** 変えると立体の形まで変わり、**持ち姿がぶれる。**
> 色だけ変えるので、**立体は同じ形が 6 つ**並ぶだけで済む。

> ### 星を宙に浮かせない
>
> はじめは絵の空いた所に星を置いた。
> **アイコンでは点が浮き、立体では四角が宙に浮く。**
> **弧の外側に沿わせる**と、飾りとして収まる。

**いま動くのは星屑だけ。** 他の弓は同じ絵を並べてあるので、**何も動かない**
（仕組みは全部の弓で同じ）。

### 2-4. 矢は引いてから出す（2026-08-29 決定）

**バニラと同じ。** 構えの絵とアイコンには**矢を描かない。**

> 一度「矢が無いと弓の収まりが悪い」と考えて常に描いたが、
> **まだ番えていないのに番えている**ことになる。**引き始めて初めて出す。**

| | |
| --- | --- |
| 筈（はず） | **弦の頂点そのもの。** 少しでも離すと「掛かっていない」ように見える |
| 太さ | **縁付きで太く。** 細いと点線に見えて、矢に見えない |
| 向き | **弦と直交**（[2-5](#2-5-矢の向きはバニラの絵から読み取った)） |
| 長さ | **一辺の 0.68**。弓の弧を抜けて、反対側へ出る |

### 2-5. 矢の向きはバニラの絵から読み取った

**一度、弦の軸に沿わせて描いた。** **矢が横を向いていて、物理的におかしい。**

**バニラの絵を 1 画素ずつ読む**と、こうなっていた:

| | |
| --- | --- |
| 弦 | 右上の先端から、左下の先端へ（弧の内側を通る直線） |
| **矢** | **弦と直交。** 弦の頂点から、**弧を抜けて反対側へ** |
| 長さ | 16 画素の絵で**端から端まで 0.8 ぶん**（＝長い） |

**分からなくなったら、バニラの絵を読む。**
`bedrock-samples` にあるので、**色ごとに文字へ起こして並べれば形が分かる。**

### 2-1. 絵を大きくすると、模型も大きくなる

**`texture_meshes` は画素 1 つを立方体 1 つに起こす**（1 章）。
**64 画素の絵は、64 単位＝4 ブロックの模型**になってしまう。

| 直し方 | どこ |
| --- | --- |
| **1/4 に縮める** | `animation.pve_bow.wield` の `scale`（**0.25**） |
| **絵の中の位置を 4 倍にする** | `local_pivot` / `position`（縮める前の値なので） |

**`tools/pve-bow-rig.py` が両方まとめて書き出す。**
**絵の大きさを変えたら、そこの `TEX` を直すだけでよい。**

> ### 立方体の数は 10 倍近くになる
>
> バニラの弓は不透明な画素が **60 ほど**。こちらは **500〜650**。
> **持っている人が多いと効いてくる。**
> **重ければ 32x32 に落とす**（`TEX` と `S` を 32 にするだけ）。

**バニラを塗り替える道具も残してある**（`tools/pve-bow-textures.py`）——
**元の形に戻したくなったとき用。**

## 2-A. 他人から見た姿（2026-08-29 追加 / 同日に直した）

**一人称の引き姿は attachable が出す。三人称は出せない。**
バニラの attachable も `rightitem` しか動かしていない——
**腕を前に出すのはプレイヤー本体のアニメーション**で、条件がこうなっている:

```
"third_person_bow_equipped": "query.get_equipped_item_name == 'bow' && ..."
```

**名前で見ている。** `pve:bow_*` は**この条件に一生入らない。**

### 2-A-1. バニラと同じ場所に置く

**`controller.animation.player.root` の `third_person` 状態の中。**
バニラの弓の条件が並んでいる、その隣に足す。

| 触るもの | 何を足すか |
| --- | --- |
| `entity/player.entity.json` | `animations` に `pve_bow_third` → **`animation.player.bow_equipped`** |
| `animation_controllers/player.animation_controllers.json` | **`third_person` 状態に条件を 1 行** |

**動きは作らない。バニラと同じでよい**（2026-08-29 決定）。

```bash
python tools/pve-player-bow.py bedrock-samples worlds/pve/packs/pve
```

### 2-A-2. 視点の見分けを、自分で書かない

**2 回失敗した。**

| やったこと | どうなったか |
| --- | --- |
| 実体の直下（`scripts.animate`）に条件を足す | **一人称にも掛かり、手元の弓が消えた** |
| そこに `!c.is_first_person` を足す | **今度は三人称から消えた** |

> ### 視点で分ける仕事は、バニラの状態機械に任せる。
>
> `root` は `first_person` / `third_person` という**状態**で分かれていて、
> **バニラの弓の条件は `third_person` の中にしか無い。**
> **同じ場所に置けば、視点の判定は書かなくてよい。**

> ### 丸ごとの上書きになる
>
> プレイヤーの**見た目の定義**と**動きの制御**を、まるごと持つ。
> **バニラが更新されても付いていかない。**
> **手で書かない。** `bedrock-samples` を新しくして、**もう一度走らせれば追従できる。**
>
> **弓を増やしたら、道具の `BOWS` にも足す。**

## 3. 撃つ側との関係

**火力は script が数える**（`itemStartUse` から `itemReleaseUse` までの tick）。

| | |
| --- | --- |
| 見た目の段 | **Molang が数える**（`pre_animation`。1-1） |
| 火力のため具合 | **script が数える**（[10-damage.md](10-damage.md) 3-1） |

**二重に数えている**が、**別々のものを数えている**——
片方は絵、もう片方は数字。

> **ためきるまでの tick は 2 か所にある**——
> `lib/charge.ts` の `FULL_CHARGE_TICKS` と `tools/pve-bow-rig.py` の `FULL_TICKS`。
> **片方だけ変えると、絵と火力がずれる。**

### 3-1. 放つ音は共通、**軌跡の音**だけ弓ごと（2026-08-29 に直した）

> **放つ音まで作り替えたら、弓を撃った感じそのものが薄くなった。**
> **放つ音はバニラで揃える**（`random.bow`）。

| | 音 |
| --- | --- |
| **放つ** | **バニラ共通**（`random.bow`） |
| 支給された弓の軌跡 | **無し。** 素っ気ない弓は、それでよい |
| 無銘弓の軌跡 | **鋭い風切り ＋ 金属の余韻**（`pve.trail.steel`） |
| 星屑の軌跡 | **昇っていく煌めき**（`pve.trail.star`） |

**軌跡の音は `weapons.ts` の 1 行**（`trailSound`。無ければ鳴らさない）。
**撃った所より少し先で鳴らす**——**飛んでいったように聞こえる。**

作り方は [16-feedback.md](16-feedback.md) 3-1。

### 3-2. ためきったら音で知らせる（2026-08-29 決定）

**狩りの弓のように、ためきった瞬間に「キン」と鳴る**（`pve.bow.charged`）。

| | |
| --- | --- |
| いつ | **その弓のため時間ちょうど**（長弓なら 2 秒、重弓なら 1.5 秒） |
| 誰に | **引いている本人だけ**（`player.playSound`） |
| 途中で離したら | **鳴らさない**（同じ引きが続いているかを見てから鳴らす） |

**いつ撃てばいいかが、画面を見なくても分かる。**
**全部の弓に付く**——ここは弓ごとに変えない。

## 4. 飛んだ跡（2026-08-29 に作り直した）

**実体にしない**（速すぎて当たり判定が抜ける）。
**線を引いて当て、その線を粒で見せる。**

> ### 点にしない。**線にする。**
>
> はじめは丸い粒を 0.8 マスおきに置いていた。
> **点が飛んでいるようにしか見えなかった。**

| | |
| --- | --- |
| 絵 | **`pve_dash`**（横に伸びた光。**新しく描いた**） |
| 向き | **進む向きへ長辺を合わせる**（`facing_camera_mode: direction_x` ＋ `custom_direction`） |
| 向きの渡し方 | **script が `v.dx` / `v.dy` / `v.dz` で渡す**（粒からは撃った向きが分からない） |
| 間隔 | **0.7 マス。** 一片の長さ（1.0〜1.2）より**短くする**——長いと点線に戻る |
| 太さ | **時間とともに細る**（式で書く） |

### 4-1. 弓ごとに変える

**拾った瞬間に、撃ち味が違うと分かるように**（[archer-weapons.md](../drafts/archer-weapons.md) 1 章）。

| 弓 | 線 | 粒 |
| --- | --- | --- |
| 支給された弓 | **素っ気ない白。** 細く、すぐ消える | `pve:trail_wood` |
| 無銘弓 | **鋼の青白。** 太く、少し残る | `pve:trail_steel` |
| 星屑 | **紫の光。** いちばん明るく、長く残る | `pve:trail_star` |
| 〃 | ＋**きらめきが線の上に点々と残る**（3 片ごと） | `pve:trail_star_spark` |

**線は `weapons.ts` の 1 行**（`trail`）。**武器を足す人が絵を選ぶ**——
撃つ処理は触らない（[11-structure.md](11-structure.md) 2-1）。

### 4-2. 絵は借りない

**バニラの粒は使わない**（[11-structure.md](11-structure.md) 3-A）。
借りると**他の場面と同じ絵になり、安っぽくなる。**

`pve_dash` は**両端と上下へ滑らかに消える**ように描いてある——
**継ぎ目が見えると、また点線に見える。**
