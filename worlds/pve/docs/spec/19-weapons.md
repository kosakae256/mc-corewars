## 1. 何を 1 本ごとに持つか

| | 決まり |
| --- | --- |
| **絵** | **4 段（構え・引き 0/1/2）** ＋ 光るものは**きらめき 2 枚**。64x64 |
| **形** | **弓ごとに変える。** ただし**角度と大きさは変えない**（持ち姿がぶれる） |
| **放つ音** | **バニラ共通**（`random.bow`）。**ここは変えない** |
| **軌跡の粒** | 5 種類から選ぶ（[4 章](#4-軌跡の粒は-5-種類から選ぶ)） |
| **軌跡の音** | **特別な弓だけ。** 無ければ鳴らさない |
| **固有能力の音** | **能力があるものだけ**（当たった瞬間・発動した瞬間） |

### 3-1. 固有能力とエンチャントの優先順位

> ### 同じことをするなら、**固有能力が勝つ。**

| 場合 | どうなるか |
| --- | --- |
| **同じこと**（貫通の弓に貫通のエンチャント） | **固有能力だけが働く。** エンチャントは意味を持たない |
| **重ねられること**（拡散の弓に拡散のエンチャント） | **掛け合わせる。** 2 本 × 5 本 ＝ 10 本 |
| **別のこと** | **両方働く** |

**重ねてよいかは、型ごとに上の表へ書く。**
**書いていないものは重ねない**——迷ったら弱いほうへ倒す。

## 4. 軌跡も音も、1 本ごとに 1 つ

> ### 5 種類の使い回しをやめた（2026-08-29）
>
> **「弓ごとに違う」と書いておきながら、粒は 5 種類・音は 2 種類を回していた。**
> **48 本ぶん作る。** 手では無理なので、**一覧から書き出す。**

| 何 | いくつ | 作る道具 |
| --- | --- | --- |
| 軌跡の粒 | **48**（`pve:trail_<key>`） | `tools/pve-trails.py` |
| 軌跡の音 | **48**（`pve.trail.<key>`） | `tools/pve-weapon-sounds.py` |
| 能力の音 | **48**（`pve.ability.<key>`） | 同上 |

**何で差が出るか。**

| 元 | 粒 | 音 |
| --- | --- | --- |
| `hue` | **色**（芯は明るく、尾は濃く） | **高さ**（色の輪をそのまま音階に写す） |
| `mat` | **形**（木＝太い筋 / 鋼＝細く長い / 水晶＝尖る / 骨＝丸い / 黒鉄＝煙） | **音色**（鈍い・金属・澄む・掠れる・低い） |
| `base` | **太さ**（重い弓ほど太い） | **重さ**（強い弓ほど低い） |
| `rarity` | **残る長さ** | 長さ |
| `ability` | **癖**（爆ぜる＝膨らむ / 貫く＝伸びる / 拡散＝短い） | **癖**（爆ぜる・抜ける・溜める・散る・歪む） |

**放つ音だけは共通**（バニラの `random.bow`）——
**そこまで変えると、弓を撃った感じそのものが薄くなる**（[13-bow-view.md](13-bow-view.md) 3-1）。

## 5. 実装の決まり

**48 本ぶんの落とし穴を、同じところで踏まないための決まり。**

| 決まり | なぜ |
| --- | --- |
| **能力から撃った矢は、着弾の能力を動かさない**（`depth`） | **跳弾が跳弾を呼んで止まらなくなる** |
| **遅らせて動かすものは `safe()` で包む** | `runTimeout` の中で投げると**その輪ごと止まる** |
| **倍率は足し算**（跳弾の +50% など） | 掛け算だと**3 回目で 3.4 倍**になる |
| **外したときだけ `onMiss`** | 当たった数を数えてから呼ぶ（連撃が毎回切れていた） |
| **数を撃つ弓は線を粗く**（`trailStep`） | 速射は毎 tick 撃つので**粒が溢れる** |
| **同じ道具は `abilities/util.ts` に集める** | 同じものを 4 か所に写していた |
| **能力の登録は混ぜる**（上書きしない） | 撃ち方と当たり方が別ファイルなので、**後勝ちで消えていた** |
