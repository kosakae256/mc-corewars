## 1. 段（グレード）

**エンチャントには段がある。** 段が上がるほど効きが強い。

| | |
| --- | --- |
| 段の幅 | **1〜5**。ものによって上限が違う（下の表の「段」） |
| 効き方 | **段に比例**（強撃 段 3 なら +60%） |
| 表し方 | 説明欄に `✦ 強撃 III`（ローマ数字） |
| いくつ付くか | **上限は決めていない**（付け方の仕組みがまだ無い） |

**1 つの弓に同じエンチャントは 1 つだけ**——段が上がるだけ。

## 3. 固有能力との重なり

> ### 同じことをするなら、**固有能力が勝つ。**
>
> 貫通の弓に貫通のエンチャントを付けても、**固有能力の貫通しか働かない。**
> **ただし拡散だけは掛け合わせる**——2 本の弓に 5 発の拡散で **10 本。**

**判断は「軸」で行う。** 同じ軸を武器が持っているかどうかだけを見る。

| 軸 | 何を動かすか | 重なり |
| --- | --- | --- |
| `power` | 攻撃力の倍率 | **足し合わせる**（掛け算） |
| `spread` | 矢の本数 | **掛け合わせる**（2 本 × 5 本 ＝ 10 本） |
| `pierce` | 貫く数 | **固有能力が勝つ** |
| `homing` | 曲がって追う | **固有能力が勝つ** |
| `bounce` | 壁で跳ねる | **固有能力が勝つ** |
| `explode` | 当たった所で爆ぜる | **固有能力が勝つ** |
| `charge` | ため時間 | **固有能力が勝つ**（ためが無い弓では効かない） |
| `element` | 属性の効き | **足し合わせる** |
| `support` | 味方への働き | 重なる |
| `gain` | 稼ぎ | 重なる |

**武器の側は「どの軸を自分が持っているか」を書く**（`Ability.owns`）。
**書いていない軸は、エンチャントがそのまま働く。**

## 4. どこに持つか

| | |
| --- | --- |
| 置き場所 | **その 1 本**（アイテムの動的プロパティ `pve:enchants`） |
| 形 | `power:3,pierce:1`（名前と段を `:` で繋ぎ、`,` で並べる） |
| 表示 | **説明欄**（[18-item-view.md](18-item-view.md) 2 章） |

**属性と同じ持ち方**（[17-element.md](17-element.md) 1 章）——
**持ち替えても、落としても、その 1 本に付いて回る。**

## 5. 付け方（いまは試験用）

**拾ったときに付く仕組みはまだ無い。** 手で付けるコマンドだけ先に作る。

```
/pve:ench power 3      手に持っているものに強撃 III
/pve:ench spread       段を書かなければ 1
/pve:ench power 0      その 1 つを外す
/pve:ench clear        全部外す
/pve:ench list         付けられる名前を並べる
```

## 6. 気をつけるところ

**下書き 2-2 の心配ごとに、いまどう答えているか。**

| 心配 | いまの答え |
| --- | --- |
| **炸裂・連鎖 × 速射弓** | **爆ぜるのは与ダメの割合**なので、1 発が軽い速射では小さくなる |
| **群狼が常時発動** | **上限 +30%**。数えるのは半径 8 マスまで |
| **孤高がパーティ遊びとぶつかる** | **効きを小さく**（段 × 12%）。離れる利点を作りすぎない |
| **矢継ぎ早 × 速射弓** | 速射弓は**ためが無い**ので、**そもそも効かない**（軸が同じ） |
| **貫魔で演出がうるさい** | **1 発に 1 回だけ**。属性ごとの粒は 0.5 秒に 1 回までにしてある |

## 7. まだ無いもの

- **拾ったときに付く**（レア度ごとの確率・[03-content.md](../03-content.md) 2 章）
- **クリティカル**（クリティカルヒットが待っている）
- **落とし物と経験**（採掘者・本の虫が待っている）
- **味方**（光の射手・連携・孤高が待っている。いま人に当たるのは癒しの弓だけ）
