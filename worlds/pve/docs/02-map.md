# マップ（未定）

企画は [00-concept.md](00-concept.md)。

## 1. 決まっていないこと

**全部。** ウェーブ制の PvE として、少なくともこれを決める。

| 論点 | |
| --- | --- |
| **形** | 閉じた闘技場か、開けた場所か、複数の部屋を移るのか |
| 広さ | 何人で遊ぶかに直結する |
| **湧く場所** | 敵がどこから来るか。**囲まれる形にするのか、方向があるのか** |
| ボスの場所 | 同じ場所か、専用の場所か |
| 復活地点 | ウェーブの終わりに戻る場所 |
| 落下・場外 | 落ちる場所を作るか |

## 2. 建てずに試せるようにする

**まず、四角い床だけで動くようにする。**

> **試せない企画は、面白いかどうかも分からない。**
> Core Wars は**マップを建てないと試せない**のが重く、そこで検証が止まった。

**見た目は後から差し替える。**
最初のマップは「湧く場所と、立つ場所がある」だけでよい。
