## 2. Archer

### 2-1. コンセプト

**対単体の火力用。**

| | |
| --- | --- |
| 当たり方 | **単一ヒットしかしない** |
| 火力 | **高い** |
| ため時間 | **1 秒** |
| **1 秒ため** | **基礎攻撃力そのもの**（[03-content.md](03-content.md) 1-1） |
| **ためなし** | **1/10** |
| 攻撃後の待ち | **0.05 秒** |

### 2-2. 武器

**名前が `○○` のものは未定。**

**基礎攻撃力は 1 秒ためたときの火力**（[03-content.md](03-content.md) 1-1）。

| レア度 | 名前 | 基礎攻撃力 | 効果 |
| --- | --- | --- | --- |
| common | **支給された弓** | **30** | — |
| uncommon | ○○ | 50 | **味方に当てると回復する**（最終攻撃力に依存） |
| uncommon | ○○ | 25 | **ため時間が無くなる**（0.05 秒に 1 発・1 発は 1/10 の 2.5） |
| uncommon | ○○ | 64 | **ため時間を 2 秒まで延ばせる**（そこまで溜めると 1.6 倍） |
| rare | ○○ | 60 | **背後にガーディアンが出る。** 最も近い敵へ自動で矢を撃つ（wynncraft） |
| rare | ○○ | 70 | **効果なし。** そのぶん素の火力が高い |
| rare | ○○ | 60 | **ヒット時に小爆発**（爆発 20・小さめの範囲攻撃） |
| legendary | **ハープーンボウ** | 40 | **弾が 5 発に増える**（拡散弾・各 40%） |
| legendary | ○○ | 60 | **後ろの敵へ貫通**（-20% 減衰・最大数あり） |
| legendary | ○○ | 60 | **エンチャントが付きやすい** |
| **mythic** | **Freedom** | — | **未定。** とりあえず馬鹿武器にする |

> **数値は 2026-08-28 に決め直した**（[03-content.md](03-content.md) 1-2）。
>
> | レア度 | 毎秒 |
> | --- | --- |
> | common | **30** |
> | uncommon | **50**（特殊能力込み） |
> | rare | **60** ＋ 特殊能力 |
> | legendary | **60** ＋ より強い特殊能力 |
>
> **火力を増やす能力を持つ武器は、基礎を下げて合わせてある**
>（ハープーンは 5 発で実質 2 倍なので 40）。
> 詳しくは [drafts/archer-weapons.md](drafts/archer-weapons.md) 7 章。

### 2-3. エンチャント

| | |
| --- | --- |
| **拡散** | 弾が **2〜5 発**に増える。威力は減衰（**2→60% / 3→45% / 4→40% / 5→35%**） |
| **反射** | 弾が壁に反射する（**1 回まで**） |
| **追尾** | 追尾するようになる |
| **速射** | 時間が短くなる |
| **狙撃** | **遠いほど**火力が上がる |
| **接射** | **近いほど**火力が上がる |
| **光の射手** | 味方に当たると回復する（最終攻撃力に依存） |
| **集中** | ため時間を延ばせる（溜めるほど火力が伸びる） |

共通エンチャント（強撃・クリティカルヒット・吸収）は [03-content.md](03-content.md) 2-1。

### 2-4. 属性効果

**ヒット時に働く。数字と作りは [spec/17-element.md](spec/17-element.md) 3 章が本体。**

| 属性 | 効果 | 溜まるか | 見せ方 |
| --- | --- | --- | --- |
| **水** | **受けるダメージが 1.25 倍**（時間で落ちる） | **溜まる** | 滴が弾け、**足元へ滴り続ける** |
| **雷** | **最終威力の 50%** ＋ **一瞬止める** | **溜まらない** | **上から落ちる雷**（6 通り）＋ **ビリッ** |
| **火** | **最終威力の 75%** を **1 秒おきに 5 回**。**重なる** | 溜まる | **炎が立ち昇る**（1 秒に 1 回削る） |
| **風** | **後ろへ弾き飛ばす** ＋ **最終威力の 20%** | **溜まらない** | 緑の筋が横へ抜ける |
| **氷** | **満ちたら炸裂**し、**現在 HP の 5%** | 溜まる | 冷気をまとい、**パリン**と割れる |

**蓄積は与えたダメージに依存する**（ヒット数を稼げばよい、にしない）。

| | |
| --- | --- |
| **溜まるのは 水・火・氷 だけ** | 雷と風は**当たればその場で満**（[spec/17-element.md](spec/17-element.md) 2-3） |
| **入れ物は武器の種類ごと** | 弓の火と、他の武器の火は別（同 2-2） |
| 落ち方 | **1 秒に耐性の 5%**（同 2-4） |
| 耐性 | **モブごと。** 既定 50（同 2-1） |

> **雷の「受けるほど減衰」は宙に浮いている。**
> 減衰は蓄積があって初めて書ける——**弓の雷は溜まらない**と決めたため
> （[spec/17-element.md](spec/17-element.md) 3-1）。**表し方は決め直す。**

## 3. Blade（未定を含む）

### 3-1. コンセプト

**前衛職。**

| | |
| --- | --- |
| 攻撃 | **範囲攻撃がデフォルト** |
| 攻撃性 | **高い** |
| 防御 | **低い。** 扱いに注意が要る |
| 殲滅力 | **最大** |

### 3-2. 動き

| | |
| --- | --- |
| 通常攻撃 | **3 振りでモーションがループする** |
| 火力の差 | **1 段目 ×1 / 2 段目 ×0.75 / 3 段目 ×2**（3 段目が最も高い） |
| 右クリック | **溜め → 前進して横なぎ。前進中は無敵** |
| 溜め | **最大まで溜める必要がある**（**0.5 秒**） |

### 3-3. 武器

| レア度 | 名前 | 基礎攻撃力 | 効果 |
| --- | --- | --- | --- |
| common | **支給された剣** | **30** | — |
| uncommon | **未定** | | |
| rare | **未定** | | |
| legendary | **未定** | | |
| mythic | **未定** | | |

### 3-4. エンチャント

| | |
| --- | --- |
| **旋風** | **攻撃範囲が広がる** |
| **衝撃波** | **攻撃が奥に伸びる** |
| **重力** | **敵を自分の正面に吸い寄せる** |
| **スタン** | **確率で敵の動きを止める** |
| **爆発** | **倒したモブが爆発する**（倒した敵の HP の n%） |
| **舞踏** | **攻撃速度が速くなる** |

共通エンチャント（強撃・クリティカルヒット・吸収・採掘者・本の虫・背水の陣）は
[03-content.md](03-content.md) 2-1。

**Archer との違いが出ている。**

| | Archer | Blade |
| --- | --- | --- |
| 伸ばす方向 | **1 発の質**（拡散・追尾・狙撃） | **巻き込む数**（旋風・衝撃波・重力） |
| 場の作り方 | 無い | **重力・スタンで敵の位置と動きを触る** |
| 連鎖 | 無い | **爆発**（倒すと次が巻き込まれる） |

#### 決めること

| 論点 | |
| --- | --- |
| **爆発の n%** | 倒した敵の HP に対する割合。**ボスで壊れないか**を見る |
| **爆発は連鎖するか** | 爆発で倒した敵も爆発するなら、**上限か減衰が要る** |
| **スタンの確率と長さ** | 属性の雷（一瞬止める・受けるほど減衰）と**役割が被らないように** |
| **重力の効き方** | 吸い寄せる距離・対象数・ボスに効くか |
| **舞踏の上げ幅** | 3 段モーション（×1 / ×0.75 / ×2）との噛み合い |

### 3-5. 属性効果

**未定。** 種類は共通（水・雷・火・風・氷）。

**蓄積が与えたダメージ依存**であること、
**耐性はモブごと**であることは Archer と同じ（[03-content.md](03-content.md) 3-5）。

### 3-6. 決めるときの論点

| 論点 | |
| --- | --- |
| **範囲攻撃で属性をどう扱うか** | 1 振りで多数に当たる。**蓄積が一気に回る**ので、そこをどう抑えるか |
| **溜め横なぎ（無敵）の位置づけ** | 移動なのか、攻撃なのか、逃げなのか |
| **防御の低さをどう見せるか** | 数字だけか、被弾時の挙動でも見せるか |
| 武器 10 種の軸 | Archer は「単体・ため」で揃えた。Blade は何で 10 種を作るか |

## 4. Mage（未定）

**まだ何も決まっていない。**

### 4-1. 決めるときの論点

| 論点 | |
| --- | --- |
| **何が強いのか** | Archer は「単体火力」、Blade は「殲滅」。**Mage は何を担うのか** |
| **何ができないのか** | 強みと引き換えに諦めるもの |
| 攻撃の形 | 遠距離／範囲／時間差／設置 |
| **縛り方** | **詠唱・マナ・冷却のどれで縛るか** |
| 属性との関係 | 属性が最初から効く職業にするのか、他と同じ扱いか |
| 武器の形 | **サイコロ・カード**のようなものを担うならここか |

> **Blade と Mage は、対になるように決める。**
> 片方だけ先に決めると、**もう片方が「その残り」になる。**
