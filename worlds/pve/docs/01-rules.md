# ルール: 進行と成長

企画は [00-concept.md](00-concept.md)。

## 1. 進行

```
開始（時間・難易度を選ぶ）
    ↓
ウェーブ 1 ── 突破 ──→ 休憩 10〜30 秒
    ↓                        ↓
  全滅                   ウェーブ 2 …
    ↓
  終了
```

| | |
| --- | --- |
| 突破の条件 | **そのウェーブのモブを倒しきる** |
| 休憩 | **最低 10 秒・最大 30 秒** |
| ボス | **15 分想定のウェーブおき** |
| 終了 | **全滅**（生きている参加者が居なくなる） |

### 1-1. 復活

**倒れても、そのウェーブが終われば戻る。**

| | |
| --- | --- |
| 戻るとき | **ウェーブの終わり** |
| ペナルティ | **未定**（付けるかどうかも含めて） |

### 1-2. 途中参加

**後から入っても、スケールに多少は追いつけるようにする。**

追いつかせ方は未定。**「追いつける」ことだけが決まっている。**

### 1-3. 人数と敵の数

**参加人数に応じて増やす。1 次関数にはしない。**

> 人数ぶんそのまま増やすと、
> **多いほど楽**（火力は人数倍、敵も人数倍だが処理は分担できる）か、
> **多いほど地獄**（湧きが飽和する）かのどちらかに振り切れる。

式は未定。

## 2. ダメージ

**バニラの計算は使わない。**

| | |
| --- | --- |
| ダメージ | **完全に別の計算**にする |
| **多段ヒット** | **扱えるようにする**（バニラの無敵時間に縛られない） |
| HP | **バニラの体力とは別に持つ** |

> **バニラのままだと、無敵時間・防具・軽減が全部かかってくる。**
> 多段ヒットも刻めない。**数字を自分たちで持つ。**

## 3. レベルとステータス

### 3-1. 上がり方

**敵を倒すか、アシストするとレベルが上がる。**

**レベルも経験値も、こちらで持つ。**
**Minecraft のレベル（経験値バー）とは別物**——数字も上がり方も、こちらが決める。

**経験値の取得量を上げるエンチャント**がある（**本の虫**。
[03-content.md](03-content.md) 2-1）。

### 3-2. ステータス

| | |
| --- | --- |
| **力** | 与えるダメージ |
| **速** | ため時間・動きの速さ |
| **防** | **被ダメージを削る率**（[3-5](#3-5-防御という概念は置かない)） |
| **HP** | **硬さそのもの** |
| **運** | **クリティカルの発生**に効く |

**武器種固有のステータス**も置く。
**今後、汎用ステータスを足す**こともある。

### 3-3. 伸び方は人によって尖る

**ゲーム開始時（参加時）に、乱数で「伸び方の尖り」を決める。**

レベルアップで伸びる量は、**この尖りに従って変わる。**

> **同じ職業でも、同じ育ち方をしない。**
> ローグライクとして、**その回ごとの引き**を作る。

### 3-4. クリティカル

**運に依存して発生する。**

### 3-5. 防御という概念は置かない（2026-08-28 決定）

> ### HP が防御力。

**硬さは HP で表す。** 「防御力で軽減する」という考え方は持たない。

| | |
| --- | --- |
| 硬い相手 | **HP が多い** |
| 柔らかい相手 | **HP が少ない** |

**防があるとしても、それは率**——
「**最終火力から 90% を削る**」のような、**掛け算のカット率**として扱う。

**なぜ**

**軽減が入ると、武器の数字が意味を失う。**
基礎攻撃力 60 の弓が、相手によって 12 になったり 60 になったりする。

> **どれだけ削れたかが、そのまま見える。**
> ローグライクとして、**拾った武器が強いかどうかを即座に判断できる**ほうがよい。

**属性の「水」は防御率を削るもの**として扱う
（[03-content.md](03-content.md) の属性表）。

## 4. ショップと通貨

**ゲームの最中に買える場所がある。**

| | |
| --- | --- |
| 通貨 | **エメラルド** |
| 持ち方 | **アイテムではなく、データとして持つ**（数だけ） |
| 手に入り方 | 敵を倒したときなど（**採掘者**でドロップ率が上がる） |
| 使い道 | **ショップでの購入** |

> **アイテムとして持たせない。**
> 持ち物の枠を食い、落として拾えて、死んだら散らばる——
> **数えたいだけのものに、モノの都合が付いてくる。**

**採掘者**（[03-content.md](03-content.md) 2-1）は、このエメラルドの落ちやすさを上げる。

### 4-1. 決まっていないこと

| 論点 | |
| --- | --- |
| **何を売るのか** | 武器か、回復か、強化か、鑑定か |
| いつ買えるか | **休憩中だけか、いつでもか** |
| どこで買うか | 画面（チェスト UI 等）か、置かれた何かに触るのか |
| エメラルドの入り方 | 敵ごとの量・ボーナス |
| 死んだとき | 持っているエメラルドはどうなるか |

---

## 5. 決まっていないこと

- 各ステータスが**何にどれだけ効くか**
- レベルの上がりやすさ（必要経験値の曲線）
- 尖りの決め方（何段階・どれくらい偏るか）
- クリティカルの倍率と発生率の式
- HP・ダメージの具体的な数値の桁
- 死亡ペナルティ／途中参加の追いつかせ方／人数の式（[00-concept.md](00-concept.md) 8 章）
