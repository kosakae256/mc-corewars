## 0. 前提

### 0-1. 操作は変えない

**右クリック長押しで溜めて、離して撃つ。** どの武器でも同じ。

| 変えてよい | 変えてはいけない |
| --- | --- |
| ため時間・弾の数・弾の動き | **押すボタン・押し方** |
| 当たった後に起きること | **撃つ以外の操作を要求すること** |
| **見た目**（形も、飛び方も、爆ぜ方も） | — |

### 0-2. 矢の前提

| | |
| --- | --- |
| 移動 | **引いている間も遅くならない** |
| 弾数 | **無い**（矢を持たない・補充しない） |
| 弾道 | **まっすぐ・かなり速い** |

**ここから外れることが売りの武器だけ、外れてよい**（跳弾・追尾・往復）。

### 0-3. 属性とは別

**属性はランダムで付く**（[03-content.md](../03-content.md) 3 章）。

**武器の固有効果に、火・氷・雷そのものは置かない。**
置くと**属性が付いたときに二重になり、どちらの演出か分からなくなる。**

**武器で差を付けるのは、形・軌道・当たり方・爆ぜ方。**

---

## 1. 何で差を付けるか（2026-08-28 変更）

> ### 数字で差を付けない。**絵で差を付ける。**

**「+20%」は、拾った瞬間に伝わらない。**
**「着弾地点に星が降る」は、1 発撃てば分かる。**

| 良い差 | 悪い差 |
| --- | --- |
| **着弾で花火が開く** | 火力 +20% |
| **画面を横切る光の線が残る** | クリティカル率が少し上がる |
| **敵が地面へ叩きつけられる** | 当てると少し回復 |
| **溜め切ってしか撃てない代わりに大砲** | ため時間がわずかに短い |

**性能は尖ってよい。** 段の中で差があっても構わない——
**尖っているほど、拾ったときに嬉しい。**

**ただし毎秒火力の目安からは外れない**（7 章）。
**尖らせるのは形であって、総火力ではない。**

## 7. 火力の合わせ方

**目安は毎秒**（[03-content.md](../03-content.md) 1-2）。

| レア度 | 毎秒 | |
| --- | --- | --- |
| common | **30** | 効果なし |
| uncommon | **50** | **特殊能力込み** |
| rare | **60** | ＋ 特殊能力 |
| legendary | **60** | ＋ より強い特殊能力 |

**基礎攻撃力＝1 秒ためた 1 発の火力**なので、**基礎の数字がそのまま毎秒**になる。

### 7-1. 火力が増える能力を持つものは、基礎を下げる

| 武器 | 能力 | 実質倍率 | 基礎 |
| --- | --- | --- | --- |
| 速射弓（3） | 1/10 を 20 連射 | ×2 | **25** |
| 散華（5） | 3 発 各 70%（全弾当たれば） | ×2.1 | **38** |
| 双龍弓（24） | 2 本 各 60% | ×1.2 | **50** |
| ハープーン（30） | 5 発 各 40% | ×2.0 | **40** |
| 残響・回旋・影武者（36・41・44） | 実質 2 発 | ×2.0 | **35** |
| 星屑・流星（33・40） | 着弾後にも降る | ×1.3〜1.5 | **45** |
| 連撃の証（43） | 最大 +100% | ×1〜2 | **40** |
| 無限矢筒（45） | 最大 3 本（-40%） | ×1〜2.2 | **30** |

> **作るときは、[spec/14-effect.md](../spec/14-effect.md) に性能表を書く。**
> **何発・いくら・誰に・どこまで・いつ**まで決めないと実装できない。
> ため具合で**発数か威力が減る**（[spec/10-damage.md](../spec/10-damage.md) 5-1）。

**足止め・回復・稼ぎだけの武器は、基礎をそのまま置く。**
**無銘弓（14）だけ 70**——**特殊能力が無い分を、素の火力で払う。**

### 7-2. ため時間が長い武器

**1 秒の時点が基礎。** そこから先は武器ごとの倍率。

| 武器 | 基礎 | 溜めきり | 毎秒 |
| --- | --- | --- | --- |
| 長弓（4） | 64 | 102（2 秒・1.6 倍） | 50 |
| 重弓（7） | 52 | 78（1.5 秒・1.5 倍） | 50 |
| 大砲弓（29） | 62 | 93（1.5 秒・1.5 倍） | 60 |

## 8. 気をつけるところ

| 武器 | 何が起きうるか |
| --- | --- |
| **星屑（33）・流星（40）・極光（48）** | **画面が光で埋まる。** 数と時間の上限が要る |
| **地雷矢（23）・結界弓（37）** | **置いたものが残る。** 寿命と数の上限が要る |
| **時詠み（34）・影縫い（35）** | **止める系はボスに効かせない**か、**大幅に短く** |
| 連撃の証（43） | **外すとリセット**が厳しすぎないか。ウェーブ終わりでどうするか |
| 賽の弓（27） | 平均が同じでも、**1 が続くと弱い武器に感じる**。下限を上げるか |
| 無限矢筒（45） | 拡散と重なると**数えられない** |
| **Apocalypse（50）** | **連鎖爆発。** 上限か減衰が無いと 1 発で画面が消える |
