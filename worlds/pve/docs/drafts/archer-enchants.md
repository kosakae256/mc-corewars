# 下書き: Archer のエンチャント

**弓にしか付かないもの。** 共通エンチャントは [03-content.md](../03-content.md) 2-1。

**候補の山。まだ仕様ではない。**

## 1. いま決まっているもの（8）

| | |
| --- | --- |
| **拡散** | 弾が **2〜5 発**に増える（**2→60% / 3→45% / 4→40% / 5→35%**） |
| **反射** | 壁で **1 回**跳ねる |
| **追尾** | 追尾するようになる |
| **速射** | ため時間が短くなる |
| **狙撃** | **遠いほど**火力が上がる |
| **接射** | **近いほど**火力が上がる |
| **光の射手** | 味方に当たると回復する |
| **集中** | ため時間を延ばせる（溜めるほど伸びる） |

**8 つとも「1 発をどう飛ばすか」の話。**
足すなら、**別の軸**から取る。

## 2. 足す案（12）

| | 効果 | 軸 |
| --- | --- | --- |
| **貫通** | 敵を **1 体貫通**する（**-30%**） | 当てる数 |
| **炸裂** | ヒットで**小さく爆発**する | 当てる数 |
| **連鎖** | ヒットで**近くの敵へ 1 回跳ぶ**（30%） | 当てる数 |
| **貫魔** | **属性の挙動が必ず起きる**（蓄積を待たずに 1 回だけ即発動） | 通し方 |
| **浸食** | **属性の蓄積が増える**（[03-content.md](../03-content.md) 3-5） | 通し方 |
| **死神** | **HP が減っている敵ほど**火力が上がる | 状況 |
| **初撃** | **まだ当てていない敵**への 1 発目が **+50%** | 状況 |
| **群狼** | **近くの敵が多いほど**火力が上がる | 状況 |
| **孤高** | **近くに味方が居ないと**火力が上がる | 立ち位置 |
| **連携** | **味方が最後に当てた敵**への火力が上がる | 立ち位置 |
| **追撃** | **同じ敵に当て続けるほど**火力が上がる（外すと戻る） | 続け方 |
| **矢継ぎ早** | **倒すと、次の 1 発のためが 0 になる** | 続け方 |

### 2-1. なぜこの 12 なのか

**既存の 8 が「1 発の飛ばし方」に寄っている。**

| 軸 | 既存 | 足す分 |
| --- | --- | --- |
| 飛ばし方 | 拡散・反射・追尾・速射・集中 | — |
| 距離 | 狙撃・接射 | — |
| 味方 | 光の射手 | **連携・孤高** |
| **当てる数** | — | **貫通・炸裂・連鎖** |
| **通し方** | — | **貫魔・浸食** |
| **状況** | — | **死神・初撃・群狼** |
| **続け方** | — | **追撃・矢継ぎ早** |

> **Archer は対単体**（[04-roles.md](../04-roles.md) 2-1）。
> **当てる数**を増やす枠は置くが、**Blade の殲滅力は超えさせない。**
> 貫通・連鎖はどちらも**「もう 1 体」まで。**

### 2-2. 気をつけるところ

| | |
| --- | --- |
| **炸裂・連鎖** | **ヒット数で発動する。** 速射弓（0.05 秒に 1 発）と組むと**桁が変わる** |
| **群狼** | ウェーブ制なので**常に敵が多い。** 上限を付けないと常時発動になる |
| **孤高** | **パーティゲームで「離れると強い」**は、遊び方とぶつからないか |
| **矢継ぎ早** | 雑魚を倒し続ける間**ためが消える。** 速射弓と重ねない |
| **貫魔** | **属性の演出が毎発出る。** 画面がうるさくならないか |

> **属性の耐性も、防御力も存在しない**
>（[03-content.md](../03-content.md) 3-3・[01-rules.md](../01-rules.md) 3-5）。
> **「耐性を無視する」「防を無視する」エンチャントは作らない。**
> 置いたのは**浸食**（蓄積を増やす）と**貫魔**（即発動）。

**ヒット数で発動するものは、属性と同じ扱いにする**——
**与えたダメージで動く**か、**発動間隔を置く**（[03-content.md](../03-content.md) 3-5）。
