# 決定 01: 3D 生成の AI は自作せず、既存のものを使う

**2026-09-21。**

## 決めたこと

| | |
| --- | --- |
| **3D 生成** | **既存のモデル**を使う。自作は「できればそれが一番」だが、**まず既存で動かす** |
| **精度** | **形は粗くてよい。** 20×20×20 のブロックに潰すので細部は消える。**ONNX 等の軽量版でも可** |
| **読み取り** | **文章の意味は正しく読めなければならない。** 「赤い車」と書いたら赤い車が出ること |
| **速さ** | 受け取り → 生成 → 置換で **10 秒以内**が目標。**速さ優先で選ぶ** |

## なぜ

- 自作すると学習データ・学習時間・評価が要り、**ゲームを作る前に終わらない**
- 20³ に潰す時点で、高精度なモデルの利点はほぼ消える。**軽くて速いもので足りる**
- ただし**読み取りだけは潰れない**——間違った物が建つと、当てようがない。
  だから「文章 → 画像」の段は**速さより読み取りの正しさ**で選ぶ

## どう効くか

- 候補の比較と実測の順は [docs/research/29](../../../../docs/research/29-text-to-blocks-feasibility.md)
- **文章 → 画像 → 3D** の 2 段に分け、**読み取りは 1 段目（＋手前の LLM）に閉じ込める**
- 実測して 10 秒に収まらなければ、**読み取りの段は削らず**、3D 側の解像度と画像の step 数を落とす
