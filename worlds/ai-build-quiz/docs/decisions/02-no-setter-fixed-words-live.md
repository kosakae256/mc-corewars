# 決定 02: 出題者を無くし、固定リストから出題し、常にその場で生成する

**2026-09-21。** genlab で 40 語ほど流して見た結果を踏まえて決めた。

## 決めたこと

| | 前 | 後 |
| --- | --- | --- |
| **出題者** | 参加者から 1 人が文章を送る | **居ない。** システムが出す |
| **お題** | 任意の文章 | **こちらで固めた単語リスト**からランダム |
| **生成** | その場で | **その場で（変更なし）。事前生成はしない** |
| **自由入力** | 本流 | **裏モード**。後回し |

## なぜ

### 出題者を無くした

- 任意入力は**無茶なお題で壊れる**。実測: 「電車」は風景になって切り抜きに失敗（21 ブロック）、「剣」「本」は 40³ でも棒と板、「村」「公園」のような**複数・風景**は確実に失敗する
- 失敗の代償を払うのは**当てる側の 30 秒**
- お絵かき当ての面白さは**当てる側の推理と答え合わせ**にあり、お題の作文には無い
- 出題者が居ないと**「文章を外に出す口」が要らない**（research/29 6-4 の未検証項目が消える）。単語は wsbridge 側が選んで BP へ渡すだけ

### 固定リスト

- **全部のお題を事前に確認できる**（1 語 3 秒。300 語 × 3 seed で 45 分）。駄目な語は外す
- **答えの判定が決まる。** 語ごとに正解と表記ゆれ（犬 / いぬ / イヌ / わんこ）を持てる
- **難易度を作れる**

### 事前生成はしない（本人）

- 「その場で AI が作る」ことが見せ物。キャッシュは**ださい**
- 代償は 1 語 3 秒の待ちと、プレイ中の VRAM 8.7 GB。どちらも予算内

## どう効くか

- 企画 [00-concept.md](../00-concept.md) を書き換えた（1 章・5 章）
- 単語リストは**仕様として管理**する（[spec/12-words.md](../spec/12-words.md)）。語・正解・表記ゆれ・難易度
- 自由入力は、リストの外の語を genlab に投げるだけなので、後から足せる（BP の口は同じ）
