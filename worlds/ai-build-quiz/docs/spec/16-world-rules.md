## 2. 飛行

**プレイヤーは常に飛べる。ただしサバイバル**（クリエイティブにしない。ブロックを壊させない・アイテムを出させないため）。

| | |
| --- | --- |
| どうやって | **`/ability <player> mayfly true`**。BP が `player.runCommand("ability @s mayfly true")` を実行する。**`/ability` はワールド設定の「教育版の機能」を ON にしないと使えない**（チートだけでは出ない。2026-09-21 実機で確認）。`player.json` の `minecraft:can_fly` はモブの経路探索用で、プレイヤーの飛行にはならない |
| いつ | **1 人につき 1 回だけ**: スクリプト起動時に居る全員、参加したとき（`playerSpawn` の初回）。**掛け直さない**（既に飛べる人に何度も掛けるのは駄目——本人・2026-09-21。掛け直すと飛行が切れる）。死亡の再スポーンでは掛けない（mayfly は死んでも残る）。ゲームモードを変えて外れた人は `/quiz:start` でもう一度全員に掛ける（1 回） |
| 確認済み | 1.26.51・教育版 ON で `mayfly` が付く（2026-09-21） |

## 3. 行動範囲（境界）

**Core Wars の境界をそのまま使う**（本人の指定）。
[worlds/core-wars/packs/game/scripts/features/border/index.ts](../../../core-wars/packs/game/scripts/features/border/index.ts) の**考え方とコードを写す**（1 アドオン 1 プロジェクトなので、共有はせず複製する）。

| | Core Wars | このワールド |
| --- | --- | --- |
| 出たら | 中へ戻す（`pushInside`。境界から 1.5 内側） | 同じ |
| 見せ方 | バニラのワールドボーダーの粒子から上昇だけ外した `game:border_wall`（RP の `particles/border_wall.json`） | **同じ粒子を RP に複製**し、id を `ai_build_quiz:border_wall` に |
| 上下 | 横だけ | **上下も切る**（飛べるので。1 章の y） |
| クリエイティブ | 通す（運営がマップを直しに行く） | 同じ（アドミンがクリエイティブのときだけ通す） |
| 通知 | 2 秒に 1 回 actionbar | 同じ |
| 状態依存 | 試合中だけ | **常に**（状態を見ない） |
| **落ちたら** | — | **y < −60 になったら、op 以外はスポーン地点に戻す**（本人・2026-09-21。ワールドのスポーン地点。ベッドで決めた人はそこ。op は境界の上下の壁だけ） |

## 4. 移動（羽のダッシュ。本人・2026-09-21）

飛べるだけだと遅いので、**羽（`minecraft:feather`）を持って右クリックすると、見ている方向へ一瞬強く加速する**。

| | |
| --- | --- |
| 配り方 | **常に持っている**（ゲーム中でなくても）。参加時・再スポーン時・5 秒ごとに「持っていなければ 1 本渡す」。死んでも落とさない（`keepOnDeath`） |
| 落とせない | `lockMode = inventory`（捨てる・移す・置くができない）。名前は「§bダッシュ §7(右クリック)」 |
| 加速 | `itemUse`（羽）で `applyKnockback`。向きは `getViewDirection()`、水平 12.5・上下は向きの y × 12.5（2.5 で試して「今の 5 倍」） |
| 連打 | 10 tick（0.5 秒）は次を受けない |
| 音 | 本人にだけ `item.trident.riptide_1` |
| 実装 | `features/dash/`（imp.md の層） |

## 5. その他のワールド設定（仮）

| | 値 | なぜ |
| --- | --- | --- |
| チート | ON | `/wsserver` `/scriptevent` に必要 |
| **教育版の機能** | **ON** | `/ability`（飛行）に必要。チートだけでは出ない |
| **実験「ベータ API」** | **ON** | `chatSend`（チャットで答える）が beta にしかない。**有効にしたワールドは元に戻せない**（imp.md 5-4）。ワールドを作るときに入れる |
| ゲームモード | サバイバル | 2 章 |
| `doDaylightCycle` | false（昼固定） | 建築を見やすく |
| `doMobSpawning` | false | 邪魔 |
| `keepInventory` / `pvp` | keep true / pvp false | 遊びに関係ない事故を無くす |
| 落下ダメージ | 飛べるので気にしない。`fallDamage` false でもよい | |

## 6. 体力（本人・2026-09-21「HP を常に 0.5 にしておいて」）

**全プレイヤーの体力を常に 1（ハート半分）にする。** `features/health` が 10 tick ごとに `health` コンポーネントで 1 に戻す（自然回復で増えても戻る）。参加時も。運営も同じ。
死んだら普通にリスポーン（コンパス・羽は `keepOnDeath`、得点は scoreboard なので消えない）。
