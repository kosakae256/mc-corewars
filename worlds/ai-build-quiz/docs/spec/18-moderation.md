# 仕様 18: 下ネタの規制

> 作成日: 2026-09-22（本人「下ネタの規制をしたい。チャットの方も、問題の方も」
> 「ルールベースでいいよ、そんな複雑にしなくていい。一般的に下ネタとされる、『ちんこ』ぐらい以上のものを規制したい」）。

**言葉の一覧に当てるだけ**（ルールベース）。AI も点数も使わない。
**「ちんこ」くらい以上のはっきりした下ネタだけ**を止める。「うんこ」程度の軽口や、暴言・悪口は追わない。

## 1. どこで止めるか

| | 何を見るか | 引っかかったら |
| --- | --- | --- |
| **チャット**（`chatSend`。全員・全モード・全状態） | 発言そのもの | **誰にも見せない**（`ev.cancel`）。**本人にだけ**「その言葉は使えません」。回答の判定にもかけない（正解にならない） |
| **出題の UI**（お題・詳細） | 両方 | キューに入れず、フォームを閉じずに赤字で打ち直させる |

- **出題者チャット・正解者チャットも同じ**（先に規制を通してから、それぞれの流し方をする）
- **運営（オペレーター）も例外にしない。** 切り替えは作らない（規制は常に効く）
- 運営にだけ「◯◯ さんの発言を伏せました」と伝える。**中身は出さない**（出すと規制の意味が無い）
- 単語リスト（787 語。[12-words.md](12-words.md)）は AI 側の出題なので関係しない

**bridge では見ない。** お題の入口は BP の UI だけなので、そこで止めれば genlab へは渡らない。
bridge で止めるとキューの先頭が詰まって次に進めなくなる（2026-09-22 決定）。

## 2. 照合のしかた（`scripts/core/ng.ts`。純粋関数）

1. **正規化**: NFKC → 小文字 → カタカナをひらがなに → **長音記号（ー）を落とす** → 文字と数字以外を落とす。
   **`normalizeAnswer`（[12-words 2 章](12-words.md)）と違う点が 2 つ**:
   **「っ」は残す**（落とすと「えっち」→「えち」が**エチオピア**に、「ぼっき」→「ぼき」が**募金**に当たる。繰り返しの「っ」は 1 つに潰す）、
   **長音は母音にせず落とす**（「おっぱーい」を「おっぱい」として当てたい）。
   **`core/answer.ts` は import しない**（テストが `.ts` を直に読むので core どうしの実行時 import は解決できない。`order.ts` が `import type` だけなのと同じ）
2. **見逃す語を消す**（3-3）
3. **日本語**: 一覧の語が**含まれていたら**引っかかる。次の **3 通りの形**で見る（本人・2026-09-22「伏字、あなる等が防がれてません」）:
   - **記号を落とした形**（「お っ ぱ い」「ち,ん,こ」）
   - **伏字の形**: 伏字に使う記号（`○ 〇 ◯ ● ◎ ■ □ ★ ☆ * ＊ × ✕ ✖`）の並びを**「どれか 1 文字」の穴**として見る（「ちん◯ん」＝ちんちん、「ま○こ」＝まんこ）。
     **読点や空白は穴にしない**（「さんま、こんぶ」が「まんこ」に当たってしまう）
   - **同じ字の連続を 1 つに潰した形**（「まんんこ」「ちーんこ」）

   「ヴ」は「ば行」に寄せる（ヴァギナ＝ばぎな）。半角カナ・全角英字は NFKC で揃う
4. **英語**: 元の文を英数字で区切って**語として**見る（部分一致だと `cockpit`・`grass`・`analysis`・`title` が引っかかる）。
   `masturbat` `ejacul` `pornograph` だけは**語の頭**で見る

## 5. これで止まらないもの（割り切り）

- **言い換え・隠語**（「ちん◯ん」「H なこと」）、**英語の 1 文字割り**（`f u c k`）。言葉を足して追うしかない
- **画像の中身**（プロンプトが普通でも、きわどい絵が出ることはある）

止めきれない前提で、運営が「出題キューを空にする」「ゲームを止める」で対応できるようにしてある（[17-modes 4 章](17-modes.md)）。

## 6. `/me` は追わない（2026-09-23 に**やめた**）

**一度入れたが、本人の判断で外した**（「me の規制一旦消してほしい、しなくていい」）。調べた結果だけ残す。

| | |
| --- | --- |
| **BP では止められない** | `/me` は**チャットではなくコマンド**なので `chatSend`（before）が発火しない。コマンドを横取りするイベントが Script API に無い。`/me` は権限レベル 0 で全員が使え、チートを切ると `/wsserver` が打てない |
| 気づくことはできる | bridge が `PlayerMessage` の `type` を見れば分かる（`"chat"` / `"me"` / `"say"` / `"tell"` が入る。実測済み）。いまも `bridge.log` には型つきで残る |
| 消す手は「流す」しかない | 1 行だけ消す API は無い。空行で押し出し、BP が覚えている公開チャットを出し直す方式を作ったが、**私信と 20 行より前が戻らない**・一瞬は見える、という割り切りが要る |
| いまの扱い | **何もしない。** 下ネタの規制（1〜5 章）は普通のチャットと出題の UI にだけ効く |

もう一度必要になったら: bridge が `type !== "chat"` で `/scriptevent quiz:me <名前>` を送り、BP が押し出して出し直す（この形で一度動いていた）。
