### 1-1. 元の 1 行（タブ区切り）

```
ja      reading     en             aliases                        level  seed  hint        english
りんご   りんご       apple          林檎,アップル                     1            果物        apple
消防車   しょうぼうしゃ fire engine   ポンプ車,はしご車                  2            はたらく車   fire engine,fire truck,firetruck
```

| 列 | 意味 |
| --- | --- |
| `ja` | 表示・正解の代表。発表で出す |
| `reading` | ひらがなの読み。**ローマ字の自動生成に使う。** 表記そのものも正解になる |
| `en` | **生成用の裏プロンプト。翻訳ではない。** 文脈と見た目の特徴を書く（`Minecraft Steve` / `red fly agaric mushroom` / `single whole lemon`）。プレイヤーには見えない。書き方は 3-1 |
| `aliases` | **日本語の別名**（2-3）。漢字・別表記・俗称・あだ名・子どもの言い方・上位語。カンマ区切り。**たっぷり書く** |
| `level` | 1 = 易 / 2 = 中 / 3 = 難 |
| `seed` | 任意。生成が安定しない語に固定 seed |
| `hint` | **ジャンル**（10 秒のヒント。4-1）。カテゴリより一段細かい。空なら 2 段目のヒントは出さない |
| `english` | **英語の答え**（カンマ区切り）。`en` は裏プロンプトなので答えには使わない。**必須**（空だとビルドが止まる。「ローマ字・英語は全語で通る」を保証する） |

`kind` はファイル名。

## 2. 「曖昧な言い回し」の定義（正解として受け付けるもの）

> **方針（本人・2026-09-21）: 意味が伝わればよい。** ローマ字・英語・カタカナ／ひらがな・漢字はもちろん、
> **同じ物の別の呼び方（机 ⇔ テーブル）、俗称・あだ名（クリーパー ⇔ 匠）、少しの打ち間違い、語尾（「犬かな？」）** も正解にする。
> ほぼ同じ物は同じ 1 語にまとめる（2-5）。厳しくして外すより、緩くして当てるほう。
>
> **上位語の扱い（本人・2026-09-21、同日に 2 回直した）。**
> 最初「ジャンルは木と言われたときに木で正解になるのはダメ」→ 上位語を全部外した → 「スニーカーが靴でフォールバックされないのは微妙。それぐらいはしてほしい」。
> 落としどころ: **物の「1 段上の普通の呼び名」は受ける**（スニーカー→靴、ショートケーキ→ケーキ、クルーズ船→船、りんごの木→木）。
> **キャラをその動物・作品の脇役を主役で当てるのは受けない**（ワンパチに「犬」、ハリーポッターに「魔法使い」、ザクに「ガンダム」）。
> そして **ジャンル名に受理語が入っていたらエラー**（ヒントを言うだけで当たる、をリスト側で防ぐ）。

例: **りんご** → りんご / リンゴ / 林檎 / アップル / ringo / apple / RINGO / ｒｉｎｇｏ / りんごかな / りんごです / apples / an apple / りんごー / りんこ

### 2-1. 正規化で自動的に同じになるもの（書かなくてよい）

BP の `core/answer.ts`（純粋関数。bridge の `src/normalize.ts` と同じ内容）が、**入力と正解の両方**にこれを掛ける:

| 変換 | 例 |
| --- | --- |
| NFKC（全角・半角の統一） | `ｒｉｎｇｏ` → `ringo`、`ﾘﾝｺﾞ` → `リンゴ` |
| カタカナ → ひらがな | `リンゴ` → `りんご` |
| 英字は小文字 | `Apple` → `apple` |
| 空白・句読点・記号を落とす | `りんご！` → `りんご`、`ice cream` → `icecream` |
| 長音「ー」は前の母音に | `コーヒー` → `こおひい`（`こーひー` でも `こおひい` でも当たる） |
| **「っ」「ッ」を落とす** | `カップ` = `カプ`（緩める。衝突はほぼ無い） |
| **紛らわしいかなを寄せる** | ぢ→じ、づ→ず、を→お、ゔ→ぶ、ゐ→い、ゑ→え、小さい ぁぃぅぇぉ → 大きく |
| **語尾・前置きを落とす** | 「犬**かな**」「犬**です**」「犬**でしょ**」「**答えは**犬」「it's a dog」→ `いぬ` / `dog`（2-4 の表） |

**受けるもの（上位語のうち）: 物の「1 段上の普通の呼び名」。** スニーカー → 靴、ショートケーキ → ケーキ、クルーズ船 → 船、スクールバス → バス、りんごの木 → 木、ゆで卵 → 卵、麦わら帽子 → 帽子、揺り椅子 → 椅子、ステーキ → 肉（本人・2026-09-21「それぐらいはしてほしい」）。
判定は 1 ラウンド 1 語なので、**別の語と重なってよい**（靴 と スニーカー が両方「靴」を受ける）。`npm run words` は重なりを数えて表示するだけ。
ただし **ジャンル名にその語の受理語が入っていたらエラー**（4-1）: スニーカーの受理語に「靴」があるなら、ジャンル名は「靴」ではなく「身につけるもの」に。

正規化で同じになるだけの衝突（ハット ⇔ ハト、鉢 ⇔ ハチ、甕 ⇔ カメ、駒 ⇔ こま）は別名のほうを外す（「っ」を落とす・読みで比べる、の副作用。語自体は残す）。

### 2-4. 一致（緩い照合）

> 本人・2026-09-21「曖昧さ解釈ちょっときつすぎるから結構緩くしていいよ」→ 下の表に広げた。**外すより当てる。**

BP は `accepted`（正規化済みの集合）を round ごとに持つ。発言を正規化し、**語尾・前置きを 1 段ずつ落とした形を全部**（「きつねかな」→ きつねかな・きつね・きつ。どこで止めるべきかは語によるので）作り、どれかが次のどれかなら正解。**出題モードは完全一致だけ**（[17-modes 3 章](17-modes.md)）:

| 規則 | 条件 | 例 |
| --- | --- | --- |
| 完全一致 | `n === t` | `いぬ` |
| **含む** | `t` が **2 文字以上**で `n` が `t` を含む（1 文字は含まない） | 「たぶんピカチュウ」→ `ぴかちゅう`、「日本人形」→ `人形`、「こいぬ」→ `いぬ`。「犬小屋」で `犬` は当たらない |
| **前半だけ** | `t` が `n` で**始まり**、`n` が 3 文字以上かつ `t` の半分以上 | 「しょうぼう」→ `しょうぼうしゃ`、「エッフェル」→ `えっふぇるとう`。**後ろだけは不正解**（「ボール」で `てにすぼおる`、「船」で `ぎょせん`。2026-09-23）。「いか」で `すいか` も当たらない |
| **打ち間違い** | `t` が 4 文字以上で編集距離 1、7 文字以上で 2、10 文字以上で 3（`n` 全体で見る） | `ぴかちゆう`、`ぴかちゅ`、`pikachi`、`hipopotamus` |
| **文の中の打ち間違い** | `n` の中の、`t` と同じ長さ±1 の窓のどれかが上の距離以内 | 「たぶんぴかちゆうだ」→ `ぴかちゅう` |

語尾・前置きとして落とすもの（正規化後。末尾は繰り返し）:

- 末尾: です・ます・でした・ました・でしょ・でしょう・でしょうか・ですか・ますか・ですね・ですよ・だよ・だね・だな・だろ・だろう・だわ・かな・かなあ・かも・かもね・かもしれない・じゃない・じゃん・じゃね・やん・やろ・かい・か・ね・よ・わ・ぞ・ぜ・な・なあ・っす・っぽい・ぽい・みたい・と思う・だと思う・かと・のかな・**w（何個でも）・笑**
- 先頭: 答えは・こたえは・正解は・たぶん・多分・絶対・ぜったい・たしか・確か・もしかして・もしや・ひょっとして・これは・それは・あれは・えっと・えーと・うーん・あー・いや・うん・はい・it's・its・it is・this is・maybe・the answer is・a・an・the

### 2-5. ほぼ同じ物は 1 語にまとめる

「机」と「テーブル」、「パソコン」と「ノートパソコン」のように**当てる側から見て同じ物**は、別々の問題にしない。片方を `ja` にし、もう片方は `aliases` に入れる（`en` は生成しやすい方）。判断は「両方の絵を見せられて、どちらがどちらか当てさせるのは意地悪か」。意地悪ならまとめる。

## 3. 入れる語の条件（語を選ぶ基準。数より「誰でも知っている」）

**「1 体で、形と色で当てられる物」だけ。** 生成の実測（[docs/spec/08 5 章](../../../../docs/spec/08-genlab.md)）から:

| 入れる | 入れない | なぜ |
| --- | --- | --- |
| 1 体で形が決まる物（犬・車・家・ロケット・ギター） | **風景・場所・集合**（村・公園・街・森・海・電車の車窓） | 絵が風景になり切り抜きに失敗する |
| 体積のある物 | **薄い物・細い物**（紙・カード・定規・針・糸・剣・鉛筆） | 60³ でも板と棒 |
| 色や輪郭に特徴がある物 | 色も形も曖昧な物（石・雲・水・砂） | 当てる手がかりが無い |
| 固有名詞でも形が決まる物（東京タワー・ピカチュウ・自由の女神） | 実在の人物 | 顔は出ない |
| 動物は**全身で特徴が出るもの** | 極端に細い動物（ミミズ・ヘビは△） | |
| **日本で名前が通じる物**（子どもから大人まで、名前を聞けば分かる） | 海外だけで有名なキャラ（ガーフィールド・カーミット・グルート）、日本で馴染みの薄い食べ物（パネトーネ・アーティチョーク）、専門的な道具（魚籠） | **当てられない物は出題にならない**（本人・2026-09-21）。海外作品のキャラは日本で放送・公開されて広く知られている物だけ |
| **作品名を答えにしない**（答えは絵に映っている**その物・そのキャラの名前**） | 妖怪ウォッチ・すみっコぐらし（作品名）。ゲゲゲの鬼太郎 → 答えは「鬼太郎」（作品名は別名に） | 作品名は絵から当てられない（本人・2026-09-21「作品名じゃ無理だよ」） |
| **誰でも知っている物だけ**（名前を見て「誰それ」「何それ」が出ない） | 作品の**脇役・マニア向け**（七人の小人・ゴラム・ドビー・チョロプー・ワドルディ・ザク）、**ディズニー・ピクサーは丸ごと**（本人「消しておいて」）、珍しい動物（オカピ・カブトガニ・バク）、珍しい食べ物（落雁・すあま・サモサ・カヌレ）、珍しい道具（オカリナ・メトロノーム・苔玉） | 本人・2026-09-21「全然わからんキャラ入れるのやめてね、誰でも知ってるものにして」「おおくはわからん」。**語数より当てられること。** 迷ったら落とす |

**落とした語は `words/<kind>.txt` に `#` でコメントアウトして理由を書く（消さない）。**

### 3-1. `en`（裏プロンプト）の書き方

| 書く | 例 | なぜ |
| --- | --- | --- |
| **文脈**（作品名・国） | `Minecraft Steve`、`Thomas the Tank Engine`、`Japanese red school backpack (randoseru)` | 単語だけでは別の物になる（Steve → 人の写真） |
| **決め手になる色・形** | `red fly agaric mushroom`、`yellow school bus`、`white sheet ghost` | ブロックになっても残る特徴を絵に出させる |
| **1 個・丸ごと** | `single whole lemon`、`one piece` | 食べ物は山盛り・輪切りになりやすい（定型でも足すが、語でも念を押す） |
| 書かない | 「〜の写真」「背景」「照明」 | 定型（[docs/spec/08 2-0](../../../../docs/spec/08-genlab.md)）が足す |

**画像モデルが知らない物（マイナーなキャラ・固有名詞）は書き方で直らない。落とす。**
実行時に言語理解モデルは使わない（固定リストは全部ここで書いておく）。裏モードだけは別（[00-concept 6 章](../00-concept.md)）。

### 3-2. 検証の seed

`verify_words.py` は seed 1 で流し、個数が足りなければ seed 2, 3 でやり直す。**使った seed を `seed` 列に写す**。
bridge は `seed` が空なら 1 を使う（`words.ts` の `DEFAULT_SEED`）。**ゲームで出る建築 ＝ 目で確かめた建築**。

## 4. カテゴリ（ヒントに使う）

**カテゴリは「前提」として全員に見えるので、外れていてはいけない**（本人・2026-09-21「ジャンルとの不一致はできるだけなくして」「カテゴリ増やしていいよ」）。合わない語があれば、カテゴリを増やしてでも合わせる。

| kind | 表示名（ヒント） | genlab の定型（`style`） | 語数（2026-09-21） |
| --- | --- | --- | --- |
| animal | 動物 | creature | 100 |
| vehicle | 乗り物 | object | 25（3D 化で千切れるので少ない） |
| building | 建物 | object | 40（風景・内部になるので少ない） |
