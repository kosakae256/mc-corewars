# 仕様 14: 置く

> 作成日: 2026-09-21 / 企画 4 章（演出）

## 1. 場所（本人の定義）

| | 値 | なぜ |
| --- | --- | --- |
| 箱 | **60 × 60 × 60。(0, 0, 0) を中心**。x, y, z とも **−30 〜 +29**（60 マス） | [16-world-rules.md](16-world-rules.md) |
| 建築の置き方 | 箱の中で **x, z は中央寄せ、y は箱の底（−30）に接地**。定数 `ANCHOR` で「中心に浮かせる」にも切り替えられる | 物は地面に立っているほうが分かりやすい。飛んで見るなら中心もあり得るので切替を残す |
| **正面** | **z が大きい側**。genlab は画像を z+ から投影している（spec/08 5-3）ので、**z+ 側から見た姿が一番忠実** | 1 枚の絵から作った 3D は正面が一番忠実。飛べるのでどこからでも見られるが、案内はここ |
| ticking area | 箱を含む範囲に**手で張る**（`/tickingarea add -40 -40 -40 40 40 40 quiz`） | プレイヤーが離れても置き続けるため |

genlab には `size=60` で頼む（60³ = 21.6 万マス。連長で 3〜6 万文字 → chunk 15〜30 回）。

## 2. 置く順と速さ

| | 決まり |
| --- | --- |
| 順 | **下の層から**。同じ層の中は**ランダム**（端から並べると「掃く」ように見える。ばらけると「ポポポポ」に見える） |
| 速さ | **10 秒で置き終わる個数/tick**: `N = ceil(count / 200)`。上限 1,300（pve-v3 の実測予算）、下限 1 |
| 輪 | `loop.ts` の 1 本の `runInterval(1)` の中で毎 tick N 個（imp.md 10-1）。**機能ごとに `runInterval` を書かない** |
| 音 | **2 tick に 1 回、全員の耳元で `random.pop`**（1 tick ごとは多い——本人）（`player.playSound`。位置に依らず、どこにいてもどの向きでも同じに聞こえる——本人・2026-09-21「ぽぽぽぽ」）。ピッチを少し揺らす。1 個ごとに鳴らすと騒音 |
| 置き方 | `dimension.setBlockType(loc, id)`。id は palette の名前に `minecraft:` を付ける |
| 置き終わり | 全部置いたら `phase` を 2 にして 30 秒を始める。**同時に音を 1 つ**（`random.levelup`） |

`count` 1 万なら N = 50 で 200 tick = 10 秒。60³ の家は 5〜7 万個になりうるので N = 300 前後。上限 1,300 に当たったら 10 秒を超えるのを許す。

## 3. 片づけ

| いつ | 何を |
| --- | --- |
| `quiz:go` を受けた直後（置き始める前） | 箱の中を `fillBlocks(..., "air")`。60³ = 216,000 > 32,768 なので **y で 7 回に割る**（pve-v3 `builder.ts` の `fillBlocks` 上限） |
| `/quiz:stop` | 同上 |
| `reveal` の後 | **消さない。** 次の `go` まで残す（見返せる） |

## 4. 守ること

- **置く場所は箱の中だけ。** 展開した座標が箱の外なら捨てる（bridge のバグでワールドを壊さない）
- **palette の名前は許可リスト**（羊毛・コンクリート・テラコッタの 49 種 ＋ air）**と照合してから置く**（imp.md 8-1。外から来た文字列をそのまま id にしない）
- 置く途中で `/quiz:stop` が来たら、その tick で止めて片づける
