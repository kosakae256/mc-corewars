# 仕様: 支柱弾（投げて柱を立てる）

**投げた先に、上下 10 マスの柱が生える。**

---

## 1. 何のためにあるのか

**足場を「作る」のではなく「投げる」。**

ブロックを積むのは時間がかかり、**戦闘中には成立しない。**
投げれば、届かない高さへ一瞬で足場が生まれる。

**ワイヤー**（[13-grapple.md](13-grapple.md)）は**引っ掛ける場所がないと使えない。**
何もない空へ逃げられない。**支柱弾はその穴を埋める。**

---

## 2. 投げてから

```
投げる
  ↓  0.1 秒（約 30 マス飛ぶ）
炸裂
  ↓
柱が生える（上 10 / 下 10）
  ↓  5 秒
崩れる
```

| | |
| --- | --- |
| クールダウン | **エンダーパールと同じくらい**（1 秒） |
| 炸裂 | **0.1 秒後に自動。** 当たったらその場で |
| 速さ | **1 tick あたり 15 マス**（2026-08-26。1.5 → 7.5 → 10 → 15） |
| 届く距離 | **約 30 マス**（速さ × 0.1 秒） |
| 柱の長さ | 炸裂点から**上 10・下 10** |
| 残る時間 | **5 秒** |

### 2-0. 速さは 5 倍、距離は元のまま（2026-08-26）

**着くのが速くなっただけ。**

| | 2026-08-25 | **いま** |
| --- | --- | --- |
| 速さ | 1.5 マス/tick | **15 マス/tick** |
| 飛ぶ時間 | 0.5 秒 | **0.1 秒** |
| 届く距離 | 15 マス | **約 30 マス** |

> 足場が要る場面は「**いま落ちる**」ときで、**待たされるほど使い道が無い。**

**距離は速さと時間の両方で決まる。**

| 試したこと | どうなったか |
| --- | --- |
| 速さ 5 倍・時間そのまま | **75 マス。遠すぎた** |
| 速さ 5 倍・時間 1/5 | 15 マス。**近すぎた** |
| 速さ 10・時間 1/5 | 約 20 マス。まだ近い |
| **速さ 15・時間 1/5** | **約 30 マス** |

**近すぎるときは、まず速さを上げる。**
時間を伸ばすと「待たされる」が戻ってくる。

**壁の当たり判定の刻みも 5 倍にした**（6 → 30）。
刻みを増やさないと、**1 tick に 7.5 マス跨いで壁を抜ける。**

### 2-1. 当たったら即座に炸裂する

**ブロックでもプレイヤーでも同じ。**
壁に当たったら壁ぎわに、当たらなければ空中で炸裂する。

### 2-2. 貫通しない

**途中にブロックがあれば、そこで止まる。**
上へ伸ばす途中で天井に当たれば、そこまで。

貫通させると、**壁の向こう側に足場ができてしまう。**

### 2-3. 置けない場所には置かない

拠点の中やジェネレータの上（[11-match.md](11-match.md) 6-G）には生えない。
**投げれば置けるなら、置けない場所を作った意味が無い。**

ロビーでは**手で置けるのと同じ規則**（y 120 以上。[25-practice.md](25-practice.md) 3-A）。

### 2-4. 人が行ける範囲の外では炸裂しない（2026-08-27 追加）

| いつ | 範囲 |
| --- | --- |
| 試合中 | **戦闘範囲**（`arena.bounds`） |
| ロビー | **ロビーの範囲**（`LOBBY_BOUNDS`） |

**外へ出た弾は、音も粒も出さずに消える。**
誰も行けない場所で爆ぜても、**驚かせるだけで意味が無い。**

## 3. 生えるブロック

**チームの色。** 自陣の色で生える。

**ロビーで撃ったぶんは白**（`game:pillar_white`。2026-08-27 追加）。
無所属で撃つので**陣営の色が無い**（[25-practice.md](25-practice.md)）。

| 性質 | |
| --- | --- |
| 硬さ | **スライムブロックと同じ。** `seconds_to_destroy: 0` で素手でも一瞬 |
| 落ちるか | **どんな壊し方でも落ちない** |
| 見た目 | 染めた土（チームの色） |

> **スライムブロックの硬さは 0。**
> 0.1 秒にしていたが、道具に関係なく一定の待ちが入るので、
> **0 にして本当に一瞬にする**（2026-08-25 修正）。

### 3-1. なぜ柔らかいのか

**相手に「壊せる」余地を残す。**
硬いと、投げただけで一方的に地形を作れてしまう。

### 3-1-1. 保護の対象から外す（2026-08-25 修正）

**守らないブロックの一覧（`lib/protection.ts`）に入れる。**

一覧に無いものは全部守られる作りなので、
**掘っても打ち消されて元に戻っていた。**
「壊せるのに戻ってくる」の正体はこれ。

> 落ちないことと硬さは**ブロック定義側**（`blocks/pillar_*.json`）で決めている。
> 保護とは別の話なので、混ぜない。

### 3-2. なぜ落ちないのか

**拾って積めると、投げ物ではなく資源になる。**
1 回投げるたびに 20 個のブロックが手に入るのはおかしい。

---

## 4. 崩れる様子を見せる

**5 秒で消えるが、黙って消さない。**

| 残り | 何が起きるか |
| --- | --- |
| 1 秒前 | **音が鳴る**（崩れる予告） |
| 0 | **下から順に消える**・粒子 |

**足場が消えることは事故につながる。**
予告が無いと、落ちた理由が分からない。

## 6. 飛ぶ速さ（2026-08-25 変更）

**届く距離は変えず、着くまでを速くした。**

| | 前 | 後 |
| --- | --- | --- |
| 炸裂まで | 1.5 秒 | **0.5 秒** |
| 速さ | 0.5 マス/tick | **1.5 マス/tick** |
| 届く距離 | 15 マス | **15 マス**（変えない） |

**投げてから 1.5 秒は、戦闘中には長すぎた。**
足場が要る場面は「いま落ちる」「いま登る」なので、
**着く前に状況が変わってしまう。**

距離を変えると射程の意味が変わるので、**速さだけを 3 倍にする。**

## 7. 炸裂する場所（2026-08-25 修正）

**壁に当たったときは、当たった位置ではなく「手前」で炸裂する。**

当たった位置で炸裂させていたので、**柱の根元が壁の中**になっていた。
根元が置けないと上下どちらにも伸びないので、
**炸裂はしているのに何も出てこない。**

| 当たり方 | どこで炸裂するか |
| --- | --- |
| **ブロック** | **ぶつかる 1 つ手前**（最後に空いていた位置） |
| プレイヤー | その場 |
| 時間切れ | いま居る場所 |

### 途中を飛ばさない

**1 tick に 1.5 マス進むので、1 回しか調べないと厚さ 1 マスの壁をすり抜ける。**
0.25 マスごとに調べる（1 tick を 6 回に分ける）。

### 炸裂は必ず見せる

**柱が立たなくても、粒と音を出す。**
何も起きないと「投げ損なった」のか「置けない場所だった」のか分からない。
