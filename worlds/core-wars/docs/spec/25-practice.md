# ロビーで試す（2026-08-27）

> ### 買ってからでないと分からない、では選べない。

ロールは **150〜500 点**（[24-role.md](24-role.md) 3-1-A）。
**10 試合貯めて買ったものが、自分に合わなかった**——これでは誰も冒険しない。

装備も同じで、**値段の高いものほど試す機会が無い。**

**ロビーでは、全部ただで試せる。**

---

## 1. 誰が試せるか

**チームに入っていない人。それだけ。**

| | |
| --- | --- |
| 条件 | **チームに入っていない** |
| **試合中** | **試せる**（2026-08-27 変更） |

はじめは「試合をしていないこと」も条件にしていたが、
**試合の間もロビーに人は居る**——参加しなかった人、後から来た人。

> **その人たちの居場所を、試合の間だけ取り上げる理由が無い。**

戦場には出られない（`features/border`）ので、
ロビーで手に入れたものが**試合に入り込む道は無い。**
参加すれば、その瞬間に持ち物ごと空になる。

**この 1 つの判定で、抜け道を全部塞ぐ。**

> 画面を開いたまま試合が始まったら、という抜け道がある。
> **開いている画面を script から閉じる手段は無い。**
>
> だから**押した瞬間に見る。**
> 所属が付いた瞬間、その画面のボタンは**全部ただの飾り**になる。

---

## 2. 何が置いてあるか

**待機所に球を 2 つ浮かべる。**

| 球 | 色 | 触ると |
| --- | --- | --- |
| ロール | 水色 | **ロールの盤面**（[24-role.md](24-role.md) 2-1） |
| ショップ | **金** | **ショップ**（[12-shop.md](12-shop.md)） |

| | |
| --- | --- |
| 場所 | **待機所（`lobbyPoint`）の左右 1.5 マス**、1 マス上 |
| 待機所を動かしたら | **付いてくる**（5 秒ごとに見張っている） |
| **試合中** | **消す** |

**待機所は `/game:setlobby` で動かせる**ので、座標を決め打たない。

---

## 3. 買い物は 0

**ロビーでは、何を押しても 0 で手に入る。**

| | |
| --- | --- |
| 値段の表示 | **`§a0`**（本来の値段は出さない——試す場では意味が無い） |
| 払うもの | **無し**（財布も金庫も減らない） |
| 買える数 | **持ち物が埋まるまで** |

**ロールも同じ。** 盤面から選べば、**点を払わずにその場で変わる。**
**買った印は付けない**——ロビーで試したものが、そのまま手に入っては困る。

> ロビーでのロール変更は**倒れない**（[24-role.md](24-role.md) 2-2）。
> 試合中の代償であって、試す場に持ち込む理由が無い。

---

## 3-A. ブロックは、ロビーの上のほうだけ（2026-08-27 決定）

**ショップで売っているブロックだけ、ロビーで置ける。**

| | |
| --- | --- |
| 置ける高さ | **y 120 以上** |
| 置けるもの | **[置ける一覧](11-match.md) に載っているものだけ**（`lib/placeable.ts`） |
| 戦場 | **置けない**（試合をしていなくても） |

> **地表には置かせない。**
> 看板も球も掲示板も地表にあるので、**囲われると誰も触れなくなる。**

**消せるものに限る。** 後片付けが消せるのは一覧に載っているものだけなので、
それ以外を置かれると**誰にも消せないまま残る。**

#### 片付けは 2 通り（2026-08-28 追加）

| いつ | どうやって |
| --- | --- |
| **試合を始めるとき** | **置いた場所を覚えている分**を消す（速い・確実） |
| **後片付けのとき**（決着・強制終了・`/game:clean`） | **y 120 以上を丸ごと掃き取る**（戦場と同じやり方） |

記録は `/reload` で消えるので、**それだけでは残る。**
**人が行ける範囲は、種類でも掃き取る**——戦場と同じ扱いにする。

**y 120 より下は触らない。** そこはロビーの建物で、**元から置けない。**

### 支柱弾も撃てる

| | |
| --- | --- |
| 柱の色 | **白**（`game:pillar_white`）——無所属なので陣営の色が無い |
| 立つ場所 | **手で置ける場所と同じ規則**（ロビーの y 120 以上） |
| **人が行ける範囲の外** | **炸裂しない**（見えない所で爆ぜても意味が無い） |

### TNT は高さを問わない

置いた瞬間に**実体へ変わる**ので、ブロックとしては残らない。
地表を囲われる心配が無いものに、高さの縛りを掛ける理由が無い。

**当たっても死なない**（[14-death.md](14-death.md) 6-A）。

### ドローンも出せる

**制限はしない。** ロビーではマナも減らない。
実体は**試合が始まるときに消える**（4 章）。

## 4. 試合には何も持ち込めない

**試合が始まる瞬間に、全部消す。**

| 消すもの | どこで |
| --- | --- |
| 持ち物・エンダーチェスト・金庫 | 参加処理（`joinMatch` → `resetInventory`） |
| **参加しない人の持ち物** | **開始時にまとめて**（ロビーで配り直される） |
| **ロールに付いた実体**（ドローンなど） | **開始時に全員ぶん**（参加する人も含む） |
| **ロビーに置かれたブロック** | 同じく開始時（**置いた場所を覚えている**） |
| 練習用の球 | 同じく開始時 |
| **ロビーで試したロール** | **持っているならそのまま**（下） |

### 選んでいたロールは持ち込める（2026-08-27 決定）

| | |
| --- | --- |
| **買ってある** | **そのまま参加する** |
| 買っていない | **Swift に戻す**（誰でも持っている） |

**倒れない。** 参加処理の途中で決めるので、
ここで倒すと**入った瞬間に死ぬ**ことになる。

**支給品を配る前に決める**——ロールに付いてくる物が変わるため。

> 試したまま参加できてしまうと、**点を貯める意味が消える。**

## 5. 実装の置き場

```
lib/practice.ts             試せるかどうかの判定（ここだけ）
features/role/keeper.ts     待機所の球（ロール・ショップ）
features/shop/index.ts      0 で渡す
features/match/index.ts     開始時の後始末
```

**判定は 1 か所に置く。** 呼ぶ側それぞれに書くと、**必ずどれか漏れる。**
