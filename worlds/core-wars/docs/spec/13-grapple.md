# 仕様: 3D Maneuver Gear

**引っ掛けて、自分を引き寄せる道具。** 立体機動そのもの。

**武器も兼ねる**（攻撃力 +4）。支給の剣は廃止し、これ 1 本で二役をこなす。

**壁でも床でも天井でもよい。** 見ている先にブロックがあれば掛かる。
面の向きは見ない。真下に撃てば地面へ、真上に撃てば天井へ引き寄せられる。

見た目は釣り竿。参加した時点で全員が持っている（支給品）。

---

## 1. 何が面白いのか

**移動の途中でワイヤーを切ると、その勢いのまま前へ飛べる。**

引き寄せは終点で止まる。だが**途中で切れば速度は残る。**
どこで切るかで到達点が変わる。**そこが腕の見せどころになる。**

> 「引き寄せる道具」ではなく「**加速する道具**」として設計する。
> 単に近づくだけなら、歩いたほうが安全で確実になってしまう。

## 2. ガス

**上限 100。** 使うと減り、時間とキルで回復する。

| | 量 |
| --- | --- |
| 引っ掛ける | **5**（固定。撃つには **10 以上**必要） |
| 引っ掛けに失敗 | **10**（固定） |
| **引き寄せを始める** | **5**（2026-08-24 追加） |
| 引き寄せ中 | **1 tick あたり 1**（1 秒あたり 20） |
| 時間で回復 | 1 秒あたり 3.3（**空から満タンまで 30 秒**）。**ワイヤーで浮いている間は回復しない** |
| キルで回復 | **40** |

**足りなければ引っ掛からない。** 撃つ前に必要量を確かめる。

### 2-A. 撃つには 10 要る（2026-08-25 変更）

| | |
| --- | --- |
| 撃つのに必要 | **10 以上** |
| 実際に減る | **5**（当たっても外しても同じ） |

#### なぜ必要量と消費量を分けるのか

**刺してから引き寄せるまでが 1 つの動作。**

撃てるだけ撃てると、**刺さった直後にガス切れで落ちる。**
引く分が残っていない状態で刺せてはいけない。

必要 10・消費 5 なら、**刺した直後には必ず 5 以上残っている。**

#### 距離では変えない

以前は**距離ぶん**取っていた（遠いほど高い）。
分かりにくいうえ、**遠くへ撃つほど引く分が残らない。**

### ワイヤーで浮いている間は回復しない

**一度地面に降りる、という区切りを作る**（2026-08-24）。

空中でも回復すると、**飛びながら次のぶんが溜まり、降りずに繋ぎ続けられる。**
ガスが上限を持っている意味が無くなる。

#### 区切るのは「ワイヤーで浮いたかどうか」（2026-08-25 修正）

以前は**足が着いているかだけ**を見ていた。これは行き過ぎだった。

> **走ってジャンプしただけで止まる。**
> 普通に移動しているときの跳躍まで数えていたので、
> **地上を走っている間もガスがほとんど溜まらない。**

見るのは**ワイヤーで浮いたかどうか。**

| 状態 | 回復 |
| --- | --- |
| 刺している間（引き寄せ中も含む） | **しない** |
| ワイヤーを離れたあと、**まだ着地していない** | **しない** |
| 着地した後 | **する** |
| 普通に走ってジャンプしている | **する**（空中でも） |

**ワイヤーから離れた瞬間に印を付け、着地したら消す。**
飛びながら溜める抜け道は塞いだまま、地上の動きは邪魔しない。

> **外すのは安く、遠くへ当てるのは高い**（2026-08-24 変更）。
>
> 当初は失敗を一番高くしていたが、射程を 25 に伸ばしたことで
> **外した瞬間に 4 分の 1 が消える**ことになり、撃つのをためらわせた。
>
> いまは「狙って遠くへ撃つ」ことに値段が付いている。

---

### 実際に届いているかは測れる（2026-08-26 追加）

**`/game:reach`（運営のみ）。**

見ている先のブロックまでの距離を、**射程（25）とその倍（50）の 2 通り**で出す。

```
上限 25 → game:map_parts_stone まで 18.4 マス
上限 50 → game:map_parts_stone まで 18.4 マス
```

**`maxDistance` に書いた数がそのまま届くとは限らない。**
ゲーム側の上限や、**読み込まれていない区画**で手前で止まることがある。

2 つの数が食い違えば、**25 で切られている**と分かる。
同じなら、そこに本当にブロックがある。

> コマンドの登録はワールドロード時にしか走らないので、**`/reload all` が要る。**

## 3. 操作

| 操作 | 状態 | 何が起きるか |
| --- | --- | --- |
| **右クリック** | 未装着 | 25 マス以内のブロックに引っ掛ける |
| **右クリック** | 装着中 | **引き寄せ開始** |
| **切る操作** | 装着中 / 移動中 | ワイヤーを切る |

### 切る操作

**持ち物を切り替えるだけ**（2026-08-24 決定）。

#### 左クリックは使えない

**「何もない空中を殴った」ことを知る手段が Script API に無い。**

殴りの通知は「ブロックに当たった」「実体に当たった」しか無く、
どちらも**届く範囲（約 5 マス）に何かある場合だけ**。

飛んでいる最中の壁はたいてい 5 マスより先にあるので、
**この機能の肝である「移動中に切る」が左クリックでは成立しない。**

#### 操作を 1 つに絞る

スニークを当てる案もあったが、採らなかった。

**切る手段が複数あると、意図せず切れる。**
飛びながらしゃがんだだけで落ちるのは、事故にしか見えない。

持ち替えなら**明確に意思がある操作**で、
しかも「切ってすぐ剣を持つ」という自然な流れに乗る。

---

### 3-A. 掛けた足場が消えたら外れる（2026-08-25 追加）

**壊された・消えた時点で切れる。**

支柱は 5 秒で崩れる（[18-pillar.md](18-pillar.md) 4章）ので、
**掛けたまま消えることが普通に起きる。**

引っ掛けた「点」しか覚えていなかったので、
足場が無くなっても点はその場に残り、**宙に向かって引かれ続けていた。**

**掛けた瞬間にブロックの座標を覚える。**
当たった点から**進んだ向きへ少し押し込んだ**マスを取る——
面の上の点をそのまま切り捨てると、**手前の空気を指すことがある。**

> **読めないときは切らない。**
> 読み込まれていないだけのことがある。

## 4. 引き寄せの動き

### 4-1. 重力を無視する

引き寄せている間は**落ちない。** 引っ掛けた点に向かってまっすぐ進む。

### 4-2. だんだん速くなる

| | 速さ |
| --- | --- |
| 動き出し | **ダッシュの 2 倍くらい** |
| 最高速 | **ダッシュの 5 倍くらい** |

**約 1 秒で最高速になる。**

> 最初から最高速だと、短い距離では速さを感じない。
> **加速があると「乗った」感覚が出る。**

### 4-3. 慣性と操作を効かせる

**まっすぐ引き寄せるだけにしない。**

- 引き寄せ始めたときの**速度が残る**（走り込んでから撃つと伸びる）
- 移動中の**操作方向で大きく曲がる**

真っ直ぐしか飛べないと、**撃つ場所を決めた時点で結果が決まる。**

**曲げる力は強い**（2026-08-24 決定）。
引っ掛けた先は「そこへ向かう力が出る場所」であって、
**飛ぶ方向は飛びながら決める。** そのほうが立体機動に近い。

**ただし空中だけ。** 足が着いているうちは効かせない。
同じだけ効かせると**地上を異常な速さで走れてしまう。**
立体機動は空中でこそ意味があり、地上の走りを速くする道具ではない。

### 4-4. 終わり方

| きっかけ | 何が起きるか |
| --- | --- |
| **3 マス以内に近づいた** | **すぐ切れる。** 勢いは残る |
| **切った** | **その時の速度のまま飛ぶ** |
| **引っ掛けた点より奥へ行った** | **切れる。** 勢いは残る |
| **25 マスより離れた** | ワイヤーが切れる |
| ガスが尽きた | ワイヤーが切れる |

**着くまで引かない**（2026-08-24 変更）。

引っ掛けた点の目の前まで引かれると、**勢いが壁に吸われて止まる。**
飛び続けたいのに減速する。

手前で切れば、そのままの勢いで通り過ぎられる。
**止まりたいなら壁にぶつかればいい**ので、切る側で止める必要が無い。

### 4-5. 通り過ぎたら切れる

**引っ掛けた点から、引き寄せ開始位置のほうへ開いた円錐の外**へ出たら切る。

```
      引き寄せ開始位置 ──────→ 引っ掛けた点
                                    ╱│╲
                                   ╱20度20度╲   この中なら切れない
```

| 広さ | 形 |
| --- | --- |
| 180 度 | 引っ掛けた点を通る**平面**。真横まで許す |
| 120 度 | 左右 60 度まで |
| 60 度 | 左右 30 度まで |
| 20 度 | 左右 10 度まで。**狭すぎた** |
| **40 度** | 左右 20 度まで |

**40 度にした**（2026-08-24 変更）。
横向きに引かれると、**進行方向と関係ない向きに曲げられる。**

円錐の外へ出たら、もう引き寄せではなく**引き戻し**になる。

放っておくと、行き過ぎた先から引き戻され、
**点の周りを行ったり来たりする。** 見た目も操作感も悪い。

**勢いは残る。** 通り過ぎたぶんだけ遠くへ飛べる。

## 5. 実装で気をつけること

### 5-1. `/reload` で壊さない

**ガスはプレイヤーの動的プロパティに持つ。**
読み込み直しでも消えない（[11-match.md](11-match.md) R-1）。

**引っ掛けている状態はメモリだけ**に持つ。
`/reload` で全部切れる。**それでよい**（宙に浮いたまま固まるより安全）。

### 5-2. 移動は「毎 tick、目標の速度を与える」

**目標の向きと速さだけから決めて、毎 tick そのまま与える。**

5 通り試して、これに落ち着いた（2026-08-24）。

| やり方 | 何が起きたか |
| --- | --- |
| テレポートで動かす | **壁を貫通する。** 見た目が飛び飛び |
| いまの速度に足す | 読み取った速度に重力や衝突が乗っていて、**値が揺れる** |
| 落下抑制の効果を掛ける | **論外。** 浮遊は動きが別物になる |
| 数 tick に 1 回だけ与える | **間の tick で落ちる。** 落ちて引き上げの繰り返し |
| **毎 tick、目標の速度を与える** | 縦が常に目標のまま。**これが「重力を無視する」** |

#### いまの速度を混ぜない

`getVelocity()` の値には**重力も衝突も乗っている。**
それを足し込むと、**値が毎 tick 揺れ、そのまま視点の揺れになる。**

目標だけから決めれば、向きも速さもなめらかに変わる。

#### 間引かない

「書き換える回数を減らせば滑らかになる」は**間違いだった。**
間の tick では重力が効くので、**落ちて引き上げ、を繰り返す。**

#### 与えた値はそのままの速度にならない

ノックバックに渡した値は目減りする。**倍率で補う。**
速さが足りない／出すぎるときは、まずそこを動かす。

> **動き出しの一蹴りだけは別に与える。**
> 目標の速さは 0 から上げるので、そのままでは踏み出しがもたつく。

### 5-3. 壁に押し付けられたら終わりにする

終点に着かなくても、**途中の壁に阻まれたらそこで切る。**

押し付けたまま速度を与え続けると、めり込んだように見えるうえ、
**ガスだけが減り続ける。**

### 5-4. 試合中だけ

**非開始・一時停止中は動かない。** 拠点の外へ出られてしまう。

## 9. 武器はすべてワイヤー射出装置（2026-08-26 追加）

> ### 武器を持ったままでも飛べる。

**ショップで売る剣は、全部これと同じ道具。**

| 品物 | 攻撃力 | ワイヤー |
| --- | --- | --- |
| 3D Maneuver Gear（支給） | **+4** | 撃てる |
| 木の剣 | +4 | **撃てる** |
| 石の剣 | +5 | **撃てる** |
| 鉄の剣 | +6 | **撃てる** |
| ダイヤの剣 | +7 | **撃てる** |

**ネザライトは廃止した。** 上を作りすぎると、
**買い切った人が一方的に強い時間**が長くなる。

### なぜ全部にするのか

剣を買うと**ワイヤーが撃てなくなる**なら、
「武器を持つ」ことが**「移動を捨てる」という意味**になる。

**立体機動のゲームなのに、戦うほど動けなくなる。**

段階で変わるのは**火力だけ。** 飛び方は変わらない。

### ガスは共通

**持ち替えても増えない。**
ガスは道具ではなく**人に紐づけて**持っている（`features/grapple/gas.ts`）。

> 剣を 2 本持てば 2 倍飛べる、では**買うほど動ける**ことになる。

### 見た目

**モデルは 1 つ。** 段階で変わるのは**刃の色だけ。**

| | |
| --- | --- |
| モデル | `geometry.grapple_sword`（`models/entity/grapple_sword.geo.json`） |
| 付け方 | **attachable**（バニラの弓と同じ書き方。`rightitem` に置く） |
| テクスチャ | `textures/entity/grapple_sword_<段階>.png` |
| 持ち物の絵 | `textures/items/game_sword_<段階>.png` |

**同じ道具の段階違い**だと一目で分かるようにする。
別々の形にすると「別の武器」に見えてしまい、
**全部ワイヤーが撃てる**ことが伝わらない。

#### 形（2026-08-26 修正）

**持ち物の絵と、手に持った姿を同じものにする。**

| 部位 | 色 |
| --- | --- |
| 尻 | 鋼（暗） |
| 握り | 黒。**筋を入れる** |
| 射出機の胴 | 鋼 |
| 口金 | 鋼（明） |
| **刃**（3 段に細くなる） | **段階の色。上の縁が光る** |

> **`/reload all` が要る**（アイテム定義とモデル）。
> テクスチャは**ゲームの再起動**が要ることもある
>（`docs/research/02-hot-reload.md`）。

## 7. コアを削れない時間

**引き寄せで移動したあと、着地してから 3 秒は、コアを壊せない。**

引き寄せは速い。**飛び込んだ勢いのまま削れると、守る余地が無い。**

### 数え始めるのは「着地から」（2026-08-26 変更）

| | いつから 3 秒 |
| --- | --- |
| 以前 | **ワイヤーを切った瞬間から** |
| **いま** | **足が地面に着いてから** |

以前の数え方だと、**飛んでいる時間がそのまま待ち時間に化けていた。**

> 高い所から長く飛べば、着いた瞬間にはもう 3 秒経っている。
> **一番速い入り方が、一番待たない入り方**になっていた。

**空中にいる間は、数え始めてすらいない。**
ワイヤーで入った以上、**必ず着地して 3 秒待つ。**

## 8. 下向きの扱い

**下へ刺したときも、引きは同じ。ワイヤーの向きへ強く引く。**

| | 縦 |
| --- | --- |
| **踏み切り（1 回だけ）** | **少し上**（下に刺したときだけ） |
| そのあとの引き | **ワイヤーの向きへそのまま。弱めない** |

### 踏み切りだけ、少し上へ

**下へ刺したとき、引き始めの一蹴りにだけ上向きを足す。**

刺した点の向きをそのまま蹴ると、**その瞬間だけ下へ叩き落とされる。**

> **ジャンプ中に使うと、一瞬下に落ちる**（2026-08-25 の指摘）。
> 上へ跳んでいる速度が、その 1 tick で下向きに置き換わっていた。

一蹴りで持ち上げれば、あとは引きに任せられる。

> 上へ刺したときには足さない。**もともと上へ強く引いている。**

### そのあとは弱めない（2026-08-25 変更）

**下向きだけ引きを弱める・縦を触らない、はどちらもやめた。**

| 試したこと | どうなったか |
| --- | --- |
| 引きを 1/4 に弱める | **計算しただけで、どこにも渡っていなかった** |
| 縦を 0 にする | 落ちない＝**上へ引かれているように感じる** |
| いまの落下速度を返す | **真下に刺すと、なぜか少しずつ上がっていく** |

**素直にワイヤーの向きへ引く。** 上へ引くときと同じ式にする。

> **同じものを別扱いにするから、どれも中途半端になった。**
> 下へ強く引かれて困るなら、それは**引きの強さの問題**であって、
> 向きで分ける理由にはならない。

### 下向きは 30 度起こす（2026-08-25 追加）

**下へ引くとき、向きを上へ 30 度倒してから引く。**

真下へ引くと**落ちるだけ**になり、回り込む余地が無い。
起こしてやると、**前へ抜けながら降りる。**

| 刺した向き | 実際に引く向き |
| --- | --- |
| 真下（−90 度） | −60 度 |
| 斜め下（−30 度） | **水平** |
| ほぼ水平（−5 度） | **水平**（上には向けない） |

**水平（0 度）が上限。** −30 度より浅いところは、全部水平になる。

**水平より上には向けない。**
起こしすぎて上向きになると、**下に刺したのに上がる**という
さっきまでの不具合と同じことが起きる。

真下ちょうどのときは横向きが決まらないので、**見ている向き**へ倒す。

#### 残っている懸念

`applyKnockback` の縦は**上向きの想定**で、
**負の値を渡しても素直には下がらない**（2026-08-24 に確認）。

強く引いても**思ったほど落ちない**ようなら、ここが天井。
そのときは別の手（速度の与え方そのもの）を考えることになる。

## 8-A. ワイヤーの見せ方（2026-08-25 追加）

**専用の粒を作る**（`resource_packs/game/particles/wire.json`、`game:wire`）。

| | |
| --- | --- |
| 寿命 | **0.1 秒**（2 tick） |
| 大きさ | 小さく |
| 色 | **チームの色**（下記） |

### 色はチームで分ける（2026-08-25 追加）

| | 色 |
| --- | --- |
| 青チーム | **水色** |
| 赤チーム | **赤** |
| 所属なし（ロビーで練習中など） | **水色**（既定） |

**薄さは 2 色で揃える。** 明るさも透明度も同じにして、**色だけ入れ替える。**
片方だけ濃いと、**同じ道具に見えなくなる。**

### なぜバニラの粒を使わないのか

**どれも寿命が長い。**

通った跡が残り続けるので、**ワイヤーではなく煙の帯**に見える。
バニラの粒の寿命は**こちらから変えられない。**

**毎 tick 描き直している**ので、**残らなくても線として見える。**
むしろ残らないほうが、**張っている 1 本**に見える。

> 当初はバニラの気体の粒を使っていたが、
> **それは実体が出すもの**で、コンテンツログにエラーが並んでいた
>（[research/11](../../../../docs/research/11-content-log.md) 7 章）。
> 作り直したのはその置き換えでもある。

## 8-B. 引かれている間の粒（2026-08-25 追加）

**速く動いているときだけ、後ろに粒を置き去りにする。**

```
        ・ ・  ・   ・
   ＜＝＝＝＝ プレイヤー →→→
        ・  ・ ・  ・
```

| | |
| --- | --- |
| いつ出るか | **一定より速いときだけ** |
| どこに出るか | **通った跡**（前の位置と今の位置の間） |
| 色 | ワイヤーと同じ**チームの色** |
| 寿命 | 短い。**すぐ消える** |

### 速いときだけ出す

**常に出すと、ただの飾りになる。**

疾走感は「**いつもは出ないものが出ている**」ことで生まれる。
歩いているときにも出ていたら、速さの合図として読めない。

### 通った跡に置く

**1 tick に 1 つでは点にしかならない。**

速く動くほど 1 tick の移動距離が伸びるので、
**前の位置と今の位置の間を埋める。**
埋めるほど**線が伸びて見え、速いほど長くなる。**

> ファイヤーチャージの弾で通った道と同じ
>（[03-content.md](../03-content.md) 1-4）。
> **点の列に見えるか、流れて見えるかは、間を埋めるかどうかで決まる。**

### 少し散らす

**真っ直ぐ 1 本だと、ワイヤーと見分けが付かない。**
進む向きと直角に少しずらして、**通り過ぎた空気**のように見せる。

### 広がりながら薄れて消える（2026-08-25 追加）

| | |
| --- | --- |
| **広がる** | 出た点から外へ流れ、**抵抗で減速する** |
| **薄れる** | 濃さだけが 0 へ落ちていく。色と大きさは変えない |

**ぱっと消えると点滅して見える。**
薄れて消えれば、**通り過ぎた空気が散っていく**ように読める。

## 9. 横ずれの条件

**横を向いているときだけずらす**（4-3 のずらし）。

| 視線と引きの角度 | どうなるか |
| --- | --- |
| **10 度以内**（左右 20 度の内側） | **まっすぐ飛ぶ** |
| 10 度より外 | 見ている側へずらす |

真っ直ぐ狙っているのにずれると、**狙いが当たらない道具**になる。
避けたいときだけ横を向く、という操作にする。
