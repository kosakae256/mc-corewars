# 仕様: グラップリングフック

**引っ掛けて、自分を引き寄せる道具。** 立体機動のような動きをする。

**壁でも床でも天井でもよい。** 見ている先にブロックがあれば掛かる。
面の向きは見ない。真下に撃てば地面へ、真上に撃てば天井へ引き寄せられる。

見た目は釣り竿。参加した時点で全員が持っている（支給品）。

---

## 1. 何が面白いのか

**移動の途中でワイヤーを切ると、その勢いのまま前へ飛べる。**

引き寄せは終点で止まる。だが**途中で切れば速度は残る。**
どこで切るかで到達点が変わる。**そこが腕の見せどころになる。**

> 「引き寄せる道具」ではなく「**加速する道具**」として設計する。
> 単に近づくだけなら、歩いたほうが安全で確実になってしまう。

---

## 2. ガス

**上限 100。** 使うと減り、時間とキルで回復する。

| | 量 |
| --- | --- |
| 引っ掛ける | **距離ぶん**（距離 10 なら 10、最大 25） |
| 引っ掛けに失敗 | **10**（固定） |
| 引き寄せ中 | **少しずつ**（1 秒あたり 10） |
| 時間で回復 | 1 秒あたり 3.3（**空から満タンまで 30 秒**）。**足が着いている間だけ** |
| キルで回復 | **40** |

**足りなければ引っ掛けられない。** 撃つ前に必要量が分かる。

### 空中では回復しない

**一度地面に降りる、という区切りを作る**（2026-08-24）。

空中でも回復すると、**飛びながら次のぶんが溜まり、降りずに繋ぎ続けられる。**
ガスが上限を持っている意味が無くなる。

> **外すのは安く、遠くへ当てるのは高い**（2026-08-24 変更）。
>
> 当初は失敗を一番高くしていたが、射程を 25 に伸ばしたことで
> **外した瞬間に 4 分の 1 が消える**ことになり、撃つのをためらわせた。
>
> いまは「狙って遠くへ撃つ」ことに値段が付いている。

## 3. 操作

| 操作 | 状態 | 何が起きるか |
| --- | --- | --- |
| **右クリック** | 未装着 | 25 マス以内のブロックに引っ掛ける |
| **右クリック** | 装着中 | **引き寄せ開始** |
| **切る操作** | 装着中 / 移動中 | ワイヤーを切る |

### 切る操作

**持ち物を切り替えるだけ**（2026-08-24 決定）。

#### 左クリックは使えない

**「何もない空中を殴った」ことを知る手段が Script API に無い。**

殴りの通知は「ブロックに当たった」「実体に当たった」しか無く、
どちらも**届く範囲（約 5 マス）に何かある場合だけ**。

飛んでいる最中の壁はたいてい 5 マスより先にあるので、
**この機能の肝である「移動中に切る」が左クリックでは成立しない。**

#### 操作を 1 つに絞る

スニークを当てる案もあったが、採らなかった。

**切る手段が複数あると、意図せず切れる。**
飛びながらしゃがんだだけで落ちるのは、事故にしか見えない。

持ち替えなら**明確に意思がある操作**で、
しかも「切ってすぐ剣を持つ」という自然な流れに乗る。

## 4. 引き寄せの動き

### 4-1. 重力を無視する

引き寄せている間は**落ちない。** 引っ掛けた点に向かってまっすぐ進む。

### 4-2. だんだん速くなる

| | 速さ |
| --- | --- |
| 動き出し | **ダッシュの 2 倍くらい** |
| 最高速 | **ダッシュの 5 倍くらい** |

**約 1 秒で最高速になる。**

> 最初から最高速だと、短い距離では速さを感じない。
> **加速があると「乗った」感覚が出る。**

### 4-3. 慣性と操作を効かせる

**まっすぐ引き寄せるだけにしない。**

- 引き寄せ始めたときの**速度が残る**（走り込んでから撃つと伸びる）
- 移動中の**操作方向で大きく曲がる**

真っ直ぐしか飛べないと、**撃つ場所を決めた時点で結果が決まる。**

**曲げる力は強い**（2026-08-24 決定）。
引っ掛けた先は「そこへ向かう力が出る場所」であって、
**飛ぶ方向は飛びながら決める。** そのほうが立体機動に近い。

**ただし空中だけ。** 足が着いているうちは効かせない。
同じだけ効かせると**地上を異常な速さで走れてしまう。**
立体機動は空中でこそ意味があり、地上の走りを速くする道具ではない。

### 4-4. 終わり方

| きっかけ | 何が起きるか |
| --- | --- |
| **3 マス以内に近づいた** | **すぐ切れる。** 勢いは残る |
| **切った** | **その時の速度のまま飛ぶ** |
| **引っ掛けた点より奥へ行った** | **切れる。** 勢いは残る |
| **25 マスより離れた** | ワイヤーが切れる |
| ガスが尽きた | ワイヤーが切れる |

**着くまで引かない**（2026-08-24 変更）。

引っ掛けた点の目の前まで引かれると、**勢いが壁に吸われて止まる。**
飛び続けたいのに減速する。

手前で切れば、そのままの勢いで通り過ぎられる。
**止まりたいなら壁にぶつかればいい**ので、切る側で止める必要が無い。

### 4-5. 通り過ぎたら切れる

**引っ掛けた点から、引き寄せ開始位置のほうへ開いた円錐の外**へ出たら切る。

```
      引き寄せ開始位置 ──────→ 引っ掛けた点
                                    ╱│╲
                                   ╱20度20度╲   この中なら切れない
```

| 広さ | 形 |
| --- | --- |
| 180 度 | 引っ掛けた点を通る**平面**。真横まで許す |
| 120 度 | 左右 60 度まで |
| 60 度 | 左右 30 度まで |
| 20 度 | 左右 10 度まで。**狭すぎた** |
| **40 度** | 左右 20 度まで |

**40 度にした**（2026-08-24 変更）。
横向きに引かれると、**進行方向と関係ない向きに曲げられる。**

円錐の外へ出たら、もう引き寄せではなく**引き戻し**になる。

放っておくと、行き過ぎた先から引き戻され、
**点の周りを行ったり来たりする。** 見た目も操作感も悪い。

**勢いは残る。** 通り過ぎたぶんだけ遠くへ飛べる。

## 5. 実装で気をつけること

### 5-1. `/reload` で壊さない

**ガスはプレイヤーの動的プロパティに持つ。**
読み込み直しでも消えない（[11-match.md](11-match.md) R-1）。

**引っ掛けている状態はメモリだけ**に持つ。
`/reload` で全部切れる。**それでよい**（宙に浮いたまま固まるより安全）。

### 5-2. 移動は「毎 tick、目標の速度を与える」

**目標の向きと速さだけから決めて、毎 tick そのまま与える。**

5 通り試して、これに落ち着いた（2026-08-24）。

| やり方 | 何が起きたか |
| --- | --- |
| テレポートで動かす | **壁を貫通する。** 見た目が飛び飛び |
| いまの速度に足す | 読み取った速度に重力や衝突が乗っていて、**値が揺れる** |
| 落下抑制の効果を掛ける | **論外。** 浮遊は動きが別物になる |
| 数 tick に 1 回だけ与える | **間の tick で落ちる。** 落ちて引き上げの繰り返し |
| **毎 tick、目標の速度を与える** | 縦が常に目標のまま。**これが「重力を無視する」** |

#### いまの速度を混ぜない

`getVelocity()` の値には**重力も衝突も乗っている。**
それを足し込むと、**値が毎 tick 揺れ、そのまま視点の揺れになる。**

目標だけから決めれば、向きも速さもなめらかに変わる。

#### 間引かない

「書き換える回数を減らせば滑らかになる」は**間違いだった。**
間の tick では重力が効くので、**落ちて引き上げ、を繰り返す。**

#### 与えた値はそのままの速度にならない

ノックバックに渡した値は目減りする。**倍率で補う。**
速さが足りない／出すぎるときは、まずそこを動かす。

> **動き出しの一蹴りだけは別に与える。**
> 目標の速さは 0 から上げるので、そのままでは踏み出しがもたつく。

### 5-3. 壁に押し付けられたら終わりにする

終点に着かなくても、**途中の壁に阻まれたらそこで切る。**

押し付けたまま速度を与え続けると、めり込んだように見えるうえ、
**ガスだけが減り続ける。**

### 5-4. 試合中だけ

**非開始・一時停止中は動かない。** 拠点の外へ出られてしまう。
