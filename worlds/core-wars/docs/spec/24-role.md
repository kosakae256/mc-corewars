# 仕様: ロール（ロール）

> **2026-08-26 決定。** いまの遊び方は、そのまま **Swift** という 1 つのロールになる。

## 1. 何を足すのか

**プレイヤーはロールを選ぶ。** ロールごとにワイヤーの性能と、できることが変わる。

| | |
| --- | --- |
| 既定 | **Swift**（いまの挙動そのまま） |
| 変える場所 | **変更用の球**（右クリックで盤面が開く） |
| 変えられる時 | **試合中でも、いつでも** |
| 手に入れ方 | **試合で貯めた点で買う**（アンロック） |

### なぜロールを足すのか

**いまは全員が同じ道具で、同じ動きをする。**

ワイヤーは面白いが、**上手い下手だけが差になる。**
役割を選べれば、**何が得意な人なのか**がチームの中で決まる。

> **Swift を一番強くする**（4 章）。
> 尖ったロールは「特定の場面で強い」に留め、**汎用性で勝てないようにする。**

## 2. ロールを変える

### 2-1. 浮いている球に触る

**チーム別ではない。** どちらの拠点にも置く。

| | |
| --- | --- |
| 見た目 | **その場に浮く球**（`game:rolekeeper`）。ゆっくり回り、上下に揺れる |
| 色 | **拠点の色**——青の拠点なら青、赤の拠点なら赤。どちらでもない場所なら水色 |
| 触ると | **盤面が開く**（チェスト UI。ショップと同じ作り） |
| 並ぶもの | **ロールの一覧。** 持っていないものは値段が出る |
| 壊せるか | **壊せない**（あらゆるダメージを受け付けない） |

**村人はやめた**（2026-08-27 変更）。
人の形をしていると**話しかけられる相手**に見えるが、
これは**装置**であって、店員のように売り買いをするものではない。

#### ロビーにも置く

**待機所にも 1 個浮かべる**（[25-practice.md](25-practice.md)）。
**無所属の間は、点を払わずに試せる**——買った印は付かない。

#### 置き場所

**地図に載っているものとして扱う**（店員と同じ。2026-08-27 変更）。

| | |
| --- | --- |
| **必ずある 2 個** | 赤 **1110.5 / -8.3 / 1000.5** ／ 青 **890.5 / -8.3 / 1000.5**（向かい合わせ） |
| 足す | `/game:rolekeeper`（いま立っている場所） |
| 足した分を消す | `/game:rolekeeper_clear`（**地図の 2 個は残る**） |

はじめは「まだ一度も置いていなければ入れる」としていたが、
**一度でもコマンドを使った後は入らない。**
試した跡が残っているだけで**マップの備品が出てこない**のでは、
置き場所を決めた意味が無い。

### 2-2. 変えると、一度倒れる（試合中だけ）

**ロールを変えた瞬間、死亡処理を通す。**

| | |
| --- | --- |
| 持ち物 | **落とさない**（ここだけ普通の死と違う） |
| 場所 | **自陣へ戻る** |
| 待ち時間 | **普通の復活と同じ** |

**倒れるのは試合中だけ。**
ロビーでは何度でも試せる（[25-practice.md](25-practice.md)）。

> **戦っている最中に、その場で乗り換えられては困る。**
> 不利になったら別のロールへ、が無料でできると**選ぶ意味が消える。**
>
> 死ぬのと同じ代償を払わせる。**ただし持ち物は守る**——
> 買った装備まで失うと、変えること自体ができなくなる。

### 2-3. ロール限定のものは、変えた時点で消える

**ロールごとに「そのロールだけのもの」がある。**

いまは Engineer のドローン（実体と操作アイテム）がそれにあたる。
**今後も増える。**

| いつ消すか | |
| --- | --- |
| ロールを変えたとき | **前のロールのものを全部** |
| その人が居なくなったとき | 同じ |

> **ロールごとに書かない。**
> ロールの定義に「片付け」を持たせ、**変えるときに必ず呼ぶ。**
> 増えるたびに変更処理を直していたら、**必ずどれか忘れる。**

## 3. アンロック

### 3-1. 点で買う

| | |
| --- | --- |
| 最初から持っている | **Swift だけ** |
| 貯まり方 | **試合の結果から** |
| 使い方 | **ロールの盤面で買う**（一度買えば消えない） |

### 3-2. 点の入り方

| 出来事 | 点 |
| --- | --- |
| **キル** | **+5** |
| **コア破壊** | **+2** |

**試合が終わった時点で配る。** 途中で抜けた人には入らない。

> 数え直さない。**戦績（`lib/stats.ts`）がすでに数えている**ので、そこから作る。

### 3-1-A. 値段（2026-08-27 決定）

| 点 | ロール |
| --- | --- |
| **0** | Swift（最初から持っている） |
| **150** | **Sky walker / Duelist / Engineer / Loophole** |
| **500** | **Zipline / 超加速装置 / パワー系** |

**2 段だけにする。** ロールごとに細かく刻んでも、
**どれがどれより高いのかを覚えていられない。**

> 150 は**数試合で届く**。まず触ってもらうためのもの。
> 500 は**しばらく貯める**。**遊び方そのものが変わるもの**をここに置く。

### 3-2-B. 初めて来た人には 300P（2026-08-28 決定）

**世界に初めて入った瞬間に配る。**

| | |
| --- | --- |
| 量 | **300P** |
| いつ | **初回のスポーン時。** 1 回だけ |
| 覚え方 | **2 か所に書く**（下） |

#### 記録は 2 か所（2026-08-28 修正）

**プレイヤー側だけでは、毎回「初参加」になっていた。**

入った直後（`playerSpawn`）は**まだ読み込みの途中**で、
書いたつもりの値が残らないことがある。
`/reload` のたびに `playerSpawn` が飛ぶので、**そのたびに配り直していた。**

| どこ | 何を |
| --- | --- |
| プレイヤー | 初めて入った時刻（`cw:first_at`） |
| **ワールド** | **来たことのある名前の一覧**（`cw:seen`。500 人まで） |

**どちらかに残っていれば「初めてではない」。**

| | |
| --- | --- |
| 見るのは | **入ってから 5 秒後**（落ち着いてから） |
| 書いたら | **読み直して確かめる** |
| 書けなければ | **配らない**（次に入ったときに回す） |

> **最初の 1 つは、遊ぶ前に選ばせる。**
>
> 点は試合の結果からしか入らない（3-2）ので、
> **初めて来た人はどのロールも触れない。**
> Swift しか無い状態で 5 試合こなせ、では**選ぶ楽しみが最初に来ない。**

**300 なら 150 のロールを 2 つ**買える。
500 のもの（遊び方そのものが変わるもの）は**貯めて買う**——ここは変えない。

#### 誰が初参加かは分かるようにする

| どこ | 何が出るか |
| --- | --- |
| 全体チャット | **`〇〇 さんは初参加です`**（迎える側が気づけるように） |
| 本人 | **300P を配ったこと**と、ロールの球の場所 |
| プレイヤー管理（[19-admin-menu.md](19-admin-menu.md) 6 章） | **その人が初参加かどうか** |

**運営が手を掛けられるようにするため**の表示。
初めての人に**やることを説明する相手**が要る。

### 3-2-A. 運営が足す・取り上げる（2026-08-27 追加）

**任意の点を、誰か 1 人か全員に渡せる。** マイナスを入れれば取り上げる。

| | どこ |
| --- | --- |
| 全員に | 設定メニュー → **ポイントを配る** |
| 1 人に | 設定メニュー → プレイヤー管理 → その人 → **ポイント** |
| コマンド | `/game:points <点> [名前]`（名前を省くと**全員**） |

| | |
| --- | --- |
| 足す | 正の数 |
| **取り上げる** | **負の数**（0 より下には行かない） |
| 知らせ | **もらった側にも出す。** 黙って増減させない |

> **試すためのもの。**
> 1 試合ぶんの点は数点しか入らないので、
> **500 点のロールを確かめるのに何十試合も要る。**
>
> 配れないと、**作ったものを誰も見られないまま**になる。

### 3-3. どこに持つか

**プレイヤーの動的プロパティ。** ワールドを閉じても残る
（[09-state-management.md](09-state-management.md) 4 章）。

| 名前 | 中身 |
| --- | --- |
| `cw:role` | いまのロール |
| `cw:roles` | 買ったロールの一覧 |
| `cw:points` | 持っている点 |

**試合をまたいで消さない。** 金庫（[22-vault.md](22-vault.md)）とはここが違う。

## 4. ロールの一覧

**Swift が基準。** 数字は「射程 / 切断距離」。

### 区分と色

| 区分 | 色 | 何が違うのか |
| --- | --- | --- |
| **通常** | 白 | 基準。**できないことが無い** |
| **操作性変化** | 水色 | **ワイヤーの効き方**が変わる |
| **特殊** | 桃 | ワイヤー以外に**別のことができる／できなくなる** |

**盤面ではロールの名前がこの色になる。持っていなくても同じ色**（2026-08-27 修正）。

はじめは持っていないものを**暗い灰**にしていたが、
**区分の色が読めないロールがあった**——
特殊も操作性変化も高いので、**買うまで灰色のまま**だった。

> **色は「何の仲間か」を表すもの。**
> **持っているかどうかは、値段が出ているかで分かる。**

### 4-1. Swift（既定）

| | |
| --- | --- |
| 射程 | **25 / 35** |
| マナ | 射出 5・引き寄せ 5・移動中に消費 |
| 特徴 | **汎用。** どの場面でも困らない |

**これが一番強くていい。** 尖ったロールは、**Swift にできないことを 1 つだけ**できる。

### 4-2. 操作性が変わるもの

#### Sky walker

| | |
| --- | --- |
| 射程 | **10 / 20** |
| 特別 | **空気に刺さる**（射程いっぱいの点。途中にブロックがあればそちらへ） |

**足場が要らない。** 短いぶん、どこでも跳べる。

> **空気に刺した点は壊れようが無い**ので、
> 「掛けた足場が消えた」判定（[13-grapple.md](13-grapple.md)）を通さない。

#### Duelist

| | |
| --- | --- |
| 射程 | **35 / 45** |
| 特別 | **マナが自動で回復しない。** プレイヤーを倒すと **100 回復** |

**倒し続けている間だけ動ける。** 外すと歩くしかない。

#### Zipline

| | |
| --- | --- |
| 射程 | **500 / 500** |
| マナ | **射出 100**・引き寄せ 0・**移動中も消費しない** |
| 特別 | **刺した点へ、重力を無視してゆっくり進む**（0.22 マス/tick） |

**移動そのものが別物。** 戦うための道具ではなく、**運ぶための道具。**

| | Swift | **Zipline** |
| --- | --- | --- |
| 加速するか | **する**（最高速まで上がる） | **しない**（一定） |
| 曲げられるか | 曲げられる | **曲げられない** |
| 切った後 | **勢いが残る** | 残らない |

#### 切れる条件も違う（2026-08-26 追加）

| 切れる条件 | Swift | **Zipline** |
| --- | --- | --- |
| 通り過ぎた | 切る | **見ない** |
| 壁で止まった | 切る | **見ない** |
| 手前まで来た | 3 マス | **2 マス** |
| 持ち替え・足場が消えた | 切る | 切る |

> 途中で放り出されると、**運ぶ道具として使えない。**
> **着いたら切れる**、それだけでよい。

#### 重力は切らない。実測から打ち消す（2026-08-26）

まっすぐ進ませるのに手間取った。**結論は「切らない」。**

| 試したこと | どうなったか |
| --- | --- |
| 何も足さない | 少しずつ沈む |
| 重力ぶん（0.08）を足す | 少しずつ浮く（**倍率が掛かって足しすぎ**） |
| 毎 tick 速度を捨てる | まだ沈む（プレイヤーには効かない） |
| **重力そのものを切る**（`minecraft:physics`） | まっすぐ進む。**が、採用しない** |
| **実測から打ち消す** | **採用** |

##### なぜ切らないのか

> **減速させる力が無くなる。**
> 移動中に殴られると、その勢いが**どこまでも残って飛んでいく。**

重力は「邪魔なもの」ではなく、**余計な速度を消してくれるもの**でもある。

##### 実測から決める

**いまの縦速度と、出したい縦速度の差**を見て、その分を足す。
**何倍で目減りするかを知らなくても、ずれていれば自動で埋まる。**

**上へは押すが、下へは押さない**（負の値は素直に効かない）。
上がりすぎたぶんは**重力が戻してくれる**——切っていないので。

> **プレイヤーの重力を切る仕掛けは削除した**（`player.json` の上書きごと）。
> 使わないものを残すと、**版が上がったときに古い定義で上書きし続ける。**

> **歩きより少し速い程度。** 500 マス先まで運べる代わりに、
> **戦っている最中には使えない遅さ**にしてある。

#### 超加速装置

| | |
| --- | --- |
| 射程 | **25 / 35**（Swift と同じ） |
| マナ | **射出 0**・**引き寄せ 100**・移動中 0 |
| 特別 | **引く速さが 8 倍** |

> **引き寄せたあとの着地が痛くない**のは、
> **いまは全員の性質**（[14-death.md](14-death.md) 6-B。2026-08-28 変更）。
> ここに書いていたが、**差ではなくなったので外した。**

**一発で吹き飛ぶ道具。**

**刺した先へ一気に着く**ので、引き続けるという操作がほとんど無い。
**満タンから 1 回**撃てて、外せば 30 秒待つことになる。

> **絵はバニラのもの**（打ち上げ花火）を借りている。
> 新しい絵を足すと `/reload all` が要る（`docs/research/02-hot-reload.md`）ので、
> **script だけで足せるロール**にした。

### 4-3. 特殊

#### Engineer

| | |
| --- | --- |
| 射程 | **15 / 25** |
| 特別 | **ドローンを使える**（[23-drone.md](23-drone.md)） |
| マナ | **召喚 50**・**物を出すときだけ**（動かしても減らない。2026-08-28 変更） |

**ドローンはショップから外す。** このロールだけのもの。

| ドローンの扱い | |
| --- | --- |
| 操作アイテム | **捨てられない** |
| 機体が壊れても | **操作アイテムは残る**（また出せる） |
| 降りたとき | **機体はその場に残る**（いまと同じ） |
| **その人が居なくなったら** | **機体も消える**（抜けた・ロールを変えた） |

#### パワー系

| | |
| --- | --- |
| 射程 | **無し。ワイヤーを使えない** |
| 特別 | **攻撃力 1.5 倍**（盤面には **+50%** と出す。**小数点が読めない**ので） |

**増える分は、体力を直接引く**（2026-08-28 修正）。

`applyDamage` を足す形にしていたが、**一度も効いていなかった**——
殴った直後は**無敵時間**（約 0.5 秒）に入っていて、
そこへ足したダメージは**まるごと捨てられる。**

**無敵時間は体力の書き換えには効かない。**
引くのは**軽減された後の値**を基準にした分なので、防具の効き目は保たれる。

**倒れるところまで削るときは、死亡処理へ渡す**——
体力を 0 にしただけでは、**誰に倒されたかも、持ち物を残すかも決まらない。**

**歩くしかない代わりに、殴れば強い。**

#### Loophole

| | |
| --- | --- |
| 射程 | Swift と同じ（25 / 35） |
| 特別 1 | **飛び込んだ直後でもコアを削れる**（[13-grapple.md](13-grapple.md) 7 章の待ち時間が無い） |
| 特別 2 | **採掘が速い**（採掘速度上昇 I） |
| 特別 3 | **敵を攻撃できない** |

**削ることしかできない。** 守りは味方に任せる。

## 4-4. 見た目

**ロールごとに絵を 1 枚描く。** 盤面に並ぶのはこの絵。

| ロール | 絵 | 色 |
| --- | --- | --- |
| Swift | **ワイヤー付きの剣** | 水色 |
| Sky walker | **雲と鉤** | 白 |
| Duelist | **交差した 2 本の剣** | 赤 |
| Zipline | **横に張った線と滑車** | 黄 |
| Engineer | **ドローンの羽根** | 緑 |
| パワー系 | **握り拳** | 橙 |
| Loophole | **ツルハシと鍵穴** | 紫 |

**16x16。** 持ち物には出ないので、**盤面で見分けられれば足りる。**

> **バニラの絵を借りない。**
> ロールは**このゲームだけのもの**なので、借りると意味がずれる。
>
> 買っていないロールも**絵はそのまま。** 値段が出ていることで見分ける。

## 5. 実装の置き場

```
lib/
  roles.ts          ロールの一覧・いまのロール・買った一覧・点
  practice.ts       ロビーで試せるかの判定（25-practice.md）
features/role/
  keeper.ts         変更用の球（見張りと設置。拠点 2 個 + 待機所）
  ui.ts             ロールの盤面
  change.ts         変えるときの流れ（倒れる・片付け・付け直し・参加時の確定）
  points.ts         試合の結果から点を配る
features/admin/
  points.ts         運営が点を配る・取り上げる（19-admin-menu.md 6-B）
resource_packs/game/
  textures/items/game_role_<ロール>.png   盤面に出す絵（16x16）
  models/entity/orb.geo.json              球の模型
  textures/entity/orb{,_blue,_red,_gold}.png  球の色
```

**ワイヤーの数値はロールから引く。** `features/grapple` は定数を直接見ない。

## 6. 決めていないこと

- **点の入り方**（キル +5 / コア +2 のまま。勝敗に点を付けるかは未定）
- 球を置く場所（いまは拠点 2 個 + 待機所）
