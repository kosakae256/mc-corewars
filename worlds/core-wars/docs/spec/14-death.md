# 仕様: 死亡と復活

**倒れてから 5 秒、観戦者として待ち、自陣に戻る。**

ルールは [01-rules.md](../01-rules.md) 4章。

---

## 1. 死亡はバニラに任せる

**死ぬこと自体は止めない**（2026-08-24 方針転換）。

代わりに**死亡画面を出さない設定**（`doImmediateRespawn`）を使う。
死んだ瞬間に復活し、そこを捕まえて観戦者にする。

```
普通に死ぬ（バニラのまま）
    ↓  死亡画面は出ない。即座に復活
その瞬間を捕まえて観戦者にする
    ↓  5 秒
自陣へ戻す
```

### なぜ変えたのか

**以前は致命傷を打ち消していた。**
体力が 0 になるとゲーム側の死亡が起きるので、
**その一撃だけを横取りする**という作りだった。

そのために「**この一撃は致命傷か**」を事前に当てる必要が生まれた。
だが**防具や魔法での軽減は、ダメージが入った後にしか分からない。**

当てようとして、次々に壊れた。

| やったこと | 何が起きたか |
| --- | --- |
| 生の値で判定 | 防具を着ていても倒れた |
| 死なない値まで削る | **体力によって威力が変わった** |
| 前の一撃から軽減率を測る | それでも一撃で倒れた（原因を特定できず） |
| 読めないときを 0 として扱う | **どんな一撃でも倒れた** |

**予測をやめれば、この行が全部消える。**

> 教訓として残す。
> **engine が持っている情報を、外から当てにいってはいけない。**
> 起きた後で受け取るほうが、必ず正確で、必ず単純になる。

---

## 2. 何が起きるか

**順番が大事。**

```
死ぬ（バニラ）
    ↓  持ち物が落ちる           ← ルール 4-4。倒した側が拾える
    ↓  即座に復活（画面は出ない）
観戦者にする・倒れた場所へ戻す
    ↓  5 秒
自陣へ戻す・体力を戻す・支給品を渡す・5 秒無敵
```

### ゲームルールはこちらで宣言する

**ゲームが前提にしている設定は、ゲームの側で立てる。**

| 設定 | 値 | なぜ |
| --- | --- | --- |
| `doImmediateRespawn` | **true** | 死亡画面を出さない。この方式の要 |
| `keepInventory` | **false** | **持ち物が落ちないと、攻める理由が消える** |
| `pvp` | true | 殴り合えないと成立しない |
| `fallDamage` | true | 落下は自前で差し替えるので、engine 側は有効に |

ワールド側の設定に任せると、**入っていないことに気づけない。**
実際に `keepInventory` が入っていて、**何も落ちなかった。**

### 持ち物はバニラが落とす

[01-rules.md](../01-rules.md) 4-4 のとおり。**倒した側が拾える。**

自分で落とす必要が無くなった。

#### 落とさないのは「配られたもの」だけ（2026-08-26 修正）

| | 死んだら |
| --- | --- |
| **Swift Sword [Mk-1]**（支給） | **残る** |
| **Mk-2 / Mk-3 / Mk-4**（買う） | **落ちる** |
| 参加の札・運営の道具 | 残る |
| それ以外 | 落ちる |

一時は**ワイヤーを撃てるものを全部残していた。**
支給品を落とさない決まりの名残で、
**買った剣まで死んでも手元に残っていた。**

> **買ったものは、死んだら落ちる。**
> 落ちないなら、**倒しても相手は何も失わない。**
> 高い剣を買うことに、失う危険が伴わなくなる。

支給品は**落としても 5 秒で配り直される**ので、落とす意味がそもそも無い。

### 観戦者にする理由

**倒れている間、身体を残したくない。**

その場に立ったままだと、殴られ続けるし、通せんぼになる。
観戦者なら**誰にも触れない。**

### 倒れた場所へ戻す

復活地点は自陣だが、**倒れた場所で観戦させる。**
どこで死んだのかが分かるほうが、次に活きる。

## 3. 誰が倒したかは正確に分かる

**`entityDie` が教えてくれる。**

推測する必要が無くなった。
奈落と落下だけは相手の記録が残らないので、
**直前に殴ってきた相手**から決める（従来どおり）。

### TNT は「点けた人」の手柄（2026-08-25 追加）

**仕掛けた道具ではなく、仕掛けた人を数える。**

| 何が当たったか | 誰の手柄になるか |
| --- | --- |
| 人が殴った | **その人** |
| 矢・雪玉 | **撃った人**（バニラが入れてくれる） |
| **TNT の爆風** | **火を点けた人** |
| それ以外 | 誰の手柄でもない |

TNT だけは、当たったものが `TNT という実体`になる。
そのままだと**誰も倒していないことになり、手柄が消える。**

味方の巻き添えを止めるために**点けた人を実体に書いてある**
（[11-match.md](11-match.md) 5-1）ので、**それを引けばよい。**

置いた分も、ドローンから落とした分も同じ
（[23-drone.md](23-drone.md)）。

> **自分の TNT で倒れた場合は誰の手柄でもない。**
> 死んだ数だけが増える。

#### 吹き飛ばして奈落へ落とした場合も同じ

**殴られた記録**（奈落・落下のときに使う）にも
**点けた人**が入る。

> **TNT の使い道は「落とすこと」**（[02-map.md](../02-map.md) 2-A-2）。
> そこで手柄が消えるなら、直接倒したときだけ数えるのと変わらない。

---

## 4. `/reload` で壊さない

**倒れている人がいる状態で読み込み直しても、置き去りにしない。**

復活する時刻を**プレイヤーの動的プロパティ**に持つ
（[11-match.md](11-match.md) R-1）。
読み込み直したら、そこを見て続きから数える。

**メモリだけに持つと、観戦者のまま戻れなくなる。**

---

## 5. 試合中だけ

**非開始・一時停止中は倒れない。**
建築中に落ちて観戦者になっても困る。

その場合は**体力を戻すだけ**にする。

## 6. 落下ダメージ

**バニラより緩くする。**

| | 痛くない高さ | 増え方 |
| --- | --- | --- |
| バニラ | 3 マスまで | 1 マスごとに 1 |
| **ここ** | **7 マスまで** | **2 マスごとに 1** |

| 落ちた高さ | ダメージ |
| --- | --- |
| 7 マス | **0** |
| 8〜9 マス | 1 |
| 10〜11 マス | 2 |
| 20 マス | 7 |
| 30 マス | 12 |

> **2026-08-25 に厳しくした**（15 マスまで無傷 / 3 マスごと → いまの値）。
> **落ちても何も起きない**に近く、高さを気にせず飛べてしまっていた。
> バニラよりは緩いまま、**高さに対する怖さは残す。**

### なぜ緩くするのか

**立体機動で高い所を行き来するゲーム**にした。
バニラのままだと、**落ちた時点で終わる。**

ワイヤーを切る位置を選ぶのがこの道具の面白さなのに、
落ちる怖さが勝つと**安全な低い所しか使わなくなる。**

### 装備で軽減できる

**バニラのぶんを取り消し、こちらの計算で与え直す。**

与え直す形にするのは、**装備や魔法での軽減をゲーム側に任せる**ため。
自分で引き算すると、防具や魔法の効果を全部作り直すことになる。

> 与え直したダメージは**もう一度こちらへ戻ってくる。**
> その 1 回だけ素通りさせないと、無限に縮み続ける。

### 落ちた距離の求め方

**バニラのダメージから逆算する。**
バニラは「落ちた距離 − 3」がダメージなので、3 を足せば距離が出る。

空中に居た時間を追うより確実で、**毎 tick 数える必要が無い。**

## 6-C. 倒れると決まった人は、もう殴れない（2026-08-28 追加）

> ### 先に当てたほうが勝つ。

**殴り合うと両方倒れていた**（2026-08-28 の指摘）。

致命傷は**打ち消してから、次の tick で倒す**——
`goDown` は画面を触るので、打ち消しの場からは呼べない。

**その 1 tick の間、倒れるはずの人がまだ立っている。**
打ち消したぶん**体力も減っていない**ので、
**倒したはずの相手に殴り返される。**

| | |
| --- | --- |
| 決まった瞬間 | **印を付ける**（`dying`） |
| 印が付いている人の攻撃 | **通らない**（`features/combat`） |
| 印が消えるとき | **次の tick**（そこで実際に倒れる） |
| 覚え方 | **メモリだけ。** `/reload` で消えてよい |

**倒れ方は問わない**——殴られても、落ちても、爆風でも同じ。

## 6-B. 引き寄せたあとの着地は痛くない（2026-08-28 変更）

**全ロール共通。**

| | |
| --- | --- |
| 効く場面 | **引き寄せを始めてから 15 秒以内の、最初の落下** |
| 効かない場面 | **自分から飛び降りた**とき（普通に痛い） |

はじめは超加速装置だけの性質だったが、**全員のものにした。**

> **ワイヤーで飛べば、必ずどこかに落ちる。**
> 移動そのものに税を掛けているようなもので、
> **飛ぶほど損をする**のでは、この道具を使う理由が削れる。

**落下ダメージを全部無くすのとは違う。**
高い所から**自分の足で飛び降りた**ぶんは、これまで通り痛い。

**ロールの説明には書かない**——差ではなく、**この道具の前提**なので。

## 6-A. 試合の外では傷つかない（2026-08-25 追加）

**試合に出ていない人は、落ちても殴られても減らない。**

| | |
| --- | --- |
| **あらゆるダメージ** | **通らない**（2026-08-27 変更） |
| 落下ダメージ | 無い |
| 人からの攻撃 | 通らない（殴る側・殴られる側どちらが外でも） |
| **爆風・火・溺れ** | **通らない** |

> **原因を並べない**（2026-08-27 修正）。
> 落下と人の攻撃だけ止めていたので、**爆風では死ねた**——
> ドローンから落とした TNT の自爆で倒れた。
>
> **数え漏らすたびに同じ事故が起きる。**
> 試合に出ていないなら**何も通さない**、の 1 行にする。

### なぜ

**ロビーはワイヤーの練習をする場所**（[13-grapple.md](13-grapple.md) 6章）。

落ちるたびに減っては、**試すこと自体ができない。**
待っている間に殴り合いが始まるのも、練習している人が巻き込まれるのも困る。

### 判定は 1 つ

**`shouldBeInBattle`。** 状態と所属を合わせて見る既存の 1 箇所を使う。

所属だけで見ると、**試合が終わったあとも「出ている」ことになる**
（[11-match.md](11-match.md) 6-Y）。

## 6-B. 炎ではダメージを受けない（2026-08-25 追加）

**燃えても減らない。** 火の中に立っても、燃え移っても、体力は動かない。

### なぜ

**火は場所を通せんぼするためのもの。**

ファイヤーチャージ（[03-content.md](../03-content.md) 1-4）は
**その場を焼いて通れなくする道具**として置いてある。
そこに**当たれば削れる**が乗ると、**遠距離から削り合う**遊びになる。

火のついた場所は「入りたくない場所」であればよく、
**入ったら減る場所**である必要が無い。

### 火炎耐性は使わない

**効果を付けて済ませない。**

| | |
| --- | --- |
| 画面に効果の印が出る | **常時ついている印**は、見ていて邪魔 |
| 画面が色付く | 火炎耐性の色被りが常に乗る |
| 効果の枠を 1 つ潰す | 他の効果と競合する |

**ダメージが来たところで打ち消す。**
見た目は普通に燃えるが、**減らないだけ。**

### 何を打ち消すのか

| | |
| --- | --- |
| **火の中に居る** | 打ち消す |
| **燃え移った**（じわじわ減るやつ） | 打ち消す |
| 溶岩 | **打ち消さない。** マップの仕掛けとして残す |

### 火そのものを減らす（2026-08-25 追記）

**ファイヤーチャージは火を残さない**ようにした
（[03-content.md](../03-content.md) 1-4）。

**減らない火は通せんぼにならない。**
見た目だけ危なそうで通っても何も起きないのでは、**嘘をついているのと同じ。**

ここの決まりは**残っている火種**（火打石・溶岩）のために残す。

### 燃えている見た目も消す（2026-08-25 追加）

**減らないのに燃え続けているのは、ただの誤解のもと。**

画面が炎で覆われて前が見えないのに体力が動かない——
**壊れているように見える。**

#### リソースパックでは消せない

**画面の炎は、地面の火と同じテクスチャを使っている。**
消すと**火そのものが見えなくなる。**

火は**「入りたくない場所」を示すもの**なので、
見えなくなっては置く意味が無い。

**燃えている状態そのものを消す。** 火が点いたら、すぐ消す。

### アイテムも燃えない（2026-08-25 追加）

**落ちている物は火で消えない。**

死んで落とした装備が、**そのあと燃え広がった火で消える**
——取り返しに行っても何も無い、が起きる。

火は**通せんぼ**であって、**物を消す仕掛けではない。**

## 7. ダメージはバニラのまま

**火力の計算に手を入れない。**

**こちらで計算するのは落下だけ**（6章）。
それ以外は engine に任せる。**手を入れた分だけ狂う。**

専用の剣に `minecraft:damage` を持たせたときは、
**バニラの計算とは別に足し込まれて一撃で倒せる状態になった。**
一度はバニラの剣を売ることにした。

**2026-08-26 に、また専用の剣に戻した**（[03-content.md](../03-content.md) 1-1）。
剣が**ワイヤー射出装置を兼ねる**ので、独自アイテムでないと作れない。

> 同じ穴に落ちないよう、**火力をバニラの剣と同じ値**（4〜7）にし、
> **上の段階（ネザライト相当）を作らない。**

**ツルハシだけは例外**（1-5-B）。
攻撃力を 1 に固定するために、**こちらで値を握っている。**

## 7-A. 倒れたら効果と装備を手放す（2026-08-25 追加）

### 効果は全部落とす

**倒れ方で分けない。** 奈落も自滅も倒されたときも同じ。

金のリンゴの吸収や強化が残ったまま復活するのでは、
**倒された不利が消える。**

**戻すときにもう一度落とす。**
観戦している 5 秒の間に付くことがあるので、
**戻った瞬間には無い状態**にしておく。

> 種類を並べて消さない。**持っているものを数えてから消す。**
> 並べると、新しい効果が増えたときに漏れる。

### 防具も落とす

**持ち物の枠しか見ていなかったので、防具だけ残っていた。**

バニラの死亡（打ち消しが間に合わなかったとき）は防具も落とすので、
**同じ死に方でも落ちたり落ちなかったりしていた。**

| 部位 | どうするか |
| --- | --- |
| 胴・脚・足 | **落とす** |
| 頭 | **触らない**（チームの帽子。[15-presentation.md](15-presentation.md) 7-2） |

防具は買い物の主役（[12-shop.md](12-shop.md)）。
落ちないなら、**倒しても相手の装備は減らない。**

## 8. 文言

### 断定できる死因は、そう書く（2026-08-26 変更）

> **矢印をやめた。**

`☠ 名前 ← 相手` は、**誰に倒されたかしか言っていない。**
何が起きて倒れたのかが分からないと、**次に同じ倒れ方を避けようが無い。**

| 場面 | 文面 |
| --- | --- |
| 剣で斬られた | `☠ 名前 は 相手 に斬られた` |
| 斧で | `☠ 名前 は 相手 に叩き斬られた` |
| ツルハシで | `☠ 名前 は 相手 にツルハシで殴られた` |
| **Swift Sword で** | `☠ 名前 は 相手 の Swift Sword で切り刻まれた` |
| 素手・その他で殴られた | `☠ 名前 は 相手 に殴り倒された` |
| 撃たれた（矢・雪玉） | `☠ 名前 は 相手 に撃たれた` |
| **TNT** | `☠ 名前 は 相手 の TNT で吹き飛ばされた` |
| **ドローンの TNT** | `☠ 名前 は 相手 のドローンの TNT で吹き飛ばされた` |
| 断定できない | `☠ 名前 は 相手 に倒された` |

自分で倒れた場合も同じ。

| 場面 | 文面 |
| --- | --- |
| 自分の TNT | `☠ 名前 は自分の TNT で吹き飛んだ` |
| 自分のドローンの TNT | `☠ 名前 は自分のドローンの TNT で吹き飛んだ` |
| 溶岩・溺れ・窒息・棘 | `☠ 名前 は溶岩に落ちた` など |
| 自分で落ちた（奈落） | `☠ 名前 は奈落死した` |
| 落とされた（奈落） | `☠ 名前 は 相手 によって奈落死させられた` |
| 自分で落ちた（落下） | `☠ 名前 は落下死した` |
| 落とされた（落下） | `☠ 名前 は 相手 によって落下死させられた` |
| 断定できない | `☠ 名前 は倒れた` |

#### 何で殴ったかは、持ち物から見る

**殴りは「殴り」としか分からない。**
engine が伝えるのは原因（`entityAttack`）だけで、道具は入っていない。

**倒した人の手に持っているもの**を見て書き分ける。

> 持ち替えた後だと外れることがある。
> **外れても害の無い言い回し**（「に殴り倒された」）に寄せてある。

#### 死因の語彙は自前で持つ

**engine の列挙をそのまま持ち回さない。**

TNT は**手から置いた分とドローンから落とした分を書き分ける**が、
原因（`entityExplosion`）は同じ。**原因だけでは足りない。**

湧かすときに実体へ書いた印（3 章）を読んで、
`tnt` / `drone_tnt` という**こちらの語彙に翻訳してから**文面を組む。
