# 仕様: 参加とルール同意

**遊ぶ前に通る門。** ここを通らないと試合に入れない。

---

## 1. 参加ルール

**同意していない人は参加できない。**

### 1-1. 文面

```
1. チート及び連打ツール等の外部ツールの悪用
2. クライアントの悪用
3. ライン越え（zerda256py の裁量）

上記を破ったものは kick あるいは ban 処置を行います。
基本 ban します。
チャタやホイールと言い訳しても普通にマシンチートなので、ただの自白です。
```

文面は [rules.ts](../../packs/game/scripts/lib/rules.ts) が唯一の正。
**ここを直すと、同意の版番号が上がる。**

### 1-2. 版番号で再同意させる

**文面を変えたら、全員にもう一度同意を求める。**

| 持ち物 | どこ |
| --- | --- |
| 同意した版番号 | プレイヤーの動的プロパティ |
| いまの版番号 | コードの中（`RULES_VERSION`） |

**番号が違えば未同意として扱う。**
「いつの文面に同意したか」を持たないと、
黙って変えた条件で縛ることになる。

### 1-3. いつ見せるか

| 場面 | 何が起きるか |
| --- | --- |
| ロビーで**参加に切り替えた** | 未同意なら**同意画面**を出す |
| **試合開始のチーム分け** | 未同意の人は**参加しない** |
| 途中参加の看板 | 未同意なら同意画面 |

**同意しないことを選べる。** 見るだけの人は居てよい。

## 2-Z. 入り方は出し続ける（2026-08-28 追加）

**ロビーに居る間、足元の行に出し続ける。**

| 状態 | 出る文 |
| --- | --- |
| 試合中 | **`看板から途中参加できます`** |
| 非開始 | `看板で参加を選べます` |

**看板を押せば入れることを、誰も知らないまま待っている。**
試合中に来た人には特に届かない——
**始まってしまえば、もう入れないと思ってしまう。**

| | |
| --- | --- |
| 出す相手 | **所属が無い人**（観戦中を除く） |
| 強さ | **いちばん弱い**（買えない・置けないといった知らせに押しのけられる） |
| 間隔 | 2 秒ごとに出し直す |

## 2. 参加 / 非参加の切り替え

**ロビーで、持ち物の中央のマスに固定される。**

| | |
| --- | --- |
| 見た目 | **チェックマーク**（参加）/ **×**（非参加） |
| 置き場所 | **持ち物の中央**（スロット 4） |
| 動かせるか | **不可。** 捨てられない、並べ替えられない |
| 運営も持つか | **持つ** |

### 2-0. 既定は「参加」（2026-08-28 変更。非参加から戻した）

| | |
| --- | --- |
| 入ってきたとき | **参加** |
| 試合が終わったとき | **参加に戻る**（答えを忘れる） |
| 出ないと決めた人 | **札を押す**。押した答えはその試合まで残る |

一度は**押さなければ入らない**形にした（2026-08-26）。
席を外した人が並び続けるのを嫌ってのことだったが、
**入りたい人まで押し忘れて弾かれた。**

> **来ている人は、たいてい遊びに来ている。**
> **出ない人が押す**ほうが、押す回数はずっと少ない。

抜けるのは**札を押すだけ**で、チーム分けの瞬間までいつでもできる。

### 2-4. 鍵は使わない（2026-08-26 変更）

**`ItemLockMode` をやめた。**

付けると、**持ち替えるたびに但し書きが出る。**

```
Swift Sword [Mk-1]
✦ ドロップできないアイテム: ドロップ、削除、クラフトでの使用
このアイテムは死亡してもなくなりません
```

**ワイヤーのガス表示と同じ場所に重なる。**

#### 言語ファイルでは消せなかった

| やり方 | どうなったか |
| --- | --- |
| 値を空にする | **バニラの文に戻る**（訳が無い扱い） |
| `§r` を入れる | **空の行が残る**（改行のように見える） |

#### 落ちたら消す

**捨てる前には止められない。**
打ち消せるドロップのイベントが無い（`entityItemDrop` は after だけ）。

拾い直して返す形も試したが、やめた。

> **落ちている支給品には、誰にとっても意味が無い。**
> 全員が最初から 1 本持っているので、**拾う理由が無い。**
> 倒した相手のものを拾えると、**同じ物が場に増えるだけ。**

**床にあるものは消す**（`features/special/nodrop`）。

| | |
| --- | --- |
| 対象 | **支給品・参加の札・退役した道具** |
| 速い経路 | `entityItemDrop`（捨てた瞬間） |
| 保険 | **1 秒ごとの見張り**（倒れてバニラが落とした分など） |
| **買ったものは** | **対象外。** 落ちるし、拾える |

#### 倒されたときも落ちない

**支給品は落とさない**（[14-death.md](14-death.md) 2 章）。
打ち消しが間に合わずバニラが落とした場合も、**上の見張りが消す。**

#### 無くした人には配り直される

| どこで | いつ戻るか |
| --- | --- |
| **ロビー** | **5 秒ごとに配り直す**（[15-presentation.md](15-presentation.md) 1 章） |
| 試合中 | **復活したとき** |

**捨てた人は、その試合の間は手ぶら。** 捨てた本人の判断として扱う。

### 2-1. 切り替えられる時と、できない時

| 状態 | 切り替え |
| --- | --- |
| **ロビーに居る**（非開始） | **できる** |
| **準備中**（開始 → チーム分けまでの 10 秒） | **できる** |
| チーム分け後 | **できない** |
| 試合中 | **できない**（アイテムそのものが消えている） |

**チーム分けの瞬間にアイテムを消す。**
消し忘れて触れてしまった場合も、**切り替えを拒否する。**
二重に止めておく。

#### 準備中は切り替えられなければならない（2026-08-25 修正）

**猶予の 10 秒は、そのための時間**（[11-match.md](11-match.md) 7-A）。
ここで切り替えられないなら、猶予を置いた意味が無い。

判定に `isRunning()` を使っていたので**開始を押した瞬間に締まっていた。**
試合の状態（`matchState()`）は開始と同時に立ち、
**「準備中」はその上に重なる印**なので、`isRunning()` だけでは区別できない。

> **状態の判定は `matchState()` に通す。**
> 個々の真偽値を直接見ると、こういう取りこぼしが出る。

#### 締め切りは、試合が終われば開く（2026-08-26 修正）

締め切りは**チーム分けの瞬間に立てる**が、
**開け直す呼び出しがどこからも来ていなかった。**

> **一度試合をすると、次からは札を押しても切り替わらない。**

**非開始に戻った時点で開ける。**
呼び出しを足すのではなく、**状態から決める**（呼び忘れようが無い）。

### 2-2. 切り替えたら本人に伝える

**チャットに状態を出す。**
アイコンだけだと、どちらが参加なのか分からなくなる。

## 3. 途中参加

**ロビーの看板を右クリック。**

| 条件 | |
| --- | --- |
| 試合中である | 必須 |
| ルールに同意している | 必須 |
| まだ所属が無い | 必須（既に所属があるなら戦場へ戻すだけ） |

### 落ちて戻ってきた人は「途中参加」ではない

**同じセッションなら所属が残っている**（[11-match.md](11-match.md) 2章）。
戻ってきた時点で**自動的に元のチームへ戻る。** 看板を押す必要は無い。

| 戻ったときの居場所 | どうなるか |
| --- | --- |
| 自拠点の中 | そのまま続行 |
| 拠点の外 | **死亡扱い。** 持ち物を落とし、5 秒後に自陣へ |

拠点の外で切断したのに、その場から再開できると
**危なくなったら落ちる**のが有効な手になってしまう。

> **別のセッション**（`/game:start` をやり直した後）なら所属は外れる。
> そのときは改めて看板から入る。

途中参加は**支給の資源を受け取らない**（[11-match.md](11-match.md)）。
開始から居た人と同じでは、遅れて入るほうが得になる。

### 入ったことは全体に知らせる（2026-08-26 追加）

**チャットに 1 行出す。**

```
ばーど が §c赤§7 に途中参加しました
戻ってきた人なら … が §9青§7 に戻りました
```

**人数が増えたことは、両チームに関わる。**

黙って増えると、

- 味方は**居るはずのない味方**を数え損ねる
- 敵は**居ないはずの敵**に不意を突かれる

> **開始からの参加では出さない。**
> 始まった時点で**顔ぶれを読み上げている**ので、二重になる。

出す場所は `joinMatch`。**看板からも運営メニューからも、必ずここを通る**
（[19-admin-menu.md](19-admin-menu.md) 6 章の組替えも同じ扱い）。

## 4. 看板

**ロビーに置く。** 金庫の看板だけは**拠点に置く**（[22-vault.md](22-vault.md) 2 章）。

| 看板の 1 行目 | 何が起きるか |
| --- | --- |
| `[途中参加]` | 途中参加する |
| `[マイセット]` | マイセットの登録画面（[17-myset.md](17-myset.md)） |
| `[ルール]` | ルールを読む／同意する |
| `[観戦]` | 観戦を始める（[20-spectate.md](20-spectate.md)） |
| `[コンセプト]` | このゲームについて読む（[00-concept.md](../00-concept.md) 1-A） |
| `[クレジット]` | 作った人を読む（[00-concept.md](../00-concept.md) 1-A） |
| `[金庫赤]` / `[金庫青]` | 持っている鉱石をまとめて預ける。**自陣のものだけ**（[22-vault.md](22-vault.md)） |

**看板の文字で見分ける。** 座標を持たない。

**どの行に書いてもよい。**
看板は「表題 + 説明」の形で書くほうが自然なので、
印が 2 行目以降に来ることがある。

**色を付けてよい。** 色記号（`§`）は無視して見比べる。

### 看板の反応を一時的に止める（2026-08-25 追加）

**`/game:signs` で、自分だけ看板が効かなくなる。**（運営のみ）

もう一度打つと戻る。

| | |
| --- | --- |
| 誰に効くか | **打った本人だけ** |
| 他の人 | **今まで通り使える** |
| `/reload` | **またいで残る**（消えると、直している最中に黙って戻る） |

#### なぜ要るのか

**印のある看板は、クリエイティブでも押した瞬間に動く。**

直したいときは**壊して置き直す**しかなかった。
文字を 1 字直すために、置き直して向きを合わせるのは手間が大きい。

> **止められるのは自分だけ。**
> 全員ぶん止めると、**直している間ゲームが止まる。**

### 看板は編集できない

**クリエイティブの人だけが編集できる。**

遊ぶ人はサバイバルか観戦者。
**看板はゲームの入口**なので、書き換えられると入れなくなる。

**何も言わない。**

看板は右クリックで使うものなので、
押すたびに「編集できません」と出ると**うるさいだけ。**
編集できないことは、編集画面が出ない時点で伝わる。

> 印の付いた看板は、クリエイティブでも押せば動く。
> 直したいなら壊して置き直す。
看板は目印なので**目立つほうがよい**のに、
色を付けた瞬間に反応しなくなるのでは置く側が使いづらい。
マップを直したときに座標を書き換える手間が要らないし、
**看板を増やせばそのまま増える。**
