# 仕様: 観戦

**試合に入らずに見る。**

---

## 1. 何をするものか

**スペクテイターになって、自由に見て回る。**

| | |
| --- | --- |
| 見えるもの | **全員の名前・体力・ガス**（[15-presentation.md](15-presentation.md) 7-3-A） |
| 触れるもの | **無い。** ブロックも人も触れない |
| 数に入るか | **入らない。** 参加者としては数えない |

### なぜ要るのか

**遊ばないが見たい人が居る。**

順番待ち、実況、運営の見回り——
そのたびに「参加しない」を選んで地上をうろつくのでは、
**戦場の中が見えない。**

---

## 2. 入り方

| 入口 | |
| --- | --- |
| **ロビーの `[観戦]` 看板** | 遊ぶ人はここから |
| 設定 → プレイヤー管理 | 運営が他人を観戦にする |

**コマンドは用意しない**（2026-08-25 変更）。
入口が増えるほど、**入れる条件を書き忘れる場所が増える。**

### いつでも入れる

**試合をしていなくても観戦できる。**

マップを見て回るのに使える。
**戻れなくなる心配は無い**——抜け方（3 章）はいつでも使える。

### 入ったら戦場へ運ぶ

**ロビーは戦場の外にある**（[15-presentation.md](15-presentation.md) 1 章）。
観戦者にしただけでは、**見たいものから遠く離れたまま。**

**中央の島の上（+25 マス）に出す。**
見渡せる高さから始める——地面に置くと、
目の前の壁しか見えないところから始まる。

そこからは自由に動けるので、細かい位置は決めない。

### 戦っている最中は入れない

**逃げ道にしない。**

戦っている最中に観戦へ抜けられると、
**負けそうなときに消えるのが最適手**になる。

> **所属では見ない**（2026-08-25 修正）。
> 「所属がある人」で弾いていたが、
> **試合が終わっても所属が残っていた**ため、
> ロビーに居るのに入れなかった。
>
> いまは所属そのものが試合中しか無い（[11-match.md](11-match.md) 6-Y）。
> 判定も `shouldBeInBattle`（状態と所属を合わせて見る 1 箇所）に寄せてある。

## 3. 抜け方

**真上を向く。** 確認が出るので「戻る」を選ぶ。

| | |
| --- | --- |
| 操作 | **真上を向く**（上下の角度 -80 度以下） |
| そのあと | **「ロビーに戻りますか？」** |
| 出る場所 | **ロビー** |

### なぜ視線なのか

**観戦者は持ち物を使えない。**
アイテムやボタンでは抜けられない——
スペクテイターは**アイテムの操作そのものが届かない。**

使えるのは**視線と姿勢**だけ。

### しゃがみは使えない

**観戦中のしゃがみは「下に降りる」操作。**
降りようとするたびに抜けてしまう。

### そのまま抜けさせない

**上を見上げただけで戻されるのでは、上が見られない。**

真上を向いたら**聞く。**
「観戦を続ける」を選べばそのまま。閉じても続ける扱いにする。
**断ったら 3 秒は聞き直さない**（上を向いたままだと出続ける）。

### 戻ったら、その場で配り直す（2026-08-25 追加）

**ロビーへ戻した瞬間に支給品を渡す**（[13-grapple.md](13-grapple.md) 6 章）。

ロビーの見張りも 5 秒ごとに配り直すが、
**戻った直後に手ぶらなのは「壊れている」ように見える。**

観戦者は持ち物を使えないのだから、
**戻ってすぐ試せること**が観戦をやめる理由そのもの。

### 抜け方を画面に出す

**サブタイトルに常に出す。**

```
                 観戦中
        真上を向くと ロビーに戻ります
```

**知らない操作は、書いていないと分からない。**
一度出して消すのでは、後から入った人が困る。

**聞いている間は出さない。** 画面が二重になる。

## 4. 観戦者の扱い

| | |
| --- | --- |
| 見つける側 | **ならない**（[15-presentation.md](15-presentation.md) 7-3-B） |
| 見つけられる側 | **ならない** |
| 頭上の表示 | **本人のものは出さない** |
| 全員の表示 | **見える**（味方も敵も） |

**倒れて観戦している人とは別**（[14-death.md](14-death.md)）。
そちらは 5 秒で戻るので、全員の表示は見えない。

### ロビーの見張りは通さない

ロビーの見張り（`features/lobby`）は**観戦者を「前の試合の名残り」と見なす。**
そのまま通すと**サバイバルに戻され、観戦の側が戻し直す**——
押し合ってちらつく。

**観戦中の人は、ロビーの見張りの対象から外す。**

> **「名残りを落とす」だけを外す**（2026-08-25 補足）。
> 観戦から戻った人には、**その場で支給品が渡る**（3 章）。

## 5. 実装の置き場

| | |
| --- | --- |
| 観戦の出入り | `features/spectate/index.ts` |
| 見せる相手 | `features/spotting/marker.ts` が問い合わせる |

**倒れている人の観戦と混ぜない。**
`features/death` が観戦者にするのとは別の状態として持つ。
混ぜると、**倒れた人が抜けられなくなる。**
