# 仕様: マイセット

**買い物を 1 回の操作で済ませる。**

---

## 1. 何をするものか

**あらかじめ「これを買う」と決めておき、まとめて買う。**

ショップを開いて 1 つずつ押すのは、**戦闘の合間にやることではない。**
復活してすぐ前線へ戻りたいのに、買い物で時間が溶ける。

| | |
| --- | --- |
| 登録できる数 | **3 件** |
| 払う元 | **持ち物の鉱石 + エンダーチェストの鉱石** |
| 足りないとき | **買わない**（全部揃わないなら 1 つも買わない） |

### 1-2. 中途半端に買わせない（2026-08-25 変更）

はじめは**安いものから、払える限り買う**ようにしていた。
「全部買えないなら何も買わない、では不便」と考えたため。

**逆だった。**

マイセットは「**この装備で前線へ戻る**」という単位で組んである。
安いものだけ買えても、**その組み合わせでは戦えない。**
それどころか、

| 起きること | |
| --- | --- |
| 資源が減る | 買い直す元手まで削れる |
| 揃っていないことに気づかない | 押したら買えた、と思って前線へ出る |
| **戻す手段が無い** | 買ったものは売れない |

**押した結果が「半分だけ」になるのは、押す前に分からない。**
だから**買えないセットは、そもそも押せないようにする。**

### 1-1. なぜエンダーチェストからも払うのか

エンダーチェストは**奪われない金庫**（[01-rules.md](../01-rules.md) 4-3）。
そこに貯めた資源を使うために、いちいち取り出すのは無駄な手間。

**預けたものは、そのまま買い物に使える。**

## 2. 開き方

| 場所 | できること |
| --- | --- |
| **ロビーの `[マイセット]` 看板** | **登録だけ**（買えない） |
| **戦場のショップ店員** | 読み込み（買う）と登録 |

**ロビーでは買えない。** 試合前に資源を持っていないので意味が無い。

店員の画面では、**種別を選ぶ画面の下段**に `マイセット` を置く
（[12-shop.md](12-shop.md) 4-5）。
**戻り先を渡す**ので、買ったあとそのままショップへ戻れる。

## 3. 画面

**ショップと同じ盤面**（[12-shop.md](12-shop.md) 3-3）。

```
     ┌─────────────────────────────┐
     │ いまの合計  鉄 48 / 金 12       │  ← 上段に常に出す
     ├─────────────────────────────┤
     │ ■ ■ ■ ■ ■ ■ ■ ■ ■  鉄で買うもの   │
     │ ■ ■ ■ ■ ■ ■ ■ ■ ■  金で買うもの   │
     │ ■ ■ ■ ■ ■ ■ ■ ■ ■  ダイヤ        │
     │ ■ ■ ■ ■ ■ ■ ■ ■ ■  エメラルド     │
     ├─────────────────────────────┤
     │        [保存]  [戻る]           │
     └─────────────────────────────┘
```

### 3-1. 買えないセットは押せない（2026-08-25 追加）

**足りないセットは、見て分かる形で止める。**

| 買えるか | 見た目 | 押すと |
| --- | --- | --- |
| 買える | チェスト | 買う |
| **足りない** | **バリア**。何がいくつ足りないかを添える | **何も起きない**（理由を出し直すだけ） |

**押せてしまうと、押した人は買えたと思う。**
「足りないので買えません」と後から言うのでは、
**画面を閉じるまで気づけない。**

### 3-2. 合計を常に出す

**登録中、いまの合計を上段に置く。**

組んでいる途中で「いくらになるか」が分からないと、
**払えないセットを作ってしまう。**

## 4. 防具は自動で着る

**買った防具のうち、いちばん強い組み合わせを着る。**

| 部位 | 選び方 |
| --- | --- |
| 胴・脚・足 | **持っている中で最も硬いもの** |
| 頭 | **触らない**（チームの帽子で固定。[15-presentation.md](15-presentation.md)） |

着られなかったぶんは持ち物に残る。**捨てない。**

**店員から 1 つずつ買ったときも同じように着る**（[12-shop.md](12-shop.md) 4-4）。
実装は `lib/armor.ts` の 1 箇所に置く。**2 箇所に書くと必ず食い違う。**

---

## 5. どこに持つか

**プレイヤーの動的プロパティ。**

| なぜ | |
| --- | --- |
| 人ごとの設定である | 世界に持つ理由が無い |
| **試合をまたいで残したい** | セッションに紐づけない |
| ワールドを閉じても残る | バックアップに乗る |

**中身は JSON。** 品物の id と個数の一覧だけを持つ。
値段は持たない。**値段はショップ側で変わる**（[12-shop.md](12-shop.md) 5章）ので、
持つと食い違う。
