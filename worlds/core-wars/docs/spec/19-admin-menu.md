# 仕様: 設定メニュー

**運営の道具を 1 つにまとめる。**

---

## 1. なぜ要るのか

**ロビーが道具まみれで邪魔。**

運営の持ち物には、切り替えの札のほかに
「開始」「建築」「掃除」「状態」「値段」「マップ移動」が並んでいた
（[15-presentation.md](15-presentation.md) 7 章の頃の作り）。

| 困ること | |
| --- | --- |
| **枠を 7 つ占める** | 遊ぶ人と同じ状態で試すのに、持ち物が埋まっている |
| **増やすたびに枠が減る** | 機能を足すほど邪魔になる |
| どれが何か分からない | 名前を読まないと判別できない |

**コンパス 1 つにする。** 押すと設定が開く。

---

## 2. 何を置くか

| | すること |
| --- | --- |
| **試合を開始 / 停止** | いまの状態に応じて出し分ける |
| **自動開始** | 入 / 切。人が揃ったら**1 分後に自動で始める** |
| **チーム分け** | **自動 / 手動**の切り替え |
| **フェーズ** | **1 / 2 を直接指定する**（2026-08-25 追加） |
| **コアの数** | **開始時の数と、いまの残り**（2026-08-25 追加） |
| **プレイヤー管理** | 一覧から選んで、チーム変更・キック |
| **建築モード** | 自分だけマップを直せるようにする／戻す |
| **後片付け** | 置かれたものを消す |
| **状態を見る** | いまの進行状況 |
| **値段を編集** | ショップの値段 |
| **マップ移動** | 決まった場所へ飛ぶ |
| **モード切替** | サバイバル ↔ クリエイティブ |

**コマンドは残す。** メニューは入口が増えるだけで、
`/game:start` などが無くなるわけではない。

> **同じ処理を 2 回書かない。**
> メニューから呼ぶのも `runAdminCommand` の中身と同じものにする。

## 3. 誰が開けるか

**オペレーター権限を持っている人だけ。**

名前では決めない（[11-match.md](11-match.md) 6-D の教訓）。
持っていない人がコンパスを押しても何も起きない。

### いつ配るか

| 状態 | 配るか |
| --- | --- |
| 戦場に居ない（ロビー・観戦） | **配る** |
| 戦場に居て、**サバイバル** | **配らない** |
| 戦場に居て、**クリエイティブ** | **配る**（2026-08-25 追加） |

**試合に出ている最中は持たせない。**
間違って押して試合を壊す。

#### クリエイティブなら試合中でも配る（2026-08-25 追加）

**クリエイティブの運営は、遊んでいない。**

試合を見ながら回している最中こそ、
止めたい・チームを直したい・人を外したいが起きる。
そこで**ロビーへ戻らないと設定を開けない**のでは、道具の意味が無い。

> **サバイバルとクリエイティブで扱いを変える。**
> サバイバルで戦場に居るなら、その人は**プレイヤーとして出ている。**
> 誤操作の危険はそのまま残るので、配らない。

## 4. チーム分けの自動 / 手動

| | チーム分けの瞬間に |
| --- | --- |
| **自動**（既定） | 参加を選んだ人を**均等に振り分ける** |
| **手動** | **既に所属が決まっている人だけ**が試合に入る |

### なぜ手動が要るのか

**人を選んで組みたいことがある。**

腕前が偏っていたり、身内で分かれたいときに、
自動で振られると**やり直す手段が無い。**

### 手動のときの流れ

1. 設定 → プレイヤー管理 → その人 → **赤 / 青**を選ぶ
2. `/game:start`（または設定の「試合を開始」）
3. **所属が付いている人だけ**が戦場へ行く

**所属が付いていない人は、参加を選んでいても入らない。**
その旨をチャットで知らせる（黙って弾くと理由が分からない）。

### 覚えておく場所

**世界の動的プロパティ。** 試合をまたいで残る。

運営が「今日は手動でやる」と決めたなら、
**1 試合ごとに設定し直させるのはおかしい。**

## 5. 自動開始

**片付けが終わって 10 秒したら、開始ボタンを押したのと同じことをする。**

連戦させるための道具。
試合が終わる → 片付けが走る → **勝手に次が始まる。**

| | |
| --- | --- |
| 待つ長さ | **10 秒** |
| 走る条件 | **非開始**・**片付けが終わっている**・**人が居る** |
| 終わったら | **`/game:start` と同じ処理** |

### なぜ片付けの終わりを待つのか

**片付け中は始められない**（[11-match.md](11-match.md) 7-5）。
途中で始めると、始めたあとに片付けが走って
**新しい試合の物を消す。**

### なぜ 10 秒待つのか

**戻ってきた人が構える時間。**
片付けが終わった瞬間に始まると、
ロビーに着いた直後にまた飛ばされる。

### 知らせ方

**チャットに「10 秒後に始めます」と 1 行出すだけ。**

**黙って始めない。** 準備していない人が戦場へ飛ばされる。
ただし、それ以上は言わない。

#### カウントダウンはしない（2026-08-25 変更）

以前は残り 5 秒から画面に数字を出して音を鳴らしていたが、やめた。

> **連戦のたびに毎回入る。**
> 自動開始は**試合と試合の間に必ず走る**ので、
> ここに演出を置くと**ロビーに戻るたびに同じものを見せられる。**
>
> 開始そのもののカウントダウン（[15-presentation.md](15-presentation.md) 2 章）は
> 戦場へ送ったあとに 1 度だけ走るので、そちらは残す。

> **止まったことは黙って忘れる。**
> 片付けの最中に「取り消しました」と流れても、意味が無い。

## 5-A. フェーズを指定する（2026-08-25 追加）

**フェーズ 1 / 2 のどちらかを、その場で指定できる。**

| 押すと | どうなる |
| --- | --- |
| **フェーズ 1 にする** | 残り時間が**5 分に戻る。** コアは削れなくなる |
| **フェーズ 2 にする** | 残り時間が**0 になる。** すぐコアを削れる |

### なぜ要るのか

**試すたびに 5 分待てない。**

コア破壊まわりを直したとき、確かめるには
**フェーズ 2 に入っていないと何も起きない**（[11-match.md](11-match.md) 6-Z）。
毎回 5 分黙って待つのは、開発でも運営でも成立しない。

運営としても、**始めてみたら人数が少なくて 5 分が長すぎる**ことがある。
そのときに畳めるほうがよい。

### 黙って変えない

**指定でフェーズ 2 に入ったときも、いつも通りの合図を出す。**
タイトルと音と、チャットの 1 行（[11-match.md](11-match.md) 6-Z）。

> 時間で切り替わったのか、運営が押したのかは**遊ぶ側には関係ない。**
> 「削れるようになった」という事実だけが要る。
> **合図の出し方を 2 通り持たない。**

フェーズ 1 に戻したときも、戻したことを出す。
**削れていたものが急に削れなくなる**ので、言わないと壊れたと思われる。

## 6. プレイヤー管理

**一覧から 1 人選ぶと、その人にできることが出る。**

| | すること |
| --- | --- |
| **赤へ / 青へ** | 所属を変える。**試合中でもできる** |
| **所属を外す** | 試合から抜けさせる |
| **ロビーへ戻す** | 戦場から引き上げる |
| **タイムアウト（1 時間）** | **居てよいが、試合に入れない** |
| **キック** | 世界から追い出す |

### 表示

名前のほかに**いまの所属**を出す。
一覧を見ただけで、どちらが何人か分かるようにする。

### 所属を変えたら、持ち物を全部戻す

**組を変えるのは「別の人として入り直す」のと同じ。**

| | |
| --- | --- |
| 持ち物 | **空にする** |
| エンダーチェスト | **空にする** |
| 装備 | **外す** |
| 効果 | **全部消す** |
| 体力 | **戻す** |

前の側で買ったものを持ち越せると、
**両チームを行き来して溜め込める。**

そのうえで、**試合中ならその場で自陣へ移す**（敵陣のど真ん中に立たせない）。
支給品と帽子は入り直したときと同じものが配られる。

### 試合から外したときも同じ

**所属を外す・ロビーへ戻す**も、持ち物・効果・装備を全部戻す
（`features/lobby/reset.ts` の `resetToLobby`）。

**戻すべき状態は 1 つしかない**ので、入口が増えても同じ関数を通す。

### タイムアウト

| | |
| --- | --- |
| 長さ | **1 時間**（実時間） |
| できること | **世界には居られる。見ていてよい** |
| できないこと | **試合に入れない**（チーム分けも途中参加も弾く） |
| かけたとき | **所属も外す。** 入れないのに試合に居るのはおかしい |
| 解く | 同じところをもう一度押す |

**キックとの違いは「追い出すかどうか」だけ。**
荒らしを止めたいだけなら、追い出す必要は無い。

> **実時間で測る**（`Date.now()`）。
> tick で測るとサーバーが止まっている間は進まず、
> **1 時間と言って 1 時間で明けない。**
>
> **プレイヤーの動的プロパティに持つ。**
> メモリだと `/reload` で解除できてしまう。

### キック

**理由を添える。**
`/kick` が使えない環境（単独プレイなど）では**失敗したと伝える。**
黙って何も起きないのが一番困る。

## 7. コアの数（2026-08-25 追加）

**設定 → コアの数** で、2 つをまとめて直せる。

| | いつ効くか |
| --- | --- |
| **開始時のコア** | **次の試合から** |
| **いまの残り**（赤・青それぞれ） | **その場で** |

### なぜ 1 つの画面に出すのか

**分けて置くと、必ず取り違える。**

> 「開始時を変えたのに減らない」
> 「残りを変えたのに次の試合で戻った」

どちらも**別のつまみを回しただけ**だが、
別々の画面にあると**同じものだと思ってしまう。**
並べて出せば、どちらを触っているか迷わない。

### 開始時の数は 1 以上

**0 にすると、始まった瞬間に決着する。**
残りのほうは 0 にできる——**決着させたい場面がある**ため。

### どこに持つか

**世界の動的プロパティ。** 値段と同じ扱い
（[12-shop.md](12-shop.md) 5 章）。

**遊びながら何度も調整するもの**なので、コードの外に出す。
`/reload` でもワールドを閉じても残る。

## 8. コマンドの権限（2026-08-25 整理）

> ### 遊ぶ人が打てるのは 2 つだけ。

| コマンド | 誰が |
| --- | --- |
| `/game:team` | **全員**（味方だけに話す） |
| `/game:unstuck` | **全員**（視点が戻らなくなったときの逃げ道） |
| **それ以外すべて** | **運営だけ** |

### 段を 1 つに揃えた

以前は `GameDirectors` と `Admin` が混ざっていた。
**混ざっていると、どれが誰に使えるのか読んで分からない。**

**運営向けは全部 `Admin`** に揃えた。

### 段だけに頼らない

**進行に関わるコマンドは、こちらでも「運営か」を確かめる。**

権限の段は**ゲーム側の設定次第で動く**。
「運営か」の判断は 1 箇所に集めてある（`lib/op.ts`）ので、そこも通す。

> **二重でも困らない。**
> 片方が緩んでも、もう片方が止める。

## 9. ルール調整（2026-08-26 追加）

**遊び方の数値と決まりを、ゲームの中から変える。**

設定メニュー → **ルール調整**。

| 項目 | 既定 | 何が変わるか |
| --- | --- | --- |
| 自陣にブロックを置ける | 切 | 自分の拠点の中でも建てられる（敵陣は不可） |
| **頭上の表示を常に出す** | **切** | **名前・ロール・体力・マナが、見つけていなくても見える** |
| ガス無限 | 切 | ワイヤーのマナが減らない |
| フェーズ 1 の長さ | 5 分 | コアを削れない時間 |
| 復活までの時間 | 5 秒 | 倒れてから自陣に戻るまで |

### 足すのは 1 箇所

**`lib/rule-config.ts` の `RULES` に書くだけで画面に出る。**
画面の側（`features/admin/rules.ts`）は中身を知らない。

### 既定は「いつもの遊び方」

**何も触っていない状態が、本来のルール。**
調整は**足すもの**であって、初期値であってはいけない。

**動的プロパティなので消えない**——`/reload` でもワールドを閉じても残る
（[09-state-management.md](09-state-management.md) 4 章）。

### 9-A. 頭上の表示を常に出す（2026-08-28 追加）

**見つける遊びを止めて、全員が全員を見えるようにする。**

| | |
| --- | --- |
| 出るもの | **名前 / ロール / 体力 / マナ**（[15-presentation.md](15-presentation.md) 7-3） |
| 見え方 | **壁越しでも見える。** 見つけていなくても消えない |
| **しゃがむと** | **敵からは隠れる。味方には見える**（2026-08-28 追加） |
| 本人 | **自分のものは見えない**（見えても意味が無い） |

**しゃがめば隠れる。バニラの名札とまったく同じ振る舞いにする**（2026-08-28 修正）。

| しゃがんでいる間 | |
| --- | --- |
| **敵から** | **消える**——**見ている相手からも消える** |
| 味方から | **見える**（味方の位置が消えると、組んで動けない） |
| ダーツ・`/game:glow` | **出たまま**（相手が働いて得たもの） |

**「見えている相手だから出る」という理屈は、ここでは持ち込まない。**
この設定の間は**見つける遊びそのものを止めている**ので、
**姿勢だけで決まる**ほうが分かりやすい。

**普段の遊びでは切っておく。**
名前を消したのは**壁の向こうの相手まで分かってしまう**からで
（[15-presentation.md](15-presentation.md) 7-1）、常時表示はそれを崩す。

> 少人数での動作確認や、**ロールの違いを見せながら教える**ときに使う。

**ロールは常に出す**（この設定に関わらず）。
何ができる相手なのかは**ロールで決まる**ので、
名前だけ見えても**間合いを取るべきか踏み込むべきかが決められない。**
