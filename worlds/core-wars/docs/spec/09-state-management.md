# 仕様: 状態の持ち方

**何をどこに置くか**の決めごと。ここが散らかると、後から追えなくなる。

## 1. 方針（確定 / 2026-08-22）

**スコアボードとタグを使う。ただし単純で、あまり動かないものに限る。**

| 置き場所 | 何を置くか | 例 |
| --- | --- | --- |
| **スコアボード** | **数値**。単純で、頻繁には変わらないもの | コアの残数、チームの得点 |
| **タグ** | **所属や状態の印**。あるか無いかで足りるもの | どちらのチームか、試合中か |
| スクリプトの変数 | **複雑なもの・よく動くもの** | 進行中の細かい状態、一時的な計算 |

### なぜ分けるか

**スコアボードとタグは、ゲーム内から見える・触れる。**

- `/scoreboard` で今の状態を確認できる
- 手で直せる。試験中に値をいじって挙動を見られる
- **スクリプトが落ちても値が残る**

一方で、**細かく動くものを入れると破綻する。**

- 更新のたびにコマンド相当の処理が走る
- 履歴も型も無いので、複雑な構造は表現できない
- **毎 tick 書き換えるようなものは入れてはいけない**

## 2. 具体的な割り当て（初版）

| 値 | 置き場所 | 理由 |
| --- | --- | --- |
| コアの残数（各チーム） | **スコアボード** | 単純な数値。変わるのは壊されたときだけ |
| プレイヤーの所属チーム | **タグ** | あるか無いかで足りる |
| 試合中かどうか | **タグ**（またはスコアボード） | 状態が少ない |
| ジェネレータの位置 | **どこにも持たない** | ワールドのブロックが正（[01-rules.md](../01-rules.md) 2-3） |
| 湧きの残り時間 | スクリプトの変数 | **毎 tick 動く。** スコアボードに入れてはいけない |
| 買い物の在庫・値段 | スクリプトの定数 | 変わらない |
