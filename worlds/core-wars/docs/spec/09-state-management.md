# 仕様: 状態の持ち方

**何をどこに置くか**の決めごと。ここが散らかると、後から追えなくなる。

## 1. 方針（確定 / 2026-08-22）

**スコアボードとタグを使う。ただし単純で、あまり動かないものに限る。**

| 置き場所 | 何を置くか | 例 |
| --- | --- | --- |
| **スコアボード** | **数値**。単純で、頻繁には変わらないもの | コアの残数、チームの得点 |
| **タグ** | **所属や状態の印**。あるか無いかで足りるもの | どちらのチームか、試合中か |
| スクリプトの変数 | **複雑なもの・よく動くもの** | 進行中の細かい状態、一時的な計算 |

### なぜ分けるか

**スコアボードとタグは、ゲーム内から見える・触れる。**

- `/scoreboard` で今の状態を確認できる
- 手で直せる。試験中に値をいじって挙動を見られる
- **スクリプトが落ちても値が残る**

一方で、**細かく動くものを入れると破綻する。**

- 更新のたびにコマンド相当の処理が走る
- 履歴も型も無いので、複雑な構造は表現できない
- **毎 tick 書き換えるようなものは入れてはいけない**

## 2. 具体的な割り当て（初版）

| 値 | 置き場所 | 理由 |
| --- | --- | --- |
| コアの残数（各チーム） | **スコアボード** | 単純な数値。変わるのは壊されたときだけ |
| プレイヤーの所属チーム | **タグ** | あるか無いかで足りる |
| 試合中かどうか | **タグ**（またはスコアボード） | 状態が少ない |
| ジェネレータの位置 | **どこにも持たない** | ワールドのブロックが正（[01-rules.md](../01-rules.md) 2-3） |
| 湧きの残り時間 | スクリプトの変数 | **毎 tick 動く。** スコアボードに入れてはいけない |
| 買い物の在庫・値段 | スクリプトの定数 | 変わらない |

## 3. 実際にはこうなった（2026-08-25 追記）

**スコアボードとタグではなく、動的プロパティ（dynamic property）に置いている。**

初版を書いた時点では Script API v2 の動的プロパティを検討していなかった。
実装してみると、こちらのほうが素直だった。

| | |
| --- | --- |
| 型がある | 数値・真偽値・文字列をそのまま置ける |
| 持ち主が決まる | **世界に置くか、人に置くか**を選べる |
| 名前で衝突しない | `cw:` を頭に付けている |

スコアボードは**表示のためだけ**に使っている（[15-presentation.md](15-presentation.md) 5 章）。

## 4. `/reload` で消えてよいもの・いけないもの（2026-08-25 追加）

> ### 試合の状況と、人の状況は、`/reload` をまたいで残ること。

`/reload` は**試合中にも打つ。** 直してすぐ試すのが開発の常なので、
「読み込み直したら試合が壊れた」は起きてはいけない。

### 判断のしかた

| 種類 | どこに置くか |
| --- | --- |
| **人が決めたこと**（所属・参加の意思・設定・締め切り） | **動的プロパティ** |
| **積み上がった結果**（コアの残り・戦績・ストリーク・ガス・吸収） | **動的プロパティ** |
| **数 tick で作り直せるもの**（視認・ワイヤー・被弾の計算） | メモリ |
| **走っている処理の札**（掃除中・走査中） | メモリ。**消えるのが正しい**（処理ごと消えるので） |
| **通知の間引き**（同じ文を連発しないための記録） | メモリ |

> **「消えても作り直せるか」で決める。**
> 作り直せないものは、人の操作か、積み上がった結果のどちらか。

**導けるものは持たない。**
状態から計算できる印を別に持つと、**二重になって必ずずれる。**

### 残すと決めたもの

| | 残さないと何が起きるか |
| --- | --- |
| 試合の状態・セッション・コアの残り | 試合が消える |
| 所属チーム | 全員が無所属になる |
| フェーズの残り | フェーズ 1 に戻る |
| 戦績・キルストリーク | 数字が飛ぶ |
| ガス | 満タンに戻る |
| 参加の意思 | 「入らない」を選んだ人が、また入る側に戻る |
| 設定（自動開始・チーム分け）・タイムアウト・値段・ロビー座標 | 設定し直しになる |
| **観戦中かどうか** | **観戦のまま迷子になる**（抜け方が効かない） |
| **増えている体力（金リンゴ）** | 頭上の表示が実際とずれる |
| **建築モード** | 直している最中に、黙って守られる側に戻る |

### 残さないと決めたもの

| | なぜ |
| --- | --- |
| 置かれたブロックの位置 | **数万マスになる。** 動的プロパティに入らない。**種類での掃き取りが保険**（[11-match.md](11-match.md) 7 章） |
| 参加の締め切り | **状態から導ける。** 締め切っているのは「準備中か試合中」のときだけなので、持つ必要が無い |
| 開始処理中 / 決着演出中 | 演出そのものが消えるので、残ると**戻れなくなる。** `/game:abort` からやり直す |
| 炎の見張り | 30 秒の保険。消えても [10-block-protection.md](10-block-protection.md) の修復が効く |
