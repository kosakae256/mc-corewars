# 仕様: ドローン

**2026-08-25 に起こした。書きかけ。**

---

## 1. 何をするものか

> ### 飛ばして、見て、落とす。

| | |
| --- | --- |
| **操作** | プレイヤーが動かす。一人称。**体は地上に残る**（2 章） |
| **視認** | ドローンが見つけた敵は、**味方全員に名前が見える** |
| **ダーツ** | 敵に撃ち込むと、**しばらく見え続ける** |
| **ファイヤーチャージ** | 持ち物にあるものを**ドローンから撃つ** |
| **TNT** | 持ち物にあるものを**その場に落とす** |
| チームの色 | **分けない** |

### 何のための道具か

**上から見る手段と、上から落とす手段。**

地上は遮蔽だらけで、**どこに誰が居るか分からない**まま撃ち合っている。
ドローンは**その霧を晴らす**役だが、
晴らしている間は**自分が何もしていない**という代償を払う。

## 2. 体は地上に残る（2026-08-25 決定）

> ### 飛ぶのは視点だけ。体は置き去りになる。

| | |
| --- | --- |
| 体 | **その場に立ったまま。** 動けない |
| 撃たれたら | **普通に減る。** 守るものは何も無い |
| 視点 | ドローンの位置へ移る |

**代償を先に払う形にする。**

上から見ている間、**自分は無防備に突っ立っている。**
「どこで上げるか」「いつ降りるか」が、そのまま判断になる。

> 乗り物にすると**本人ごと空へ行く**ので、
> 見ている間も戦えてしまい、**代償が無くなる。**

### 作りが重いのは承知のうえ

バニラには**乗り物として飛ばす部品**が揃っている
（`minecraft:rideable` + `minecraft:free_camera_controlled`。
ハッピーガストが使っている）。
**乗せてしまえば操作感はゲーム側が持ってくれる。**

体を残すなら、**視点も入力も自前**になる。

| 何を自分で作るか | 使うもの |
| --- | --- |
| 視点をドローンへ移す | `Player.camera.setCamera("minecraft:free", { location, facingLocation })` |
| 体を動かさない | `player.inputPermissions.setPermissionCategory(Movement, false)` |
| 進む向きを取る | `player.inputInfo.getMovementVector()`（前後左右） |
| 見る向きを取る | `player.getRotation()` |
| 上下する | `inputInfo.getButtonState(Jump / Sneak)` |

### 操作の割り当て

| 入力 | 何が起きるか |
| --- | --- |
| **マウス** | 機体の向きが変わる |
| **W / S** | 向いている方へ進む・下がる |
| **A / D** | 横へずれる |
| **ジャンプ** | 上がる |
| **スニーク** | 下がる |
| **もう一度右クリック** | **戻る**（体に視点が返る） |

**上下をジャンプとスニークに割り当てる**ので、
**降りる操作は別に要る。** 出したのと同じ操作で戻すのが分かりやすい。

### 進む向きは「見ている向き」

**マウスで向きを変え、W で進む。** 飛行機ではなく、**歩くのと同じ感覚。**

上を向いて W なら上へ進む。**ジャンプとスニークは、向きを変えずに高さだけ変える**ためのもの。

### 確かめた結果（2026-08-25）

| | 結果 |
| --- | --- |
| カメラを移した状態でマウスが効くか | **効く。向きは滑らか** |
| `Movement` を切っても入力が読めるか | **読める** |
| `minecraft:free` は使えるか | **使える**（位置を渡す形だけ） |
| **視点の移動が滑らかか** | **ならない**（下記） |

### 視点だけ飛ばすと、必ずガタつく

**スクリプトは 1 秒に 20 回しか動けない。** 描画はもっと細かい。
位置を渡す形では、**カメラは 20 回/秒で飛ぶ。**

| 試したこと | 結果 |
| --- | --- |
| 機体をテレポートから速度へ変える | **変わらない**（カメラ側の問題） |
| `easeOptions` で間を埋める | **入力が効かなくなる** |
| 実体にカメラを貼る（`targetEntity`） | **`free` は無反応、`follow_orbit` はプレイヤーに付く** |

詳しくは [research/13](../../../../docs/research/13-scripted-camera.md)。

> ### 滑らかなカメラは、プレイヤー自身のカメラだけ。

**「視点だけ飛ばす」は、滑らかにはできない。**

滑らかにしたいなら、**プレイヤー本人を飛ばす**しかない。
体を残したいなら、**残すのは本人ではなく身代わり**になる（7-2）。

## 3. 視認

**プレイヤーの視認と同じ仕組みに合流させる**
（[15-presentation.md](15-presentation.md) 7-3）。

| | |
| --- | --- |
| 条件 | **プレイヤーと同じ**（角度・距離・遮蔽） |
| 見つけたら | **その敵の名前と体力が、操縦者の味方全員に見える** |
| 壁の向こう | **見えない** |

**別の仕組みを作らない。**
「誰が見つけたか」を持つ場所は既にあるので、そこにドローンを足す。

条件を変えないのは、**どちらの目で見つけたかで挙動が変わると分からなくなる**から。

### 共有はドローンだけの特権ではない（2026-08-26 変更）

| | 誰に見えるか |
| --- | --- |
| プレイヤーが見つけた | **その組の全員**（[15-presentation.md](15-presentation.md) 7-3） |
| ドローンが見つけた | **同じ** |

**見つけた情報を本人だけに留める理由が無い**ので、共有は全員の決まりにした。

#### では、ドローンの値打ちは何か

**高さと射程。**

| | |
| --- | --- |
| 目の高さ | **好きなだけ上げられる**（人は地面を走る） |
| 見える範囲 | **遮蔽の向こう側へ回り込める** |
| 代償 | **本人は棒立ち**（2 章） |

「組で共有できること」ではなく、**そもそも人の目では届かない所を見ること**が値打ち。

### 機体にも名札が出る（2026-08-25 追加）

**`ばーど のドローン`** と、機体の上に出る。

| 相手 | 何が見えるか | いつ |
| --- | --- | --- |
| **味方** | **`ばーど のドローン`** | **常に**（誰の機体かが分かる） |
| **敵** | **`敵のドローン`** | **見つけている間だけ**（プレイヤーと同じ条件） |
| 本人 | **出さない** | —（自分の機体だと分かっている） |

**敵に持ち主の名前は渡さない。**
誰の機体かは**味方の中でだけ意味がある**情報で、
敵には「敵の機体がそこに居る」以上のことは要らない。

実体の名札は**全員に同じものが出る**ので使えない。
プレイヤーの頭上表示と同じ仕組みで、**人ごとに出し分ける。**

#### 色は「その機体の所属」（2026-08-25 修正）

**敵の機体は、赤ではなく、その機体のチームの色で出す。**

赤で固定していたので、
**赤チームから見た青の機体まで赤く出ていた。**
自分の側の色が敵に付くのは、混戦では致命的に紛らわしい。

プレイヤーの頭上表示は**その人自身のチームの色**で出している
（[15-presentation.md](15-presentation.md) 7-3-A）。**同じ規則にそろえる。**

> 所属が分からないとき（試合をしていない間）だけ**赤**にする。
> 色で伝えられることが無いので、**敵という意味の赤**を使う。

### 照準を自分で置く

**カメラを移すと、画面の真ん中の印が出ない。**
どこを狙っているのか分からないので、**見ている先に小さな印を置く。**

**本人にだけ見せる。** 他の人の画面に出ては困る。

### 操縦している人には印が出る

**味方から見て、その人の名前の横に `[操縦中]` が出る。**

飛ばしている間、その人は**立っているだけで何もできない。**
味方から見て**守るべき相手**だと分かる必要がある。

## 3-A. 当たり判定は見た目より大きい（2026-08-25 追加）

**縦・横・高さをそれぞれ 2 倍にする**（体積で 8 倍）。

| | 見た目・ぶつかり | **当たり判定** |
| --- | --- | --- |
| 横 | 0.9 | **1.8** |
| 高さ | 0.4 | **0.8** |

### なぜ大きくするのか

**機体は小さく、空に浮いていて、動いている。**

体力 1 で落ちるのに、**当てること自体が難しい**のでは、
上げっぱなしが最適手になってしまう。

> **上げる代償は「本人が棒立ちになること」**（2 章）。
> 落とす側の難易度が高すぎると、その代償が代償にならない。

### ぶつかり判定は変えない

**`minecraft:custom_hit_test` を使う。**
これは**殴り・飛び道具・狙いの当たり判定だけ**を差し替える部品で、
`minecraft:collision_box`（＝物としてのぶつかり）はそのまま。

collision_box を大きくすると、

- **機体が壁や隙間に入らなくなる**（飛ばす感触が変わる）
- **味方の足場としての形も変わる**（4-A）

**変えたいのは「当てやすさ」だけ**なので、そこだけを触る。

> **JSON なので `/reload all` が要る**（`docs/research/02-hot-reload.md`）。

## 4. ダーツ

**敵に撃ち込むと、しばらく見え続ける。**

見つけ続けるには**ドローンが見ていなければならない**が、
ダーツは**刺さっている間、見ていなくても見える。**

> ドローンは**落とされる。**
> 落とされた後に何も残らないなら、**上がる意味が薄い。**
> ダーツは**成果を持ち帰る**ための手段。

### 撃ち方（2026-08-26 改定）

| | |
| --- | --- |
| 操作 | **剣を持って右クリック** |
| 使うマナ | **5**（当たっても外しても同じだけ減る） |
| 届く距離 | **30 マス**（そこで消える） |
| 当たると | **ダメージ 1** と**名札 1 分** |
| 味方 | **効かない** |
| **敵の機体** | **落ちる**（体力 1。5-A） |

**剣を持っているときだけにした。**
以前は「他の何かを持っていれば撃つ」だったので、
**撃つつもりのない右クリックでも飛んでいた。**
持ち替えが、そのまま**撃つ構え**になる。

### 飛ぶものにした（2026-08-26 変更）

はじめは**視線と相手の距離**で当たりを決めていた。
だが**撃ったことが分からなかった**——
飛ぶものも、当たった手応えも、外れた理由も無い。

> **速い投げ物にする。**
> 飛んでいくものが見えれば、**当たったかどうかは目で分かる。**

| | |
| --- | --- |
| 実体 | **専用の投げ物**（`game:dart`。**姿は描かず、粒で見せる**） |
| 速さ | **5 マス/tick**（矢より速い） |
| 重力 | **無し**——30 マス先まで**まっすぐ飛ぶ** |
| 消えるまで | **6 tick**（5 × 6 ＝ 30 マス） |
| **ノックバック** | **無し** |
| 素のダメージ | **0**（1 は script で入れる） |
| 撃った音 | 弓 |
| 当たった音 | 矢の命中 |

**効くのはこちらで入れる分だけ。** 投げ物そのものは何もしない。

### 雪玉は使わない（2026-08-26 変更）

はじめは雪玉を飛ばしていたが、**当たると相手が吹き飛ぶ。**

かといって**雪玉そのものを直すわけにはいかない**——
店で売っている雪玉は、**弾き飛ばすために売っている**
（[12-shop.md](12-shop.md)）。

**同じものを直せば、別の用途まで巻き添えになる。** 専用の投げ物を作る。

### 見た目は粒で描く（2026-08-26 決定）

**模型はやめた。** 三度やって、三度とも駄目だった。

| 試したこと | どうなったか |
| --- | --- |
| アイテムの絵を板で貼る（`item_sprite`） | **矢のアイテムが平たいまま飛ぶ。** 見苦しい |
| 矢の模型を借りる（`geometry.arrow`） | **途中で横を向く**——`animation.arrow.move` は `query.target_*_rotation` で向けており、狙う相手が無いと 0 になる |
| 投げた槍と同じ形（模型とテクスチャだけ） | **何も描かれない** |

> **見えることが目的なら、粒で描けばいい。**

**向きの問題も、模型の粗さも、そもそも起きない。**

| | |
| --- | --- |
| 実体 | **描かない**（当たり判定だけを持たせる） |
| 見え方 | **水色の点が尾を引く**（`game:dart_trail`） |
| 点の間隔 | 1 tick を **6 等分**——5 マス進むので、点だけでは線に見えない |
| 点の寿命 | **0.1 秒**（2 tick）。**残ると、通った跡が長く居座る** |

**壁に当たったときの音も消した**（`sound_volume` 0）。
実体が壊れる音が鳴っていた。

### 自分には当たらない（2026-08-26 修正）

体は地上に置いたまま、機体から撃つ。
**機体が自分の真上に居ると、自分の雪玉が自分に落ちてくる。**
撃った本人には**効かない**ことにする。

### 刺さっている間

| | |
| --- | --- |
| 長さ | **1 分** |
| 見え方 | **名札が出たままになる**（見ていなくても、壁越しでも） |
| ダメージ | **当たった瞬間の 1 だけ**（刺さっている間は減らない） |
| 倒れたら | **抜ける** |

倒れて抜けるのは、**死んでも位置が漏れ続けると復活の意味が無い**から。

## 4-A. ワイヤーを刺せる（2026-08-25 追加）

> ### ドローンは、ワイヤーの的になる。

**敵味方どちらの機体にも刺さる。**

| 誰の機体か | 刺すと |
| --- | --- |
| **味方** | 刺さる。**何も起きない**（足場として使える） |
| **敵** | **刺した 0.5 秒後に落ちる** |

### 落ちるのは「掛けた時点」から（2026-08-26 変更）

以前は**引いてから 0.5 秒**だった。

> **刺してから引かない、という選択が生まれていた。**
> 刺さっているのに何も起きない時間ができ、
> **当てた側が「効いたのか」分からない。**

**掛けた時点で決まる。** 引くかどうかは、その後の自分の移動の話。

> 0.5 秒の間があるのは**見た目のため。**
> 線が届いて、それから落ちる。

### 当たり判定は 2 倍（2026-08-26 追加）

**機体は小さく、空を速く動く。**

3-A で殴り・飛び道具の判定を 2 倍にしたのと同じ理由で、
**ワイヤーの判定も 2 倍の箱で見る。**

| | 実際の大きさ | ワイヤーの判定 |
| --- | --- | --- |
| 横 | 0.9 | **1.8** |
| 高さ | 0.4 | **0.8** |

#### ゲーム側の判定は使わない

`getEntitiesFromRay` は**実際の大きさでしか当たらない。**
25 マス先の小さな的に線を当てるのは無理がある。

**箱との交差を自分で計算する**（`features/grapple` の `rayBox`）。
こうすると `custom_hit_test` が効くかどうかにも左右されない。

### 動く的

**刺した点は機体に付いていく。**
その場に固定すると、**機体だけ先に行ってしまう。**

機体が消えたら（落とされた・片付けられた）、**ワイヤーは切れる。**

> **動くものに刺すのは、これが初めて。**
> それまでブロックにしか刺していなかったので、
> **点を毎 tick 合わせ直す**仕組みを足した。

## 5. 持ち物から撃つ・落とす

**ドローンは弾を持たない。** 撃つのも落とすのも、**乗っている人の持ち物から。**

| | |
| --- | --- |
| ファイヤーチャージ | **ドローンの位置から撃つ**（地上と同じ弾） |
| TNT | **その場に落とす**（置いた瞬間に着火する。[03-content.md](../03-content.md) 1-4） |

**持っていなければ何も起きない。**
ドローンに乗れば強くなるのではなく、**持ち込んだものが上から使える**だけ。

### 出どころは機体（2026-08-25 実装）

**本人は地上に立っている。** そのままだと**足元から出てしまう。**

| | どこから |
| --- | --- |
| ファイヤーチャージ | **機体の前から、見ている向きへ** |
| **雪玉** | 同じ |
| **支柱弾** | 同じ |
| TNT | **機体の真下へ落とす**（投げない） |

**機体の中からではなく、少し前から出す。** 中から出すと**自分の機体に当たる。**

### 使えないもの

| | なぜ |
| --- | --- |
| **エンダーパール** | **空から投げると、どこへでも一瞬で入れてしまう** |

### 押しっぱなしで連射しない

**ブロックに向けた右クリックは、押している間ずっと届く。**
そのままだと**TNT が一瞬で全部消える**（2026-08-25 の指摘）。

**0.3 秒の間隔**を空ける。

これは強さの調整ではない。**同じ 1 押しを 1 回に数えるための仕掛け。**
人の連打は 0.3 秒より速くはならない。

> **「使う」ボタンの押し下げは読めない**（`InputButton` は Jump と Sneak だけ）。
> 押しっぱなしと連打は**時間でしか分けられない。**

TNT は**その場に落とすだけ。** 上から落とすのがこの道具の役なので、
狙って投げる必要が無い。

置いた瞬間に着火するのは地上と同じ（[03-content.md](../03-content.md) 1-4）。

### 導火線は「着地から 4 秒」（2026-08-28 変更。6 → 4）

**ドローンから落とした分も、手で置いた分も同じ**（2026-08-26 変更）。

高い所から落とすと、**落ちている間に燃え尽きる。**
着いてから数えれば、**どこから落としても同じ 4 秒。**

決まりと仕組みは [03-content.md](../03-content.md) 1-4 に置いてある。

## 5-D. 空から使うものには、マナを払う（2026-08-26 改定）

> ### 空からは、撃ち返されない。

機体は**高い所に居て、狙って落とすのが難しい**（3-A）。
そこから連射できると、**撃ち合いにならないまま押し切れる。**

**以前は待ち時間（CT）で釣り合いを取っていた。**
ロールを入れたときに**マナへ寄せた**（[24-role.md](24-role.md) 4-3）。

> **待ち時間は「待てば戻る」。** 空にいる限り、待つのは損ではない。
> **マナは減ったら戻らない**——動かすためにも要る。
> **同じ資源を、動くことと撃つことで取り合わせる。**

| | 使うマナ |
| --- | --- |
| 機体を出す | **50** |
| **TNT** | **30**（2026-08-28 変更。50 → 30） |
| **ファイヤーチャージ** | **15** |
| **支柱弾** | **10** |
| 雪玉 | **3** |
| **ダーツ** | **5**（剣を持っているときだけ。4 章） |

**待ち時間は無い。** 出せるかどうかは**残りマナだけ**が決める。

### 飛ばしている間は減らない（2026-08-28 変更）

| | |
| --- | --- |
| 動かしている間 | **減らない** |
| 止めている間 | 同じ |
| 回復 | **どちらも普通に回復する**（1 秒で約 3） |

動かしている間だけ 0.1／tick 取っていたが、**やめた。**

> **上げている間ずっと減ると、動かすこと自体をためらう。**
> 決めさせたいのは**上げるかどうか**であって、
> **飛ばし方を渋らせたいわけではない。**

**値段は出すときに付ける**（上の表）。
本人は地上で棒立ちなので、**居座る代償はもう払っている**（2 章）。

### 残りは足元ではなく、経験値の帯に出す

マナの表示は**経験値の段と帯**に移した（[13-grapple.md](13-grapple.md)）。
**カメラを空へ移すと隠れる**ので、操縦中は毎 tick 出し直している。

## 5-B. 出し方と戻り方（2026-08-25 決定）

**ショップで買うアイテム。** ダイヤ 5。

| | |
| --- | --- |
| 使うと | **機体を出して、操縦に入る** |
| 既に機体があるなら | **その場所から再開する**（出し直さない） |
| 落とされたら | **アイテムも終わり**（無くなる） |

**アイテムは「その機体の遠隔操作」。** 機体が死ねば、操作するものが無くなる。

### 戻り方

| | |
| --- | --- |
| **スニーク + ジャンプを 1 秒** | 自分から降りる |
| **ドローンを右クリック** | 同じ（持ち替えずに降りられる） |
| **体を殴られた** | 強制的に戻される |
| 機体が落とされた | 戻される（アイテムも消える） |

**降りても機体はその場に残る。** また使えば**そこから再開できる。**

> **置いてきた機体は狙われる。**
> 見張りとして置きっぱなしにできるが、**見つかれば壊される。**
> どこに置いて降りるかが、そのまま判断になる。

#### 飛んでいる間も物を拾える（2026-08-26 変更）

**味方が物を渡せる。**

以前は拾えなくしていた。本人は空を見ているので、
**足元で何が起きているか分からない**まま拾うのは筋が通らない、と考えていた。

> だが上げている間、その人は**棒立ちで無防備**（2 章）。
> **面倒を見るのは味方の仕事**で、**弾を足してやることもその一部。**

敵の落とし物まで拾ってしまうが、**そこに立っているのは本人の判断。**

#### なぜ殴られたら戻るのか

**飛ばしている間、本人は棒立ち。**
気づかないまま削られては、**何が起きたのか分からないまま倒れる。**

**殴られた時点で必ず体に戻す。** 戦うか逃げるかは、そこから選ぶ。

#### 味方には壊せない（2026-08-25 追加）

**機体は体力 1。** 当たれば必ず落ちる。

混戦の中で振った剣が当たるだけで、**その人のダイヤ 5 が消える。**

| 誰が | 壊せるか |
| --- | --- |
| 敵 | **壊せる** |
| 味方 | **壊せない** |
| **持ち主本人** | **壊せない** |

**手段は問わない**（殴りも、矢や雪玉も）。
体力 1 では「殴りだけ止める」では足りない。

判断は味方判定 1 箇所に寄せてある（[11-match.md](11-match.md) 5-1）。

> **敵のワイヤーで落ちるのは別**（4-A）。
> あれはダメージではなく、**引かれた 0.5 秒後に落とす**仕掛け（4-A）。

#### 自分の機体は自分に見えない

**カメラを機体の少し前に置く。**

実体を**人ごとに隠す手が無い**ので、
機体の中にカメラを置くと**自分の羽根が視界でちらつく。**
前へ出せば、**後ろにある物は映らない。**

#### なぜスニーク + ジャンプなのか

**どちらも飛ぶのに使う。** 片方だけだと、動かしている最中に降りてしまう。
**両方同時に 1 秒**は、飛んでいる間には起きない組み合わせ。

## 5-C. 戻れなくなったときの逃げ道（2026-08-25 追加）

**`/game:unstuck`。誰でも使える。**

視点が機体に貼り付いたまま戻らなくなったら、これで自分の視点を戻す。

| | |
| --- | --- |
| 誰が使えるか | **全員**（取り残されるのは運営とは限らない） |
| 飛んでいる記録が無くても | **効く** |
| 何が戻るか | **視点と、体の止め**の両方 |

### なぜ要るのか

**視点を戻す経路が多い。**
落とされた・殴られた・倒れた・降りた・`/reload` した——
どれか 1 つでも取りこぼすと、**その人は何もできなくなる。**

経路を全部塞ぐ努力は続けるが、**塞ぎ切れたことは証明できない。**
**最後の逃げ道を 1 つ置いておく。**

> 記録が消えていても効くようにしてある。
> `/reload` で飛行の記録は消えるが、**視点と体の止めは消えない**——
> **そこが一番取り残されやすい。**

## 5-A-2. 落下では壊れない（2026-08-26 修正）

**地面に降りると落下ダメージで墜落していた。**

機体は**重力を持たない**（`has_gravity: false`）が、
**下へ動かした分は落下距離として積まれる。**
体力は 1 なので、**降りた瞬間に必ず死ぬ。**

> **降ろせない乗り物は使えない。**

`minecraft:damage_sensor` で**落下だけ効かなくする。**
殴られれば 1 で落ちるのは変わらない（5-A）。
