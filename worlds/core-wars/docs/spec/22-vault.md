# 仕様: 金庫

**2026-08-25 に決めた。**

---

## 1. 何をするものか

> ### 鉱石を預けて、持ち物を空ける。
> ### **引き出せない。ショップでしか使えない。**

| | |
| --- | --- |
| 預けられるもの | **鉄・金・ダイヤ・エメラルド**の 4 種 |
| 預け方 | **看板を押す**（一括） |
| 引き出し | **できない** |
| 使い道 | **ショップの支払いだけ** |
| 試合をまたぐか | **またがない。参加のたびに 0 に戻す** |

### なぜ要るのか

**エンダーチェストが鉱石まみれになって邪魔。**

エンダーチェストは**奪われない置き場**（[01-rules.md](../01-rules.md) 4-3）だが、
**装備や建材を置く場所でもある。**
そこへ資源を積むと、**本来しまいたいものが入らなくなる。**

金庫は**枠を持たない。** 数字として持つだけなので、いくら預けても場所を取らない。

### なぜ引き出せないのか

**取り出せると、ただの安全な倉庫になる。**

引き出せるなら、**死ぬ前に預けて、復活してから出す**のが常に正解になり、
落とし合いという駆け引きが消える。

**買うことにしか使えない**なら、
「いま買うか、貯めてから買うか」という**選択が残る。**

> **失わない代わりに、使い道を狭める。** これで釣り合う。

### なぜ試合をまたがないのか

**次の試合が「前の試合の続き」になってはいけない。**

前回たくさん貯めた人が、**開幕から装備を揃えられる**ようでは、
1 試合ごとに区切っている意味が無い。

**参加処理で必ず 0 に戻す**（[11-match.md](11-match.md) 7-1）。
持ち物とエンダーチェストを空にするのと**同じ場所で、同じ理由**で行う。

### いつ 0 になるか

**「持ち物を空にするとき」は、必ず金庫も空にする。**

| 場面 | 空になるか |
| --- | --- |
| 試合開始のチーム分け | **なる** |
| **途中参加**（看板） | **なる** |
| **運営が組を変えた**（入れ替わり） | **なる** |
| 運営が所属を外した | **なる** |
| 試合終了 → ロビーへ戻る | **なる** |
| 抜けて入り直した | **なる**（もう一度参加処理を通る） |
| **倒れた** | **ならない** |

**倒れても消えないのが金庫の値打ち。**
そこが消えるなら、預ける意味が無い。

> **抜け道を残さない。**
> 組を変えて往復すれば溜め込める、が成り立ってはいけない。
> だから**「入り直し」と名の付くものは、すべて 0 にする。**

## 2. 預け方

**自陣の金庫の看板を押す。**

| 看板 | 誰が使えるか |
| --- | --- |
| `[金庫赤]` | **赤チームだけ** |
| `[金庫青]` | **青チームだけ** |

### 敵陣の金庫は使えない

**看板ごとに所属を持たせる。**

金庫は**自陣まで戻って預ける**もの。
敵陣で預けられると、**攻め込んだ先で資源を安全にできてしまう。**

> **前線から戻る理由をひとつ作る。**
> 溜め込んだまま戦い続けると落としたときに全部失う——
> だから一度戻る。その往復が駆け引きになる。

**所属が合わなければ、理由を出して断る。**
黙って何も起きないと、壊れていると思われる。

**試合に出ていない人も使えない。** 所属が無いので、どちらの看板とも合わない。

### 押すと何が起きるか

押した瞬間、**持ち物にある 4 種の鉱石を全部**預ける。

| | |
| --- | --- |
| 選ばせない | **何をいくつ、を選ばせると手間**。全部でよい |
| エンダーチェストからは取らない | あちらは**自分で置いた物。** 勝手に動かさない |
| 何も無ければ | **その旨を出す。** 黙って何も起きないのが一番困る |

預けたら、**何をいくつ預けたかと、いまの残高**を出す。

### 看板はどこにでも置ける

**座標を持たない。** 看板の文字で見分ける
（[16-participation.md](16-participation.md) 4 章と同じ作り）。

**どちらのチームのものかも、看板の文字で決まる。**
置いた場所では決めない——拠点の範囲を別に持つと、**必ずずれる。**

置いた数だけ増える。

## 3. 使い方

**ショップとマイセットの支払いに、自動で使われる。**

押す前に別の操作をさせない。**持っている額として合算する。**

### 払う順番

| 順 | どこから |
| --- | --- |
| 1 | **金庫** |
| 2 | 持ち物 |
| 3 | エンダーチェスト |

**金庫から先に使う。**

引き出せない以上、**残っても何にもならない。**
手持ちを先に使うと、**金庫が余ったまま試合が終わる**ことになる。

> 手持ちは落とせば奪われるが、**それは持ち主が判断すること。**
> 使い道の無い金から先に消すのは、迷う余地が無い。

## 4. 残高の見せ方

**ショップの画面の見出しに出す。**

```
     ショップ  鉄12 金3
```

| | |
| --- | --- |
| **0 のものは出さない** | 4 種すべて並べると長い |
| 全部 0 なら | **何も出さない** |
| **「金庫」と名乗らない** | 数字が読めれば足りる |
| **種別の名前も出さない** | 並んでいる品物を見れば分かる。書くと幅を取るだけ |

**名前は短く書く**（`エメラルド` ではなく `エメ`）。
4 つ並べても 1 行に収まるように。

### 看板を押したときは足元の行に出す

**ワイヤーのガス残量と同じ場所**（画面下、持ち物の上）。

```
     鉄12   金3   ダイヤ1   エメ0
```

**画面の真ん中に出すほどのことではない。**
題も副題も、**手を止めさせる**表示。金庫は**数を見に来ただけ**なので、
そこまでの割り込みは要らない。

「金庫」と名乗らない——押した本人は金庫を押しているので、
**名乗られても情報が増えない。**

**ガスの残量より強く出す。** ワイヤーを持っていても数秒はこちらが残る。

| | |
| --- | --- |
| **4 種すべて出す** | 0 のものも。**並びが毎回変わると、どこを見ればよいか分からない** |
| **預けるものが無くても出す** | **数を確かめに来ることもある。** 空振りにしない |

見出しに出すぶん（0 を省く）と扱いが違うのは、**用途が違う**から。
見出しは**ついでに目に入るもの**、副題は**見に来たときの答え。**

## 5. どこに持つか

**プレイヤーの動的プロパティ。**

`/reload` でもワールドを閉じても残る
（[09-state-management.md](09-state-management.md) 4 章）。

**積み上がった結果**なので、消えてはいけない側。
消すのは**参加処理のときだけ。**
