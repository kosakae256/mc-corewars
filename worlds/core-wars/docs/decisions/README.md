# 決定記録

**「なぜそうしたか」を残す場所。**

仕様（`docs/spec/`）は「今どうなっているか」を書く。
ここは**「なぜその形に決めたか」「何を捨てたか」**を書く。

同じ議論を二度しないため、そして後から方針を変えるとき、
**元の判断の前提が今も成り立つかを確かめられるようにするため。**

## 書き方

1ファイル1決定。`NN-短い題名.md`。

```markdown
# 決定: <何を決めたか>

日付 / 状態（採用 | 保留 | 撤回）

## 決めたこと
## なぜ
## 捨てた案とその理由
## この判断が崩れる条件
```

最後の項目が重要。**前提が変わったら見直す**ための引き金になる。
