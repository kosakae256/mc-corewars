# 中身: アイテム・敵・報酬

> ルール（[01-rules.md](01-rules.md)）が決まってから書く。

## 1. アイテム

### 1-1. 剣

**火力を 4〜8 の等差にする。**

| 剣 | 火力 | 通貨 |
| --- | --- | --- |
| 石の剣 | **4** | 鉄 |
| 銅の剣 | **5** | 鉄 |
| 鉄の剣 | **6** | 金 |
| ダイヤの剣 | **7** | ダイヤ |
| ネザライトの剣 | **8** | エメラルド |

**1 段上げるごとに必ず 1 上がる。** どれを買うか迷ったときに、
値段と火力を素直に比べられる。

#### バニラの剣は使わない

**バニラのアイテムの火力は書き換えられない。**
ブロックのテクスチャのように、既存のものを上書きする手段が無い
（[10-custom-block-replacement.md](../../../docs/research/10-custom-block-replacement.md) と違う）。

**専用の剣を作る**（`game:sword_*`）。見た目はバニラのテクスチャを借りる。

> **バニラの剣は売らない。** 並べると火力が違う同名の剣が 2 種類でき、
> どちらを持っているか分からなくなる。

#### 失うもの

専用の剣は、バニラの剣が持っている挙動を**自動では引き継がない。**

| | どうするか |
| --- | --- |
| 耐久度 | **持たせる**（バニラと同じ値） |
| エンチャント | **持たせる** |
| 修繕（金床） | **持たせる** |
| クモの巣・竹を速く切る | **持たせない。** 試合に関係しない |
| 範囲攻撃（スイープ） | **未確認。** 効かないかもしれない |

> 火力の表は [gen-swords.mjs](../../../tools/gen-swords.mjs) にある。
> **そこを直して動かし直せば、定義ファイルが作り直される。**

### 1-2. 防具

**4 段階。それぞれ一式と部位ごとで買える。**

| 段階 | 通貨 |
| --- | --- |
| 革 | 鉄 |
| チェーン | 金 |
| 鉄 | ダイヤ |
| ダイヤ | エメラルド |

**一式のほうが安い。** まとめて買えば得、
必要な所だけ強化したいなら部位で買う、という選択にする。

### 1-3. ポーション

| 効果 | 通貨 |
| --- | --- |
| 再生力 | 金 |
| 即時回復 / 即時回復（投げる） | 金 |
| 再生力 II / 即時回復 II / 即時回復 II（投げる） | ダイヤ |
| 移動速度上昇 II / 攻撃力上昇 | ダイヤ |
| 透明化 | エメラルド |

#### ポーションは ID が 1 つしかない

**全部 `minecraft:potion`** で、効果は**データ値**で分かれる。

いまの Script API に**ポーションを作る手段が無い**ので、
`give` コマンドで渡す。品揃えの `give` に `data` を書く。

**絵も名前では出ない**（全部ただの水に見える）。
種類ごとにテクスチャの道を指定する。

#### 透明は 3 分

**1 分の透明ポーションは作れない。** バニラに無い。
効果時間を変えるには、飲んだのを見て効果を付け直すことになり、
**「ポーションを渡す」という単純さが崩れる。**

**3 分のまま行く**（2026-08-24 決定）。
効果時間のために仕組みを増やすほどの差ではない。

### 1-4. 特殊アイテム

| 品物 | 単位 | 通貨 |
| --- | --- | --- |
| 雪玉 | 8 / 32 | 鉄 |
| ファイヤーチャージ | 1 / 4 | 金 |
| TNT | 1 | 金 |
| 金のリンゴ | 1 | ダイヤ |
| エンダーパール | 1 | エメラルド |

#### TNT は置いた瞬間に着火する

**置いてから火を点ける手順を挟むと、戦闘中に使えない。**
火打石を別に買わせるのも、持ち物の枠を 1 つ潰すだけで面白くならない。

**置いた = 投げた**にすれば、
TNT は「時間差の攻撃」という分かりやすい 1 つの道具になる。

> 一瞬でブロックでなくなるので、**後片付けの対象にならない。**

#### 拠点に入り込んだ TNT は消える

**置けなくても、投げ込める。**
拠点の外で着火して、爆風や坂で転がり込ませることができる。

拠点は**ブロックを置けない場所**として守っているのに、
爆破だけ通ってしまうと守っている意味が無くなる。

**消すのは実体だけ。** 拠点の外で爆発するぶんには何も起きない。
範囲は[置けない範囲](spec/11-match.md)をそのまま使う。別に持つと必ずずれる。

### 1-5. 建材

| 品物 | 単位 | 通貨 |
| --- | --- | --- |
| 羊毛ブロック | 16 / 64 | 鉄 |
| 天然石 | 16 / 64 | 鉄 |
| 合成鋼 | 1 / 4 / 16 | 金 |
| 黒曜石 | 1 / 4 | ダイヤ |

**同じものを違う単位で並べる。**
少しだけ欲しいときと、まとめて欲しいときで要る量が全く違う。
単位を 1 つに絞ると、**どちらかが必ず不便になる。**
