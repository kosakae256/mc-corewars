## 1. アイテム

### 1-1. 剣

> ### 剣は全部ワイヤー射出装置（2026-08-26 変更）。

| 剣 | 攻撃力 | 通貨 | ワイヤー |
| --- | --- | --- | --- |
| 木の剣 | +4 | 鉄 | **撃てる** |
| 石の剣 | +5 | 鉄 | **撃てる** |
| 鉄の剣 | +6 | 金 | **撃てる** |
| ダイヤの剣 | +7 | ダイヤ | **撃てる** |

**ネザライトは廃止した。**

#### なぜ全部ワイヤーなのか

**武器を持ったままでも飛びたい。**

剣を買うとワイヤーが撃てないなら、
「武器を持つ」ことが**「移動を捨てる」という意味**になる。
**立体機動のゲームなのに、戦うほど動けなくなる。**

段階で変わるのは**火力だけ**（[13-grapple.md](spec/13-grapple.md) 9 章）。
**ガスは人に紐づくので、何本持っても増えない。**

#### バニラの剣に戻した経緯と、今回

一度は**専用の剣をやめてバニラを売っていた**（2026-08-24）。
`minecraft:damage` がバニラの計算と別に足し込まれ、
**ネザライトの剣で一撃で倒せた**ため。

今回は**火力を engine に合わせた値**（バニラの剣と同じ 4〜7）にし、
**上の段階（ネザライト）を作らない**ことで同じ穴を避ける。

#### 支給の剣は無い

**[3D Maneuver Gear](spec/13-grapple.md) が武器も兼ねる**（攻撃力 +4）。
移動と攻撃を 1 本に持たせることで、**持ち物の枠が 1 つ空く。**

買った剣は**その上位互換**（火力が上がるだけ）。

**4 段階。それぞれ一式と部位ごとで買える。**

**部位は胴・脚・足の 3 点。**
頭はチームの帽子で固定されている（[15-presentation.md](spec/15-presentation.md) 7-2）。

| 段階 | 通貨 |
| --- | --- |
| 革 | 鉄 |
| チェーン | 金 |
| 鉄 | ダイヤ |
| ダイヤ | エメラルド |

**一式のほうが安い。** まとめて買えば得、
必要な所だけ強化したいなら部位で買う、という選択にする。

### 1-3. ポーション

| 効果 | 通貨 |
| --- | --- |
| 再生力 | 金 |
| 即時回復 / 即時回復（投げる） | 金 |
| 再生力 II / 即時回復 II / 即時回復 II（投げる） | ダイヤ |
| 移動速度上昇 II / 攻撃力上昇 | ダイヤ |
| 透明化 | エメラルド |

#### ポーションは ID が 1 つしかない

**全部 `minecraft:potion`** で、効果は**データ値**で分かれる。

いまの Script API に**ポーションを作る手段が無い**ので、
`give` コマンドで渡す。品揃えの `give` に `data` を書く。

**絵も名前では出ない**（全部ただの水に見える）。
種類ごとにテクスチャの道を指定する。

#### 空き瓶は残さない（2026-08-26 追加）

**飲んだ直後に消す。**

飲むたびに持ち物が 1 枠埋まる。
ポーションは**戦っている最中に飲むもの**なのに、
飲んだ結果として**要らない物が手元に増える。**

空き瓶は**このゲームでは使い道が無い**（水汲みも醸造も無い）。

##### 出さない、はできない

バニラのポーションは**アイテム定義が手元に無い**（上記のとおり ID は 1 つ）。
**「返ってくる物」を定義から消せない。**

だから**返ってきた直後に消す。**

**持ち物が一杯なら足元に落ちる**ので、そこも見る。
落ちた分を見ないと「拾えば残る」ことになる。

#### 透明は 3 分

**1 分の透明ポーションは作れない。** バニラに無い。
効果時間を変えるには、飲んだのを見て効果を付け直すことになり、
**「ポーションを渡す」という単純さが崩れる。**

**3 分のまま行く**（2026-08-24 決定）。
効果時間のために仕組みを増やすほどの差ではない。

### 1-4. 特殊アイテム

| 品物 | 単位 | 通貨 |
| --- | --- | --- |
| 雪玉 | 8 / 32 | 鉄 |
| ファイヤーチャージ | 1 / 4 | 金 |
| TNT | 1 | 金 |
| 金のリンゴ | 1 | ダイヤ |
| エンダーパール | 1 | エメラルド |
| **ドローン** | 1 | **ダイヤ 5**（[23-drone.md](spec/23-drone.md)） |

#### ファイヤーチャージは投げ物にする（2026-08-25 変更）

**バニラでは投げられない。**
手で使うと**目の前のブロックに火を点けるだけ**で、
飛ばせるのはディスペンサーからだけ。

**それでは「投げる特殊アイテム」にならない。**

##### 独自アイテムにする（2026-08-25 修正）

**バニラの動きを打ち消して差し替える手は効かなかった。**

`minecraft:fire_charge` は**空に向けて右クリックしても何も起きない。**
イベントそのものが飛ばないので、**拾える瞬間が無い。**

**`game:fire_charge` を作る。** 見た目はバニラの火の玉のまま
（テクスチャを借りる）。中身の無い独自アイテムなので、
支柱弾（[18-pillar.md](spec/18-pillar.md)）と同じように素直に反応する。

> **ショップで配るのはこちら。** バニラのほうは品揃えから外す。

| | |
| --- | --- |
| 使うと | **視線の方向へ飛んでいく** |
| 当たると | **爆発する。** 爆発力は**ガストと同じ**（2026-08-26 に 4 倍から戻した） |
| 爆発は | **ブロックだけ壊す。人にも生き物にも当たらない** |
| 火は | **残さない**（2026-08-25 変更） |
| 壊せないもの | **合成鋼と黒曜石**（下の 1-5） |

##### なぜ人に当たらないのか

**これは陣地を焼く道具で、人を倒す道具ではない。**

倒す手段は既にある（[13-grapple.md](spec/13-grapple.md)・剣・TNT）。
そこに**もう 1 つの当たれば強い遠距離攻撃**を足すと、
**近づく理由が減る。**

**足場を落とす道具**として効く。
相手の登り道や陣取った場所を、遠くから崩せる。

> **TNT とは役割を分ける。**
> TNT は**人も巻き込む時間差の攻撃**、
> ファイヤーチャージは**当てた所を即座に崩すもの。**

##### 火は残さない（2026-08-25 変更）

当初はガストと同じく火を残していたが、やめた。

**火では誰も何も損なわない**と決めた（[14-death.md](spec/14-death.md) 6-B）ので、
**残っても画面がうるさいだけ**になった。

> 減らない火は**通せんぼにならない。**
> 見た目だけ危なそうで、通っても何も起きない——
> **嘘をついているのと同じ。**

##### 壊せるのは壊せるブロックだけ

爆発は**守るブロックの判定をそのまま通る**
（[10-block-protection.md](spec/10-block-protection.md)）。
マップは削れず、**置かれたものだけが飛ぶ。**

#### TNT は置いた瞬間に着火する

**置いてから火を点ける手順を挟むと、戦闘中に使えない。**
火打石を別に買わせるのも、持ち物の枠を 1 つ潰すだけで面白くならない。

**置いた = 投げた**にすれば、
TNT は「時間差の攻撃」という分かりやすい 1 つの道具になる。

> 一瞬でブロックでなくなるので、**後片付けの対象にならない。**

##### 爆ぜるのは「地面に着いてから 6 秒」（2026-08-26 変更）

**置いてからではなく、着いてから数える。**

| | |
| --- | --- |
| 置いた／落とした | **まだ数えない**（落ちている間は数えない） |
| **地面に着いた** | **ここから 6 秒** |

**落ちている間に燃え尽きるのを避ける。**
ドローンから落とすと（[23-drone.md](spec/23-drone.md) 5-D）、
高さによって**着く前に爆ぜたり、着いた瞬間に爆ぜたり**する。

着いてから数えれば、**どこから落としても同じ 6 秒。**
落とされた側にも、逃げるか押し返すかを決める時間が同じだけある。

###### 導火線はこちらで握る

バニラの導火線は 4 秒で、**後から変えられない。**

`behavior_packs/game/entities/tnt.json` に
**導火線を 60 秒まで延ばす component group** を足し、
**実際の起爆は script が行う**（`features/special/tnt.ts`）。

60 秒で切ってあるのは保険。**script が止まっても、いつかは消える。**

> `/reload` をまたいだ TNT は**控えが消えている。**
> 見つけ次第こちらの管理下に入れ直すが、
> **誰が点けたかは分からなくなる**（全員に当たる扱いになる）。

#### 拠点の中でも使える（2026-08-25 変更）

以前は**拠点に入り込んだ TNT を消していた**が、やめた。

拠点で禁じたいのは**「埋めて塞ぐ」こと**（[11-match.md](spec/11-match.md) 6-G）。
TNT は置いた瞬間に実体になるので、**ブロックとして残らない。**

**攻める側に、拠点を崩す手段を 1 つ渡す。**

#### コアの真上では爆ぜない（2026-08-26 追加）

**コアの上に張った箱の中では、爆発そのものが起きない。**

| | |
| --- | --- |
| 横 | コアから **10 マス** |
| 下端 | コアの **5 マス上** |
| 上端 | 青天井 |

**屋根の上から掘り抜いて、コアを直接殴れてしまう。**
拠点を崩す道は残したいが、**上から一直線に開けるのは別の話。**

> **屋内はそのまま。** 中で使うぶんには普通に爆ぜる。
> 止めたいのは屋根越しの一手だけなので、**範囲で切る。**

### 1-5. 建材

| 品物 | 単位 | 通貨 |
| --- | --- | --- |
| 羊毛ブロック | 16 / 64 | 鉄 |
| 天然石 | 16 / 64 | 鉄 |
| 合成鋼 | 1 / 4 / 16 | 金 |
| 黒曜石 | 1 / 4 | ダイヤ |

**同じものを違う単位で並べる。**
少しだけ欲しいときと、まとめて欲しいときで要る量が全く違う。
単位を 1 つに絞ると、**どちらかが必ず不便になる。**

#### 何が何を壊せるか（2026-08-25 追加）

| 建材 | ファイヤーチャージ | TNT |
| --- | --- | --- |
| 羊毛・天然石 | **壊れる** | 壊れる |
| **合成鋼** | **壊れない** | **壊れない**（2026-08-26 変更） |
| 黒曜石 | 壊れない | 壊れない |

> **合成鋼は爆発では壊れなくなった。**
> **一番硬い建材**として売っているのに、TNT 1 つで穴が開いていた。
> **掘る速さは変えていない。** ツルハシで削るぶんには今までどおり。
>
> 合成鋼はバニラのブロックの差し替えなので、**定義に爆発耐性を書けない。**
> script で爆発の対象から抜いている（`features/protection`）。

**建材を買う意味を、値段以外にも持たせる。**

合成鋼がファイヤーチャージで飛ぶなら、
**金 2 個の弾で金 2 個の壁が消える**ことになり、置く意味が無い。

| 攻める側 | 何を持ち出すか |
| --- | --- |
| 羊毛の壁 | **ファイヤーチャージで十分** |
| 合成鋼の壁 | **TNT が要る**（置きに行く手間と時間差） |
| 黒曜石 | **壊せない。** 回り込むか、上から入る |

> **遠くから安く崩せる範囲**に上限を作る。
> それが無いと、**壁を建てる遊びが成立しない。**

##### 壊すものは自分で選ぶ（2026-08-25 変更）

**バニラの爆発は使っていない。**

バニラの爆発は**人も物も巻き込む前提の仕組み**で、
「人に当てない」設定が無い。ダメージを後から打ち消していたが、**取りこぼした。**

| 起きていたこと | なぜ |
| --- | --- |
| **たまにプレイヤーが死ぬ** | ダメージが次の tick に回ると、打ち消す窓から外れる |
| **落ちている物が消える** | 傷つける経路を通らずに消えるものがある |
| **コアが壊れる** | 守るブロックではないので、爆発の対象に入っていた |

**壊すブロックを自分で選んで消す。**
実体には**一切触らない**ので、取りこぼしようが無い。

| 触らないもの | |
| --- | --- |
| マップ | 掘るときと同じ判定を通す |
| **合成鋼** | 上の表の通り |
| **コア** | **削るのは殴ったときだけ** |
| 人・落ちている物・その他の実体 | **一切触らない** |

TNT はバニラの爆発のままなので、**今まで通り人も巻き込む。**
