# 企画: Core Wars

## 1. 一言でいうと

**2チームに分かれ、相手のコアを先に 100 回壊した方が勝ちのチーム PvP。**

コアはブロック（コンクリート）で、ツルハシ等で殴って壊す。
壊すたびに相手の残数が減り、先に 0 にした方が勝つ。

## 2. 誰が、何人で、どれくらい遊ぶか

| 項目 | 決め |
| --- | --- |
| チーム数 | **2** |
| 1チームの人数 | **不定。1〜15人**（上限15） |
| 人数の決まり方 | **ランダム。** 1v1 のこともあれば 15v15 のこともある |
| 途中参加 | **あり** |
| 1回の長さ | 時間制限なし（実質 **999 分**） |

### 人数が不定であることの意味

**これはこのゲームの前提であり、あらゆる設計がここに縛られる。**

- **人数で釣り合いを取れない。** 1v1 と 15v15 が同じルールで成立する必要がある
- **途中参加者は、進行したゲームに放り込まれる。**
  相手が育ちきった状態から始まることがある
- 人数差が出ないよう、**参加時に少ない方のチームへ入れる**必要がある

> 「人数に依存しない設計」を通すこと。
> 人数比で強さが決まる要素は、この前提と噛み合わない。

## 3. 何が面白いのか

**「攻めに出るか、資源を伸ばすか」の判断が常に迫られること。**

- コアを殴りに行けば、その間チームの生産が止まる
- 資源を伸ばせば強くなるが、その間に削られる
- **コア 100 回という長い勝利条件**が、この綱引きを何度も往復させる

即死ではなく**削り合い**なので、一度の失敗で終わらない。
そこが「1回で決まらない緊張感」を生む。

## 4. 勝ち負け

| 項目 | 決め |
| --- | --- |
| 勝利条件 | 相手のコアを **100 回**破壊する |
| 敗北条件 | 自陣のコアを 100 回破壊される |
| 時間制限 | **設けない。** ただし内部的には **999 分**として持つ |
| 引き分け | 時間制限が無いので、今は起きない |

> **999 分は「制限なし」の代わりであって、無効化ではない。**
> 後から制限時間を付けられるよう、**最初から設定値として持っておく**。
> 時間切れの判定（残数で勝敗を決めるか等）は、付けると決めたときに考える。

## 5. 経済（通貨）

**4種の通貨が、ジェネレータと呼ばれる場所から湧く。**

| 通貨 | 位置づけ |
| --- | --- |
| 鉄 | 最も安く大量に出る。消耗品の土台 |
| 金 | 鉄の一段上 |
| ダイヤ | 貴重。強化に使う |
| エメラルド | 最も貴重 |

**ジェネレータの置き場所が、そのまま戦いの場所を決める。**
安全な自陣に置いたものは安定供給、中央に置いたものは奪い合いになる。

**稼いだものは持ち歩くか、預けるかを選べる。**
死ぬと持ち歩き分は地面に落ち、倒した相手に渡る。
預けた分（エンダーチェスト・チェスト）は残る。
**この選択が、中央から帰る道を危険地帯にする。**

詳細は [01-rules.md](01-rules.md)。
