# world — ワールドの資産

ゲームが動くワールドそのものに関わるもの。

| | 用途 |
| --- | --- |
| `structures/` | 建築の部品（`.mcstructure`）。手で建てたものをここに保存する |
| `backups/` | ワールド丸ごとのスナップショット |

## なぜ保存するのか

**手作業の建築は、消えたら戻らない。**
コードは書き直せるが、地形と建物は同じものを二度作れない。

- ワールド全体 → `node tools/mc.mjs backup dev --label 何をした時点か`
- 部品単位 → ゲーム内で構造物ブロックを使って `.mcstructure` に保存し、
  ここへ置く

## 注意

- **バックアップはサーバー停止中にしか取れない。**
  稼働中はファイルの書き込み途中を掴んで壊れたコピーになる
- `backups/` は容量を食う。要らない世代は消してよい
- ワールドの中身は Git に入れない想定
  （バイナリで差分が効かず、リポジトリが肥大化するため）
