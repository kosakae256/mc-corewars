# 調査: アイテムの「長押し」を取る

**2026-08-25 に調べた。** Minecraft 1.26.44、`@minecraft/server` 2.9.0。

## 何が知りたかったか

**押している間だけ効く操作**を作りたい。

`itemUse` は**押した瞬間に 1 回**しか飛ばない。
「押し続けている間」も「離した瞬間」も分からない。

---

## 1. 答え: `use_modifiers` を付けると長押しになる

**アイテムに `minecraft:use_modifiers` を付けると、
そのアイテムは「チャージするもの」になる**（弓や食べ物と同じ扱い）。

```jsonc
"minecraft:use_modifiers": {
  "use_duration": 72000,      // チャージが終わるまでの tick。**実質無限**
  "movement_modifier": 1.0,   // 使用中の移動速度。1.0 で**遅くならない**
  "emit_vibrations": false
}
```

すると Script API 側に飛んでくる。

| イベント | いつ |
| --- | --- |
| `world.afterEvents.itemStartUse` | **押した瞬間** |
| `world.afterEvents.itemStopUse` | **離した瞬間**（チャージ完了前） |
| `world.afterEvents.itemCompleteUse` | **チャージが終わったとき** |

**`use_duration` を大きくして、完了させない。**
バニラの `copper_spear` が **72000**（＝1 時間）を使っている。
弓と同じ「引き絞り続けられる」状態にするための値。

### `movement_modifier` を 1.0 にする

**既定では遅くなる。** 弓を引くと歩けなくなるのと同じ。
移動しながら使う道具では **1.0**（減速なし）にする。

これもバニラの `copper_spear` が 1.0 を使っている。

---

## 2. 単押しは「開始 → すぐ停止」になる

**タップしても `itemStartUse` は飛ぶ。** そのあとすぐ `itemStopUse` が来る。

だから**「1 回目は刺す、2 回目は長押しで動く」**のような
段を作りたいなら、**こちら側で段を持つ。**
イベントの種類では区別できない。

---

## 3. 注意

- **`itemStopUse` の `itemStack` は `undefined` になりうる。**
  型定義に「別のディメンションへテレポートしたときに起こりうる」と書いてある。
  **アイテムを見て判定するなら、必ず存在を確かめる。**
- `use_duration` が完了すると `itemCompleteUse` が飛び、**そこで使用が終わる。**
  終わらせたくないなら大きい値にする。
- これらは **`beforeEvents` ではない。** 打ち消せない。

---

## 4. 使っているところ

- [`worlds/core-wars/docs/spec/21-grapple-v2.md`](../../worlds/core-wars/docs/spec/21-grapple-v2.md)
  — 押している間だけ加速し、**離した瞬間に外れる**

## 5. おまけ: バニラのアイテムは「使った」が飛ばないことがある（2026-08-25）

**`minecraft:fire_charge` は、空に向けて右クリックしても `itemUse` が飛ばない。**

そのアイテムに**空中での使用動作が無い**ため。
ブロックに向けたときだけ `playerInteractWithBlock` が飛ぶ。

**打ち消して差し替える手が使えない。**
拾える瞬間そのものが無いので、`cancel` する対象が存在しない。

### どうするか

**中身の無い独自アイテムを作る。**

```jsonc
// テクスチャはバニラのものを借りられる
"game_fire_charge": { "textures": "textures/items/fireball" }
```

独自アイテムなら**空中でも `itemUse` が飛ぶ**（`game:pillar_shot` で確認済み）。
打ち消す必要も無い——**元の動きが無いのだから。**

> **バニラのアイテムに新しい動きを足したくなったら、まずこれを疑う。**
> 「イベントが来ない」のであって、「打ち消せない」のではない。

### ついでに: チェストの画面には独自アイテムの絵が出ない

チェスト風の画面（`vendor/chest-ui`）は、
**アイテム名を番号に直して**絵を出している（`typeIds.js`）。

**独自アイテムはその表に載っていない。**
名前をそのまま渡すと**何も出ない**（2026-08-25）。

| 手 | どうなるか |
| --- | --- |
| **バニラの名前を指す** | そのバニラの絵が出る。**見た目が同じなら一番楽** |
| **テクスチャの道を指す**（`textures/...`） | その絵が出る。ただし平面（光沢や立体表示は付かない） |
| `constants.js` に登録する | 出るが、**custom_content の数がバニラの番号をずらす。** 触らないほうがよい |
