# 調査: スクリプトからカメラを動かせるか

**2026-08-25 に、実際に飛ばして確かめた。** Minecraft 1.26.44、`@minecraft/server` 2.9.0。

## 知りたかったこと

**プレイヤーの体を置いたまま、視点だけ別の場所へ飛ばしたい。**

ドローン（`worlds/core-wars/docs/spec/23-drone.md`）のために調べた。

---

## 1. 結論

> ### スクリプトから動かすカメラは、滑らかにならない。

**位置を渡す形しか動かない。** そしてその形は、
**1 秒に 20 回しか位置を変えられない。**

| 試したこと | 結果 |
| --- | --- |
| `setCamera("minecraft:free", { location, facingLocation })` | **動く。** ただし移動がガタつく |
| `setCamera(..., { easeOptions })` で間を埋める | **入力が効かなくなる** |
| `setCamera("minecraft:free", { targetEntity })` | **動かない** |
| `setCamera("minecraft:follow_orbit", { targetEntity })` | **プレイヤーの位置に付く。** 対象の実体を見ない |

**向きは滑らか。** ガタつくのは**位置だけ。**

---

## 2. なぜガタつくのか

**スクリプトは 1 tick（1/20 秒）に 1 回しか動けない。**
描画はそれよりずっと細かい（60〜120 回/秒）。

位置を渡す形だと、**カメラは 20 回/秒で飛ぶ。**
間は誰も埋めない。

### 機体を滑らかに動かしても直らない

**実体の動かし方をテレポートから速度に変えても、変わらなかった。**

実体の位置はクライアントが補間するが、
**カメラはこちらが渡した座標にしか行かない。**
補間された機体の位置ではなく、**こちらが読んだ 20 回/秒の座標**を使うため。

---

## 3. `easeOptions` は使えない

**間を埋めるための仕組みだが、埋めている間プレイヤーの入力が効かない。**

毎 tick 出し直すと**補間が終わらず、入力が戻ってこない。**
滑らかさと引き換えに**操作を失う。**

---

## 4. 実体に貼り付けることはできない

`CameraTargetOptions`（`targetEntity`）は型としては存在するが、

| プリセット | どうなったか |
| --- | --- |
| `minecraft:free` | **何も起きない** |
| `minecraft:follow_orbit` | **プレイヤーの位置**にカメラが付く。渡した実体を見ていない |

**周回カメラ向けの仕組み**で、任意の実体に一人称で貼り付けるためのものではない。

---

## 5. 滑らかなカメラは 1 つだけ

> ### プレイヤー自身のカメラ。

**プレイヤーを速度で動かすと、視点は滑らかに付いてくる。**
クライアントが自分の位置を予測・補間しているため。

同じワールドのワイヤー射出装置（`docs/spec/13-grapple.md`）が
毎 tick 速度を与えてプレイヤーを飛ばしているが、**あれはガタつかない。**

### つまり

**「視点だけ飛ばす」は、滑らかにはできない。**

滑らかにしたいなら、**プレイヤー本人を飛ばす**しかない。
体を残したいなら、**残すのは本人ではなく身代わり**になる。

---

## 6. 妥協するなら

**ガタつきの大きさ＝1 tick の移動距離。**

速く動かすほど飛ぶ幅が広がる。
**ゆっくり動かすぶんには気にならない**ので、
「そういう見え方の道具」として速度を落とす手はある。
